# Run1 生产预测 — CSV 字段说明（供回测）

**文件:** `run1_production_preds_from_2025_08.csv`（130,698 行）
**内容:** BTCUSDT **永续**最佳单模型 Run1 的**真实生产模拟预测** —— 预测未来 **600 秒（10 分钟）**前向对数收益 `y_600`。每月由前 450 天数据训练的模型对该月做样本外（OOS）预测，逐月按时间拼接。**严格 walk-forward、无泄漏、单 seed。**
**时间跨度:** 2025-08-10 → 2026-05（每月测试窗从 10 号起）。**步长 180 秒（每 3 分钟一行）。**

## 字段

| 列 | 类型 | 单位/含义 |
|---|---|---|
| `timestamp_ms` | int64 | 决策时刻 t 的 Unix 毫秒时间戳（UTC）。预测在此刻用 ≤t 的数据生成 |
| `datetime_utc` | str | 同上，人读 `YYYY-MM-DD HH:MM:SS`（UTC） |
| `month` | str | 所属月份 `YYYY_MM`（用于分月评估） |
| `y_pred_bps` | float | **模型预测**：t → t+600s 前向对数收益，单位 **bps**（1bps=0.01%） |
| `y_true_bps` | float | **真实实现**：t → t+600s 实际前向对数收益，单位 **bps**（回测标的） |
| `mask` | bool | `True`=有效行；`False`=padding/无效（**回测请丢弃 `False`**，822 行） |
| `has_ytrue` | bool | `True`=该行有真实 y（可用于评估/回测）；`False`=无真实 y（19,800 行，见覆盖说明） |

## 回测使用须知（重要）

1. **过滤:** 只用 `mask==True AND has_ytrue==True` 的行（= 110,898 行有效可回测）。
2. **预测尺度:** 预测是**弱信号的方向/排序信号** —— `y_pred_bps` 的 σ≈0.87bps，而 `y_true_bps` 的 σ≈20.6bps（σŷ/σy≈0.04）。**预测幅度是压缩的、未按实现幅度校准**。请当作**方向 + 排序**用；若策略需要真实 bps 幅度，请自行做一次校准/缩放（不改变排序/IC）。
3. **horizon 重叠:** 步长 180s < horizon 600s，相邻行的 [t, t+600] **重叠**。做**非重叠（clean）评估**时，请每 ≥600s 取一行（推荐按 UTC 日内贪心选 ≥600s 间隔）。
4. **口径:** `y_pred_bps` = 模型 q50 反归一到 bps；`y_true_bps` = **raw** 600s 前向对数收益（bps，**未截断**）。真实 y 有重尾（min −960 / max +382 bps）。
5. **成本（我们的净成本回测结论）:** 单资产 y_600 是 **maker-only 信号,且仅好费率档（盈亏平衡单边成本 ≈0.76 bps/side）** —— **非 taker-可交易**（连尾部选择也不 robustly 过 taker 1.7bps/side），**非零售 maker（2bps）**。请用真实 maker/taker 成本回测，别用零成本数。
