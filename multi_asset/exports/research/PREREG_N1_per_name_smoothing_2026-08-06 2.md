# PREREG N1 — 逐名自适应平滑: 均匀 EMA 之上还有没有东西

## 1. 机制(为什么应该有信号, 不是"试试看")

均匀 EMA 对 110 个名字用**同一个** a。但"该不该为这个名字付换手"逐名不同:

```
交易名字 i 的边际价值 = (i 的快 alpha)  −  (i 的换手 × i 的成本)
```
⇒ **a_i 应当随 1/成本_i 上升**: 便宜的名字交易得快, 贵的名字持有得久。
这正是**带逐名成本的优化器**会做的事(该文 §11), 只是用一个单参数族近似它。

**★ 本文【不】估计逐名快 alpha**(逐名估计在 110 名上噪声极大, 且用前视收益估计即泄漏)。
**假设快 alpha 在名字间同比例** ⇒ 只剩 `a_i ∝ 1/成本_i` 这一条, 这是最小、机制最干净的形式。

**成本代理**: 面板通道 `dvol_24h`(24h 美元成交额)。成本 ≈ f(1/流动性) 是微结构常识, 且我在 #48
实测 `spread_bps` 的横截面 rank-IC −0.026(|t|=4.49, 五年符号一致) —— 点差在横截面上真实可分。

```
a_i = clip( a_base × (dvol_i / median dvol)^γ , 0.001, 1.0 )
w_i = (1−a_i)·w_i^prev + a_i·w_i^raw  → 二次 demean → 归一到同毛敞口
```

## 2. ★ 判据(封于结果之前)

**★★ 比较必须在【同换手】下做, 不是同 a_base。** 自适应会改变总换手 ⇒ 比两个点没有意义。
**判的是两条前沿**: 对每个族扫 a_base, 得到 (换手, 净夏普) 曲线; **自适应族必须在同换手处
给出更高的净夏普**。

| 结果 | 裁定 |
|---|---|
| 自适应前沿在**同换手**处 ≥ 均匀 + **0.10 夏普**, 且 γ=0.5 与 γ=1.0 同向 | **有效**, 出提案 |
| 差距 < 0.10 或两个 γ 反向 | **杀** —— 均匀 EMA 已够, 逐名不加分 |
| **随机代理对照臂**给出同等增益 | **全表作废** —— 增益来自"任何逐名扰动"而非成本感知 |

## 3. 对照臂(缺一不可)

- **有效性**: `a_base=1.0` 必须逐位复现未打补丁 replay。
- **伙伴检查(随机代理)**: 把 `dvol` 向量在名字间**打乱**后同法构造 a_i。**它是本轨最重要的对照** ——
  若打乱后一样好, 说明起作用的是"逐名速度有差异"这个事实本身, 与成本无关。
- 均匀族(γ=0)即 E1 的曲线, 作为被超越的对象。

## 4. 已登记的设计风险(必须随结果同行)

**前沿轴 c 的永久随行条款**: "执行过滤器与 size 腿信号耦合, 本轴只答受限问题。"
`dvol_24h` 与 `size_dvol`(size 腿信号)高度相关(记录: `lturnover~size_dvol` ρ=−0.870)。
**⇒ 本轨继承同一限定。** 缓解: 线上 size 腿权重**已为 0**(已摘除), 耦合的实害小于当初;
但**该限定必须与任何引用同行**, 不得单独引用增益数。

## 4-bis. 判决(2026-08-06 10:5x, §2 判据逐字执行) —— **杀**

**有效性**: `a_base=1` 逐位复现未打补丁 replay ✓; 均匀族(γ=0)逐位复现 E1 的曲线 ✓(跨脚本可重复)。

**同换手比较**(对每个自适应点在均匀前沿上线性内插):

| 族 | turn≈180 | turn≈105 | turn≈73 | turn≈59 | 最大 |
|---|---|---|---|---|---|
| 成本感知 γ=0.5 | −0.009 | −0.010 | +0.006 | +0.053 | **+0.053** |
| 成本感知 γ=1.0 | +0.031 | +0.037 | +0.047 | +0.079 | **+0.079** |
| **★随机代理 γ=1.0** | −0.003 | +0.005 | +0.010 | +0.026 | **+0.026** |

**⇒ 判决: 杀。** 最大增益 **+0.079 < 判据线 +0.10**; 且 γ=0.5 与 γ=1.0 **不同向**(前者含负格),
两条判据条件各自独立地未过。**不放宽, 不外延网格找及格点。**

### ★ 但两件必须与"杀"同等力度记下

1. **机制是真的, 只是不值钱。** 随机代理对照臂最大只 **+0.026**, 而成本感知 γ=1.0 到 **+0.079** ——
   **差值 ≈+0.05 是【成本感知本身】的贡献, 不是"任何逐名扰动"。** ⇒ 本次是
   **"想法对但幅度不够"**, 不是"想法错"。这两者对后续纲领的含义完全不同, 不可混写。
2. **γ=1.0 的增益随换手下降【单调上升】**(+0.031→+0.037→+0.047→+0.079)。
   ⇒ 在更低换手处可能越过 +0.10。**但事后外延网格去找及格点就是 p-hacking, 本轨不做。**
   若将来有独立理由重开, 须**另出预注册**且判据由未看过本表的一方写。

### 对纲领的三条含义(负结果的价值)

- **部署被极大简化**: 价值在**速度**本身, 不在速度的逐名分配 ⇒ **一个标量参数, 不是一个逐名模型**。
  对刚从两次止损恢复的实盘系统, 这是好消息。
- **下调 §11 联合优化器的预期**: 若逐名成本分化在平滑轴上只值 0.03–0.05, 优化器的 `λ_turn` 项
  大概率也主要在调**总速度**而非**逐名分配** ⇒ 其增量应从"高"下调到"中"。
- **"下一个大数字"唯一化**: N1 杀之后, 仍被定价在 +1 夏普量级的**只剩 E4**(原生持续性), 需 GPU 交接。

## 5. 本文不建立什么

- 不建立部署; 不建立"成本代理 = 真实成本"(它只是代理, 真实逐名成本在 110 名上没有实测);
- 不建立逐名快 alpha 的任何结论(§1 明确假设它同比例, 该假设未被检验);
- 不建立均匀 EMA 的最优点(E1 的曲线**未拐头**, 那是另一件事)。
