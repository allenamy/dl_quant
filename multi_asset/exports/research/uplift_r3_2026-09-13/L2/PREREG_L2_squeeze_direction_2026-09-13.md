## §7 统计量(格 = 模型 × 目标 × 特征集 × 种子; 样本外分数合并四个测试年)

- **锚入选**: 锚 i 的人口目标有限行数 `n_i ≥ 10`。
- **顶 / 底十分位**: `m_i = ceil(0.1·n_i)`; Q_i = p 最大的 m_i 行, B_i = p 最小的 m_i 行(平手按列序号小者优先, lexsort 决定)。
- `D_i = mean_{Q_i} s − mean_{全部 n_i} s`; `H_i = mean_{B_i} s − mean_{全部} s`; `M_i = median_{Q_i} s − median_{全部} s`(稳健位置)。
- `G = mean_i D_i`(锚等权); `H = mean_i H_i`; `TB = G − H`; `G_med = mean_i M_i`; 逐年 `G_Y`、`H_Y`。
- `ΔG = G(FULL) − G(BASE)`(同锚, 锚入选只依赖目标, 两集合相同)。
- **CI**: 块自举; 块 = `floor((UTC 日 − 2023-01-01) / L_T)`, **L_A = 1 日, L_B = 3 日**(24h 目标跨日重叠; §13 合成校准), 块升序编号 nb, 抽样 `default_rng([20260905, b]).integers(0, nb, nb)`, b = 0..1999(T8 / r18 流约定), 以逐块 (Σ D_i, Σ H_i, 锚数) 重算; `CI95 = np.percentile(·, [2.5, 97.5])`; 同一目标内 G、H、TB、ΔG 共用同一组抽样。
- **描述量(不参与判决)**: |smr| 加权版; 合并(非锚内)十分位版; 锚内 Spearman(p, r) 均值; 样本外 R²; 顶十分位与人口的 s 标准差比(方差读数); P_neg 版; DESC 集的 G 与 `G(FULL) − G(DESC)`; 逐年表; 特征覆盖率逐年表。

## §9 读法(冻结)

### §9.1 过门格
格 c ∈ {R, L} × {A, B}(FULL, P_all)**在两个种子上都**满足:
- **C1 方向**: `G < 0` 且 CI95 上界 < 0。
- **C2 逐年**: 2023、2024、2025、2026 四年 `G_Y < 0`。
- **C3 超越费率**: `ΔG = G(FULL) − G(BASE) < 0` 且 CI95 上界 < 0。
- **C4 非方差**: (a) `TB` 的 CI95 上界 < 0; (b) H 的 CI95 上界 ≥ 0(底十分位不得同样显著亏; 两端都亏 = 挑出的是波动); (c) `G_med < 0`(点估计; 顶十分位的**典型**名也亏, 不是只靠少数尾部挤空拉低均值)。任一不成立 ⇒ VARIANCE。
- **C5 族零分布**: `z(c) ≤ q05`(该种子)。
- **C6 平移谱**: 前向峰在 h = 0。
