## 2. 三条硬约束(来自更早的服务侧实测)

1. **只用 ±0.2% 带**。REST `limit=1000` 对 BTC 只到 ±0.19%(127/128 币可复现);
   ±1%~±5% 对 BTC/ETH 实盘算不出 ⇒ 训了即 train/serve 断裂(ch31 教训)。
2. **绝对深度不进横截面**。F5 的 780× 差意味着直接排序=排流动性不排信号。
   ⇒ 自归一(除以该币自身滚动中位数), **不用 ±5% 做分母**(它不可服务)。
3. **mid 用 klines close(独立源)**, 不从 book 内部字段反推 —— 避免同源伪相关
   (与 metrics v2 的 F8 交互项同一纪律)。

## 3. 特征规格(13 列, 全部滞后 1h, 仅 ±0.2% 带)

每小时 120 帧上聚合; `bd/ad` = 买/卖侧 depth, `bn/an` = 买/卖侧 notional。

**核心不平衡 (3)** — 对抗结构的主轴
- `obi_mean` = mean_t[(bd−ad)/(bd+ad)]
- `obi_std` — 小时内不平衡的**波动**(metrics 的教训: std 是最强子集, 不可只取均值)
- `obi_slope` — 后 1/3 均值 − 前 1/3 均值(小时内漂移)

**价量背离 (1)** — 挂单"值"与"量"不在同一处
- `obi_nd_gap` = notional-OBI − depth-OBI。非零 ⇒ 两侧挂单在带内的价格分布不同。

**带内集中度, 逐侧 (2)** — 挂单离盘口多远(加权)
- `conc_bid` = (mid − bn/bd)/mid × 1e4 (bps); `conc_ask` = (an/ad − mid)/mid × 1e4
- 小=贴盘口(易被吃穿), 大=铺开(有纵深)

**集中度不对称 (1)**
- `conc_asym` = conc_ask − conc_bid ⇒ 哪一侧更"薄前置"

**逐侧波动 + 不对称 (3)** — ★ F4 的直接落地
- `cv_bid` = sd/mean(bd), `cv_ask` = sd/mean(ad)
- `cv_asym` = log(cv_ask / cv_bid) ⇒ 实测该量典型 +1.15(卖侧 3.2×)

**自归一水平 + 变化 (2)**
- `dep_lvl` = log(total_depth / rolling_30d_median(total_depth)) —— 流动性 regime, 尺度无关
- `dep_chg1h` = log(total_depth_t / total_depth_{t−1})

**韧性 (1)**
- `refill` = #(Δdepth>0) / #(Δdepth≠0) 小时内 —— 补单 vs 撤单的非对称

**弃选与理由**: 宽带(±1~5%)= 不可服务; 绝对深度进横截面 = 排流动性; 逐带曲线形状 = 需宽带;
末值快照 = metrics 已实测反号; 12 带全量描述子 = 稀释(E14 教训: 更多粗列 ≠ 更好)。

## 4. 预写判据(采纳门, 与 T0 对标)

- **G1** 全列 \|IC vs 未来24h\| < 0.15; **G1b** 时移不对称无一例(对过去相关 ≥ 对未来)
- **G2** Ridge 逐年走前(2024/2025/2026 三折, 2023 起族才有数): 均值 \|IC\| > 0.005 且无反号
- **G3** PR 上升; 与 32ch 最大 \|corr\| < 0.8
- **G4 DL 增量**: 以**族塔**(FusionTwoTowerEncoder, split=32)接入,
  Δresid ≥ +0.003 vs rb32 同装置, 双种子同向, σŷ/σy ≥ 0.02
- **不过 G4 但过 G1-G3** ⇒ 记为"独立但无 4h/24h 增量", 转入更短视界(y4/y8)复测,
  因为 F4 的 AR(1h)=0.102 提示书信息衰减快, 24h 可能已越过其半衰期。

## 5. 已知风险

- **纪元**: 2023-01 起 ⇒ 2021-22 全空。与 metrics 的填充断层同族问题;
  但族塔 + 零初始化门在缺失纪元可学会关闭(E14 已验证融合能挽回 68% 断层伤害)。
- **半衰期错配**: AR(1h) 仅 0.102 ⇒ 书状态在 24h 视界可能过快衰减。这是 §4 备选路径的由来。
- **成本相关**: 书深度与执行成本强相关 ⇒ 若入选, 必须查它是否只是把成本信息重新包装
  (与 R1 执行成本轨的边界)。

# 附2: DESIGN — book v2 空间结构塔 (用户方向 2026-08-08: 档位空间关系 + 1×1conv/TCN + SE 融合)

**约束重开**: ±1..±5% 五带全史 3.6 年, 实盘 121/128 币可服务(仅 BTC/ETH/BNB/ZEC/XMR 等够不到宽带
—— 而 BTC/ETH 本来连 ±1% 都够不到, v1 已经把它们置空)。多付 ~5 币覆盖, 换完整深度剖面。

**结构化预处理(不展平)**: 每币每小时保留张量 (level=5, side=2, quant=2):
- share[l,s] = 该带深度 / 币自身 30d 滚动中位总深(尺度无关, 自归一)
- 逐带小时内 {mean, std}(metrics 教训: std 是强子集) ⇒ (5,2,2) + 总量 2 标量 = 22 维/币时
- 因果滞后 1h 同前; BTC/ETH 等宽带缺失币 → 掩码置零(塔门可学会关闭, E14 已验证该机制)

**空间编码(1×1/小核 conv 沿档位轴)**: 档位是有序空间轴 —— 相邻带的深度差 = 剖面斜率,
二阶差 = 曲率(挂单在哪一层堆积)。Conv1d(in=4[side×quant], k=3, 沿 5 档) → GELU →
Conv1d(k=3) → 池化 → d_b。买卖两侧作为通道并入同一卷积 ⇒ 核直接学侧间不对称。

**时间编码**: 空间池化后接因果 depthwise conv(k=24, 沿 W=168) → last token(书状态 AR 高, 不需深时序)。
**融合**: 沿用零初始化门控加法(champion trunk + α·gate·h_book); SE 式通道重加权
(SharedTemporalEncoder 的 se_gate 机关已在, 零初始化)作为第二臂备选。

**判据(champion 配置, 对 0.0475 基线)**: Δresid ≥ +0.005 双种子同向; y24 与 y4 双视界各测;
σŷ/σy≥0.02; 塔方差(已知门控代价)若 >2× 基线散布, 加 gate 温度约束再判。
