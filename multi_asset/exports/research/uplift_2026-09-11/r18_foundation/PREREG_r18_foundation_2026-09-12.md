## §6 True rolling maxDD (the corrected N4 statistic, frozen)

Given UTC-day returns `rs` on unique days `ud` (seconds): for each start s, `e = searchsorted(ud, ud[s] + 365·86400, "right")`; keep the window iff `e − s ≥ 300` and `ud[e−1] − ud[s] ≥ 350·86400` (r12's window rule, kept so the two statistics differ **only** in the drawdown definition); `nav = [1, cumprod(1 + rs[s:e])]`; `true_maxDD = min(nav / cummax(nav) − 1)`; `start_loss = min(nav[1:]) − 1` (r12's quantity); rolling return = `nav[−1] − 1`. `p_true_maxDD25 = mean(true_maxDD ≤ −0.25)`; `p_start_loss25 = mean(start_loss ≤ −0.25)`. halts/yr = `count(rs ≤ −0.04) / ((ud[−1] − ud[0]) / (365.25·86400))`. Leverage grid and M as §5.5. The stored "median 1y CAGR" of r12 is the median rolling return (not annualised beyond the 1y window) — same here.
