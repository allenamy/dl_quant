#### definition
PRODUCER (seat history / book score): channel 0 of state/rolling.npz is the venue 5m kline close-to-close SIMPLE return, ret5 = c/prev_c − 1, clipped to [−0.3, 0.3], stored float16, row-stamped by bar CLOSE time (close_s = open_ms/1000 + 300). The per-anchor 4h return is y4v[name] = plain float32 SUM of the 48 channel-0 values whose close times lie in (E, E+4h] (rows pi+1..ai), NaN→0 inside the sum, set to NaN if fewer than 46 finite bars. Leg return appended to state/leg_returns_live.json at anchor E+4h = 1e4 × Σ_members (z̃/‖z̃‖₁) · y4v, where z̃ = stored legz (rank scores) masked to finite-y4 members and demeaned. Seats w3 = max(mean/(std+1e-9), 0) over the last 900 leg rows, normalised to sum 1 (equal thirds if <900 rows). Book score gross_bps = 1e4 × Σ sm·y4v; net = gross − carry − cost. No expm1/log1p/log is applied to any return quantity on this path (the only expm1 is on log-volume for qv4h; log1p/log only on quote volume / trade count). BUNDLE SEED (840 of the 950 rows in leg_returns_live.json, i.e. 790 of the 900 rows the seat formula uses today): same Σ-of-simple-5m caliber and same leg formula, but the pod's window is rows E..E+47 = closes in [E, E+4h−5m] (one bar EARLIER than live). EXECUTOR: NAV = totalWalletBalance + totalUnrealizedProfit from /fapi/v3/account; realised P&L = Σ income of REALIZED_PNL + COMMISSION + FUNDING_FEE from /fapi/v1/income since 00:00Z; per-name stop depth = unrealizedProfit/|notional| per position from the same account call (wide profile d30_n2_c42: ≤ −0.30 on 2 consecutive end-of-anchor readbacks, 7-day cooloff, min notional 5 USDT); day-loss = (nav − prev_day_nav)/prev_day_nav; cumulative drawdown = Π(1 + nav_d/nav_prev − 1) − 1 from starting equity; gross = NAV × gross_mult(2.0); target notional = w/gross_in × gross. All executor accounting is venue-side USDT simple arithmetic; no panel returns and no log/expm1 enter it.
