#### definition
Let r5[t,j] = channel 0 ('ret5') of dlnative_5m_wide829_f16_ext.npz = float16( clip( c_t / c_{t-1} − 1 , −0.3, 0.3 ) ) — a SIMPLE (pct_change) 5-minute close-to-close return, where row t carries ts = bar open_time + 5 min (i.e. the bar's close time), so the row whose ts equals anchor N (N % 14400 == 0) is the bar (N−5m, N]. For anchor N with 5-minute row E (ts[E] == N):

  Y4[N, j] = float32( CS_r[E+48, j] − CS_r[E, j] ),  CS_r = leading-zero float64 cumsum of (isfinite(r5) ? float64(float32(r5)) : 0)
           = float32( Σ_{k=E}^{E+47} r5[k, j] )  with NaN bars counted as 0,
  Y4[N, j] = NaN  if  #finite r5 in rows [E, E+47] < 46.

I.e. Y4 is the ARITHMETIC SUM of 48 simple 5-minute returns over the 'old' window rows [E, E+47] (price interval (N−5min, N+3h55min]). It is not a log return (no log1p anywhere in its construction) and not a compounded simple return (no product / expm1). y4 in wide_fea_v2ext_meta.npz is the identical quantity computed by the identical line in pod_fea_ext.py (same cache, rows [E,E+47], same <46 rule), restricted to anchors with E ≥ 576 and ≥ 50 eligible members. wide_panel_4h_v3splice.npz Y4 = v1 rows for ts ≤ 2026-08-15 00:00 (cut) concatenated with v2ext rows for ts > cut, bitwise. wide_panel_4h_v1.npz (2020-01-31 → 2026-08-15) carries the same formula computed from a 2020-start cache built with the same channel-0 code; on all 10,122 of its anchors from 2022-01-01 04:00 onward it is bitwise equal to the recomputation from the ext cache (the lone 2022-01-01 00:00 anchor differs in 136 cells only because the 2022-start ext cache has no returns in its rows 0–1).
