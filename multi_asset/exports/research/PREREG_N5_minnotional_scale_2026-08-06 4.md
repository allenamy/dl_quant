# PREREG N5 — minNotional × 账户规模 × 收割速度: replay 乐观了多少, 以及加金值多少

## 1. 问题(线索来自主线 R1: 实测掉名 60–86 单/锚)

`replay_fullhist` **完全不建模 minNotional** —— 它假设每个目标权重都能成交。
但实盘实测每锚有 **60–86 单 `skipped_min_notional`**(约占该锚订单的 28%)。

**⇒ 我此前报告的全部夏普都是【乐观】的, 而乐观的程度是账户规模的函数:**
```
NAV 2200 × 2× 杠杆 = 毛敞口 4400
110 名平均每名 |w| ≈ 1/110 = 0.91% 毛 ≈ 40 USDT
交易所下限 5–20 USDT ⇒ 只有 2–8 倍余量 ⇒ 大量名字贴着门槛
```

**两个此前没人问过的问题**:
1. **replay 乐观了多少?**(把 minNotional 加进去, 夏普掉多少)
2. **它与收割速度交互吗?** 先验: 慢书仓位更大更稳(EMA 平滑掉了小幅摆动) ⇒ **掉名应更少** ⇒
   若成立, **我的慢书发现比测到的更稳健**, 且"加金"与"降速"是**部分可替代**的两条路。

## 2. 干预(一行, 加在 shaping 之后)

```
w_i := 0   若 |w_i| × GROSS < MIN_NOTIONAL       # 交易所拒单 ⇒ 该腿不存在
然后 re-demean → 归一回原毛敞口                   # 剩下的名字承接被掉名字的敞口
```
**★ 归一回原毛敞口是关键**: 实盘不会因为掉名就降杠杆, 敞口会集中到能成交的名字上。
不归一 = 悄悄把"掉名"变成"降暴露", 那是另一个干预。

- `NAV` ∈ {2200(当前), 5000, 10000, 22000} × 2× 杠杆 ⇒ GROSS ∈ {4400, 10000, 20000, 44000}

### ★ 我的先验被证伪, 且方向相反 —— 机制值得记

预写"慢书仓位更大更稳 ⇒ 掉名更少"。**实测慢书掉 82–90 名, 快书只掉 9.9–38.2 名。**
**机制**: EMA 是过去多期书的加权平均, 平均会产生一条**"正在缓慢平掉的历史仓位"长尾** ——
82–90 个名字合计只占毛敞口 **2.1–2.6%**, 每个都极小, 全压在门槛下。
而快书的 rank 映射把权重集中, 没有这条尾巴。
**⇒ 这是慢书一个此前没人知道的结构性质**(不是缺陷 —— 影响只有 0.05–0.07 夏普),
但**部署时会看到每锚 80–90 个 sub-minNotional 目标**, 应事先知道而不是当异常。

### ★ 第二个意外: 在 mn=20 / GROSS 4400, 快书【因为掉名而变好】(+0.060)

它掉掉了 **11.57% 的毛敞口**、换手反而**升了** 10%(961→1058, 名字在门槛上下反复进出 = 阈值抖动),
**夏普却改善**。⇒ 被掉掉的那些小仓位, **其 alpha 覆盖不了自身成本** ——
这实际上是《时序世界模型》§10.4"最小期望边际"规则的一个**粗糙实现**, 由交易所免费提供。
**⇒ 一条便宜的候选(未测): 在书里显式置零小权重, 而不是让交易所去掉 —— 可消除阈值抖动。
但按本表增益 ≈0, 属卫生问题不是价值问题。**

### ★ 对用户 #13(加金 10k)的直接含义

本文原本是为给"加金"定价而设计的。**结论: minNotional 给不出任何加金的理由。**
当前规模影响 ±0.07, 44000 处归零。**⇒ 加金的理由必须来自别处**(容量 / 费率档位 / 风险分散),
**不能用"小账户被交易所门槛卡住"当依据** —— 这条依据实测不存在。
