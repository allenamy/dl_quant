## 1. 机制 — 为什么这是一个问题而不是一次算术游戏

Grinold 基本法则: `IR = TC × IC × √BR`。三个因子在本项目里的实测状态极不对称:

| 因子 | 状态 | 投入 |
|---|---|---|
| **IC** | 反复测量、四条证据线合围、已知 0.054–0.062 | 数月, 已近穷尽 |
| **BR**(独立赌注数) | **从未测量** | 0 |
| **TC**(转换系数) | **从未测量** | 0 |

**⇒ 我们把全部力气花在被测得最透的那个因子上, 而另外两个连数都没有。**

代入实测(见 §2 的输入清单): 若把零成本夏普 ~1.7–2.0 当作 `TC×IC×√BR` 的实现值, 并暂令 TC=1,
反解出的 **N_eff ≈ 2**。即: **这本书的行为等价于只持有约 2 个独立赌注, 尽管它有 110 个名字。**

这个数**同时解释三件此前互不相关的实测**, 这是本文认为它值得下注的唯一理由:
1. **#21 的 14 个价量因子零录取** —— 若残差截面只有约 2 个独立方向, 则新因子必然落在已有跨度内,
   **加 sleeve 不加 breadth**。零录取从"因子不好"变成"空间只有 2 维"的**必然后果**。
2. **funding_ema 是唯一过净成本门的新因子** —— 它是唯一不在价量空间里的量。
3. **模型侧四条线全部证伪** —— 若瓶颈在 BR 而非 IC, 那么提升 IC 的任何努力都只能按 √ 关系
   线性地小幅移动 IR, 而这正是实测形状(每次 ΔIC 都换不到 ΔSharpe)。

**一个结构解释三个独立事实** —— 但这仍只是一个**假说**, 因为 N_eff≈2 是**反解**出来的,
它把 BR 与 TC 混在一个观测量里。**必须直接测 BR, 才能把两者分开。**

## 3. 测量(两个口径, 缺一不可)

### (a) 宇宙提供多少 — `N_eff^universe`
逐时间戳把 Y4 做**横截面 demean**(市场中性书的真实暴露), 在 MEMBER & CL4 上按年/滚动窗构造
名字间相关阵 `C`, 特征分解, 取**参与率**:
```
N_eff = (Σλ_i)² / Σλ_i²        (1 = 全同向; N = 全独立)
```

### (b) 书实际收割多少 — `N_eff^book`
用同一相关阵与**书的实际权重** w(按线上配方 `rank→L1→cap99→demean→σ缩放` 从 king/s2/funding
预测重建, 与 replay 同装置), 计算书的风险沿主成分的分布:
```
风险贡献 r_i = (w'v_i)² λ_i  →  N_eff^book = (Σr_i)² / Σr_i²
```

**(a) 与 (b) 的比值就是【组合构造损失】** —— 宇宙给了多少、书拿走了多少, 差额是可回收的部分。

### 有效性检查(装置必须有分辨率)
- 对**已知答案的合成输入**跑同一程序: ① 110 个 i.i.d. 名字 ⇒ N_eff 必须 ≈110;
  ② 1 个共同因子 + 微噪声 ⇒ N_eff 必须 ≈1。**两条不过 ⇒ 全表作废。**

### 伙伴检查(读数不能是装置造的)
- 用**打乱名字顺序**的同一数据重跑 ⇒ N_eff 必须不变(它是谱性质, 与排序无关)。
- 用**时间打乱**的收益重跑 ⇒ 相关结构应被破坏, N_eff 应显著上升。

### 判决: 落在 §4 第二格 —— **(a) ≥ 10 且 (b) ≤ 4 ⇒ 构造受限**

**★ 最关键的对照不是 46 vs 2.8, 而是 20.8 vs 2.8。** 等额随机符号书是**同类可比对象**(同样是一个
权重向量、同样单次抽取), 它收割 **20.8** 个独立赌注; 现行书收割 **2.79**。⇒ **现行书的风险集中

alpha 信号本身压在少数几个主成分上, 书在不知情的情况下做了一个集中的因子押注。**

### 算术闭合(本文最强的一条自洽性证据)

把**实测**的 N_eff^book 代回基本法则:
```
BR = 514 × 2.79 = 1434  →  √BR = 37.9  →  IR = 0.055 × 37.9 = 2.08
实测零成本净夏普        = 1.7 – 2.0
```
**预测 2.08 vs 实测 1.7–2.0 —— 基本法则用实测 breadth 复现了观测到的毛夏普。** §1 里 N_eff≈2 的
反解值(当时是猜)与独立测得的 2.79 一致 ⇒ 框架自洽, **"5× 缺口在 BR 不在 IC"得到定量确认**。

反事实(**是上界, 不是预测**): 若同样的 IC 摊到随机书那样的 20.8 个方向:
```
BR = 514 × 20.8 = 10,691  →  √BR = 103  →  IR = 0.055 × 103 = 5.7
```
⇒ **目标夏普 5 在【当前 IC 水平】上可达, 前提是构造能把 alpha 摊开而不损失 IC。**

### ★ 本测量【不】建立什么(诚实边界, 与结果同等力度)

1. **不建立"去集中化会提高夏普"。** 本文证明书把风险压在 ~3 个主成分上, **没有**证明 alpha 在
   另外 43 个方向上有信息。**若 alpha 本来就只活在那几个因子方向, 集中就是 alpha 本身而不是缺陷。**
   ⇒ 这是唯一能推翻整条路线的假说, 必须由 §9 直接回答。
2. **funding 腿未计入 (b)**: 重建用 king .5952 + s2 .2024(占书 80%), funding 腿因符号约定未逐行

3. **基本法则前提(IC 平稳)已知不成立**(逐月 0.025–0.08 漂移)⇒ 5.7 是上界, IC 不平稳会吃掉一部分。
4. **相关阵用同期收益估计** —— 风险模型的合法用法; 但据此改造书时必须改用**滚动因果估计**(§6 已登记)。
