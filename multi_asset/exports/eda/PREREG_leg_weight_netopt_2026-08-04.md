# PREREG — 腿权重的【净额最优】重估(用户令: 因子组合要按协同与净效益优化, 不是拍权重)

## 0. 问题(不含答案)

现行权重 `king .5952 / s2 .2024 / funding .2024 / size 0` **是在【脏书】上定的**。此后发生了两件足以让它失效的事:
1. **两条 DL 腿干净化后 IC 大约腰斩**(S1 层面 0.0838→0.0449), 而 **funding 腿是 model-free 的, 它没变** ⇒ 按信息量, king 该降 funding 该升。
2. **各腿换手率差一个数量级**(king 4h / funding 8h / s2 24h; king 占 59.5% 权重却贡献 **91%** 毛换手)⇒ **按 IC 最优 ≠ 按净额最优。**

**⇒ 本实验只回答一个问题: 在同一装置上换权重, 净夏普能多多少, 而且这个"多"能不能走出样本。**

## 2. 权重空间

`size` 固定 **0**(它已被摘除, 重新录取是另一个问题, 不在本实验内 —— 一次一个变量)。
在 `(king, s2, funding)` 单纯形上格点扫描, **步长 0.05**, 全部 `w ≥ 0` 且和为 1。

## 3. ★ 判读协议(预写死; 样本内最优只作上界, 不作结论)

```
逐年 walk-forward:  对每个评估年 Y (2023..2026):
                      w*(Y) = 在【严格早于 Y 的年份】上净夏普最大的权重
                      记录 w*(Y) 在 Y 上的净夏普                 ← 这是唯一算数的读数
  OOS 读数 = 上述逐年读数的均值
对照(同一协议下同样算):
  (a) 现行权重  .5952/.2024/.2024        ← 要打败的对象
  (b) 等权      1/3 each                  ← 若优化连它都打不过, 优化没找到东西
  (c) 样本内最优(全历史一次拟合)           ← 只作【上界】, 明确标注不可部署
```

| 条件 | 结论 |
|---|---|
| OOS(优化) − OOS(现行) 的 **day-block CI 下界 > 0** | **权重可换**, 给出建议权重 = 最后一年的 `w*` |
| CI 含 0 但点估计 > 0 | **不换**, 记为"方向性证据"; 用户可覆盖 |
| OOS(优化) ≤ OOS(等权) | **装置没找到东西** —— 报"权重优化在本书上无效", 不挑一个好看的格点充数 |

**★ 附带必报(不可省)**: 每个候选权重的 **`gross_turn_ann`**。若最优权重靠**降换手**而非**升毛额**取胜, 那是一个与"组合优化"不同的结论(它其实是 cadence/换手那条线的胜利), 必须分开陈述。

## 4. 本实验不建立什么

- **不建立 `Σ⁻¹·IC` 那套解析最优**。那条路要估腿间相关阵, 在 IC 小的情形下极不稳定, 需配 Ledoit-Wolf 收缩 —— **另开**, 本实验先用格点直接优化净额(目标函数就是我们真正要的那个)。
- **不建立 size 腿该不该回来。**
- **不建立这些权重对 S2 世代仍最优** —— 本实验用的是当前干净世代的预测。S2 出来后须重跑(判据不变, 数据换)。
