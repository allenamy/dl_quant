# 附录 C (2026-08-02 21:xx UTC) — **infl 估计器钉死: B 为 canonical**

## C1 两种估计器的定义与读数 (同一条月度序列, n=54)

```
d      = 逐月 ΔNet 差序列 (λ=1 − λ=0)
x̄      = mean(d)                                  # 全序列均值
S      = Σ_{i=1..n} (d_i − x̄)²                    # 全序列平方和, n 项

估计器 A —— 全序列 mean/var 的有偏 ACF (Bartlett / Newey-West 惯例;
             ≡ statsmodels.tsa.stattools.acf(d, adjusted=False))
    ρ_k^A = Σ_{i=1..n−k} (d_i − x̄)(d_{i+k} − x̄) / S
    · 两段均用全序列均值 x̄ 去均值
    · 分母为全序列平方和(n 项), 分子仅 n−k 项 ⇒ ρ 随 k 自然收缩

估计器 B —— 分段 np.corrcoef                     ★ CANONICAL
    ρ_k^B = corrcoef(d[0 : n−k], d[k : n])[0,1]
    · 每段各自去均值、各自除以自身标准差
    · 不随 k 收缩

两者共用: infl = 1 + 2·Σ_{k=1..12} max(ρ_k, 0);  t_eff = t_raw / √infl
```

| 估计器 | infl | **t_eff** | 来源 |
|---|---|---|---|
| A(全序列 mean/var) | 9.8145 | +3.3142 | 0C 全程使用 |
| **B(分段 corrcoef)** | **11.2935** | **+3.0895** | team-lead 独立复现 (`/tmp/lead_repro.py`) |

共用量(两侧逐位一致): `ΔNet = +1.81420` · `t_raw = +10.3826` · `p⁺ = 0.9630` · `n = 54`。
