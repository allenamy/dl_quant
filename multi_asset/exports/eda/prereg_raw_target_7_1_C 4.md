# 预注册 · §7.1-C raw 目标训练(IC 轨第一件)

## §0 时序声明 —— 这一份是【真】预注册

**本文件在训练启动【之前】落盘。** 与 cadence 那份(探索在前、预注册治理剩余部分)不同, 这一件的**全部读数都还不存在**。写下来正是为了让它可以失败。

## §1 假说与机制

**改动**: 与 S1F **完全同配方**(同架构 / 同折 / 同面板 `wide_dl_full_corrfund_causal_v1` / 同 `lam_orth=0` / 同 `xattn`), **唯一变动 = 训练目标从残差化的 `YR4` 换成原始 `Y4`**。

**实现**: 用 harness 既有的 `--target_npz` 接口(`wide_panel_dataset.py:37-40` 覆写 `self.Y`), **不改 harness 一行**。`resid_sigma` 由 `self.Y` 自动重算(`:70-73`), 所以尺度自适应, 不需要额外处理。`self.Yraw` 保持 `Y4` 供评估。

**机制假说**: 残差化在**标签**上扣掉了市场/beta 成分, 代价是**信噪比更低的标签**(残差比原始收益小且更噪)。若模型学到的东西本来就可以在**事后**用横截面残差化取出, 那么"在更高信噪比的目标上训练 + 事后中性化"应当**不劣于**"直接训练残差目标" —— 而前者是文档全篇最便宜的一条 IC 杠杆。

### §1-b ★ 启动前抓到的一个"第二变量", 记在这里因为它差点让实验变成两变量

`Y4` 有 **5,149,962** 个有限格, `YR4` 只有 **4,516,485** —— **多 633,477 格 (+14.0%)**。

> 直接把未加掩码的 `Y4` 交给 raw 臂, 会同时改两件事: **目标的值** 与 **哪些格子有标签**。
> 后者不是"唯一改动 = 目标", 而且它还会**破坏配对 5 折 SE** —— 两臂看的不是同一批格子。

**⇒ 处置: raw 的【值】, 残差臂的【有限格模式】。** 已实测 `nan-pattern equal to YR4 = True`。

标签统计(同一批格子上): `std(raw) = 0.024214` vs `std(YR4) = 0.012877` ⇒ **比值 1.880**;
`corr(raw, resid) = 0.5318`。**⇒ "raw 信噪比更高"这个前提在【尺度】上确实成立**(残差扣掉了约一半的变差), 而两者只有 0.53 相关 ⇒ 它们确实是两个不同的目标, 不是同一个东西差个常数。

## §2 判据(全部写死在跑之前)

**主判**: raw 训练 + **事后**横截面残差化后的 **residual rank-IC**, 对比 **B 臂 = S1F(残差目标训练)在同一实验内实测的 residual rank-IC**。

```
击杀线(同实验内, 不搬任何历史常数):
    raw+事后中性化  >=  B 臂实测 − SE_paired      ⇒ 残差标签训练【不必要】
                                                   ⇒ 训练目标可换到信噪比高一档的 raw
    否则                                          ⇒ 残差标签训练是必要的, 本杠杆否决
```
**★ B 臂的数必须在本实验内重测**, 不得引用 0.048 之类的历史常数 —— 历史常数带着别的折/别的面板/别的口径。

**SE_paired**: 逐折配对差的标准误(5 折), 因为两臂共享折结构 ⇒ 配对比独立更紧。

**对侧尺子(§8-b, 缺了就只有读数没有判定)**:
```
raw 模型【不做】事后中性化 的 residual rank-IC   —— 应当【显著低】
```
若它**不**显著低, 则"事后中性化"这一步本身没有作用 ⇒ 主判的比较失去意义(两臂在比同一个东西), **整个实验作废重设计**, 而不是宣布 raw 获胜。

## §3 预期(落盘于跑之前 —— 偏离本身就是发现)

| 量 | 预期 | 理由 |
|---|---|---|
| raw 训练的 **raw** rank-IC | **高于** B 臂的 raw rank-IC | raw 目标信噪比更高, 且它直接优化这个量 |
| raw+事后中性化的 **residual** rank-IC | **与 B 臂同量级, 方向未定** | 这正是待测的东西; 我**不**预测符号 |
| raw **不**中性化的 residual rank-IC | **显著低于**上一行 | 若不成立 ⇒ 对侧尺子失效 ⇒ 实验作废 |
| 收敛 epoch | 与 S1F 同量级(0–4) | 同配方同数据量 |

**★ 我不预测主判的符号。** 预测一个自己没有机制依据的方向, 会在事后变成"我早就说了"的两头堵。有机制依据的只有第一行和第三行, 只写这两行。

## §4 什么算失败 / 什么算无效

| 条件 | 判定 |
|---|---|
| 对侧尺子不显著低 | **实验无效**(不是 raw 赢), 重设计 |
| raw 臂训练崩(σ 塌缩 / val IC ≈ 0) | 本杠杆否决, 但记为"raw 目标不可训"而非"残差必要" |
| raw+中性化 < B 臂 − SE_paired | **本杠杆否决** —— 残差标签训练是必要的 |
| 两臂折结构不逐位相同 | **停** —— 配对 SE 不成立, 比较无效 |
