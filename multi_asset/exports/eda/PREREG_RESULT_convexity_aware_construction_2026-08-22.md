## P. 预注册(冻结段; 本段 SHA256 先于任何数字入库)

### P.0 一句话机制
空头单位名义的简单盈亏期望 = −(μ + ½σ²), 多头 = +(μ + ½σ²)(μ = 对数收益期望, σ² = 4h 对数收益方差)。模型分数按 μ(残差/对数/秩目标)排序, **不含 σ**; 书把分数最负的名空掉, 不论其 σ 多大 ⇒ 高波动空头每锚白付 ½σ², 高波动多头白拿 ½σ²。σ 持久可测(这不是预测收益, 也不是全书 vol-target 那种择时), 把它变成**每名**的决策变量: 分数扣凸性(A1)/ 重排(A4)/ 空头 vol 封顶(A2)/ 多空不对称 gross(A3, 仅敏感)。

### P.2 σ̂² 与单位(只用 ≤T 信息)
- σ̂²_i(T) = 过去 L 个 4h 窗 (T−4h·n, T−4h·(n−1)], n=1..L 的**对数**收益平方均值(原始二阶矩, 不去均值; 最后一窗止于 T, 决策用 C(T) ⇒ 因果); **L = 30(主)/ 90(敏感)**; 要求有限样本 ≥ ⌈2L/3⌉, 否则取当锚成员内 σ̂² 的截面中位数。
- 凸性项 c_i = ½σ̂²_i × 1e4(bps/锚/单位名义); σ̂_i = √σ̂²_i(A2 用)。

### P.3 分数 → bps 标定(走前, 900 锚, 不含当锚)
- 复合分数 s_i = Σ_k w3_k·xz(sc_k)_i 经逐腿 over-sel 去均值后的和(= 基线链里 L1 归一前的 w), 单位 rank-z。
- 每锚记 sel 内去均值量的乘积和: Σs·r_sim, Σs·r_log, Σs², Σc·r_sim, Σc·r_log, Σc², Σs·c, n(r 以 bps, c 以 bps); 标定窗 = 过去 900 锚(不含当锚; 不足 900 时 ≥300 即用, <300 不调整)。
- **β_log1** = Σs·r_log / Σs²(单回归, 对数收益斜率): **A1(k 固定)/A4 用它把 s 换成 bps**(理论一致: 若模型预测的是对数/残差收益, 其对 s 的斜率就是 β_log1)。
- **(β_sim2, γ_sim2)** = r_sim 对 (s, c) 的二元 OLS(正规方程): γ_sim2 = 经验凸性载荷; **A1γ 用 (β_sim2, clip(γ_sim2, 0, 2))**。
- 诊断并报: β_sim1, γ_log2(理论: 若模型不含 σ 且 σ̂² 无偏预测 r², 则 γ_sim2 ≈ 1、γ_log2 ≈ 0、β_log1 ≈ β_sim2; 若 γ_sim2 ≈ 0 ⇒ 模型(king 目标 = Σ简单 5m ≈ log + ½RV)已隐含定价凸性, A1 k=1 为过度修正 —— 这是机制读数, 先写在这里)。
- 守卫: 所用 β ≤ 0 的锚不调整(= 基线), 计数上报。

### R.3 四问
- **口径**: 全继承 WA(简单 / 实盘相位 / 3.52 / 逐结算 carry / 净@2); 臂间比较同锚同函数(summarize/gates 同一代码); 权重原样口径 Δ 同号(A1 −1.11 / A2 p80 +0.11 / p90 +0.14); 成本 4.137 / 6.64 下全部同号。

### R.4 判决与含义
**三选一: 主臂 A1(k=1.0)判负; 凸性感知构造作为 alpha 路线在宽书上关闭(DO-NOT-RETRY 形态: 分数加/扣 ½σ̂²、按 ½σ̂² 重排、多空不对称 gross);** 仅剩 "A2 空头 vol 封顶" 可作为**风险预算类**提案(夏普 +0.09~0.10, 净额 0, CI 含 0)在换装后另开预注册 —— 不是 alpha。
- **对 SR/WA/RC 的凸性读数的重新表述**: "在役 70% / 宽书 14–17% 的毛利是凸性"应读作"对数口径多记了这么多", 不可读作"有这么多可以通过构造收回"。路径文档 §3.6 第 1 条(E2, 预期 +0.1~0.2 夏普)**实测为 −0.9(主臂)/ 最好 +0.10(A2 p90, 含 0)** ⇒ E2 从"最大 edge"降为"已测关闭"。
- **对 09-01 重训目标的含义**: 宽书 king 目标(Σ简单 5m)本就 ≈ 算术收益, γ_sim2 ≈ 0 与之一致 ⇒ "改目标为简单收益"对宽书预期增量 ≈ 0(仍应做, 为口径一致); 在役 DL 的残差**对数**目标理论上会学到高 σ 名的 −½σ² 对数漂移, 但在役已退役且其分数未在本装置上标定(见 R.5)。
- **白话三句**: ① 我们以为"做空高波动币每 4 小时白白多付它方差的一半", 照这个想法把高波动币往多头挪、低波动币往空头挪, 宽书夏普从 1.67 掉到 0.78(最稳的改法也只到 0.92), 五年里没有一年变好。② 原因: 用过去数据校准后发现, 在同样的模型分数下, 高波动币的**真实(算术)**收益并不比低波动币高 —— 那"多付的一半方差"只是对数口径记账时多记给空头的纸面利润, 换成交易所口径它就不存在了, 单独做一本"多高波动/空低波动"的书, 算术收益是零。③ 唯一不亏的是给最大的 20% 高波动空头封顶(夏普 +0.09, 但净额不变、区间含零、逐年 3/5), 那是降风险不是赚钱; 全书 vol-target 对照照样亏 −0.22, 和以前一样。
