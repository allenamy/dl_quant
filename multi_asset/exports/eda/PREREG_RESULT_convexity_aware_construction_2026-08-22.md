## P. 预注册(冻结段; 本段 SHA256 先于任何数字入库)

### P.0 一句话机制
空头单位名义的简单盈亏期望 = −(μ + ½σ²), 多头 = +(μ + ½σ²)(μ = 对数收益期望, σ² = 4h 对数收益方差)。模型分数按 μ(残差/对数/秩目标)排序, **不含 σ**; 书把分数最负的名空掉, 不论其 σ 多大 ⇒ 高波动空头每锚白付 ½σ², 高波动多头白拿 ½σ²。σ 持久可测(这不是预测收益, 也不是全书 vol-target 那种择时), 把它变成**每名**的决策变量: 分数扣凸性(A1)/ 重排(A4)/ 空头 vol 封顶(A2)/ 多空不对称 gross(A3, 仅敏感)。

### P.1 对象、数据、口径(全部继承 WA, 零改动)
- **对象**: 宽书 **W-b 链**(WA 装置 `kcurve_2026-08-21/devices_2026-08-22/wide_full_caliber_audit.py`, SHA `9792ecd0…808b`, `run_chain` 语义): 三腿 king = slow LGBM OOS(`pod_backup_2026-08-21/slow_pred_hist_oos.npy`)/ rev24 = −`f_rev_24h` / fund = `f_fund_ema_v1`(`wide_panel_4h_hist_v2.npz`); 截面秩 z ∈ [−0.5, 0.5] → 走前 msharpe(900 锚)配三腿权重 w3 → 逐腿去均值(over sel)/ L1 / cap 2.5/n / 再归一 → 止损 d30_n2_c42(EMA 前置零)→ EMA α0.1 → 带 2.5e-4; sel = 收益有数 ∧ qv4h ≥ 2.5e5; 2021-01 暖机, 2022-01 起记录。
- **数据**: WA 自建 1h 收盘网格 `probe_artifacts/wa/close1h_829.npz`(829 名)与逐结算资金费 `funding_829.npz`; 4h 简单收益 RET = C(T+4h)/C(T) − 1, 对数 LRET = ln(C(T+4h)/C(T)); 锚 T ∈ {00,04,…,20}Z, 持仓窗 (T, T+4h](实盘相位)。
- **记账**: WA `account()` 语义 —— 价格 pnl = Σw·RET(简单); carry = 逐结算实现(结算时刻 ∈ (T,T+4h] 作用于 w(T)); 成本 = 3.52 bps × Σ|Δw|(单向意图换手, NAV 份额); 敏感 4.137 / 6.64; **净@2** = 每锚按 2/Σ|w| 缩放(恒定 gross 2, 主口径), 权重原样并报。
- **统计**: 锚级夏普 = 均/σ×√2190(主), 日聚合 ×√365 并报; CI = 42 锚块自助 2000 次; 臂间 Δ = 配对块自助(同锚)。
- **跨度**: 主 = 2022-01-01 → 2026-06-30 23:00(WA "2022-01..2026-06"块, 9,852 锚); 并报 FULL(→ 2026-08-15)、2022-23、2024-26。
- **收据 R1(先于一切)**: 本装置 A0(无任何修改的链)权重 ≡ WA `probe_artifacts/wa/wa_weights_Wb_d30.npz`(逐锚逐名 max|Δw| < 1e-6), 且 A0 净@2 锚级夏普(2022-01..2026-06)= WA 的 **1.668**(W-b d30)。对不上照实报、不调和, 且不得出任何结论。

### P.2 σ̂² 与单位(只用 ≤T 信息)
- σ̂²_i(T) = 过去 L 个 4h 窗 (T−4h·n, T−4h·(n−1)], n=1..L 的**对数**收益平方均值(原始二阶矩, 不去均值; 最后一窗止于 T, 决策用 C(T) ⇒ 因果); **L = 30(主)/ 90(敏感)**; 要求有限样本 ≥ ⌈2L/3⌉, 否则取当锚成员内 σ̂² 的截面中位数。
- 凸性项 c_i = ½σ̂²_i × 1e4(bps/锚/单位名义); σ̂_i = √σ̂²_i(A2 用)。

### P.3 分数 → bps 标定(走前, 900 锚, 不含当锚)
- 复合分数 s_i = Σ_k w3_k·xz(sc_k)_i 经逐腿 over-sel 去均值后的和(= 基线链里 L1 归一前的 w), 单位 rank-z。
- 每锚记 sel 内去均值量的乘积和: Σs·r_sim, Σs·r_log, Σs², Σc·r_sim, Σc·r_log, Σc², Σs·c, n(r 以 bps, c 以 bps); 标定窗 = 过去 900 锚(不含当锚; 不足 900 时 ≥300 即用, <300 不调整)。
- **β_log1** = Σs·r_log / Σs²(单回归, 对数收益斜率): **A1(k 固定)/A4 用它把 s 换成 bps**(理论一致: 若模型预测的是对数/残差收益, 其对 s 的斜率就是 β_log1)。
- **(β_sim2, γ_sim2)** = r_sim 对 (s, c) 的二元 OLS(正规方程): γ_sim2 = 经验凸性载荷; **A1γ 用 (β_sim2, clip(γ_sim2, 0, 2))**。
- 诊断并报: β_sim1, γ_log2(理论: 若模型不含 σ 且 σ̂² 无偏预测 r², 则 γ_sim2 ≈ 1、γ_log2 ≈ 0、β_log1 ≈ β_sim2; 若 γ_sim2 ≈ 0 ⇒ 模型(king 目标 = Σ简单 5m ≈ log + ½RV)已隐含定价凸性, A1 k=1 为过度修正 —— 这是机制读数, 先写在这里)。
- 守卫: 所用 β ≤ 0 的锚不调整(= 基线), 计数上报。

### P.5 判据(冻结; 主臂 A1 k=1.0 vs A0; 净@2; 2022-01→2026-06 共同锚)
- **G1** Δ锚级夏普 ≥ +0.10(点估计; 并报配对 42 锚块自助 CI95)。
- **G2** 逐年 Δ夏普 ≥ 0 的年数 ≥ 4/5(2022–2026)。
- **G3** Q4 不劣: 以等权市场 4h 收益五分位(WA 同法)切, 臂的**最差档均值 ≥ 基线最差档均值**; 且 |市场| 最高档均值不低于基线。两者同时。
- **G4** 换手: 臂的平均单向换手 ≤ 1.20 × 基线。
- **G5** 去 fund 腿情景: Δ夏普(A1 no_fund − A0 no_fund)≥ +0.05。
- **判决**: 五门全过 ⇒ **PASS(采纳候选; 进影子对照臂/换装预注册, 仍需用户裁定)**; G1 不过 ⇒ **判负**; G1 过而 G2–G5 任一不过 ⇒ **降为"敏感"(方向性读数, 不采纳)**。
- 其它臂(k=0.5 / A1γ / L=90 / A4 / A2 / A3 / C1 / C2)用同五门并报, **标"次要", 本预注册不授予任何次要臂晋升资格** —— 次要臂过门 ⇒ 另开预注册。
- 并报(非门): 2022-23 vs 2024-26 分段; 成本 4.137 / 6.64; 权重原样口径; 凸性项(多/空侧)逐臂; 主臂的 tilt 分量份额 λ_T 与 tilt 分量自身净额; 日级夏普。

### P.6 四问
- **口径**: 简单持有收益 / 实盘相位 [N,N+4h] / 3.52 / 逐结算 carry(全继承 WA); σ̂ 与标定只用 ≤T 信息。
- **泄漏**: σ̂² 窗与 β/γ 窗均不含当锚; 链的其余输入为 WA 已认证 OOS 产物(slow OOS 预测等, 本装置不重新验证其 OOS 性, 同 WA D-4)。
- **选择效应**: 臂与 k 两档事前写死, 主臂事前指定; 次要臂不得晋升; A2 分位两档事前写死。
- **regime**: 逐年 + 2022-23/2024-26 + 市场五分位 + |市场| 五分位。

### P.7 预期方向(先写)
若模型不含 σ: γ_sim2 ≈ 1, 主臂应把凸性项从 −0.25 转正并净赚 ~0.2–0.5 bps/锚 @2(≈ +0.1–0.3 夏普), 空头侧 ½σ² 降、多头侧升; 换手增量小(σ̂ 慢变)。若 γ_sim2 ≈ 0: 模型已隐含凸性, 主臂过度修正 ⇒ 判负/敏感, 而 A1γ ≈ 基线。C1 应不过门。C2 的符号决定"倾斜本身是否有正期望简单收益"。
