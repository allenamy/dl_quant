### 2.3 四条腿的原始值

```
king_raw    = king_pred[t, m]
s2_raw      = s2_pred[t, m]
funding_raw = CH[t, m, idx('funding_ema')]
size_raw    = CH[t, m, idx('size_dvol')]        # 本轮权重为 0, 但仍需存在
```

### 2.4 腿的变换 (逐字)

```
z(x):              mask = isfinite(x); out = 0
                   若 mask.sum() >= 3 且 std(x[mask]) > 1e-12:
                       out[mask] = (x[mask] − mean(x[mask])) / std(x[mask])     # 总体 std, ddof=0
rank_centered(x):  mask = isfinite(x); out = 0
                   若 mask.sum() >= 3:
                       r = rankdata(x[mask])                                    # 平均秩处理并列
                       out[mask] = 2*(r − 1)/(k − 1) − 1,  k = len(r)
l1(x):             g = Σ|x|;  返回 x/g 若 g > 1e-9, 否则 x
```

```
signs = {king: +1, s2: +1, funding: −1, size: +1}
leg_signal[king]    = +1 · z(king_raw)
leg_signal[s2]      = +1 · z(s2_raw)
leg_signal[funding] = −1 · rank_centered(funding_raw)      # funding_mode = "rank"
leg_signal[size]    = +1 · z(size_raw)
leg_position[k]     = l1(leg_signal[k])                    # 每条腿单位 gross
```

### 2.5 权重与 netting 的 cadence-hold (**第二个容易错的地方**)

```
w = {king: 0.595, s2: 0.202, funding: 0.202, size: 0.0}
cadence_h = {king: 4, s2: 24, funding: 8, size: 24}
```

netting 不是每锚重算每条腿, 而是**各腿按自己的 cadence 持有**:

```
held[k] = 全 N 零向量
对第 i 个锚点(索引 ti, 即面板的小时下标):
    对每条腿 k:
        若 i == 0 或 (ti % cadence_h[k] == 0):
            held[k] = 全 N 零向量; held[k][m] = leg_position[k]      # 只在该腿的节拍上更新
    combo_full = Σ_k w[k] · held[k]                                  # 全 N
    active     = combo_full[m]
```
**★ 取模作用在**面板小时下标 `ti`**上, 不是墙钟小时。** 面板是小时网格, 所以两者通常一致, 但请照下标写。
**★ `held[k]` 在全 N 空间累积, 因此成员进出会把旧成员的权重留在 held 里直到该腿下一次节拍。** 这是生产行为, 不是 bug。

### 2.6 σ 的定义 (**第三个容易错的地方 —— 这里出错会静默改变一切**)

```
σ_raw = CH[t, m, idx('rvol_72h')]
σ     = σ_raw, 但把 非有限 或 ≤0 的元素替换为 该锚横截面的中位数(在有效元素上取)
σ     = max(σ, percentile(σ, 5))        # 下限截断到该锚横截面 p05
                                        # 不截上限
```
`rvol_72h` 是**原始收益单位**(该面板中位约 0.0137), 不是标准化量 —— 若你的读数量级不是 1e-2, 说明取错了通道。

### 2.7 成书 (顺序是预注册写死的)

```
shaped = clip(active, percentile(active,1), percentile(active,99))    # 1. 双侧 99 分位裁剪
shaped = shaped / σ**λ                                                 # 2. ★ 唯一的改动
shaped = shaped − mean(shaped)                                         # 3. 市场中性
w_t    = shaped / Σ|shaped|   (置于 m 上, 其余为 0)                    # 4. 单位 gross
```
**顺序不可换**: "先除 σ 再裁剪"会把被放大的低波动名字裁掉, 效应大部分消失;"先中性化再除 σ"会破坏中性。
**λ=0 时第 2 步必须被完全跳过**(不是除以 1 —— 数值上等价, 但请确认你的分支不会在 λ=0 时碰 σ, 否则基线会被 σ 的缺失值填补逻辑污染)。

> **注(免得你追一个不存在的差异)**: 生产 `engine/netting.py` 在 `shape_position` 之后有一步 `shaped *= gref/gsh`(把书缩回未成形前的 gross)。**第 4 步的单位化会把它完全抵消**, 因此可以不实现。若你实现了它, 结果应逐位不变。

### 2.8 P&L 与统计量

```
gross_t = Σ_s w_t[s] · Y4[t, s]           # 只对 isfinite(Y4) 求和
turn_t  = Σ_s |w_t[s] − w_{t−1}[s]|       # ★ 在全 N 空间上算, 缺席记 0(与生产一致)
net_t   = 1.0 · (gross_t − turn_t · 1.9e-4)          # FILL = 1.0, cost = 1.9 bps
```
**★ `gross` 只算 finite 而 `turn` 算全 N —— 两个口径不同是**故意的****(补零在点积里无害、在换手里必要: 成员离场必须计为换手)。若你把 turn 也限制到 finite 集合, 会少算换手。

```
按日历月对 net_t 求和 → 月序列
ΔNet   = Σ(月序列(λ=1) − 月序列(λ=0))
d      = 逐月差序列, n = 54
t_raw  = mean(d)/std(d, ddof=1) · √n
p⁺     = (d > 0) 的比例
infl   = 1 + 2·Σ_{k=1..12} max(ρ_k, 0)
t_eff  = t_raw / √infl
```

### 2.8.1 ★ `ρ_k` 的定义 —— 逐字钉死 (2026-08-02 补, 因复算在此处分叉)

**初版 §2.8 只写了「逐月差序列的 lag-k 自相关」, 这不足以确定一个数。** 复算证实两种都合理的写法给出不同的 `infl`(9.81 vs 11.29), 因此两种都在此写死, 且**两种都必须报**:

```
xbar = mean(d)                                   # 全序列均值
S    = Σ_{i=1..n} (d_i − xbar)²                  # 全序列平方和, n 项

估计量 A —— 有偏 ACF (Bartlett / Newey-West 惯例; 等价于 statsmodels acf(adjusted=False))
    ρ_k^A = Σ_{i=1..n−k} (d_i − xbar)(d_{i+k} − xbar) / S
    · 两段都用**全序列**均值 xbar 去均值
    · 分母是**全序列**平方和(n 项), 分子只有 n−k 项 ⇒ ρ 随 k 自然收缩

估计量 B —— 逐对 Pearson
    ρ_k^B = corr( d[1 .. n−k] , d[k+1 .. n] )
    · 每一段用**自己**的均值去均值、除以**自己**的标准差
    · 不随 k 收缩
```

**决策规则(我的建议, 待 team-lead 裁定): `t_eff := min(t_eff^A, t_eff^B)`。**
理由: 这样**估计量的选择不再是一个杠杆** —— 无论如何选都不可能变得更宽松。这正是 §56-3(4)「禁止末尾改用更宽松估计量」要防的东西, 而"钉死其中一个"只是把同一个杠杆留给下一次歧义。
**代价, 明写: `min` 比任一单一估计量都更严, 因此它会让所有历史 `t_eff` 略微收紧 —— 见 §2.8.3 的追溯范围核查。**
