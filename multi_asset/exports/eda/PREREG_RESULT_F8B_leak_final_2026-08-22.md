# F-8B · 特征泄漏终审 —— 每族一行判决: 有泄漏 / 无泄漏 / 该列不可判定

**背景(白话 4 句, 用户被 "尺子红" 绕晕的那件事)**: F-8 预注册照抄了 DLW(深度学习装置)的两条有效性判据。第一条把"预测 vs **别的时刻**的收益应当 ≈0"当泄漏检验 —— 但只要目标里存在"同一批币在一年内持续偏强/偏弱"的横截面持久结构, **任何**正常模型(包括不加任何新列的 82 列基线, 实测 +0.011)都读正, 所以它红不代表泄漏。第二条要求"预测与各时刻收益的相关峰必须在当下" —— 但 82 列基线和新列里**本来就装着过去已实现的收益**(例如"上一个 4h 收益"这一列就是上一锚的目标), 预测与**过去**收益相关大是输入的机械回声, 与"偷看未来"无关(基线自己 k=−1 读 −0.39)。所以这两条对本类装置**必然假红**, 它们的红不承载泄漏信息。本文改用四台对泄漏敏感、对上述两种结构不敏感的仪器, 判决词只有三种。

## V. 判决装置与规则(冻结)

### V.1 四台仪器(每族 D / E / J / T1-T3(=S300 档新列) / ALL(89) 各过一遍; 无增量族 A/B/C/F/G/H/I 并报但判"无增量, 泄漏判定不适用")
1. **结构审计(必要条件)**: 逐族最大特征行偏移 vs E(锚收盘行)≤ 0; 引用 `f8_build_report.json`(SHA `4f59fe73…`)`struct_assert` 与 `max_row_offset_vs_E`; E 族同相位窗右端 ≤ E−240; J 族 lag 块 ≤ E−48; S300 档引 `f8s_build_report.json`(`385698d2…`)。
2. **配对 shuffle-future null(泄漏敏感 / 持久结构不敏感的正确形状)**: 同年内把目标行随机重配(锚 i 的预测对锚 j 的未来收益打分, j 同年随机), **同一置换**同时作用于"臂"与"base", 读 **Δnull_i = IC_null(臂, i) − IC_null(base, i)** 的均值与锚级 SE(3 种子合并)。真实增量与泄漏在置换下同死, 两臂共享的持久结构在配对差里相消 ⇒ 无泄漏预期 Δnull = 0 ± 2SE。
3. **修正版偏移谱(只读增量)**: 臂预测对 base 预测逐锚秩 OLS 残差 = "新列的净贡献", 对 YR4s_{i+k}(k ∈ [−6, +6])的逐锚 Spearman 均值。**判据只看 k ≥ 0 半边**: max_{k∈[0,6]} 必须在 k=0(预测的净贡献最强对应的就是它要预测的那个窗)。k<0 只作机械回声记录(输入含已实现收益的构造性结果), 不进判据。
4. **陈化塌缩曲线(已跑, 预期先写于装置 docstring; 本文补 SE 并正式化)**: 新 89 列整体改用同名 4h 前 / 24h 前的值(基线保持新鲜), Δ(0h)/Δ(4h)/Δ(24h) ± SE。泄漏形态 = 4h 后塌到 ≤ 0(泄漏窗移到上一锚的目标 = 基线已有列的副本); 真实信息形态 = 显著 >0 的部分保留。联测(89 列整体), 不逐族。
5. **2026 封存段(旁证)**: 每族 2026 折 Δ(训练 <2026, 时间上完全封存); 泄漏若存在于构造, 不会单独在 2026 消失。

### V.2 判决规则(冻结; 判决词只许三个)
- **无泄漏**: 仪器1 ✓ 且 |Δnull| ≤ 2SE 且 增量谱 k≥0 峰在 k=0。
- **有泄漏**: 仪器1 发现任何未来行; 或 Δnull > 2SE **且** 增量谱 k≥0 峰在 k>0(两台同时指向"借了未来")。
- **该列不可判定**: 其余组合(单台越界另一台干净)。
- ALL 与 S300 档同规则; 陈化曲线与 2026 段并报作旁证, 不改判决词(它们对"有泄漏"是强反证, 对"无泄漏"是支持)。
