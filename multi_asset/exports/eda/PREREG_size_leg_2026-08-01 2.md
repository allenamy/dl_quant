## 3. 必须产出的量 (先列清单, 免得事后挑指标)

**(a) 全历史逐月序列**(2022-01 → 2026-07, 含 2026 影子切片), 主口径:
- `IC_m` = 该月 size 腿 signed 逐锚横截面 rank-IC 均值, 及其逐月 t;
- `MC_m` = **对整书的边际贡献** = `IC(w_full) − IC(w_full with size→0)`, 其中 `IC(w)=w'r/√(w'Ωw)`, r 与 Ω **按月估计**;
- `ΔNet_m` = 含 size 与不含 size 两本书的**净收益差**(按当时可得的成本口径; 若无实测成本则用 1.9bps 建模成本并明标)。
**三个量都报, 裁决以 `MC_m` 为主、`IC_m` 为辅、`ΔNet_m` 为净收益确认。**

**(b) regime 分层:** 按 `btc_rvol_bps_min` 的预注册阈值 **calm < 7 / stress ≥ 18**(沿用 `live/regime_classifier.py`, **不重新调参**), 分别报 (a) 的三个量。中间带(7–18)单列, 不并入任何一侧。

## 4. 判据 (先写后算, 四选一, 互斥且穷尽)

记全历史主口径的边际贡献均值为 `MC̄`, 其 `t_eff`, 逐月为正的月份比例为 `p⁺`, 近 3 个月为 `MC_recent`。

| # | 形状 | 裁决 |
|---|---|---|
| **A** | `MC̄ > 0` 且 `t_eff ≥ 2` 且 `p⁺ ≥ 0.60`, **且**近月反号(`MC_recent < 0`) | **保留 + 观察.** 这是 regime/近期漂移, 不是因子失效。**线上不动**, 进月度监控, 连续 [见 §5] 个月 `MC_m < 0` 才重开本案。 |
| **B** | `MC̄ > 0` 且 `t_eff ≥ 2` 且 `p⁺ ≥ 0.60`, 且近月**未**反号 | **保留.** 影子那个 −0.0315 是单月噪声, 结案。 |
| **C** | `MC̄ ≤ 0` **在主口径上**(无论 as-trained 口径如何) | **摘除.** 并且: **这意味着当初的留腿决定建立在错误口径上** —— 须在结论里明写这一点, 并检查还有哪些结论继承自同一个口径错误。 |
| **D** | `MC̄ > 0` 但 `t_eff < 2` 或 `p⁺ < 0.60`(证据弱/不稳) | **降权.** 权重降到 `min(当前权重, MC̄ 对应的 Σ⁻¹ 最优权重)`, 且**不得低于 0**(不做符号翻转 —— 翻转是新因子, 走新因子的门, 不走本案)。 |

**边界规则(先定, 免得事后解释):**
- 若 `MC̄ > 0` 但 **stress 分层下 `MC̄_stress < 0` 且 `n_stress ≥ 30 锚`** ⇒ 无论 A/B/D, 一律**降级为 D(降权)**, 理由: 一条在逆境中反号的永久腿, 在 GP 框架下会被放大(§E5)。
- 若 `n_stress < 30 锚` ⇒ **stress 结论不可评**, 明标, **不得**用"stress 没问题"支持保留。
- **禁止**用 `IC_m` 单独推翻 `MC_m`: 一条 IC 为负但与其它腿负相关的腿仍可有正边际贡献, 那正是保留它的合法理由。**边际贡献是裁决量。**
