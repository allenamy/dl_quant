## 1. 唯一改动: §4-1 的分子口径

```
v1:  c_day = (Σ fee + Σ |avg_fill_px − mid_at_anchor|/mid × notional) / Σ notional
v2:  c_day = (Σ fee + Σ SIGNED slip) / Σ notional
     SIGNED slip: BUY 成交高于锚点 mid = 成本(+), 低于 = 抵扣(−); SELL 镜像。
```

**机制理由(为什么 v1 口径是错的量):** |slip| 把**有利成交也计为成本**, 等价于把"挂单到成交
的时间"计价为成本 —— 它测的是**离散度**不是**钱**。实测: 触发窗五天 |slip| 7.4→14.3 上升(真),
同期 signed 0.0~5.8(小); maker edge 甚至把 day0805 的净滑点做成 **−0.96**。一个 gate 测两个
不同性质的量 = v1 已在 protective_flatten 裁定里写明并排除过一次的错误形状, 这是同一形状的第二处。

**离散度不丢弃 —— 单列**: `per_day_dispersion_bps`(= Σ|slip|/Σn) 逐日上报;
**alert(只页不停)**: 连续 3 个定价日 dispersion > **16.0 bps**(= 2 × testnet 中位点差 8.0,
v1 §5 标定常数, 触发前来源)。alert 永不进 `triggers`。

**其余全部逐字继承 v1**: 9.0 bps 限值 / 连续 5 定价日 / "无定价日既不断也不续" /
protective_flatten 排除于 c(单列上报) / cond2-7 / §2 规模 / §3 阈值 / §6 challenger / 恢复走
`resume_from_trip.sh` 硬门(v2 下门自己重新评估, **不存在任何 override**)。

## 2. 限值的来源(全部触发前)

9.0 bps 是 v1 自己的数, 对净成本它的解释链: 回测成本假设 3.63 [95%CI 1.5, 5.8](触发前重建),
红线 6.93, crossover 8.49 ⇒ 9.0 = 红线之上、crossover 之上, "连续五天净成本超它" = 成本假设
结构性破产, 正是 v1 §4-1 的原意。**没有一个数字来自 08-01 之后的实盘观察。**

## 4. 恢复语义(一般防呆, 本次甚至用不上)
