# PREREG — 2×2 因子: 把"换装变差"拆成 模型效应 / 装置效应 / 交互

今天已有的同锚装置只做到**分数级**(`paired_gen_homepanel_v.py`), 没走完书。本门补上。

## 1. 设计

同 **50 个实盘锚**(2026-08-01 → 08-09, 4h 对齐), 同成员掩码, 同 `CLOSE` 实现收益, 同 funding 腿。
**只交叉两个因子:**

| | **装置-旧**(无风险预算, α=1 λ=0) | **装置-新**(α=0.5 λ=1.0) |
|---|---|---|
| **分数-旧**(`5a7b27d9/8b1bc1ab` @ 家面板 as_trained+centered) | **A** = 换装前的真实书 | **C** |
| **分数-新**(`45f08e81/f0ca61f5` @ 家面板 normfix+trailing) | **D** | **B** = 换装后的真实书 |

- `B − A` = 实盘看到的**总差**(应与实盘方向一致, 见 §3 的一致性检验)
- `C − A` = **装置效应**(只换风险预算)
- `D − A` = **模型效应**(只换模型+其家面板)
- `(B−A) − (C−A) − (D−A)` = **交互**

**★ 每一代的分数在【自己的家面板】上生成** —— 这是今日已证的正确口径(`RESULT_oldnew_coincidence` §2)。
**★ 装置除风险预算外逐位相同**: 同权重 (.5952/.2024/.2024)、同 cap99、同 `|s|^0.5`、同 l1、同 cadence。

## 2. 判据(顺序固定)

**G0 · 一致性(前置, 不过则整门作废)**: `B` 的逐锚 rank-IC 与实盘换装后 24 锚的逐锚 rank-IC
`corr ≥ 0.5`; `A` 与实盘换装前 26 锚 `corr ≥ 0.5`。
 **理由**: 若重建的书跟真实的书都对不上, 这个 2×2 拆的就不是实盘那件事。
 (今日已测: 分数级 corr 新臂 +0.631 / 旧臂 +0.506 ⇒ 0.5 是一个会红的门, 不是走过场。)

**G1 · 总差方向**: `B − A` 的毛额差。**若 `B−A ≥ 0`(新书不差), 则"S2 实盘更差"在同锚上不复现
⇒ 判为【锚点/市场差异】, 模型与装置都不是根因, 本门结束。**

**G2 · 分解**(仅在 G1 显示 `B−A < 0` 时读): 报告 `C−A`、`D−A`、交互, 各附日块 bootstrap CI95。
 **归因阈值: 某一项的 |Δ| ≥ 总差的 50% 且 CI 排除 0, 才可称为"主因"。** 否则报"未能归因"。

**G3 · 净额**: 全部四臂必须同时报 **毛额 / 换手 / 净@3.115 / 净@5.8**。
 **毛额上的结论若在净额上反号, 以净额为准**(今日四次实测都是这个形态)。

**G4 · 功效**: n=50。若 `B−A` 的 CI 覆盖 0, **判"总差本身不显著"**, 且 §G2 的分解不得解读为归因,
 只作描述。**必须给出 N\*。**

  且模型级 5 折证据说新模型 **+52.5%**。**若如此, 结论是"实盘那 24 锚的差主要来自市场, 不是来自换装"。**

  ⇒ 若 50 锚给出相反符号, **首先怀疑的是 50 锚的功效, 不是 9821 锚的结论。**
