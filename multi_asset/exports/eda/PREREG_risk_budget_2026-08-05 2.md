# PREREG — 风险预算书: 用 rank-IC 的固定预算, 换尽可能多的风险下降

## 0. 问题(不含答案)

书现在**只 cap 分数, 不管风险**。实测(实盘 20-21 锚, 逐名重建):
```
波动离散 18.9×  vs  仓位离散 3.0×      ⇒ 风险由波动主导, sizing 不参与
corr(波动, 仓位) = +0.380              ⇒ 书【主动】超配高波动名字
风险贡献 HHI = 3.90 ⇒ 有效独立赌注 ≈ 28 个, 不是 110
★ 21% 的仓位承载 46% 的毛敞口          ⇒ cap99 的直接后果
1000RATS: 波动 p99 · 仓位 p92 · 亏 −55.33(全书净利仅 +37.10)
```
**⇒ 它拿到大仓不是因为分数极端, 是因为【同一个分数 × p99 的波动】。**

**★ 已证伪的相邻假说(不得再作为本项理由)**: "尾部表现差"。剔除 1000RATS 后尾部 +8.4 vs 中段 +9.0,
**无法区分** ⇒ **不存在尾部效应, 只存在单名效应。** (该对比含"剔除会重排分位阈值"的混淆, 已注明。)

## 1. 干预(一个族, 两个旋钮)

```
score_i  = 现行合成分(不动 —— alpha 在这里)
σ_i      = 面板通道 8 `rvol_24h`(因果, 且是【模型吃的同一个量】, 不引入新口径)
w_i      = sign(score_i) · |score_i|^α / (σ_i/median σ)^λ
可选 cap : |w_i| ≤ κ · (Σ|w|)/N , 超出者截断后重归一
最后     : demean(市场中性) → L1 到原毛敞口
```
**参数预算(兑现 B4 的 (d) 条)**: **α, λ, κ = 3 个可拟合标量。** 超出必须在表头声明。
**α=1, λ=0, κ=∞ 时逐位回落到现行书** —— 现行是本族的一个点, 比较是精确的。
