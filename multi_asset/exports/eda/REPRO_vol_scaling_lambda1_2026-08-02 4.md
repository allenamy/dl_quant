## 2. 独立路径 (**这才是这道门**)

### 2.1 三行规格 —— 请照这个重写, 不要读我的代码

书的构造(与生产 `engine/signal_chain.py` + `engine/netting.py` 一致, 唯一改动是插入 σ):

```
每个锚点 t:
  1. legs      = SignalChain.leg_positions(t)          # 四条腿各自 L1 归一, 生产代码原样
  2. combo     = Σ_k w_k · legs[k]                     # w = {king .595, s2 .202, funding .202, size 0}
  3. capped    = clip(combo, pct1, pct99)              # 99 百分位双侧裁剪
  4. scaled    = capped / σ_t^λ                        # ★ 唯一的改动。λ=1.0
  5. shaped    = scaled − mean(scaled)                 # 市场中性
  6. w_t       = shaped / Σ|shaped|                    # 单位 gross
```

**σ 的定义(逐字, 这里出错会静默改变一切):**
- 取面板 `wide_dl_full_fundfix.npz` 的 `CH[t, m, idx('rvol_72h')]`, `m` = 该锚的 tradeable 集合;
- 非有限或 ≤0 的值 → 用该锚横截面中位数填补;
- **下限截断: `σ = max(σ, 该锚横截面的 p05)`**;
- **不截上限。**

评估:
```
gross_t = Σ_s w_{s,t} · Y4[t,s]        (仅 finite)
turn_t  = Σ_s |w_{s,t} − w_{s,t-1}|    (全 N 空间, 缺席记 0)
net_t   = 1.0 · (gross_t − turn_t · 1.9e-4)
```
`ΔNet` = 逐月对 `net_t` 求和后相减;`t_eff = t_raw/√infl`, `infl = 1 + 2·Σ_{k=1..12} max(ρ_k, 0)`(ρ 为逐月序列的自相关)。

### 2.2 三个可以不依赖我的代码就做的交叉检验

**X1 — σ 的方向性自检(最便宜, 且能抓住符号错误).**
计算 `corr(|w_s|, σ_s)` 逐锚均值。**λ=0 应 ≈ +0.097;λ=1 应 ≈ −0.199。**
**若 λ=1 的相关不是负的, 说明 σ 用反了(乘而非除), 此时 R1/R2 全部无意义。** 这一步不需要跑回测, 只要建书。

**X2 — 反向构造必须变差(证伪自检的独立重做).**
用同一实现跑 **λ = −1**。**必须得到: 风险贡献 top1 ≈ 0.1092(比 λ=0 的 0.0556 翻倍), 逐锚 P&L top1 ≈ 0.1379, netSum ≈ 8.13(低于 λ=0 的 9.88)。**
**若 λ=−1 没有变差, 说明整个 σ 通路是惰性的(σ 根本没进书), 而 λ=+1 的"改善"就只是重跑噪声。** 这是最强的单项检验, 我建议**先做这个**。

**X3 — 安慰剂的零点(R3 的独立重做).**
把四条腿的信号在**锚内横截面打乱**后跑同一 λ=1.0 与 λ=0, 取 ΔNet。**应 ≈ 0(|ΔNet| < 0.05)。**
**若打乱后仍得到显著为正的 ΔNet, 则收益改善不依赖 alpha, §A5 的部署理由必须改写。**

### 3.2 ★ 请重点看这五处 (我认为最可能出错的地方, 按危险度排序)

1. **`VolScaled.shape_position` 里的顺序: cap → 除 σ → demean。**
 顺序换成"除 σ → cap"会先把被放大的低波动名字裁掉, 效应大部分消失;换成"demean → 除 σ"会破坏市场中性。**顺序是预注册写死的, 请核对代码与 §2.1 第 3–5 步一致。**
2. **σ 的暂存跨锚风险。** σ 在 `leg_signals(t)` 里算好存进 `self._sig`, 在**同一轮**的 `shape_position()` 里消费。这依赖 `engine/netting.py` 的 `run()` 在单次循环迭代内**先调 `leg_positions` 再调 `shape_position`**(已核: `netting.py:49` 与 `:59`)。
 **若 netting 被改成并行、或跨锚缓存 legs, 这个暂存会串锚 —— 那是一个静默的、结果仍然"好看"的错误。** 请确认这两行仍在同一个 `for` 体内。
3. **`λ=0` 分支必须完全跳过 σ。** 代码里是 `if self.lam:` —— 若某次改动让 λ=0 也走了 σ 路径(例如 `if self.lam is not None`), 基线就被污染, ΔNet 全部失真。
4. **`Y4` 的 NaN 处理。** `gross` 只对 finite 求和, 但 `turn` 在全 N 空间上算(缺席记 0)。这两个口径不同是**故意的**(与 `engine/replay_fullhist.py` 一致: 补零在点积里无害、在秩相关里有害), 但如果复现方把 turn 也限制到 finite 集合, 成员进出会被少算换手。
5. **安慰剂的打乱轴。** `np.random.default_rng(...).shuffle(v)` 作用在**成员轴**上, 且 seed 依赖锚点 `t` ⇒ 每个锚独立打乱。**若打乱变成跨锚共用一个排列, alpha 不会被完全破坏, 安慰剂就会假性显示效应。**
