# PREREG — 窗口特异性: plain 的 −0.053 是不是【那条】泄漏

## 0. 上一次为什么失败, 以及这次改了什么

上一版想把 `leak` 拆成"可预测/不可预测"两半, 但**没有断言拆分真的发生了** —— 预测器样本外 R² ≈ 0 ⇒ `leak_unpred ≈ leak` ⇒ 规则复述了输入。
**登记的通用教训: 任何"把 X 拆成 A+B 再分别相关"的设计, 必须先断言【拆分真的发生】。伙伴判据(防"读数是装置造的")与有效性判据(防"装置没有分辨率")是两件事。**

**本版不做拆分, 改测【定位】。** 那条泄漏是**恰好** `market[t+1…t+11]` 这 11 个抽头(中心卷积 `np.convolve(...,"same")` 的前视臂)。**一条真的残留泄漏通路必须对这个特定窗口敏感**; 一个与"未来市场"泛泛相关的关系不会。

## 1. 装置

```
对偏移 Δ ∈ {0, 11, 22, 33, 44, 66, 88, 110} (单位: 小时):
    W_Δ[t] = Σ market[t+1+Δ … t+11+Δ]        ← 把那 11 抽头整体推向更远的未来
    c(Δ)   = corr(tilt, W_Δ)
参照(非判据, 只为读图): Δ = −22 (推向过去, 应落在 causal 那一族)
CI: 与 §8-2 同款 moving-block bootstrap (block=60, nboot=2000)
tilt / market / 重抽样: import `measure_lookahead_exploitation_s1`, 不复制
```

## 2. ★★ 有效性判据(先判; 不过则全表作废, 这是上一版缺的那一条)

**冻结(脏) run 必须在 Δ=0 处出现【尖峰】:**
```
peak_drop = c(0) − mean(|c(Δ)| for Δ ≥ 44)
frozen_plain 与 frozen_xattn 的 peak_drop 都必须 > 0 且 bootstrap CI 排除 0
```
理由: 它们**确实**吃了 `market[t+1…t+11]`, 若把窗口推远 4 倍其相关不下降, 说明本装置**分辨不出窗口**, 那么它对 clean 的任何读数都不承载信息。**不过 ⇒ 全表作废, 选臂不由本文推进。**

## 3. 伙伴判据(与有效性判据并列, 不可互相替代)

冻结 run 在 Δ=0 的 c(0) 必须**显著为正**(重复 §8-2 已知结论)。
—— 有效性判据答"仪器有没有分辨率", 伙伴判据答"读数是不是装置造的"。**两条都要过。**

## 4. 判读规则(预写死)

对 `clean_plain`(唯一待判者; `clean_xattn` 同表报出作一致性检查):

| 条件 | 结论 |
|---|---|
| §2 或 §3 不过 | **全表作废** |
| plain 的 `peak_drop` **CI 排除 0**(即 Δ=0 处显著更强) | **(b) 窗口特异 ⇒ 是【那条】泄漏的残留通路 ⇒ plain 出局, 上 xattn** |
| plain 的 `peak_drop` **CI 含 0**(即 c(Δ) 随 Δ 基本平坦) | **(a) 非窗口特异 ⇒ 不是那条泄漏, 而是与"未来市场"的泛泛关系 ⇒ §8-2 对 plain 的『不过』不构成泄漏证据, plain 清白** |

**★ 符号说明(预写, 免得事后解释): plain 的 c(0) 是【负】的, 冻结 run 是【正】的。`peak_drop` 对 plain 用 `|c(0)| − mean(|c(Δ≥44)|)` 的绝对值形式**, 因为本判据问的是"强度是否集中在该窗口", 不是"方向"。方向本身是另一个未解释的现象, 单独登记, 不在本判据内。
