# 预注册 — 波动缩放 sizing (vol-scaling)

**假设:** 当前链 `rank → cap → demean → L1` 中**没有任何 σ 项** ⇒ 相对于对角协方差下的最优解, 系统性超配高波动名字。

**★ 与已被证伪的"幅度 sizing"的区别(采纳 team-lead 的论证, 并补一条):** 被证伪的是**用 alpha 幅度**(isotonic, 净 −1.3), 失败原因是 alpha 幅度估计不可靠;波动的估计精度高一个数量级, 那条证伪不迁移。**补一条: 已摘除的 size 腿是 `−log(dvol30)` = 成交额(流动性), 与波动是不同的量 —— 但两者在横截面上相关, 因此本检验必须报告 vol-scaling 的效果在多大程度上只是把 size 腿以另一种形式装回来**(见 §5-G7)。

## 1. 先记录一处与派工前提不一致的实测 (在冻结判据之前写下, 因为它改变预期幅度)

派工给出的实盘读数是 `1000RATSUSDT 波动 31.75%` vs `TRXUSDT 波动 0.03%`, 比值 **~1000×**。
**面板实测的横截面波动离散度远小于此**(2026 年中某锚, N=110 成员):

| 度量 | min | 中位 | max | max/min |
|---|---|---|---|---|
| `rvol_72h`(面板通道) | 0.0040 | 0.0137 | 0.0404 | **10.1×** |
| 尾随 720h 的 `Y4` 标准差(我自算, 原始收益单位) | 0.0061 | 0.0183 | 0.0440 | **7.2×** |

⇒ **面板口径下的波动离散度是 7–10 倍, 不是 1000 倍。** 0.03% 的"波动"作为 30 日已实现波动不可信, 更像单锚/单日读数。
**这不否定派工的结构性论点**(`corr(名义额, 波动) ≈ 0` 说明书是等金额), **但它把预期效应的幅度下调了一个数量级**: vol-scaling 能改变的相对权重跨度是 ~7–10 倍, 不是 ~1000 倍。**本预注册的所有阈值按 7–10 倍的离散度来设, 若按 1000 倍设会全部落空。**

## 3. 候选集 (现在写死;**不扫参数**)

在现有链的**尾部**应用, 顺序固定为 **`combined → cap → 除以 σ^λ → demean → L1`**(除法插在 cap 之后、demean 之前, 以保持市场中性由 demean 承担):

| 代号 | λ | 含义 |
|---|---|---|
| **SQ** | **0** | 现状等金额(强制基线) |
| **VS-0.5** | 0.5 | 中间形态 / 收缩 |
| **VS-1** | 1 | **理论解 A**: 若 score 预测的是**波动归一化**收益(`μ_i = c·s_i·σ_i` ⇒ `w* ∝ s_i/σ_i`) |
| **VS-2** | 2 | **理论解 B**: 若 score 预测的是**原始**收益(`μ_i = c·s_i` ⇒ `w* ∝ s_i/σ_i²`) |

**★ λ=2 是我在派工清单(0.5, 1)之外加的, 理由在见数据之前写下: 对角协方差下 `w* ∝ μ_i/σ_i²`, 而 `μ_i` 与 `s_i` 的关系有两种可能, 它们分别对应 λ=1 与 λ=2。只跑 {0.5,1} 会把 λ=2 这个同样有理论依据的假设排除在外, 而两者的判别正是本检验最有信息量的部分。** 加入它不是扫参数: 网格由理论端点决定, 且在见数据前固定。**运行中出现的任何第五个 λ 一律不认。**

## 5. 判据 (先写后算)

### 5.1 ★ 安慰剂在这里的角色与 ALT 门**不同**, 现在说清楚

在 `RESULT_alt_weights_2026-08-02.md` 里, 安慰剂检验的是**伪影**: 零 alpha 的东西被记成贡献 ⇒ 安慰剂显著即尺子坏, 结果作废。
**这里不是。vol-scaling 是一个风险陈述, 它在 alpha 为零时**本来就应该**改善风险结构 —— 那不是伪影, 那是它的机制之一。** 因此:

- **安慰剂的 ΔSharpe = 纯风险重分配效应**(与 alpha 无关, 打乱信号也能拿到);
- **真实 − 安慰剂 = alpha 交互效应**(vol-scaling 与我们的信号是否互补)。
- **两者都要报, 且必须分开命名。禁止把总效应说成 alpha 改进。**

### 5.2 三条互斥的结论形态 (先写死)

| # | 形状 | 结论 |
|---|---|---|
| **A. alpha 改进** | `真实 ΔNet − 安慰剂 ΔNet > 0` 且该差的 `t_eff ≥ 3` | vol-scaling 与我们的 alpha **互补**。按"alpha 改进"上报。 |
| **B. 纯风险改进** | A 不成立, 但**安慰剂自身**的 ΔSharpe > 0 且 §4-4 的最大单名占比下降 ≥ **10 个百分点** | 这是**风险结构改进, 不是 alpha 改进**。**仍可采纳**, 但必须以"风险重分配"之名上报, 且不得引用任何 alpha 论证。 |
| **C. 无改进** | A 与 B 均不成立 | NO-GO。 |

### 5.3 GO 的硬条件 (A 或 B 成立后**仍须**全部满足)

| # | 条件 | 阈值 |
|---|---|---|
| **G2** | 净 Sharpe 相对 SQ 提升 | `ΔNet` 合计 > 0 且 `t_eff ≥ 3` |
| **G3** | **风险结构不得恶化** | 最大单名 P&L 占比**不得上升**;前 5 名占比不得上升 |
| **G4** | **★ 派工点名的反面: IC 不得因此塌** | 书的全历史 rank-IC 相对 SQ 下降 **≤ 10%(相对)** |
| **G5** | 成本稳健 | `ΔNet` 在 **5.92–8.71 bps** 区间内任一点仍 > 0 |
| **G6** | **★ 派工点名的另一面: 地板交互** | 在 gross 4,285 下, 低于有效地板的名字数**增加 ≤ 3 个**(现状实测 10–16) |
| **G7** | **不得只是把 size 腿装回来** | `corr(λ 引入的权重变化, size 腿信号)` 必须报告;若 `|corr| ≥ 0.7`, 结论须改写为"等价于恢复 size 腿", 并与 `PREREG_size_leg` 的已有结论对质 |
| **G8** | 两个 σ 窗口同号 | `rvol_72h` 与 `rvol_24h` 的 `ΔNet` 符号一致 |

**任一条不满足 ⇒ NO-GO。** NO-GO 的默认动作是**维持现状**, 本门不产生折中 λ。

### 5.4 λ 的选择规则 (防止事后挑 λ)

**若多个 λ 同时满足 GO: 选 `t_eff` 最高的那个, 而不是 ΔNet 最大的那个。** 理由先写下: ΔNet 最大值在 4 个候选里是一个极值统计量, 会系统性偏向噪声最大的那个 λ;`t_eff` 已含离散度惩罚。

## 6. 明写: 本门放弃了什么

1. **σ 用的是 72h 窗, 不是派工要求的 30 日窗 —— 面板里没有那个通道。** 若 30 日窗的结论不同, 本门测不出来。
2. **只在链尾做标量缩放, 不做真正的协方差优化。** 对角协方差是一个假设; 名字间的相关(尤其 BTC-beta)完全没被处理, 而那可能是比单名波动更大的风险源。**本门不宣称做了风险模型。**
3. **不扫 λ**(§3), 因此不会知道最优 λ, 只会知道 4 个点里哪个更好。
4. **全部基准仍是建模成本 1.9 bps**, 实测成本只用于 G5 的稳健性。
5. 面板波动离散度是 7–10 倍(§1), **因此即便 vol-scaling 完全正确, 它能带来的权重重排幅度也是有界的** —— 不要期待数量级的改变。
6. **地板交互只在当前 gross(4,285)下测一个点**, 不做 gross 曲线。
