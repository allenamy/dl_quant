# PREREG — 跨场所族(Hyperliquid vs Binance)

## 0. 为什么是这一族, 以及它凭什么排在 C2 前面

`#21` 宽度门零录取后, 预注册自己写的转向是「资金费率族 / 期限结构族」。今日实测:
- **期限结构: 当场划掉** —— 110 宇宙里只有 **5 个**有季度合约(BTC/ETH/BNB/SOL/XRP), 做不成横截面腿。
- **C2(basis⟂funding): 三关全过但只值 +0.1 bps/锚**, 且前向配对差需 ≈12 天。
- **跨场所: 81/110 交集, 2.2 年逐小时历史, 可【离线立判】** —— 不需要前向等待。

**⇒ 它是目前唯一"数据齐、历史够、今天就能判"的候选族。**

## 1. ★ 必须先钉死的口径: 逐笔间隔归一

HL funding 是**逐小时**; Binance 是**离散结算**。**今日实测 81 个 symbol 的结算间隔分布:
4h = 138,005 笔 · 8h = 128,941 笔 · 1h = 1,602 · 2h = 1** —— **4h 与 8h 各占约一半。**

⇒ **若按统一 8h 处理, 一半数据差 2 倍。** 这正是记忆 `funding_settlement_interval_unit_bug`
造出假 −0.006 rank-IC 的机制。且 `config/funding_span_table.json` 自己的注释写着
「实测 2026-07-26, **15 个我们仍标 8h 的名字在生产上已是 4h**」⇒ **静态表不可用。**

**本族一律用**: `per_hour_rate = fundingRate / interval_h`, 其中 `interval_h`
**由相邻结算时间戳的间距逐笔算出**(对迁移自动免疫)。产物 `bn_funding_settlements.npz`
的 `INTERVAL_H` 即此。**任何不带这一步的读数一律作废。**

## 2. 候选与机制

**H1 · funding 背离** = `rank_centered( hl_per_hour − bn_per_hour )`, **sign −1**
 **机制**: 同一个永续在两个场所, funding 差 = **两批用户的定位分歧**。HL 更偏散户/高杠杆,
 Binance 混合。HL funding 显著高于 Binance ⇒ HL 侧多头更拥挤 ⇒ 拥挤反转。
 **★ 它是【差】不是【水平】⇒ Binance 的水平(= 在役 funding 腿交易的东西)按构造抵消。**
 这与 C2 成功的设计逻辑同源。

**H2 · premium 背离** = `rank_centered( hl_premium − bn_premiumIndex )`, **sign −1**
 **机制**: 纯基差错位, 不含 funding 的封顶与结算离散化。

**★ 符号由机制预定, 不做搜索。`+1` 臂仅作诊断, 永不用于录取。**
**★ 无自由参数**: 不加 EMA、不调 winsor、不搜 cadence。cadence 预定 **8h**(与在役 funding 腿同)。

## 3. ★ 预先声明的三条预言(写在跑之前)

| # | 预言 | 会红的方向 |
|---|---|---|
| **P1** | **H1 过关三**(与在役三腿逐锚净额 \|ρ\|<0.3)—— 因为它是差, Binance 水平已抵消 | 若不过 ⇒ "差可抵消水平"这个设计逻辑失效, **C2 的录取依据同时受质疑** |

## 4. ★ 覆盖偏差(本族最可能的死因, 先写出来)

HL 只覆盖 **81/110**。而 HL 上市的多半是**更大更流动**的币 ⇒ **"有 HL 数据"这件事本身就与 size 相关**。
无 HL 数据的 29 个名字权重为 0 ⇒ **这条腿在构造上就是一个子集下注**。
**⇒ P3 是本族的专属门, #21/round2 都没有这一条。** 不过 P3 ⇒ 不录取, 无论 IC 多好。

## 5. 两阶段判据

### 阶段 A(本机, **不需要 jpline**)—— 决定值不值得排队
数据: `hl_funding_hourly.npz` · `bn_funding_settlements.npz` · `bn_klines_1h.npz`(全部已在本机)
- **A1 独立 IC**: 4h 前向收益(klines 收盘价)上的逐锚横截面 rank-IC, 全期 + 逐年
- **A2 换手画像**: 8h cadence 下的逐锚换手
- **A3 与 Binance funding 水平的相关**(P1 的廉价前哨)
- **A4 与 size 代理的相关**(P3; size 用 `−log(dollar volume)`, 由 klines 量重建)
- **门**: A1 全期 rank-IC 的 day-block CI 下界 > 0 **且** A4 的 \|ρ\| < 0.3
  ⇒ 才进阶段 B。**否则当场关闭, 不占 jpline 的窗口。**

### 阶段 B(需要 jpline)—— 正式宽度门
逐字沿用 `PREREG_breadth_round2_basis` 的三关(关三先跑)+ 实盘同构记账 + 同槽位安慰剂 5 种子。
**阈值一字不改。**
