## 1. 判据(三问, 按顺序)

泄漏的形式是**每锚一个标量** `mkt24[t]`(含 11 项未来市场收益), 它在横截面去均值的书上**只能通过与 `beta_i` 交互表达**。⇒ 逐条结论问三个问题:

```
Q1  这个结论的数字, 是不是从 king/s2 的输出(或其构成的书)算出来的?
      否 -> 走 Q3
      是 -> 泄漏在 CH 里, CH 喂 king/s2 => 结论继承一个 beta-择时成分 -> 走 Q2
Q2  这个数字是【水平】还是【两个都含泄漏的臂之差】?
      水平(Sharpe / IC / PnL / 净成本门) -> 【A 类: 污染, 须重估】
      差值(A/B 对照, 且两臂同面板同模型)  -> 【B 类: 泄漏可能大部分对消, 但【不得假定】, 须逐案检验】
Q3  它是否触及 beta / 市场暴露 / 全名字共同因子的择时?
      是 -> 【A 类】     否, 且纯横截面 idio 或非 DL 腿 -> 【C 类: 影响小】
★ 凡数字完全来自【实盘数据】(pilot_log / 实盘 mid / 场所回读) -> 【D 类: 干净】, 不受影响。
```

**★ B 类是本清单最有价值的一格, 也是最容易被两个方向搞错的一格:**
**说它干净是错的**(泄漏经 beta 表达, 而两臂若改变了 beta 暴露的分布 —— 例如 vol-scaling 按 1/σ 调仓, 而 σ 与 beta 相关 —— 泄漏就不会对消)。
**说它和 A 类一样脏也是错的**(共同成分确实会消掉大部分)。**必须逐案检验, 检验方法见 §4。**

## 4. B 类的检验方法(便宜, 不需重训)

对任一"两臂之差"型结论:
```
1. 用 §9 的三口径机制, 把该结论在【TRAIN 口径】与【SERVE 口径】下各算一次
   (SERVE = 实盘实际拿到的, 即无泄漏的那一版)
2. 若两个口径下的【差值】基本不变 -> 泄漏确实对消, 结论可保
3. 若差值显著改变 -> 该结论落入 A 类
```
**成本: 每个结论一次离线重跑(冻结模型, 不重训), 与 §9 同量级。**
**⇒ 建议第一个跑 vol-scaling 的 ΔNet —— 它支撑今天的部署, 且它是 B 类里唯一有明确机制理由担心不对消的(σ 与 beta 相关)。**

**度量(与 §11 判别检验同款):**
```

前视利用度 = corr(tilt, leak)        (对照: corr(tilt, 因果项))
```
