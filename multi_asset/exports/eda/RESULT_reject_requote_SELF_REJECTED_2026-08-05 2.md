# RESULT — `-5022` 重挂提案: **否决**。拒绝不是缺陷, 是一个对我们有利的选择机制

## 1. 结论

**不改。** 期望净 edge **−7.30 bps vs 现状 −6.53 bps**, 即**亏 0.77 bps**。

## 2. 算式(全部来自 5 天实盘成交记录, 非模拟)

```
现状(拒 → taker 接)         净 edge = −1.53 − 5.0(taker费) = −6.53 bps
重挂【成交】                净 edge = +1.96 − 2.0(maker费) = −0.04 bps
重挂【未成交】→ partial     净 edge = −40.04 − 5.0        = −45.04 bps
盈亏平衡成交率 p* = (−6.53 −(−45.04)) / (−0.04 −(−45.04)) = 0.8558
实测成交率      p  = 42,321 / 50,468(真正挂上去过的 maker, 按名义) = 0.8386
期望 = 0.8386×(−0.04) + 0.1614×(−45.04) = −7.30
```

## 3. 机制(为什么直觉是反的)

**两族补单的经济性差 26 倍, 混在一起看会得出相反结论:**
```
topup/from_reject   13,343 USDT   −1.53 bps  (中位 +3.12 ← 正值)
topup/from_partial   3,637 USDT  −40.04 bps  (中位 −28.59)
topup/未标源         2,290 USDT  −28.21 bps
[混合读数 −11.97 是两族混出来的, 不可引用]
```
`from_reject` **便宜是因为它不含逆向选择** —— 订单在提交时就被拒, 与"市场是否跑开"无关。
`from_partial` **贵正是因为逆向选择** —— 挂单没成交, 恰恰因为价格跑开了。
**⇒ 把拒绝单转成挂单, 等于把一族没有逆向选择的量, 送进有逆向选择的那一族。**

## 4. 不对称风险(即使判据擦边也不做的理由)

- 下行: 若真实成交率低于 0.8386(样本 5 天), 亏损**随差距线性放大**, 无界。
- p 与 p* **只差 1.7 个百分点**; `−40.04` 仅 n=103。**判据擦边 + 下行厚尾 ⇒ 不做。**
