# 预注册 — champion 在 SERVE 口径下是否仍胜(写在看到数之前)

**为什么要写这份:** 今天已经两次出现「机制故事跟着结果走」——(i) 派工的 L3 预判被证伪, (ii) 我自己的反向 L3 又被 team-lead 的独立算法质疑, 最后靠 n=6 功效才判明。**⇒ 在这一件上, 我把预期先钉住, 免得事后无论哪个方向我都能讲出一个自洽的故事。**

## 1. 参赛者(证据来源: 加冕脚本, 非记忆)

## 2. 我的先验(**方向性, 可被证伪**)

> **我预期 champion 在 SERVE 口径下的优势会【缩小】, 且缩小幅度大于 lam0 自身的退化。**

**机制理由(写在前面, 所以它不是事后编的):** 泄漏是**每锚一个共同标量** `mkt24[t]`, 且 `betaadj_ret24` 在横截面上是 `ret_24h`/`beta_24h` 的**精确恒等式**(journal §10)⇒ 该标量是**可恢复的**。**cross-asset attention 恰恰是「让每个 asset 看到所有其它 asset」的模块 —— 它是横截面聚合器, 而恢复一个共同标量正需要横截面聚合。** ⇒ 先验: xattn 使 champion 比 lam0 **更擅长**利用这条泄漏, 因此它的优势中泄漏成分占比更高, 去掉泄漏后优势应更多地蒸发。

**已知的旁证(不是证明):** 污染面清单 §7-2 实测部署 champion 的 `corr(倾斜, 泄漏)` = **+0.2518**, 高于候选中位 ≈ +0.11。**但那没有和 `lam0_5yr` 比过** —— 本实验才是那个对照。

## 3. 判读规则(先写死, 免得事后挑)

设 `margin(cal) = rank-IC(champ) − rank-IC(lam0)`, 逐锚配对, 同一批锚。

| 结果形态 | 读法 |
|---|---|
| `margin(SERVE) > 0` 且 day-block 95% CI 不含 0 | **champion 在实盘口径下仍胜。选型结论站得住。** |
| `margin(SERVE)` CI 含 0, 而 `margin(TRAIN) > 0` 且 CI 不含 0 | **优势只在含前视的口径下存在 ⇒ 选型证据被污染, 须重估。** |
| `margin(SERVE) < 0` 且 CI 不含 0 | **在实盘拿得到的信号上 champion 反而更差。** |
| 两个口径 margin 都含 0 | **两者本来就分不开**, 当年的 +41% 需要重新解释。 |

**`margin(SERVE) − margin(TRAIN)` 的 day-block CI 是主判据**(它直接量「优势有多少依赖前视」), 单看两个 margin 各自的显著性是次要的。

## 4. 本实验**不能**回答的(明标)

1. **不回答「重训后谁更好」。** 三个模型**都是用泄漏训出来的**;我只是喂它们实盘口径的输入。**「没有泄漏时 xattn 是否仍值得」需要重训, 本实验测不了**(与审计 §9-3 同一条保留)。
2. **只换 ch31。** 若 champ 与 lam0 对其它通道的依赖不同, 测不出来。
3. **qim 不是受控对照**(不同头类、不同损失), 它的差里混着模型类差异。
4. **SERVE 在全历史面板上是构造口径**(逐行按「假如这是最后一行」), 不是面板自然状态。
5. 选型当年用的是 `YR4`(残差目标)+ 书级 Sharpe/blend 规则, **不只是 rank-IC**。本实验只复核 rank-IC 这一个维度, **不重跑当年的完整加冕判据**。
