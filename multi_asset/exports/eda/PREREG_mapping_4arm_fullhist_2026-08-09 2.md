# PREREG — 仓位映射四臂 · 9821 锚 · 用【实盘的书】

## 0. 为什么必须重跑(不是重复劳动)

今日发现: **实盘 `signal/legs.py::compose_book` 的整形是 `cap99 → demean → [风险预算] → l1`,
其中 `|s|^0.5` 只通过风险预算的 α 进来**; 而我早上在引擎 `SignalChain.shape_position` 上做的五臂,
假设了整形自带 0.5 次幂并用 `**2.0` 去"还原"。**两者不是同一个对比。**
⇒ 早上那组五臂与 R 三臂的结论**只对引擎口径成立**, 对实盘不可直接引用。本门用实盘的书重做。

**已知的冲突(本门要解的就是它)**:
- 引擎口径 9821 锚: R-on 净@3.115 **−1.100** 优于 R-off **−1.563**
- 实盘口径 50 锚: 新模型 M0 线性 **+4.311** 优于 M3 在役 **+1.158**

## 1. 臂(冻结, 四个, 不加不改)

装置 = **实盘 `compose_book`**(import, 不重写), 在役三腿权重, 面板 = 引擎回放源(2022-01→2026-06),
DL 分数 = **在役世代 newgen**(服务器上只有它)。**只变 `risk_budget`:**

| 臂 | α | λ | 含义 |
|---|---|---|---|
| **M0** | 1.0 | 0.0 | 线性(代码定义的 no-op) |
| **M1** | 0.5 | 0.0 | 只压幅度 |
| **M2** | 1.0 | 1.0 | 只除波动 |
| **M3** | 0.5 | 1.0 | **在役** |

**无参数搜索**: α∈{0.5,1.0}, λ∈{0,1.0}, 就这四格。**不加 λ=0.5, 不搜 α。**

## 2. 前置断言(不过则本门作废)

**P1 同码**: jpline 上的 `legs.py` 与 `~/dl_quant_live/signal/legs.py` **SHA256 逐位相同**(两端各算一次并打印)。
**P2 M3 复现**: M3 臂的毛额/换手必须与今日引擎口径的 S0 基线(**+1.832 / 0.4707**)**在 ±15% 内**;
 若不在, 说明两套装置的差异不止风险预算一处 ⇒ **报告差异, 不得把两者的数字混用**。
 (★ 这条**预期会红**, 因为引擎的 `shape_position` 与 `compose_book` 本就不同; 红了不是失败, 是把差异定量。)

## 3. 判据(钱优先, 顺序固定)

**G1 净额**: 每个候选(M0/M1/M2)对 M3 的 `Δ净@3.115` 与 `Δ净@5.8`, 日块 bootstrap(块长5) CI95。
 **两档都要 CI 下界 > 0 才算"优于在役"。** 任一档覆盖 0 ⇒ 该臂判**不优于**。

**G2 逐年**: `Δ净@3.115` 逐年 ≥0 的年份占比 **≥80%(4/5)**。

**G3 净夏普**: 两档成本各报 `均值/sd × √(6×365)`。**G1 通过但净夏普更差 ⇒ 判"不采纳"**
 (风险预算当初就是拿 IC 换风险被接受的, 只看均值是把它的理由删掉)。

**G4 与 50 锚的一致性**: 报告 9821 锚与 50 锚的排序是否一致。
 **不一致 ⇒ 以 9821 锚为准**(本文事前裁定, 与 `PREREG_risk_budget_relitigation` §4 同规则)。

## 4. ★ 会红的方向(先写)

- **最可能: M0/M1/M2 都在 G1 上挂**, 因为 9821 锚里毛额只有约 1.8 bps 而换手成本约 2.9 bps
  ⇒ **凡是抬毛额的映射都会抬换手, 而在这个信噪比下换手总是吃得更多**(今日已四次实测同一形态)。
- **次可能: M2 在 G1 过而 G3(净夏普)挂** —— 除波动是降风险的, 关掉它均值可能升但 sd 也升。
- **我预期 50 锚与 9821 锚不一致**, 因为 50 锚窗口四臂全是净正而 9821 锚净负。**那时以 9821 为准。**

## 5. 本门不建立什么

- **不建立实盘改动。** 即便某臂全过, 改风险预算是书行为改动, 需独立预注册 + **用户裁定**
  (它当初的判据就是用户定的, 见 `PREREG_risk_budget_2026-08-05` 69dba0ad)。
- 不建立"根因已确立" —— 本门只判映射优劣, 不判换装归因(那是 `PREREG_2x2_swap_attribution` 的事,
  且其 G2 已判**未能归因**: 交互占 94% 但 CI 含 0)。
- 不测两代对比(服务器无 old-gen 分数)。
