## 四个发现

**1. 名义加权均值 = 3.63 bps, 而它分解为【手续费 2.85 + 滑点 0.78】。**
成本的 ~79% 是手续费(结构性、随换手线性、逐锚稳定); 滑点均值只有 0.78 但**逐锚极散**。
⇒ **压成本-每元成交 的空间几乎只在滑点与费率档; 压【总成本】的真杠杆是换手(cadence)。**

**2. 逐锚 sd = 4.44 bps ⇒ SE(均值) ≈ 1.11 ⇒ 点估计 3.63 的 95%CI ≈ [1.5, 5.8]。**
两个锚是**负成本**(−3.45/−5.00: maker 吃到价差+顺向漂移)。⇒ **"成本 3.79"从来不是一个准数, 它带 ±2 bps 的置信带** —— 所有 gap_to_clear 都必须对着这个带读, 不是对着点。

**3. ★ 趋势分档【不存在 0.84/4.48 结构, 方向还反了】:**
```
|BTC 4h| < 50bps(更平静):  n=7  wavg 4.12
|BTC 4h| ≥ 50bps(更趋势):  n=8  wavg 3.33      ← 趋势锚反而【便宜】(n 小, 差 0.8bps 属噪声)
```
⇒ 在这个(已记录阈值的)标签下**没有** 5× 结构。§17 的"平静 0.84 / 奔跑 4.48"若真实存在, 用的是**另一个未记录的标签**。

**4. ★★ 3.79 本身也无法复现: 同口径 last-11 窗口 = 2.73**(全窗 3.63)。差 39%, 且窗口平移 ±2 锚仍在 2.6–2.7。§17 计算**无持久化产物、无记录阈值** ⇒ 无从对账。

## 裁定

**§17 成本块(3.79 / 0.84 / 4.48)整体退役, 不再被任何决策引用。** 替代口径:
```
实测成本 = 3.63 bps [95%CI 1.5, 5.8], 其中手续费地板 2.85
gap_to_clear 一律对 3.63 与 CI 上界 5.8 双报
```
**位置关系随之变**: 干净书 k=.595 的 BE 3.639 与点估计 3.63 **打平**("水下 4.1%"是对着退役数说的); cadence 信封 5.6–6.0 过点估计 +55%, **但未完全清出 CI 上界 5.8** —— 书级实验(#17)按双靶报。

## 限制

n=16 且**全部 vol-calm**(试点从未在 normal/stress 交易); 趋势标签用同期窗(仅归因); 手续费占比意味着 maker/taker 份额是下一个可分解轴(未做); 本重建自身的口径若与 §17 未记录的口径不同, 差异不可仲裁 —— **这正是"无记录口径的数字必然退役"的理由, 而非本表正确性的证明**。
