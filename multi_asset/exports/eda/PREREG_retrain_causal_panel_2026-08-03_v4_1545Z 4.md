## 4. ★ S1 的具名假设(写死在看结果之前 —— 这就是预注册存在的意义)

> **H-ATT:** 泄漏在横截面上是**每锚一个共同标量**(已证: `betaadj_ret24` 横截面 R²=1.0000, 泄漏只能经 `beta_i` 交互表达)。**cross-asset attention 恰是最擅长提取横截面共同信号的模块。⇒ 当年 attention 相对无 attention 的 +41% 优势, 有相当部分是对泄漏的收割; 干净面板上该优势将大幅缩水。**

**判别(三分, 先定死):**

**`margin_dirty` 的定义(v4 裁定, 取代 docstring 的 +41%):**
```
margin_dirty := C3 16:42Z 对照产出的【TRAIN 口径】champion − lamorth0 边际
                目标: YR4 为主判(加冕当年用的是残差目标), Y4 并报
                出处: 该文档落盘 SHA(冻结本文时该文档尚不存在)
margin_clean := 干净面板重训后的同口径边际
```

**★ 为什么不用 docstring 里的 +41%(这条理由比"它没出处"更深, 是 team-lead 指出的):**
> **+41% 是一个【转述的历史数】, 而 H-ATT 的 dirty/clean 两侧应当出自【同一测量装置】(同折、同网格、同记录分数法)。否则 margin 的变化里混着装置差 —— 而我们要测的是泄漏差。**

**⇒ 这与今天反复出现的是同一族**(池化 vs 横截面 / 合成指数 vs 真价格 / 兄弟 run): **两个数各自都对, 但它们不是被同一把尺子量出来的, 于是它们的差不是被问的那个差。** 我原稿只标了"+41% 无出处" —— **那是一个更浅的诊断: 问题不在于它缺一张出生证, 而在于它和对照方不同源。**

**三分阈值(0.5× / 0.8×)作用在这个新的 `margin_dirty` 上, 阈值本身不变。**

| 结果 | 判定 |
|---|---|
| `margin_clean < 0.5 × margin_dirty` | **H-ATT 成立** —— attention 优势相当部分是收割泄漏 |
| `margin_clean ≥ 0.8 × margin_dirty` | **H-ATT 证伪** —— attention 优势是真的 |
| 之间 | **不决定性** —— 两种成分都在, 幅度未定, 不得单向表述 |

**★ 两件必须一起说:**
1. **H-ATT 成立 ≠「attention 无用」。** 两者可同时为真: attention 既真有用, 又同时收割了泄漏。**三分里的"不决定性"就是为这种情形留的, 不得被压成二选一。**
2. **`margin_dirty` 的来源文档在本文冻结时尚不存在**(C3 排期产出), 判别须等它落盘。

### 4-2 ★★ 按 team-lead 的"同一装置"逻辑往下推, S1 现设计里还留着同一个问题

**裁定 1 把 `margin_dirty` 从"转述的历史数"换成"C3 的同折测量", 消掉了【测量法】的装置差。但还剩一层没消:**

```
margin_dirty : 用【当年训好的】checkpoint(lamorth0_xattn_5yr / lamorth0_5yr), 脏面板
margin_clean : 用【本次新训的】模型,                                   干净面板
                    ^^^^^^^^^^^^^^  这一侧换了 run 世代
```

**⇒ `margin_clean − margin_dirty` 里混着两样东西: (i) 泄漏被移除; (ii) 重新训练一次的 run-to-run 变异(不同初始化/不同训练轨迹)。** 后者未被控制。

**两个选项, 我不自选:**

| 选项 | 做法 | 代价 | 后果 |
|---|---|---|---|
| **A(现设计)** | dirty 侧用历史 checkpoint | 省一半机时 | **H-ATT 结论必须带"含 run 世代混杂"限定词**; 若 margin 变化幅度与 run-to-run 变异同量级, **三分判不出来** |
| **B(2×2)** | S1 同时在【脏面板】上用同协议重训两架构 ⇒ 2×2(xattn/无 × 脏/干净), 四臂同世代 | **S1 机时翻倍** | 装置完全对齐, `margin_clean − margin_dirty` 是纯泄漏效应 |

**⇒ 需 team-lead 裁。** 我的观察: **若选 A, 至少应有一个 run-to-run 变异的量级参照**(例如已有的 `xattn_seed43/44` 之间的边际差), 否则"缩水了 0.5×"无法与"换了个种子"区分。
