# PREREG — C2(basis ⟂ funding)前向影子

## 0. 为什么是前向, 以及本文【不】做什么

C2 已在 `PREREG_breadth_round2_basis_2026-08-09`(FROZEN `bac67648`)下三关全过。
但**那全部是历史回放**。`engine/live/challenger.py` 的开篇写死了这条: 能填上回放与实盘之间那个缺口的
**只有样本外影子证据**。本文产生那份证据。

**本文不做**: 不碰交易路径任何一行 · 不改 `legs_raw` / `SignalChain` / `book.json` ·
不建议任何部署动作 · **不复现在役信号链**(见 §2 的诚实限定)。

## 1. 采集(前向, 从冻结时刻起)

每个锚点快照(只读实盘状态, 写入独立目录 `exports/live/c2_shadow/`):
- `preds_latest.json` 的 `symbols` / `funding_ema` / `anchor_ts_ms` —— 在役的 funding 向量
- Binance 公开端点 `premiumIndexKlines(interval=1h)` 取同一批 symbol 的最新溢价(**无鉴权, 只读**)
- 由此按**与离线逐字相同的配方**构造 C2:
  `C2 = −1 × rank_centered( resid( rank_centered(basis) ~ rank_centered(funding_ema) ) )`, 再 `l1`
- cadence **8h**(与在役 funding 腿同, 预注册于 round2 §1)
- 下一锚到达时, 用 `anchors.jsonl` 的 `mid_at_anchor_vector` 算已实现 4h 收益, 给上一锚的 C2 计分

## 2. ★ 诚实限定(写在最前, 因为它决定这份证据能说什么)

**本影子测的是【C2 这条腿自己】的前向表现与它同在役书的相关, 不是"含 C2 的五腿书"。**
理由: 在役 `legs_raw` 硬编码四条腿, `book.json` 的读取器**会拒绝**不是恰好四条腿的权重字典
(那是有意的守卫)。要跑真正的五腿书必须改交易路径 —— 那是另一个批次。
⇒ **本影子能回答**: C2 前向是否仍有正收益 · 它与在役书的逐锚净额相关是否仍 <0.3 · 它的换手画像。
⇒ **本影子不能回答**: 五腿书的确切净夏普。**引用时不得越界。**

## 3. 判读协议(两步, 方差先于方向 —— 沿用 chase 的顺序纪律)

**第一步(方差)**: 累计 **≥20 个影子锚**后, 计算 C2 腿逐锚净额(bps/单位 gross)的 sd,
写入 `c2_shadow_sd.json`(必填 `caliber: "c2_leg_net_bps"`), 并**据此解出 N\*** 并冻结:
```
N* = ceil( 7.8489 × sd² / MDE² )        α=0.05 双侧, β=0.20
MDE = 1.0 bps/锚   ← ★ 本文定死, 不在看到 sd 之后改
```
**MDE 的来源(机制, 非拍脑袋)**: 在役书换装后实测毛收益 **+1.28 bps/锚**, 成本 ≈2.06 ⇒ 净 ≈ −0.4。
一条腿要在书里有意义, 其自身净额至少要能移动这个量级的**四分之一** ⇒ **1.0 bps/锚**。

**第二步(方向)**: 累计到 N\* 后才读方向。**在此之前任何"看起来在赚/在亏"的观察都不得进入判定。**

## 4. 判据(预写死)

| # | 条件 | 判 |
|---|---|---|
| G1 | C2 腿前向逐锚净额均值 **> 0**, 且 day-block CI95 下界 **> 0** | 必要 |
| G2 | 与在役书逐锚净额的相关 **\|ρ\| < 0.3**(关三在前向的复核) | 必要 |
| G3 | 前向 sd **≤ 历史 sd 的 2×**(形态未变的健全性检查) | 必要 |
| G4 | 换手画像与历史一致(8h cadence 下 ±50% 以内) | 必要 |

**四条全过 ⇒ 记为"前向证据支持 C2", 进入部署批次的排队(仍需五腿改造 + 用户裁定)。**
**任一不过 ⇒ 不进部署队列**; 若 G2 破(相关升过 0.3)⇒ **C2 退回研究状态**, 因为宽度的定义就是正交性。

## 5. ★ 会红的方向(必须先说)

- **最可能红的是 G1**: 历史 C2 在 w=0.15 只值 +0.24 夏普, 单腿自身的净额是小量;
  20-40 个锚(3-7 天)极可能 **CI 跨零**。⇒ **"没过 G1"的第一解释是样本不足, 不是 C2 无效**,
  该情形下正确动作是**继续累积**, 不是判负。**N\* 就是为防止在这里提前下结论而存在的。**
- **G2 若破**, 那是真发现: 说明历史上的 0.126 正交性是样本特性, 不是结构。

## 6. 不做什么(边界)

- 不因为影子好看就跳过五腿改造的深校验。
- 不把本影子的 Sharpe 外推成整书 Sharpe(§2)。
- 不在 chase 方向读数之前提任何实盘调整建议(用户令)。

## A-1 为什么改(缺陷是我的, 照实写)

原 §4 的 **G1 写的是「C2 腿【自己】的逐锚净额均值 > 0」**。用实测逐锚净额 sd 16.3 bps 与
预注册 MDE 1.0 bps 解 N\*:  `7.8489 × (16.3/1)² ≈ 2086 锚 ≈ 348 天`。
**⇒ 按字面执行需要将近一年。这是我设计时没算的。**

而**录取真正要回答的问题不是「这条腿赚不赚钱」, 是「加上它这本书变好没有」** —— 那是**同锚配对差**,
它把两本书的共同成分消掉。w=0.15 时书只变约 15%, 差序列 sd 预计 ≈ **3 bps**(待第一步实测),
`N* ≈ 7.8489 × 9 ≈ 71 锚 ≈ 12 天`。**同一个 MDE, 同一个 α/β, 差 25 倍。**

## A-2 改什么(唯一一处)

**G1 改为**: `Δ净(book+w·C2 − book)` 的逐锚均值 > 0, 且 day-block CI95 下界 > 0。
`w` 取 **0.10**(round2 预注册里的格点, **不取 0.15** —— 0.15 是事后读数, 不作主判)。
**MDE 仍 1.0 bps/锚, α=0.05 双侧, β=0.20, N\* 公式不变。**
**G2/G3/G4 一字不改。**

## A-3 叠加近似的诚实声明

`book+w·C2` 用**叠加**构造: 取实盘 `target_w`, 加 `w × l1(C2)`, 再 `l1` 归一。
**它不是五腿信号链的逐位复现** —— 真链会在合成后重新过 cap99/风险预算。
⇒ **本影子给的是叠加口径的配对差**; 五腿链的确切数仍需工程改造后才能测。
**引用时必须带这句。** 小 w 下两者差异应有限, 但**未标定**。
