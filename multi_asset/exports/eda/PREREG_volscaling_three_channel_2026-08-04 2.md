# PREREG — 波动缩放 sizing: **三个通道分开测**, 而不是一个 ΔNet

## 0. 为什么重开这件已经被否过的事(用户令, 且旧否定的范围被我说过头了)

旧读数: λ vol-scaling 在脏书上 ΔNet **+1.814**, SERVE 口径 **−0.083** ⇒ 判为"那 +1.8 是泄漏兑现的"。
**该判定成立, 但它被我当成了整个 sizing 问题的否决 —— 那是过度外推。** 旧实验把**至少三个互相独立的通道压成了一个数**:

| 通道 | 机制 | 泄漏拔掉后还在吗 |
|---|---|---|
| **① 方差** | 等名义 ≠ 等风险; 单名 σ 离散度 3–5× ⇒ 书的方差被高波动名字支配 | **在**(与 alpha 无关) |
| **② 换手成本** | 高波动名字**也是分数移动最快**的那批(收益更噪⇒特征更动⇒分数更动) ⇒ 压小它们=压小换手 | **在**(与 alpha 无关) |
| **③ alpha 交互** | 缩放与信号强度的交互 —— 旧 +1.814 主要落在这里 | **大概率不在**(它压的是泄漏制造的集中) |
**⇒ 一个 ΔNet 无法区分"没效果"与"三个通道互相抵消"。本预注册就是把它们拆开。**

## 1. 参数族(现行嵌套在 λ=0, 所以比较是精确的)

```
w_i  ←  w_i / σ_i^λ ,   λ ∈ {0, 0.25, 0.5, 0.75, 1.0}      λ=0 即现行(等名义)
σ_i  =  24h 已实现波动(engine 已有 rvol; 具名取用, 不新造)
```

**★ shaping 顺序与它的陷阱(必须照此实现并测量):**
```
combo → cap → demean → (÷σ^λ) → demean 二次 → L1
```
按 1/σ 缩放**会破坏市场中性**(demean 过的书一缩放就不再和为零) ⇒ 必须二次 demean。
**而二次 demean 会【部分抵消】缩放本身。** ⇒ **必报: 缩放前后书的 σ 加权分布实际变了多少**(即抵消掉多少)。若抵消 >80%, 则本实验测的是一个几乎没发生的干预, 判读作废。

## 2. ★ 有效性判据(先判; 不过则全表作废)

**臂 B(下方)在 λ=1 上的 ΔSharpe 必须【显著为正】。**
臂 B = 同样的 1/σ 缩放, 但 **alpha 逐锚横截面随机置换**(σ 与掩码不变, 信息置零)。它测的是**纯方差通道**, 与 alpha 无关, 因此**必须**有效——若连它都 ≈0, 说明本书的单名 σ 离散度根本不足以让风险平价起作用, **那么"vol scaling 没用"这个结论是关于装置的, 不是关于 vol scaling 的**, 全表不承载信息。
(这是 2026-08-04 那次拆分失败买来的教训: 伙伴判据防"读数是装置造的", **有效性判据防"装置没分辨率"**, 两者不可互相替代。)

## 3. 三个通道的分离读数(全部必报, 不可只报总额)

| 读数 | 怎么算 |
|---|---|
| **总 ΔSharpe(λ)** | 臂 A: 真 alpha + 1/σ^λ, 对 λ=0 |
| **① 方差通道** | 臂 B: 置换 alpha + 1/σ^λ 的 ΔSharpe |
| **③ alpha 交互** | 臂 A − 臂 B |
| **② 换手通道** | `gross_turn_ann(λ)` vs `λ=0`; 并把 Δ换手 按实测成本 3.63 折成 bps, 报**它单独贡献了多少 ΔSharpe** |
| 中性度代价 | 二次 demean 抵消掉的缩放比例(见 §1) |

**★ 归因纪律(与权重预注册同款)**: 若最优 λ 的收益**主要来自 ②**, 那这是**换手线的胜利而不是 sizing 线的**, 必须分开陈述, 不得记在 sizing 头上。

## 4. 判读规则(预写死)

| 条件 | 结论 |
|---|---|
| §2 有效性判据不过 | **全表作废** —— 报"本书 σ 离散度不足以让风险平价起作用", 不报"vol scaling 无效" |
| 臂 A 的 ΔSharpe day-block CI 下界 > 0(在 3.63 与 5.8 两档) | **可上**, 建议 λ = 两档同时最优者; 并按 §3 拆明三通道各占多少 |
| CI 含 0 | **不上**; 但仍报三通道拆解 —— 因为"①正 ②正 ③负、合计≈0"与"三者皆≈0"是**不同的事实**, 前者指向"缩放有用但与 alpha 打架", 是下一个实验的入口 |

## 5. 本实验不建立什么

- 不建立流动性 sizing(轴 2)。那条的**上界已经算出来 ≈0.78 bps**(成本 3.63 中滑点那一份; 手续费 2.85=79% 随换手线性、与单量无关) —— 单独排期。
- 不建立"持续性 sizing"(轴 4)。需先有逐名持续性估计, 尚无。
- 不建立这些结论对 S2 世代成立 —— S2 出来后按同判据重跑。
