## 4. 判据 (先写后算; A–D 互斥且穷尽; **C 支已按 §1 补上统计限定**)

记主口径、主书上的全历史 `MC̄`、其 `t_eff`、逐月为正比例 `p⁺`、`ΔNet` 的 `t_eff` 为 `t_eff^Net`。

| # | 形状 | 裁决 |
|---|---|---|
| **A** | `MC̄ > 0` 且 `t_eff ≥ 2` 且 `p⁺ ≥ 0.60`, **且**近 3 月 `MC` 均值 < 0 | **保留 + 观察.** 线上不动, 进月度监控。 |
| **B** | `MC̄ > 0` 且 `t_eff ≥ 2` 且 `p⁺ ≥ 0.60`, 且近 3 月未反号 | **保留.** 结案。 |
| **C** | `MC̄ ≤ 0` **且** ( `t_eff ≤ −2` **或** `t_eff^Net ≤ −2` ) | **摘除.** |
| **D** | 其余一切 —— 含 `MC̄ > 0` 但证据弱(`t_eff < 2` 或 `p⁺ < 0.60`), **以及 `MC̄ ≤ 0` 但两个 t_eff 都不显著** | **降权 / 观察, 不摘.** 见下方降权规则。 |

**★ C 与 D 的分界就是 size 案暴露的那个缺陷的修补: 微负且不显著 ⇒ D, 不再自动落进摘除。**

**降权规则 (D 支, 现在定死):**
- 新权重 = `min(当前权重, w*_L)`, 其中 `w*` 是主口径全历史 **收缩后** Σ⁻¹ 最优解在 w≥0 约束下的值;
- **不得低于 0**(不做符号翻转 —— 翻转是新因子, 走新因子的门);
- **变动幅度上限 每次 ≤0.05/腿**, 且**本轮至多降一条腿**(若 funding 与 s2 同时落 D, 先降 `MC̄` 更低的那条, 另一条下轮再议)——防止一次审计把书改成另一本。

**固定切点降级规则 (§3(d) 的角色, 现在定死):**
- 若某腿判为 **A 或 B**, 但其 **2023-11 之后**子样本的 `MC̄ < 0` 且 `t_eff ≤ −2` ⇒ **降级为 D**。
- 反向不成立: 前段为负、后段为正**不**升级任何裁决。
- 理由: size 案证明"全历史均值 ≈ 0"可以是"有效前段 + 32 个月负值后段"的平均。**这条规则的存在就是为了让同一形状不能再躲过一次。**

**regime 边界规则 (沿用 size 案):**
