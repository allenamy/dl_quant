# SEQ 3 — 逐腿换手分解: 那个 `−32%` 成立, 但它**不是**两台仪器

## 0. 三句话

1. **`−32%` 成立** —— 不是拼接, 也没有被 s2 的面板切换污染。**s2 单独切换只值 `−0.1%`。**
2. **但 team-lead 推导里的 "单腿降 32% 在书上应只反映约 19%" 这个前提【是错的】** —— 换手份额不正比于**权重**, 而正比于**权重 × 更新频率**。**king 的 cadence 是 4h, s2 是 24h, funding 是 8h ⇒ king 占毛换手的 91.0%, 不是 59.5%。**
3. **⇒ 真正的问题不是"为什么是 32% 而不是 19%", 而是: 这两个 −32% 【不是两台独立仪器】。书的换手 91% 就是 king 的换手 ⇒ 二者是【同一个测量在两个聚合层级上的两次报告】。** ⇒ **不得作为互证引用**(与 C3 留话一致, 但理由不同)。

## 2. ★★ 为什么是 32% 而不是 19% —— 前提错在"份额 ∝ 权重"

```python
engine/netting.py:25   LEG_CADENCE_H = {"king": 4, "s2": 24, "funding": 8, "size": 24}
engine/netting.py:~48  if i == 0 or (ti % self.cad[k] == 0):     # 腿只在自己的 cadence 上更新
                           gross_turn += self.w[k] * |new − held[k]|
```

**⇒ 一条腿对换手的贡献 ∝ 权重 × 更新频率**, 而不是 ∝ 权重。

**实测份额(BASE 臂):**

| 腿 | 占毛换手 | 权重 | cadence |
|---|---|---|---|
| **king** | **91.0%** | 0.595 | **4h** |
| s2 | 4.7% | 0.202 | 24h |
| funding | 4.3% | 0.202 | 8h |
| size | 0.0% | 0.000 | 24h |

**⇒ king 每 4 小时换一次, s2 每 24 小时才换一次 —— 频率差 6 倍。** 于是 king 以 0.595 的权重占了 **91%** 的换手。

**⇒ 算术闭合: 0.910 × (−32.4%) = −29.5%, 实测净书 −31.4%。**(余下 ~2pp 来自净额化与整形的非线性 —— 见 §4-2, 我没有进一步拆。)
**⇒ "应当只有 19%"这个期望值来自 `0.595 × 32%`, 它把 cadence 当成了对所有腿相同。**

## 3. ★ 于是真正的问题变了: 它们不是两台仪器

**原问句是"为什么两条路径吻合得超出各自精度"。分解之后, 这个问句本身失效了:**

> **书的换手 91% 就是 king 的换手。** ⇒ "DL 单腿换手 −31.6%" 与 "四腿书换手 −31.9%" **不是两个对象的两次测量, 是同一个对象在两个聚合层级上的两次报告。**
> **它们当然吻合 —— 不吻合才需要解释。**

**⇒ 处置(与 C3 留话一致, 但理由不同):**
- **C3 说的是**"在做完分解之前不要引用 −32% 作为互证" —— **谨慎, 且是对的。**
- **分解做完之后, 结论不是"可以互证了", 而是"永远不能互证"** —— **因为它们共享 91% 的被测对象。**

**★ 这与今天上午那个 `+29.2%` 是【镜像的两种错法】:**

| | 上午的 Frankenstein 比值 | 今天的两个 −32% |
|---|---|---|
| 表面 | 两台独立仪器吻合到 0.1pp | 两条路径吻合到 0.3pp |
| 实情 | **一个数由两把尺子拼成** ⇒ 吻合是**制造**出来的 | **两个数测的几乎是同一个对象** ⇒ 吻合是**必然**的 |
| 错误方向 | 高估了**数的可靠性** | 高估了**证据的独立性** |
| 共同点 | **"吻合"被当成了确证, 而两次都不是** | |

> **⇒ 一条通用判据: 看到两个数吻合, 先问的不是"它们准不准", 而是"它们是不是同一个东西"。**
