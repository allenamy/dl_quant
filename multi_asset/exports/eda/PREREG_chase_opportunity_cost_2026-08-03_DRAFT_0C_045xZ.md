**两个数都对, 但它们是两个不同的总体:**

## 1. 主判据: 机会成本配对差

### 1-1 总体与单元

```
单元      = (锚 a, 名字 i)
总体 P_a  = { i ∈ from_partial 残差集 : i ∈ C 的 skip 集, 且 |resid_i| ≥ floor_i(a) }
            floor_i(a) = max(min_notional_i, step_i × price_i(a))     ← 与执行器同一地板
            (裁定 B 时: 去掉 |resid| ≥ floor 这一条)
处理      = no_chase(扣下)     对照 = chase(照发)
chase_forced 永不入样本(按规模选出, 不可交换 —— `PREREG_chase_arms` §3-2 已定)
```

### 1-2 ★ 机会成本的几何 (派工 (a) 的核心)

设名字 i 在锚 a:
- `q_i` = **扣下时刻的残差**(带符号, 合约数)。**它在随机化之前就已确定** ⇒ 两臂同定义。
- `t_w` = 该名字在补单循环里被决策的时刻(chase 臂 = 实际提交时刻;no_chase 臂 = 同一循环位置, **必须落行记录**)。
- `P_w` = `t_w` 的 **mid**(不是成交价 —— 成交价含我们自己的冲击, 两臂不可比)。
- `P_next` = **下一锚的 mid**(`PREREG_chase_arms` §4 已冻结: 用下一锚 mid, 不用成交价)。

**残差在下一锚被重算 ⇒ 反事实持有窗口就是 `[t_w, 下一锚]`, 到期后它并入下一次目标, 不再单独存在。** 因此:

```
持有价值   H_i = q_i × (P_next − P_w)            ← 若把这笔残差建上, 到下一锚为止赚/亏多少
执行成本   X_i = q_i × (F_i − P_w) + fee_i       ← 为把它建上付出的(F_i = 实际成交价)
名字层净效应  Y_i = H_i − X_i
```

- **`H_i` 对两个臂都可计算**: 它只需要 `q_i`(随机化前定)与两个 mid(市场路径)。**不使用任何 >t 的信息去决定任何量** —— `P_next` 是结果, 不是决策输入。
- **`X_i` 只在 chase 臂可观测。**

**⇒ 估计量 (主):**
```
ATE = E[H]  −  E[X | chase]
      ↑ 用【两个臂的全部名字】估计        ↑ 只能用 chase 臂估计
```
**这是本文相对朴素做法的主要设计贡献: `H` 与臂分配无关, 因此可以用两倍的样本估计, 而 4-6 名/锚的稀薄只落在 `X` 上。** 朴素做法(chase 臂 `Y=H−X`, no_chase 臂 `Y=0`, 作差)只用一半样本估 `H`, 方差显著更大。

**该等式成立的假设, 明写并可检验:** `H_i` 对 chase 名字用的 `P_next` 发生在**我们自己那笔成交之后** ⇒ 若我们的冲击持续到下一锚, `H` 在两臂间不可交换。
**内建证伪: 比较两臂的 `H` 分布(锚内配对)。在"我方冲击不残留"的零假设下二者应可交换;若系统性不同 ⇒ 冲击污染结果, 本估计量作废, 退回朴素估计量。** 该检验先写死, 结果两向都照报。

### 1-2b ★ 持有窗口的终点, 四种情形全部写死 (team-lead 补充要求, 不留"看情况")

**先把结论说清楚: 窗口终点在四种情形下**都是**「下一锚」, 不随情形变化。变的不是终点, 是终点上的处置。**

**为什么终点必须固定而不能"看情况": 任何随结果而定的窗口都会在两臂间不同** —— chase 名字持有仓位, no_chase 名字没有, 因此"什么时候被平掉"本身就是处理的后果。**用一个后果去定义估计量的窗口, 就是让处理改变自己的度量尺。** 固定窗口是唯一与臂无关的选择。

记下一锚该名字的目标为 `T_i`, 扣下的残差为 `q_i`(同号为正表示同方向)。

| # | 情形 | 下一锚发生什么 | `S_i = (|T_i| − |T_i − q_i|) × c_{a+1}` 的取值 | 谁吃亏 |
|---|---|---|---|---|
| **1** | **信号走掉, 残差消失** (`T_i ≈ 0`) | chase 臂必须**平掉** `q_i`;no_chase 臂无事 | `≈ −|q_i|·c` **(负)** | **追价方多付一次平仓** —— 追价是一次往返 |
| **2** | **下一锚仍要这个仓位** (`T_i` 同号且 `|T_i| ≥ |q_i|`) | chase 臂只补增量;no_chase 臂要从头建 | `≈ +|q_i|·c` **(正)** | **不追方并未省下成本, 只是推迟** —— 且推迟到下一锚的价格上 |
| **3** | **部分保留** (`T_i` 同号, `0 < |T_i| < |q_i|`) | 两臂都要动, 方向不同 | 在 ±`|q_i|·c` 之间连续插值 | 视幅度 |
| **4** | **符号翻转** (`T_i` 与 `q_i` 反号) | chase 臂要先平再反向建 | `= −|q_i|·c` **(负)**, 与情形 1 同 | 追价方 |

**⇒ `S_i` 这一个带符号的式子已经覆盖四种情形, 无需分支。本表的作用是证明它覆盖了, 而不是引入新公式。**

**★ 由此得到一条必须写在判词旁边的话: 主判据 `E[H] − E[X]` 把 `S` 排除在外, 而 `S` 的符号随情形而变 ⇒ 排除 `S` 不是中性的。**
- 情形 1/4 多时, 排除 `S` **高估**追价的价值(漏掉了往返的第二腿);
- 情形 2 多时, 排除 `S` **低估**追价的价值(不追只是推迟付费)。
**⇒ 因此四种情形的实测占比是**必报项**(§3-1 公开字段), 且次级判据 `E[H] − E[X] + E[S]` 与主判据必须并排出现。若两者符号相反, 结论以"主判据 + 情形占比"共同表述, 不得只报其一。**

### 1-2c ★ 情形 5: 仓位在下一锚**没有被交易**, 于是窗口被越过

**这不是理论角落, 在本实验里很可能是常态。** 这些残差按构造就贴着地板(§0 实测均值 \$3.52–4.91), 因此在下一锚, chase 臂持有的 `q_i` 所需的调整 `|T_i − q_i|` **很可能仍低于地板 ⇒ 不交易 ⇒ 该仓位继续留着**, 持有期实际超过一个锚。

**处置(先写死):**
1. **主判据的窗口仍固定为一个锚。** 理由同 §1-2b: 一个"持有到它真的被交易为止"的窗口, 其长度是处理的后果, 不能用来定义估计量。
2. **越窗持有单独计量**: 记 `carry_i = 1` 若下一锚该名字的计划成交被地板挡下。**逐锚报告 `carry` 比例**, 它衡量"主判据的一个锚窗口低估了多少真实持有期"。
3. **`carry_i = 1` 的单元不剔除** —— 剔除会按结果选样本。它们进主判据, 同时进 `carry` 统计。
4. **若 `carry` 比例 > 50%**, 主判据的"一个锚"口径就与现实相距过远 ⇒ **在读数报告首行声明, 并把次级判据(含 `S`)提为并列主判据**。该阈值现在定死, 不等看到数再定。

### 1-3 二阶项: 下一锚的成交差 (派工 (a) 提到的"信号自己走掉"的另一半)

到下一锚时: chase 名持有 `q_i`, 交易到目标 `T_i` ⇒ 成交名义 `|T_i − q_i|`;no_chase 名持有 0 ⇒ `|T_i|`。
```
S_i = ( |T_i| − |T_i − q_i| ) × c_{a+1}        c_{a+1} = 下一锚实测混合成本(bps)
```
**符号可正可负** —— 扣下有时让下一锚交易得更多, 有时更少。
- **主判据 = `E[H] − E[X]`**(与 `PREREG_chase_arms` §6-4 一致, 那里明记二阶项未计);
- **次级判据 = `E[H] − E[X] + E[S]`**, **必须同时报**。
- `S` 用的是**实测成本率的插补**, 因此它是次级而非主判据。

### 1-4 判词

```
ATE > 0  ⇒ 追价值得 —— 持有收益盖过执行成本 ⇒ 维持 A/C-fill
ATE < 0  ⇒ 追价不值 —— 支付超过机会成本 ⇒ 支持 C(或 B)
```
**并列硬约束不变**(`PREREG_chase_arms` §4, 未改): **任一案系统性把 `|net/gross|` 推过 3% ⇒ 该案 NO-GO, 与收益无关。**

## 1-5. ★ 主判据的两侧分解与版本化 (team-lead 追加要求, 冻结前纳入)

**动机(team-lead): 追价执行政策本身要迭代(re-peg / 升温阶梯 / 微观门)。若主判据只是单一配对差, 任何政策改动都会改变 chase 臂成本 ⇒ 正在攒的样本作废。实验与执行迭代会互相锁死。**

### 1-5-1 分解 (它就是 §1-2 的估计量, 但加上了一条我原稿没有的性质)

```
机会成本侧  = E[H],  H_i = q_i × (P_next − P_w)     ← 与【补单执行政策】无关
追价成本侧  = E[X | policy_version],  X_i = q_i × (F_i − P_w) + fee_i
决策规则    追 iff  E[X | 当前版本]  <  E[H]        (等价于 §1-4 的 ATE > 0)
```

**我原稿已有这个分解, 但没有下面这条 —— 它是本节的实质:**
> **`H` 需要随机化且昂贵(每锚只有 4-6 个真正被扣下的名字), 但它是政策不变量 ⇒ 样本可以跨版本累积;`X` 便宜(逐锚数十个直接观测)但随版本而变 ⇒ 每换一版重新估计即可。⇒ 把两侧分开, 政策迭代只作废便宜的那一侧。**

### 1-5-2 ★ 但"政策不变"是有条件的, 条件现在写死

`H_i = q_i × (P_next − P_w)`。**函数形式**与执行政策无关, **但两个输入不是:**

| 输入 | 对**补单**政策(re-peg/升温/微观门) | 对**maker 阶梯**的改动 |
|---|---|---|
| `q_i`(残差) | **不变** —— 残差在补单腿之前就已确定 | **会变** —— maker 成交率变 ⇒ 残差分布变 |
| `P_w`(扣下时刻的 mid) | **可能变** —— 若补单腿的决策时点被政策挪动 | 会变 |

**⇒ 不变性成立于「改动只发生在补单腿内部」;若某一版同时动了 maker 阶梯, `E[H]` 的跨版本合并也失效。**

**版本可合并性检验(先写死, 逐版本报告):**
```
per policy_version:  mean(|q|), sd(|q|), 越地板比例, median(t_w − anchor_ts)
合并条件(三条全满足才允许把该版本的 H 并入池):
  |Δ mean|q||        ≤ 25% (相对合并池)
  |Δ 越地板比例|     ≤ 10 个百分点
  |Δ median t_w 偏移| ≤ 120 秒
```
**三个数是政策数, 不是从数据导出的**, 现在定死以免事后调。**任一条越界 ⇒ 该版本的 `H` 单独成层, 并在读数报告首行声明"跨版本合并已作废"。**

### 1-5-3 `E[X]` 的总体: 只用随机化的 chase 臂, **不得并入 `chase_forced`**

派工说"逐锚 ~40 名直接测量"。实测随机化 chase 臂是 **36 / 28 / 38** 名/锚, 而 `chase_forced` 是 **2 / 7 / 3** 名/锚 —— 合起来才接近 40。

**但决策规则问的是"C 的 skip 集该不该追", 所以 `E[X]` 的总体必须是 skip 集。`chase_forced` 是按 |残差| 从大到小选出来的(`PREREG_chase_arms` §3-2), 与 skip 集不可交换;若成本随规模变化, 并入它会系统性偏移 `E[X]`。**
⇒ **`E[X]` 只在随机化 chase 臂上估计。`chase_forced` 的成本单列为描述性, 且必须标注"按规模选出, 不进决策规则"。**

### 1-5-4 相位边界与各侧的样本量

- **`policy_version` 逐锚落盘**;版本切换 = **相位边界**。
- **锚点跨越切换**(同一锚内前后不同版本)⇒ **该锚不入样本并计数**。
- **`N*` 只对机会成本侧定义**(§3-2), 因为只有它需要随机化功效。
- **★ 但成本侧也要有下限, 否则新版本第一个锚就能翻转决策**: `MIN_ANCHORS_PER_VERSION_FOR_X = 3`(政策数, 与 0B 的 `MIN_ANCHORS_FOR_SD` 取同值), 且**必须同时报 `SE(E[X|version])`**。**版本内锚数 < 3 ⇒ 决策规则不出结论, 沿用上一版本的判词并声明。**

### 1-5-5 配对差仍报, 但标注

**`PREREG_chase_arms` §4 的单一配对差继续计算并报告**(诚实完整), **但必须带一行标注: 「本量混合了 policy_version 效应, 不可用于跨版本比较;跨版本结论以两侧分解为准。」**

### 1-5-6 这条改动没有改变的东西 (免得被读成改判据)

主判据的**判词**(§1-4)、**并列硬约束**(3% 中性度)、**窗口终点**(§1-2b/c)、**总体定义**(§0/§1-1)全部未变。**本节只是把 `ATE = E[H] − E[X]` 的右边两项赋予不同的累积与作废规则。**

## 2. 配对口径与推断 (派工 (b))

- **配对层级: 名字级 within-anchor;锚 = 聚类单位。**
- **点估计**: 先算每锚的臂均值差(或 §1-2 的 `Ĥ_a − X̂_a`), 再对锚**等权平均**。锚等权而非名字等权 —— 名字数在锚间差 3 倍, 名字等权会让最宽的锚主导。
- **★ 主推断 = 锚内随机化检验(permutation)**: 在每个锚内置换臂标签, 重算统计量, 得经验分布。锚数少时这是唯一诚实的推断;正态近似与 cluster-robust t 作为**次级**并报(df = n_anchors − 1)。
- **跨锚相关性**: 同一 symbol 在相邻锚的残差有携带(本锚扣下 ⇒ 下锚 delta 更大), 且分配每锚重掷(`seed = rebalance_id`)⇒ **同名字跨锚不独立**。置换在锚内进行, 因此不依赖跨锚独立性;但**报告必须给出同名字重复出现的频次表**, 供判断有效独立单元数。

### 3-2 N\* 的推导 (公式先定死, 数值由 sd 产物填)

锚级臂均值差的方差:
```
Var(Δ_a) = sd_within² × (1/n_chase,a + 1/n_nochase,a) + sd_between²
N*      = ceil( (z_{1−α/2} + z_{1−β})² × Var(Δ) / MDE² )      α=0.05, β=0.20(双侧)
```
**★ 结构性预判(先写下, 供事后核对): 0B 实测 chase 臂成本随"锚内市场是否在跑"从 17 单调升到 52 bps ⇒ `sd_between` 很可能主导。若果真如此, `N*` 由锚数决定而几乎不随每锚名字数变化 —— 也就是说 **稀薄的处理组不是瓶颈, 锚点数才是**, 且 §0 的 A/B 之争对 N\* 的影响会比 25 倍小。这条预判可被 sd 产物证伪。**

**MDE 必须在见到 sd 之前定。** 建议锚定到经济量而非统计量: **MDE = 每锚 \$0.75**(= `PREREG_chase_arms` §2 表里 C 案每锚成本), 即"我们要能分辨的最小效应, 是这个政策本身每锚的花费量级"。**请 team-lead 确认或改;不确认则本文不冻结。**
