## 0. 设计起点(lead 指定):C3m 在 pre-2026 的价格通道

| 臂 | pre2026 `pnl`(价格通道) | pre2026 `car`(已付资金费) | pre2026 `cst` | pre2026 `g` |
|---|---|---|---|---|
| **C3m** s42 / s2027 | **−957.8 / −1389.8** | −407.1 / −227.5 | +50.1 / +46.3 | −600.9 / −1208.6 |
| C3 s42 / s2027 | −665.9 / −1355.2 | −344.4 / −270.3 | +181.9 / +187.8 | −503.4 / −1272.7 |

**这就是要解释的那个价格**: 剔除"极端负资金费的空头"在 pre-2026 让**价格通道**亏 **−958 / −1390 bps**。
机制上讲得通: 极端负资金费 ⇒ 空头**付**资金费(所以剔除后 `car` 变负 = 少付), 但这类名同时处在**下行动量**里,
空着它们在 pre-2026 是**赚价格**的。C3 把两者一起切掉 —— 2026 资金费那一面占优(+1.95/+2.71), pre-2026 价格那一面占优。

⇒ **任何按资金费挑名的机制, 都会在 pre-2026 重演这个价格代价。** 这是设计必须绕开的东西。

## 1. 机制:一个与资金费无关的结构性偏斜(实测, 四年都在)

生产 chain(`vendor_live/fea171/combo_stage.py`, sha `fb5a94074583b328…`):
```
L109: w = np.where(sel, w - (w[sel].mean() if sel.any() else 0), w)   # 按 sel 集去均值 ⇒ Σw = 0
L112: w = w / g                                                       # L1 归一
L113: capw = P["cap_mult"] / max(int(sel.sum()), 1)                    # cap_mult = 2.5(生产值)
L114: w = np.clip(w, -capw, capw)                                      # 逐名 cap, **对称**
L116: if g2 > 1e-9: w = w / g2                                         # 再 L1 归一
L118: smv = H + P["alpha"] * (tgt - H)                                 # EMA, alpha = 0.1
L120: smv = np.where(np.abs(trade) < P["band"], H, smv)                # 带, band = 2.5e-4
L128: leave = (~keep) & (np.abs(smv) > 1e-12); smv = np.where(leave, 0.0, smv)   # 强制出场
```

L109 的去均值让 **Σw = 0**, 即在**那一层**多头总额恰等于空头总额。但 **L118 的 EMA、L120 的带、L128–129 的强制
出场都不保持这个等式**, 所以**落盘的 `weights` 不是总额对称的**。实测(在役 NC 组合, `scaled_diagnostic`):

| 年 | s42 多头总额 / 空头总额 | 偏斜 `(short−long)/gross` | 偏空锚占比 |
|---|---|---|---|
| 2023 | 0.2585 / 0.2608 | **+0.0075** | 61.6% |
| 2024 | 0.3031 / 0.3021 | **+0.0072** | 60.5% |
| 2025 | 0.2926 / 0.3155 | **+0.0073** | 58.1% |
| 2026 | 0.3614 / 0.4015 | **+0.0445** | **90.8%** |

s2027: +0.0038 / +0.0174 / +0.0091 / **+0.0440**(偏空锚占比 56.8 / 66.3 / 58.4 / **89.9%**)。
多空总额在**100% 的已发布锚上都不相等**(|差| 中位 1.87e-2, 最大 1.93e-1)。

**这是一个结构性偏斜, 不是信号**: 它来自 chain 后段算子不保持前段的等式, 四年都在、两个种子都在。
**2026 大 6 倍**且近乎普遍, 与在案的"实盘书对 BTC 日 beta ≈ −0.35"方向一致。

## 2. 两个臂(≤ 2, 门槛 = 自然值, 无扫参)

两臂都是对**落盘权重**的后处理(与 B4/B5/C3m 同一论证: `evolve` 无条件写 `kc/fc/raw`), 注入点 = `weights` 写出之后。

**共同的对称化算子**(自然值 = **相等**, 无参数):
```
long_g  = w[w>0].sum();  short_g = -w[w<0].sum()
s       = long_g / short_g                      # 只在 short_g > long_g 时 < 1
w_sym   = where(w < 0, w * min(s, 1.0), w)      # 把**偏多的那一侧不动**, 只压偏空的一侧
```
即:**只动空头侧**(修订 4 允许的三类机制之一), 且只在空头总额**超过**多头总额时动, 压到相等为止。

| 臂 | 对称化之后 | 隔离的是什么 |
|---|---|---|
| **S1** | **不**恢复总额 —— 书变小, 差额进现金 | 削减(不再分配) |
| **S2** | 恢复总额 —— 两侧同比放大回原 gross(照 L116 的做法) | 削减 + **再分配** |

**S1 与 S2 只差一个算子**(是否 L1 复原), 所以 `d(S2) − d(S1)` 就是**再分配**的效应(给定偏斜已被压平)。
⚠ 与 C3m 同样的告诫: 这个分解是**顺序的**, 不是加性的; 另一个顺序会给出不同拆分, 本件不测。

## 3. 为什么预期**不**付 C3m 那个价格代价(lead 指定必须回答)

三条理由, 都可被读数否掉:

1. **不按资金费挑名。** C3/C3m 切掉的是"极端负资金费"这个**尾部子集**, 而该子集在 pre-2026 恰好价格动量最好
   (A2 的分档表: q0 空头长期均值最高)。S1/S2 压的是空头侧的**按比例一刀**(每个空头名乘同一个 `s`),
   放弃的价格 P&L 是空头书的**平均**, 不是动量最富的尾部。
   ⇒ **可检验的预测**: **每单位被移除 gross 的价格通道代价**, S1/S2 应**显著小于** C3m。
   读出时报 `Δpnl / |Δgross|` 三者并排; 若 S1/S2 不小于 C3m, 本条被否。
2. **C3 的价格代价里含"再分配"。** C3 在 z 层置零, 随后 chain 的 **L116 把释放出来的 gross 再分配**到其余名上 ——
   所以 C3 的 `Δpnl` 不只是"少了那些空头", 还含"其余名被放大"。**S1 不做再分配**, 结构上避开这一部分。
   ⇒ **可检验的预测**: `d(S2) − d(S1)`(再分配效应)与 C3m 的价格通道**同号**。若异号, 本条被否。
3. **动的量小一个数量级。** 偏斜中位 +0.0075(pre-2026)⇒ S1/S2 在 pre-2026 每锚只动约 **0.4%** 的 gross,
   而 C3 动的是 171–260 个名的整段权重。**量级小 ⇒ 代价小**是最弱的一条理由, 单独不足, 与 1、2 并列而非替代。
   ⚠ 反面: 量级小同样意味着**收益也可能小到不显著** —— 这是本族最可能的失败模式, 事先写明。

- 2026 段的任何读数(本臂族的机制与量化以 **pre-2026 四年**为据, 见下)。

**来源 —— 臂的识别与门槛只来自这两处**:

   (+0.0075/+0.0072/+0.0073 与 +0.0038/+0.0174/+0.0091), 偏空锚占比 56.8–66.3%。

## 5. 控制(G0 类, 任一不过则停)

1. **退化(逐位)**: 把对称化算子的触发条件改成永不触发(等价于 `min(s,1.0)` 恒为 1)⇒ 两臂产物与基准**逐位相同**。
2. **对称化生效(逐锚断言)**: S1/S2 输出上 `|long_g − short_g| ≤ 1e-12` **逐锚成立**(这是臂的定义, 必须断言而非描述)。
3. **S1 与 S2 的唯一差别**: S1 的 `gross < ` 基准 gross(严格, 在偏空锚上); S2 的 `gross` 与基准**逐位相等**。
   两条都要断言 —— 否则"是否再分配"这个分离没有实现。
4. **只动空头侧**: 多头侧权重在两臂上都与基准**逐位相同**(`w[w>0]` 逐位), 断言之。
5. **非空**: 两臂都必须与基准有逐锚差异, 且差异锚数 ≈ 偏空锚数(pre-2026 ~58–66%)。
6. **发布决策**: S2 保 gross ⇒ 预期 `trade_mask` 与基准逐位相同, 断言之。**S1 降 gross ⇒ 预期会改变
   `gross<0.4` 的咬合**, 故 S1 **必须**并排报发布集两个方向的计数(C3 的教训: 净数会藏住非单调)。
7. **口径**: 冻结 `news_stats.dbar`(sha `7141ba42…`, import 并调用), 段定义 `6cd94f947`, 延长轴,
   并排报 SEG 截断版; 装置自报 `self_sha256` + env 白名单; 复跑命令逐字入收据。
