## §9 限定与下一步

- **本文没有重跑流 R。** 用 `price_logtable_raw.npy` + `price_meta_raw.npz` 替换 RUN_CONFIG 的 price_logtable / price_meta 两个 pin 重跑, 才能给出 R5-02 要的「受影响的成交 / 止损 / 美元量」。这属于流 R 的 owner, 本文只交付输入与影响面(§0-4)。
- 未裁剪 bar 仍是 float16(每根相对 ≤ 2.4e-4 量级的舍入), 这是缓存的全局精度, 回放所有 bar 都一样。本修复只去掉裁剪与缺数两类系统性错误。
- T2(目标暴露)是持仓的代理; 执行器的「退不出去继续持有」可能让实际持有面更宽, 所以修复范围按 T1 做全。
- 缺数段的 UNAVAILABLE 部分(交易所无 K 线)没有有限的情景界; 如果以后发现回放在这些段内持仓, 应当拒绝在段内定价, 而不是补路径。
- 回放价格表之外, **meta RAW y4 本身在两个地方与真实价格不同:** BNXUSDT 缺数段被按 0 计; 那 5 个没修的格 y4 为 NaN。凡是用 meta y4 做记账的研究装置(S2 等)也继承了这两处。本文不改 meta, 只登记。
