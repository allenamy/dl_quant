### 2.4 我自己的操作化缺陷(不是数据的性质)

lead 的实质主张是**方向性的**(「共同/风格顺风**抬起**这一族的任何书」)。我把它操作化成了**相似性**(「和 BASE 一样约 46/54」)。
实测是: `NONE` 的改善**比 BASE 更偏共同/风格**, 而且它的 Δ共同是全部臂里最显著的(p = 0.0002)。**按方向性判据这是支持; 按我写的相似性判据这是不支持。**
**我不改判据**(写在数字之前的就是写在数字之前的), 但必须点名: **判据比主张严, 而且严在一个会把「更强的同向证据」判成「不支持」的方向上**。这是操作化的失误 ——
**可推广的验收线: 把一个「方向 + 显著」的主张操作化成「与参照相似」之前, 先问一句「如果效应比参照更强, 我的判据会不会判它不支持?」** 会, 就说明操作化错了。

## §4 层与量的纪律(我差点在这里写错一句)

本文的 `price` 是 **L2 纸面价格**(`1e4·Σ W·RET`), **不是** L1 已实现 `g`。`g = 价格 − 资金费 − 手续费 − UNKNOWN`, 所以**层不同、量也不同**, 两者不能直接相减。
我第一次看数时把 `NONE` 的 **L2 Δ价格 +4.431** 与 CF3 的 **L1 Δg +2.784** 相减, 得到一个 1.65 的「缺口」并准备写成发现 —— **那是苹果比橘子**(既跨层又跨量)。按同量同层重算(两边都取**价格**分量):

| 臂 | L1 Δ价格 | L2 Δ价格 | 差(= 执行残差) |
|---|---|---|---|
| `BASE` | +3.4243 | +3.2405 | −0.1838 |
| `NONE` | +4.3254 | +4.4314 | +0.1060 |
| `noFUND` | −0.2213 | −0.4635 | −0.2422 |

差全部 ≤ 0.37 bps/锚, 就是归因件块 R 那个量级的执行残差。**没有那个 1.65 的缺口。**
**仍然成立且值得记的一条**: `NONE` 的**价格**改善(+4.33 / +4.43)**大于** BASE 的(+3.42 / +3.24), 但它的**已实现 g** 改善(+2.784)**小于** BASE 的(+2.915) —— 差别落在 `g` 相对价格多扣掉的那几项(资金费、手续费、换手), 与 CF3 §5.6 的「回退书换手更高」同向。

## §5 局限(前两条为预注册, 后三条为本次新增)

1. **风格回归回答的是「钱从哪来」, 不是「有多少是本事」** —— 风格桶是书**故意下的注**(归因件 §5 自己的限定)。共同/风格份额高**不蕴含**「不是技能」。
2. **2026 与 combo 形态的选型样本重合** ⇒ 一切都是**样本内描述**。`NONE` 臂把**构造**从解释里去掉了, **没有**把样本内这件事去掉。
3. **本文不测持久性**。「共同/风格顺风」即使成立, 本文**没有**测过它会不会延续 —— 那需要前瞻。把 `s` 读成「2026 会不会重演」是越界。
4. **`NONE` 不是一个干净的「无信号世界」**: 它是生产者**原始三腿 king 书**(king + rev24 + fund, 未掩码席位), 本身仍是一本有信号的书。所以「两个结构不同的世界」是真的, 「其中一个没有信号」是假的。
5. **`s` 只在 Δ 的两个成分同号且分母不近零时可读**(§3 的 `noFUND` 就是反例)。任何引用 `s` 的地方必须同时给 Δ价格与两个 p。
