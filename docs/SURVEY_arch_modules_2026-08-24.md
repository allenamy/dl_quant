# 弱信号表格/截面模型: 架构模块与正则化调研 (第三轮, 补前两轮空档)

**范围:** 只覆盖六轴 — 特征交叉 / 门控条件化 / 低SNR正则 / 短历史编码 / 截面注意力精修 / 路径目标训练力学。编码器与目标函数见前两轮。

**证据分级:** A = 金融或表格 OOS 多组独立复现; B = 单域强证据(金融单文 / 表格基准 / 工业A/B); C = 仅通用基准(视觉/NLP/CTR)或机制论证。**CTR-only 证据一律显式标注** — CTR 是稀疏类别嵌入+十亿行+分类, 与我们 171 稠密工程特征+270万行+回归/排序差三个量级的形态, 只能作方向参考。

**贯穿全文的元结论(先给):** 表格深度学习 2021-2025 三篇里程碑(Kadra 正则鸡尾酒 NeurIPS'21 / RealMLP NeurIPS'24 / TabM ICLR'25)指向同一件事 — **在表格域, 预算应该花在正则化+数值嵌入+训练配方上, 而不是新奇模块; attention/检索类模块的复杂度在受控对比下不回本**。这与本仓 "预处理>架构; 机制>堆叠" 硬约束、以及 GKX(2020 RFS, 浅网 NN3 最优、加深单调变差)完全同向。V3 全配置的正确姿势是: 每个模块近零初始化门控接入, 逐模块消融, 不回本即摘除。

## 轴1 特征交叉架构 (DCNv2 / xDeepFM CIN / FinalMLP / GDCN / MaskNet / AutoInt)

**机制.** 显式交叉层直接构造特征的乘性组合(DCNv2: x_{l+1} = x_0 ⊙ (W_l x_l + b_l) + x_l, 低秩版 W=UV^T), 绕开 MLP 用深度逼近乘法的低效; 门控版(GDCN/MaskNet)在每阶交叉上加信息门, 抑制高阶噪声项。对弱信号的意义: 乘性项方差大, 门控/低秩等价于对交叉空间做容量约束。

**证据.**
- 全族证据基本 **CTR-only**。FuxiCTR/BARS 大规模复现(4600 实验)的核心负面结果: **调好的双流 MLP 即可打平大多数交叉设计** — FinalMLP(AAAI'23)本质就是这个发现的产品化(双流+门控+双线性融合); 2026-06 预印本 "Dual-Stream MLP is All You Need" 再次同向。⇒ 交叉模块的真实边际远小于论文表格呈现。[B, CTR-only]
- **Pinterest 工业约束实测**(2024, 真 A/B): 在显存/延迟/重训稳定性约束下, 七种交叉模块对比, 胜者 = **3 路并行 MaskNet + 4 层 DCNv2**(参数净零增, 线上 +1.42% save); **FinalMLP 与 Transformer 线上为负**(−0.83~−1.30%); 高阶有用(8 层堆叠 DCNv2 +0.58% 离线)、并行优于单路(+0.33%)、低秩交叉内加 ReLU 非线性 +0.52%。这是最接近"生产约束下什么活下来"的证据, 但仍是 CTR 分类+十亿行。[B, CTR-only]
- GDCN(CIKM'23): 门控交叉使更深阶交叉不衰减+可解释, 幅度 +0.28% AUC 量级。DCNv3(2024): 指数阶交叉+自掩码, 对 DCNv2 仅 +0.17% AUC, 单组来源, 观望。xDeepFM CIN: 计算贵且在 BARS 复现中被 DCNv2 族压制。AutoInt(特征轴注意力): TabM 的结论直接判它 — 表格域注意力不回本。[均 B-/C, CTR-only]
- **金融/稠密数值域直接证据: 近乎空白。** 资产定价 ML 文献确认交互效应存在且树模型/浅网能吃到(GKX 2020), 但没有"显式交叉层 > MLP"的金融 OOS 受据。本仓内部受据同向: 手工乘积列实测死(禁令受据), 方向一终判"面板+resid 下树/king/深表格等价 ±0.002" — 说明交互 alpha 在这个特征集上已被树和浅网吃平, 交叉层可挖的剩余极小。

**我们尺度的配方(若保留).** 低秩 DCNv2, r=16~32, **2 层封顶**(Pinterest 的 8 层证据在十亿行 CTR, 270万行弱信号照搬必过拟合), 与 MLP 主干**并行**接入, 融合处 LayerScale 门控近零初始化(α≈1e-2), 使初始状态 = 冠军基线; 低秩内加 ReLU(Pinterest 唯一可信的免费增益)。参数增量 <5%。判据: 干净面板多折 ΔIC≥+0.003 且 Q4 不劣化, 不过即摘。

**判语:** 可试但期望要压到 0~+0.003。它是 V3 里证据最弱、内部反证最强的模块。

## 轴2 门控/条件化 (FiLM vs GLU/SwiGLU vs 超网络 vs 软 MoE)

**机制.** 四者是同一件事的四个容量档: 用低维市场上下文 c 调制主干计算。FiLM = 逐通道仿射 γ(c)⊙h+β(c)(秩1, 最省参数); GLU/SwiGLU = 自门控(不吃外部 c, 属激活函数层面); 超网络 = 由 c 生成整层权重(容量最大最不稳); 软 MoE-of-towers = K 套塔按 softmax(g(c)) 加权混合(容量介于 FiLM 与超网络之间, 软=全可微无路由离散性)。

**证据.**
- FiLM: 通用条件化标准件(Perez 2018 起, 跨域复现充分)[A-, 通用]; **金融最近亲 = MASTER(AAAI'24)**: 市场状态向量生成特征选择门控, 在 CSI300/800 上超此前 SOTA — 结构上就是 FiLM 的门控变体 [B, 金融学术盘]。**内部受据: film2 在冠军终装(forest×film2), 4 维因果市场上下文已在役** — 这是全六轴里内部证据最硬的模块, 保留无争议。
- SwiGLU: Shazeer 2020, NLP 大模型标配 [B, 通用]; 表格域 RealMLP/TabM 均未采用它作为关键件 ⇒ 表格边际存疑。作为激活替换属"动冠军主干", 单独一臂测, 期望 ≈0。
- 超网络: 金融证据空白, 训练不稳定性文献充分。**免死理由: FiLM 是超网络的秩1退化安全版, 4 维上下文撑不起整层权重生成, 上限被 FiLM 已捕获的一阶效应封死。**
- 软 MoE: Soft MoE(Puigcerver 2023)解决的是硬路由的不稳定/token 丢弃, 但那是 ViT token 级 [C]; MMoE(KDD'18)软门控多专家有工业 A/B 受据 [B, 推荐域]; MIGA(2024, arXiv:2410.02241)金融 MoE 在 CSI 三指数超 SOTA, 但属学术盘无成本口径、且"动态切换风格专家"实质是路由 [B-, 金融学术盘]。**内部反证: router +0.0019 OOS 不迁移(已封卷)。** 塔数估算: 270万行 ÷ (每塔有效容量需求) 且上下文仅 4 维 ⇒ K=2~3 塔是上限, 而 K=2 软混合与 FiLM 的表达差距 ≈ 一个二阶项。

**我们尺度的配方.** FiLM 保留: 只调制第 1~2 个主干块, γ 初始化 1、β 初始化 0, 生成器 4→32→2d 小 MLP + weight decay 1e-3(压 γ 偏离), 这样条件化关闭时精确回退基线。SwiGLU/软 MoE 均**不进 V3**: SwiGLU 入候补池(单臂, 期望零), 软 MoE 免死(FiLM 已占其一阶效应, 内部 router 受据在先, K=2 时增益空间被夹死)。

## 轴3 现代低SNR正则 (SAM 族 / R-Drop / 特征 dropout / 随机深度 / C-Mixup / 权重 EMA / 对抗扰动)

先给本轴的 A 级元证据: **Kadra et al. NeurIPS'21(40 数据集): 素 MLP + 13 种正则的鸡尾酒搜索 > 一切花式架构、> XGBoost; RealMLP NeurIPS'24(118+90 数据集): 稳健缩放+平滑截断+数值嵌入+对角权重层+调度的元调参默认即打平 GBDT; TabM ICLR'25: MLP+BatchEnsemble 型参数高效集成 > 一切注意力/检索架构。** 三篇同向: 表格域的收益在正则与配方, 不在模块。

逐项:

- **SAM/ASAM/GSAM.** 机制: 极小极大找平坦谷, 对弱信号的价值 = 压制对训练噪声的记忆。证据: 视觉/NLP 一致 +0.5~1% [B, 通用]; **表格/金融: 两次定向检索均未找到任何已发表证据**(这是个诚实的空白, 不是"有但小")。附加坑: SAM 收益随大 batch 缩水(m-sharpness), 我们 b1024 正在坏区间; 2× 计算。配方(若测): 素 SAM ρ∈{0.02,0.05,0.1} 扫一遍, 特征尺度异质则 ASAM ρ=0.5~1.0; 与 sqrt-LR 无冲突。**判语: 计划里的 SAM 降级为"探索臂", 不做默认开。同预算下优先做下一条 —**
- **对抗输入扰动(Adv-ALSTM 型).** 机制: 对(归一化后)输入或末层隐层加 ε 级最坏方向扰动, 显式模拟"价格含噪声"这一金融本体事实。**证据: Feng et al. IJCAI'19 股票走势预测 +3.11% 相对精度, 是本轴唯一有金融 OOS 受据的正则** [B, 金融]。配方: FGSM 单步, ε=0.01~0.05·σ(逐特征), 扰动加在特征归一化之后; 计算开销与 SAM 同为 2×, 但证据在金融侧。**推荐顺位排 SAM 之前。**
- **特征/列 dropout.** 机制: 随机遮蔽输入列 = 逼模型不依赖任一列 = 对 171 列冗余族(内部已知因子簇高冗余)的显式去依赖。证据: Kadra 鸡尾酒成员 + SCARF 腐蚀式自监督 + Kaggle 长期实践 [B, 表格]。配方: 逐样本逐列 Bernoulli p=0.10~0.15(输入层), 主干内标准 dropout 0.1~0.2 另算; 注意与交叉层的交互 — dropout 放在交叉之前天然正则化交互项, 是好事。已在计划内, 背书。
- **随机深度.** 免死: 为 ≥10 层残差网设计, 我们 2~4 块无"深度可丢", 机制不成立。
- **C-Mixup(NeurIPS'22).** 机制: 按标签相近采样配对做 mixup, 修复回归域 mixup 的标签错插; 有 OOD 稳健性证据(含时序数据集)[B, 回归非金融]。**但我们的损失是组合路径目标不是逐行回归 — 对输入做 mixup 会破坏"一行=一名一锚"的书语义。仅当存在辅助逐行回归头时可对该头启用**(Beta α=1.5~2, 带宽取标签距离中位数)。无辅助头则免死。
- **R-Drop(NeurIPS'21).** 机制: 两次 dropout 前向的输出一致性约束。证据: NLP/ViT [C, 通用]; 回归/表格证据空白; 标量分数上的"KL"退化为 MSE 一致性, 与其做这个不如直接上 TabM 的 k 头(同一思想的原则化版本)。免死: 2× 计算买一个无域证据的弱形式。
- **权重 EMA(训练中).** 机制: Polyak 平均 = 沿轨迹平滑掉 SGD 噪声, 等效落入平坦谷; 系统研究(arXiv:2411.18704)证实泛化/校准/一致性全面改善, 且允许更缓的 LR 衰减 [B, 通用]。**合规裁定(我方判断, 终裁归用户): 若 EMA 衰减率在预注册时冻结、从第 0 步起唯一评估对象就是 EMA 权重、单种子单轨迹 — 它是优化器的一部分, 不是训后技巧; 它恰恰替换掉"挑 BEST checkpoint"这个已入反模式 #24 的更 cherry-pick 的环节。** 与已判负的 swa_post_hoc(训后选点平均)是两个东西, 引用时须区分。配方: decay 使平均视界 ≈ 1~2 个 epoch(按步数折算, 例如每 epoch 2600 步 → decay≈0.9995), 评估/早停/落盘全用 EMA 权重。单臂预注册后推荐进 V3。
- **TabM 型参数高效集成(ICLR'25).** 机制: 一次训练内 k 份符号向量适配器共享一个 MLP 骨架(BatchEnsemble), 输出平均; 权重共享本身是正则。证据: 表格 SOTA, 多基准, "注意力/检索不回本"的结论即出自它 [A-, 表格]。**合规灰区: 机械上是单种子单次训练的一个架构, 不是多种子集成; 但精神上是集成家族。列为"待用户一字裁定"的候选, 不擅自进 V3。** 若准入: k=8(原文 k=32 在我们样本量偏奢), 只对主干 MLP 部分做, 头部共享。
- **数值特征嵌入(PLE/周期嵌入, Gorishniy NeurIPS'22).**(轴外快报, 因前两轮未覆盖)机制: 标量→分段线性/周期向量, 给 MLP 免费的非线性分辨率; 是 RealMLP/TabM 配方的公共成分。[A-, 表格] 配方: PLE 每特征 8 维, 分位数分箱; 参数 +171×8×d_proj, 可控。**这是本调研发现的、V3 清单之外证据等级最高的单件增补。**

## 轴4 决策节奏上的逐名短历史编码器 (K=8~32 锚, 工程特征序列)

**机制.** 对每名把最近 K 锚的 171 维工程特征当作长度 K 的序列编码, 期望吃到"特征的动力学"(变化率/拐点)这一 last-anchor 输入不含的信息。

**证据(核心, 本轴唯一能直接回答"是否胜过 last-anchor-only"的公开对照):** Qlib CSI300 官方基准(20 种子均值) —
- **工程特征集 Alpha158: MLP IC 0.0376 ≥ LSTM 0.0318 / GRU 0.0315, ≈ ALSTM 0.0362; 唯一显著超出的是 TRA 0.0440 — 而 TRA 是路由器(内部已判死家族)。**
- 原始窗口集 Alpha360: MLP 0.0273 → GRU 0.0493 / ALSTM 0.0497, 序列模型大胜。

⇒ 结论清晰: **序列编码的增益来自"替代特征工程"(原始输入), 不来自"叠在工程特征之上"。特征已含回看窗(EMA/动量列)时, 历史编码器主要在重建已有列** [B, 金融学术盘, 但对照干净]。内部同向受据: 弹药战役"bar/书一阶二阶构造空间对 78 列近饱和"; 5m 战役 catch-22(新数据形态 solo 涨但 ρ 涨, 混合仅 +1.5%)。

- Conformer 于短工程特征序列: 无任何已发表证据; Conformer 为语音长序列设计, K=16 token 上其 MHSA 子层没有可路由的东西, 纯参数开销。
- 反方向证据(简单混合即可): TSMixer(KDD'23/Google)与 DLinear 家族 — **线性时间混合在预测基准上打平/超过 Transformer** [B, 时序非金融]; ModernTCN(深度可分离卷积, ICLR'24)同向, 且本仓单资产时代已用过该家族。

**我们尺度的配方(若保留本模块).** 把 Conformer-lite **降级为二选一轻量件**: (a) 因果深度可分离卷积 2 块, kernel 3~5, 每特征组投影 d=32; 或 (b) TSMixer 式单层可学习时间混合矩阵(K×K, 每特征共享)。输出与 last-anchor 特征做门控残差拼接, 门近零初始化。K=16 足够, K=32 无机制理由。判据同轴1: 干净 ΔIC≥+0.003 且 Q4 不劣。**期望值要压到 0~+0.002: 这是六轴里最可能白花参数的一件**, 免死候选; 若砍, 理由一行 = "Alpha158 对照: 序列编码叠加工程特征不增益, 唯一例外是被禁的路由器"。

## 轴5 截面注意力精修 (n≈300)

**机制.** 截面注意力让每名的分数在"当锚全市场语境"中定型, 数学上 = 可学习的动态截面去均值/分组; 市场 token = 显式共同模式聚合点。

**证据.**
- 通用/排序域: Set Transformer/ISAB(ICML'19)[B, 通用]; **listwise LTR 的 allRank(Pobrotyn 2020): 自注意力打分显著超逐条 MLP, MSLR-WEB30K SOTA, 且对 pointwise/pairwise/listwise 损失一致** — 这是"截面语境帮助排序"最干净的非金融 OOS 证据 [B, 排序]。SetRank(SIGIR'20)同向。
- 金融: MASTER(AAAI'24)inter-stock 注意力 + 市场门控超 SOTA [B, 学术盘]; 2025 起截面注意力池化类工作持续出现(方向拥挤, 均无成本口径)。
- **内部受据: xattn +0.031(引擎A矿工), 冠军=lamorth0_xattn。本模块内外证据都是正的, 六轴中唯一。**
- ISAB 在 n=300 的定位要说清: 300×300 注意力矩阵每锚 9 万分, 计算上毫无压力 — **ISAB 的价值不是省算力而是 m 个诱导点构成低秩瓶颈 = "市场只有 m 个模式"的结构先验**, 是正则不是加速。
- 秩感知注意力: 无成熟已发表件 [C]; 但机制论证充分 — 注意力打分若吃截面秩/z 化特征, 其分布跨 regime 平稳(与本仓 rank+cap 正典同构), 原始尺度特征进 QK 则注意力权重携带波动率 regime。

**我们尺度的配方.** 单层 MHA: **2 头封顶, d_k=32**(n=300+弱信号, 多头无分工可学); pre-LN + **QK LayerNorm**(注意力 logit 稳定) + 温度可学; **LayerScale α=1e-2 门控残差** — 注意力起步 = 恒等, 学不到东西时零伤害(这是弱信号下上注意力的关键保险, 对应内部"近零初始化守卫"经验); Q/K 输入用截面秩化/z 化后的特征子集, V 用全特征; 市场 token 保留(已知内部件)。若观察到过拟合(train-val IC 张开), 换 ISAB m=16 作为低秩正则版, 不是为了算力。attention dropout 0.1。

## 轴6 路径目标训练力学 (损失穿过组合递推链)

**谱系定位.** 你们的目标(净路径 − 换手成本 + 尾部惩罚, 梯度穿过 EMA 仓位递推)在文献里有 25 年谱系, 恰好各给一件可拿走的技巧:

- **Moody & Saffell RRL(NeurIPS'98 / IEEE'01): 梯度穿过含成本仓位递推的原型。** 两个可拿走: (i) 最大化差分夏普比最大化利润更稳(与 F10 单目标设计一致); (ii) 在线差分夏普 = 夏普对时间的指数加权一阶展开, 若做流式/滚动重训是现成的增量目标 [A-, 金融, 被 FX/crypto 多次复现]。
- **Deep Hedging(Buehler et al. 2019 QF): 有交易成本时 CVaR 目标必须配递归结构**(与你们的 EMA 递推同型), 且 **CVaR 的标准可微化 = Rockafellar–Uryasev 辅助标量: CVaR_q(L) = min_w [w + E(L−w)⁺/(1−q)], 把 w 作为一个可训练标量与 θ 联合下降** — 免去对尾部做任何排序/采样近似, 训练稳定, 被大量后续复现 [A-, 金融]。若 F10 的 CVaR 抗跌项还没用这个重写, 这是本轴第一优先的具体改动。
- **No-transaction-band 网络(Imaki et al. 2021; 2026-03 结构先验续作): 把不交易带做成网络结构(软死区)而非事后规则, 收敛更快终值更好** [B, 金融]。与在役显式带 b=0.002 呼应: V3 训练递推里应内置软带(tanh/软死区松弛), 训练所见 = 部署所为, 消一层训练-部署口径差(内部"引擎回放不是实盘那本书"教训的训练侧对偶)。
- **成本课程(cost annealing): 有直接文献支持** — RL 交易文(2025)明确: 起步就全额成本会淹没主奖励信号, 用调度器把训练内成本从 0 线性升到全额; 通用约束课程文献同向 [B]。配方: 成本乘子 0→1 于前 25% 步数线性升温, 之后冻结; 尾部惩罚项同样可延后 10% 步数再开(先学信号再学抗跌)。与你们已见的 γ-折扣证据同族。
- **τ 退火(软秩温度):** 可微排序文献(NeuralSort/SoftSort/Blondel'20/单调可微排序网络 Petersen ICLR'22)的共识: (i) 温度过低梯度消失、过高排序失真; (ii) **优先用单调松弛(单调排序网络/软秩投影), 保证梯度符号永远正确** — 非单调松弛在弱信号下会给出反号梯度; (iii) 退火不要退到 0: 以"软秩与硬秩的相关 ≥0.99"为停点, 前 50% 步数从初值指数退到停点后冻结 [B, 通用+机制]。
- **TBPTT 窗口算术(照你们的 α 代入):** 截断泄漏 = (1−α)^W。α=0.05 ⇒ W=60 剩 4.6%、W=90 剩 1%; α=0.3 ⇒ W=13 剩 1%。配方: 有状态 TBPTT — 窗口 W 取"泄漏 ≤5%"档(α=0.05 时 W=64), **50% 重叠, 重叠段只做状态热身不计损失**, 窗间仓位状态跨窗携带但 detach; 窗内锚严格顺序, 打乱只在窗级。偏差控制的正式文献(ARTBP/自适应 TBPTT)存在但工程上以上配方即够 [B]。梯度裁剪 1.0; 递推链上除权重外对成本项分母类量 stop-gradient(防自扰动记账, 对应内部 ledger-not-book 家族)。
- **决策导向训练的系统性偏差(2026-05 预印本, SPO 通胀文): 决策诱导排序会系统性抬高边际名的预测并制造超额换手** — 你们把换手成本内生进目标已是该文的"解药"形态, 但监控义务留下: 训练中盯 σŷ/σy 与分数尺度漂移(已有守卫), 幅度校准继续留在训后(正典不变)[B]。
- 梯度噪声(Neelakantan'15): 免死 — 老证据, 被 batch/LR 配方时代淘汰, 且与四大胜利(b1024+sqrt LR)冲突。
- QP/cvxpylayers/BPQP(Butler-Kwon'23, Uysal'23, BPQP'24): 免死 — 该школа解决"梯度穿过 argmin"; 你们的书是 EMA 递推+带, 闭式可微, 不需要隐式层。仅当未来书里出现显式约束优化步才回头看 BPQP。

**消融纪律(不属本文新增, 重申):** 每模块一臂、近零门控、干净因果面板、多折+Q4、ΔIC≥+0.003 线; 全配置一把梭上线属"生硬堆叠", 被硬约束 3 明文禁止。

## 不做清单

| 项 | 一行理由 |
|---|---|
| xDeepFM CIN | 计算贵且 BARS 复现中被 DCNv2 族压制, CTR-only |
| AutoInt / FT 式特征轴注意力 | TabM 受控对比: 表格域注意力不回本 |
| DCNv3 | 对 DCNv2 仅 +0.17% AUC, 单组来源, 观望 ≥1 个代际 |
| FinalMLP 整件照搬 | Pinterest 线上为负; 其两流思想已被我们的并行支路覆盖 |
| 硬路由 MoE / TRA / MIGA | 内部 router 受据判死 + 路由不稳定文献; TRA 是 Alpha158 唯一超 MLP 者但正因路由被禁 |
| 超网络 | FiLM 是其秩1安全退化, 4 维上下文撑不起整层生成 |
| 随机深度 | 2~4 块无深度可丢, 机制不成立 |
| R-Drop | 回归/表格零证据, 标量输出上退化为弱一致性, 2× 计算 |
| C-Mixup(书目标上) | 输入插值破坏一名一锚的书语义; 仅辅助逐行头可用 |
| 梯度噪声 | 被 batch/LR 时代淘汰, 与四大胜利配方冲突 |
| QP/cvxpylayers 隐式层 | EMA 递推+带闭式可微, 无 argmin 可穿 |
| 完整 Conformer(K=16) | 短序列上 MHSA 子层纯参数开销, 零已发表证据 |
| ISAB 当加速件 | n=300 注意力本来就不贵; 只在过拟合时当低秩正则用 |
| TabR/检索式 | 训练集近邻检索在时序金融即前视泄漏面 |
| 多种子集成/训后技巧 | 用户硬禁令, 本文一切建议均在单种子单轨迹内 |
