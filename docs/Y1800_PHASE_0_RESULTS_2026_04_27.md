# Y1800 Phase 0 — Ridge + XGBoost Baseline Ablation

## TL;DR

**DL ema_pool ≫ Ridge ≫ XGB** on y_1800 single-asset 49-feat space (apples-to-apples 3-fold canonical clean):

| 模型 | P | S | β | Verdict |
|---|---:|---:|---:|---|
| **DL ema_pool LIVE** | **+0.022** | **+0.033** | 0.37 | **Winner — sequence modeling 有效** |
| DL ema_pool EMA | +0.021 | +0.027 | 0.47 | 接近 LIVE |
| Ridge (alpha=10) | +0.002 | -0.016 | 0.04 | **线性几乎无信号** |
| XGBoost (depth=5, n_est=2k) | -0.053 | +0.013 | n/a | **非线性 100% 拟合噪声** |

**Implication:** Architecture/representation learning DOES extract real value beyond static features — the DL ceiling is NOT feature-bound. Phase 1 (calibration) + Phase 2 (paradigm) research investments are justified.

## 实验细节

### 共同 setup
- NPZ: `data/npz_v4_y1800/` 1004 days, 49 features (depth-only, no trades), input_len=1200, stride=600, horizon=1800
- Walk-forward: train_days=700, val_days=30, test_days=90, fold_stride=60
- DL 用 fold 0/1/2 (前 3 folds);Ridge/XGB 跑全 4 folds 但取前 3 做 apples-to-apples 对照
- 评估: canonical clean = stride=3 BEFORE mask, pooled across folds

### Ridge (sklearn.linear_model.Ridge alpha=10)
- 训练: 700 days × ~70 win/day ≈ 40k samples (last-timestep features only)
- Standardize on train moments
- ~5 min CPU per 4-fold run

**Per-fold (canonical clean stride=3):**
| Fold | N | P | S |
|:-:|---:|---:|---:|
| 0 | 1534 | +0.0163 | +0.0008 |
| 1 | 1463 | -0.0079 | -0.0342 |
| 2 | 1665 | +0.0042 | +0.0058 |
| **POOLED** | **4662** | **+0.0017** | **-0.0155** |

### XGBoost (gbdt depth=5, n_est=2000, lr=0.02, early_stop=50)
- ~4 min CPU per fold

**Per-fold (stride=10 AFTER mask, full 4 folds):**
| Fold | best_iter | clean P | clean S |
|:-:|:-:|---:|---:|
| 0 | **0** ⚠ | -0.078 | +0.030 |
| 1 | **0** ⚠ | +0.071 | -0.022 |
| 2 | 81 | -0.026 | +0.010 |
| 3 | **0** ⚠ | -0.014 | +0.026 |
| **POOLED** | — | **-0.053** | +0.013 |

**`best_iter=0` 含义:** XGB 在 train 集上 boosting 进展无法在 val 上 generalize,**最优 ckpt 是 init prediction (基本零)**。这强烈暗示信号在 49-feat 上是 **near-linear-only** + **极弱**,任何额外 capacity 都退化为 overfitting。

## 分析: 为什么 DL > Ridge?

### 假设 1: Sequence context 有用
- DL 用 1200 个时间步的 context,Ridge 只用 last timestep 的 49 features
- ema_pool 通过时序加权,捕捉到了 last timestep 之外的信号 (例如近期 vol trend, OBI persistence)

### 假设 2: 非线性激活有效 (轻度)
- 虽然 XGB 全失败,但 GDCN + ChannelMix 的 cascaded 非线性可能 capture 到一些 monotonic-but-not-linear 关系
- 注意 XGB depth=5 是 axis-aligned 切分,DL 是 dense linear combinations + activations
- 这是**研究价值假设** — 后续可以用 deeper Ridge + interaction features 验证

### 假设 3: Calibration loss + EMA 提供了正则化
- 我们的 V1 calib loss (dir_huber + β_calib) 限制了模型过度拟合 noise
- EMA 平滑了 epoch-level noise

## 修正前文 (上一份 morning report) 的判断

之前 morning report 写: "ema_pool LIVE S=0.033 ≈ y_600 noise scaling 0.032,可能已是 single-asset ceiling"

**这个判断不完全对:**
- 噪声 scaling argument 看上去 numerically 对上了
- **但** Ridge 在同一 NPZ 只能 P=0.002 — 如果是纯噪声 scaling,Ridge 应该也能拿到接近 0.022 的 P
- Ridge ≈ 0 而 DL = 0.022 → **0.020 P 是 DL 的 representational add-on**,不是噪声

**DL 在 y_1800 上仍有 representational space**,这就是 Phase 1+2 研究的合理性来源。
