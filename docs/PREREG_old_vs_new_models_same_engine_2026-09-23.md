## Stage 2:M2 —— BTC-beta 叠加对冲(不动 alpha 书)

**机制**:实盘书美元中性但日 beta ≈ −0.35(空头腿是高 beta 山寨币),BTC 急涨时被挤。研究员的 β 投影改了名字权重、长期 Sharpe 全降 —— 无法区分"负 beta 有报酬"与"投影扭曲了 alpha"。M2 **不改任何名字的权重**,只加一条 BTC 对冲,把这两件事分开。

**公式(冻结,零自由参数)**:在锚 A、对已发布目标 `w`(gross 单位):
1. 每名 `β_i` = 该名 4h 对数收益对 BTCUSDT 4h 对数收益的 OLS 斜率,样本为截至 A 已完成的最近 180 根 4h bar,有效观测 ≥ 120,否则 `β_i = 1.0`;截断到 `[−1, 4]`;BTCUSDT 自身 `β = 1`。价格源:认证 `price_full_raw_x0918r`,缺测区间不计入(不填零)。
2. `β_book = Σ_i w_i β_i`。
3. BTCUSDT 目标权重 `+= −β_book`;**其余名字权重不变**;总 gross 相应变化(逐锚报告)。
4. HOLD 锚(未发布)不加对冲 —— 与生产发布语义一致。

**在 OLD 与 NEW_s42、NEW_s2027 三个底座上各跑一次**(同 32 路径、同设置)。

**判据(对自己的底座,pre-2026)**:

| # | 判据 |
|---|---|
| H2.1 | 叠加后书对 BTC 的**已实现**日 beta 落在 [−0.10, +0.10](对冲真的中和了);底座的已实现 beta 同报 |
| H2.2 | Sharpe(底座+M2) − Sharpe(底座):pre-2026 合并 > 0,且三段中至少 2 段 > 0 |
| H2.3 | pre-2026 最大回撤与最差日**不变差** |
| H2.4 | 认证成本格下 H2.2 合并差符号不变 |

**必须同报的分解**:对冲腿的 P&L 分成 **漂移项**(`−β_book × BTC 均值收益`)与 **方差项**(底座与叠加后的日收益标准差)。若 H2.2 通过但**方差没有下降、收益增量全来自 BTC 漂移**,判词标 **DRIFT-DEPENDENT** —— 那是"这段历史 BTC 上涨",不是稳健改进,不据此换装。
