## 1. 先回答:S1 两个模型的 σ 比都低于 0.02,是信号太弱,还是设定让预测塌缩?

**答:两个模型都没有塌缩。这个守卫在当前定义下,对「校准过的回归」相当于第二道 IC 门槛,而 S1 在 IC 门上本来就不过。** 只用 S1 已有收据推出,没有新跑。

### 1a. 一个恒等式

- 若预测是校准的(E[y | ŷ] = ŷ),则 σŷ/σy = corr(ŷ, y)。
- 所以守卫 σŷ/σy ≥ 0.02,对校准模型就等于要求**皮尔逊相关 ≥ 0.02**,比主判的秩 IC ≥ 0.015 还严。
- 它不是在测「预测是否退化成常数」,而是在给 IC 设第二道门槛。

### 1b. Ridge(α = 训练行数):收缩恰好一半,和收据对得上

- 特征已标准化(`l2_b_common.Prep`),α = n。于是 β = (X'X/n + I)⁻¹ · cov(X, y);特征近似正交时,β ≈ OLS 的一半。
- 收据核对(`RECEIPT_L2N_fit.json`):
  - 六个 Ridge 折的 √Σβ² 为 0.63–0.77 bps;
  - 训练目标截断区间 [−407, 642] 到 [−516, 811] bps,按正态折算 σy ≈ 200–260 bps;
  - 推出 σŷ/σy ≈ 0.0025–0.0038。实测 0.0040 / 0.0042(测试目标不截断,σy 更大,方向一致)。
- **σ 比 / IC:s42 0.46,s2027 0.51**。这正是「校准界 × α = n 的一半收缩」的预言值(≈ 0.5)。
- 结论:Ridge 的预测没有塌缩,只是被设计成一半强度。若要过 σ ≥ 0.02,皮尔逊相关需要约 0.04。

### 1c. LGBM(300 轮,学习率 0.02,叶子 ≥ 200 行,L2 = 10)

- σ 比 0.0165 / 0.0166;**σ 比 / IC = 2.0 / 2.2,是过度离散,不是塌缩**。
- 若预测 = 信号部分(σ = ρσy)+ 噪声,总 σ 为 2ρσy ⇒ 预测方差中约 75% 是与目标无关的噪声。
- 它离 0.02 更近,是因为它拟合了更多噪声,不是因为信号更强。

### 1d. 合起来

- **信号弱是主因**:8 个段点的 IC 为 0.005–0.010,低于 0.015,这一条单独就判 FAIL。
- 守卫在这里没有提供「是否塌缩」的信息:Ridge 低是设计造成的,LGBM 高是噪声造成的。
- **给 lead 的建议**(判据归你,我有利害,只作建议):下一批凡是经过拟合模型的判据,塌缩守卫改为与尺度无关的形式。例如:
  - (i)逐锚截面上 ŷ 的离散度 > 0 的锚占比 ≥ 95%;或
  - (ii)σŷ/σy ≥ 0.25 × |IC|;
  - 并在同一收据里报 Ridge 的校准斜率,说明收缩是否为设计所致。
  - S1 的判词不受影响,不回溯。
