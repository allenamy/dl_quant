**Goal:** A multi-asset deep-learning model that predicts y_600 (10-min forward return) for 14 Binance USDT-perp symbols, achieving **avg per-asset Pearson 0.10** (vs single-asset BTC 0.065) with healthy β≈1, monotonic calibration, near-zero long-short bias — by exploiting cross-asset structure the single-asset model cannot see.

**Architecture:** ONE shared-parameter REG_arch (universal weights across symbols, per-symbol FiLM embedding) over a timestamp-synchronized 14-symbol panel, with cross-asset attention on pooled embeddings (temporal-first → cross-asset-second) and a directed BTC market-factor token. Risk-laddered: **Approach C** (BTC→alt beta-projection) is the ~0.045 baseline floor; **Approach A** (shared backbone + cross-asset mixing) is the primary model adding residual alpha; **Approach B** (BTC 25-level LOB enrichment of the leader) is a conditional escalation.

**Tech Stack:** PyTorch 2.x, single RTX 3090 (24GB), jpline server, HDF5 bar data, NumPy/Pandas/scikit-learn (Ridge baselines). Reuses single-asset code as a read-only library.

## 0. CRITICAL REFRAMING (empirically grounded — read first)

Two facts, **measured on our data** (18 days 2023–2025, clean non-overlap stride≥600), invert the naive plan:

| Finding | Number | Consequence |
|:---|:---|:---|
| Contemporaneous BTC→alt beta is **huge** | ETH corr 0.84, avg alt corr **~0.70** to BTC_y600 | The dominant structure is the **common BTC factor**, not lagged lead-lag |
| Lagged BTC→alt at **600s is weak** | trailing-60s BTC ret → alt y_600 corr 0.02–0.05; at 600s ~0 (except TRX 0.06, LTC/FIL ~0.02) | The lead-lag momentum thesis is **weak at this horizon**; lives at 1–60s |
| Beta-projection is nearly free | ρ(ŷ_BTC, alt) ≈ ρ(alt,BTC) × ρ(ŷ_BTC,BTC) ≈ 0.70 × 0.065 ≈ **0.045** | Projecting the proven BTC prediction onto alts gives ~0.045 Pearson/alt with zero alt-specific modeling |

**The research problem is therefore the RESIDUAL.** The beta floor (~0.045) is free; the model's job is to add ~0.055 of **idiosyncratic + cross-sectional + (weak) lead-lag** alpha to reach 0.10. The three user-proposed approaches map precisely:

- **Approach C (beta-projection)** = baseline FLOOR (~0.045) + an input prior. Cheapest, lowest-risk, least coupled. Build first as the benchmark to beat.
- **Approach A (shared-backbone end-to-end)** = PRIMARY model. Adds residual alpha via parameter pooling + cross-asset attention + cross-sectional target. Highest ceiling.
- **Approach B (BTC 25-level LOB)** = enrich the LEADER's input → better ŷ_BTC → lifts the whole projection (multiplier). Conditional escalation if BTC-on-bar underperforms single-asset.

Server: `work_hsy/quant_research_multi_asset`.
- **Target:** predict **raw per-asset y_600** (per-asset MAD-σ normalized); **dual-caliber eval** = avg per-asset Pearson (headline 0.10 goal) AND cross-sectional rank-IC; demean predictions cross-sectionally to kill long-short bias.
- **Universe:** 14 USDT-margined primary (BTC ETH SOL BNB XRP DOGE ADA LINK BCH TRX LTC DOT FIL ETC). 5 USDC dups excluded from the cross-section (held as robustness/denoising check only).

**Data facts (verified read-only):** 14 USDT syms (+5 USDC), 1s bars, 85,800/day, 1430 days (2022-01→2025-11, ~3.9yr), 0 intra-day gaps, ~0 NaN. 5-level LOB + 9-bucket cumulative depth profile (`cumu_*sz_dep_X`) + trade flow + book add/del + mid-change.
