## §2 前瞻窗与停止规则(取代 AMENDMENT 1 §1 表里「P 前瞻级」的窗口写法)

- **起点 T_start** = 下列两件都已提交之后的第一个 UTC 零点: (a) 判官冻结提交 —— 模拟器 v3 在**修订后的** V1b 门下通过其**前瞻**验证(不是历史诊断段)、原始 5m 价格补丁、认证的生产路径对象, 三者 sha 写进一份 `C_FORWARD_START` 提交; (b) 本修订。T_start 在该提交里写死, 早于任何前瞻数据被读取。**T_start 之前的日子一律不算前瞻样本**(即使它们晚于 09-20)。
- **冻结清单(T_start 时全部钉 sha)**: 三个覆盖层代码、基准(同判官无覆盖层)、成本模型、价格数据版本、模拟器与标定文件、数据构建器、本文统计装置。T_start 之后任一项改动 ⇒ 受影响候选的前瞻读数作废(不重开窗)。
- **两次读数, 预先分配错误预算(Bonferroni 分到两次读数, 保守)**:
  - 第 1 次: T_start + 90 个 UTC 日, 家族单侧 α₁ = 0.003, **只能**判 (A); 未判 (A) 的候选继续。
  - 第 2 次(终点): T_start + 180 个 UTC 日, 家族单侧 α₂ = 0.047; 判 (A) / (B) / (C)。之后不再延长、不再读。
  - 两次之外**不看**任何候选臂的前瞻结果(装置只在这两个时刻运行, 运行记录入库)。
- **最低有效样本**: 每次读数时, 三个候选与基准都可计算的完整锚数 ≥ 该段应有锚数的 85%; 不足 ⇒ 该次读数 **UNAVAILABLE**(不延长, 不补读)。缺输入 / 停机 / 仪器未建成的锚在两臂中**同时**剔除(配对), 计数写入收据。

## §3 唯一估计量与检验(取代原文 §3 统计量段与 AMENDMENT 1 §4)

**主终点预先固定, 不再由结果触发切换**(删除 AMENDMENT 1 的「gross 变化 > 5% 改用 NAV 判据」规则; gross 变化只作报告项: 每种子、每读数段的 mean |Δgross| / mean gross, 相对值)。

- **C1 / C2 主终点 = Δg**: 逐锚配对差 Δg_{s,t} = g_{s,cand,t} − g_{s,base,t}(判官定义 g = net_ex / gross_total)。主估计量 = 两种子逐锚配对差的**平均序列** Δg_t = (Δg_{42,t} + Δg_{2027,t}) / 2 的均值(线性统计量, 平均后再自举是合法的)。
- **C3 主终点 = 联合门(Sharpe 优效 ∧ 收益非劣)**, 在固定 2× 基准杠杆的 NAV 路径上:
  - 日收益 r_{s,a,d}: 每个种子 s、每臂 a 的 NAV 按 UTC 日复利(含成本、资金费、日止损规则; 与判官同一路径)。四条序列按共同日历日对齐; 任一缺失的日子四条同时剔除并计数。
  - ΔSR = ½ Σ_s [SR(r_{s,cand}) − SR(r_{s,base})], SR = 均值 / 样本标准差(ddof = 1)× √365。**不是**差序列的 Sharpe。
  - ΔR = ½ Σ_s [CAGR_{s,cand} − CAGR_{s,base}], CAGR = (Π_d(1 + r_d))^{365 / n_days} − 1(复合年化, 不是算术年化)。NAV 触及 ≤ 0 的路径 CAGR 记 −100%; 零波动 ⇒ 该次重抽的 SR 无定义并计数, 无定义占比 > 1% ⇒ 读数 UNAVAILABLE。
  - 非劣预算 δ_R = **2.0 个百分点 / 年(CAGR, 固定 2× gross)**。这是 lead 提出的**经济预算**, 不是由数据推出的「合理损失」; 在恒定 2× gross、忽略复利与停机的近似下约合 0.046 bps / 4h / gross, 两者不可互换使用。**须在 T_start 之前由用户确认或改定**, 确认值写进 `C_FORWARD_START` 提交。
- **重抽**: 日历日的移动块自举, 块长 **5 日为主读数**; 1 日与 10 日块只作敏感性报告, 不参与判决。B = 10,000; rng = `numpy.random.default_rng([20260919, i])`, i = 候选序号(C1 = 1, C2 = 2, C3 = 3)。同一组重抽日下标同时施于四条序列(两种子 × 两臂), 每次重抽**重算**非线性统计量。
- **单侧 p 值**(中心化自举):
  - p_g = (1 + #{Δg*_b − Δĝ ≥ Δĝ}) / (B + 1), 原假设 Δg ≤ 0;
  - p_SR = (1 + #{ΔSR*_b − ΔSR^ ≥ ΔSR^}) / (B + 1), 原假设 ΔSR ≤ 0;
  - p_NI = (1 + #{ΔR*_b − ΔR^ ≥ ΔR^ + δ_R}) / (B + 1), 原假设 ΔR ≤ −δ_R。
- **候选的检验 p**: C1、C2 = p_g; C3 = **max(p_SR, p_NI)**(交并检验: 两个原假设都被拒才算拒)。
- **家族**: 每次读数对 {p_C1, p_C2, p_C3} 做 Holm, 家族水平 = 该次读数的 α(α₁ 或 α₂)。第 1 次读数已判 (A) 的候选在第 2 次读数中不再参与 Holm(保守)。
- **判词**: (A) = 在该次读数被 Holm 拒绝; (B)(只在终点)= 主终点反方向的单侧 p < 0.05(C1 / C2: Δg 上界; C3: ΔSR 上界 < 0); 其余 (C)。同报逐种子读数、1 日 / 10 日块敏感性、gross 变化、2× 采样最大回撤(标明是 4h 采样)、日收益 CVaR 5%。
