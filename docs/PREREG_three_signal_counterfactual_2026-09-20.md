### 5.1 退化约定 C-DEGEN(**先于任何数字声明**)

`chain` 在 `Σ|w| < 1e-9` 时 `return None`, 生产代码随后会在 `abs(None)` 上崩溃 ⇒ 该锚交易 king 文件(档案里 10,039 锚中这样的锚恰有 1 个, 2022-01-31T00Z, 在全部报告窗之外)。

- **C-DEGEN(主口径)**: 某个组件的 z 恒为 0 时, 该组件的 `sm` 取**零向量**(该组件不贡献), 另一个组件照常。这是对生产代码的**一处明示偏离**, 目的是让反事实停留在**信号空间**而不是**崩溃语义**。
- **两个组件都为 0 时**(`NONE` 臂全窗; `noFUND` 臂在 w3m[0] == 0 的锚; `noKING`/`noF10` 不会): `combo_raw = 0` ⇒ 名数 0 ⇒ B-scaled 门必然不过 ⇒ **交易 king 文件**。这一条**两种口径一致**(崩溃口径也交易 king 文件), 不是偏离。
- 因此两种口径只在 `onlyKING` / `onlyF10` 上不同; 该差异的锚数逐时段**点名报出**, 忠实口径的完整 judge 运行**只在 lead 要求时**追加。
- **`BASE` 臂不受 C-DEGEN 影响**(档案里除首锚外没有退化), 所以 Gate S 仍是逐位门。

### 5.2 交易书决策(kind)的处理

B-scaled 的 COMBO_LIVE 前飞门(F10 覆盖 ≥ ⌈380·n/400⌉、`gross ∈ [0.4,1.2]`、名数 ≥ ⌈150·n/400⌉、宇宙内、`gross_in > 0.4`、king 文件存在)里 `gross` 与名数**依赖臂**。

## §6 交互项的处理(**先于看到任何数字写死**)

`chain` 非线性 ⇒ **留一法(LOO)之和不等于总量**。本预注册不把差额静默分摊。

设 v(S) = 联盟 S 的 judge 读数(主量见 §8)。记 N = {FUND,KING,F10}。

1. **逐联盟原值**: 8 个 v(S) 全部列出, 各带人口 n。
2. **LOO 效应**: `LOO_i = v(N) − v(N∖{i})`。
3. **LOI 效应**: `LOI_i = v({i}) − v(∅)`。
4. **交互缺口(显式报出, 不分摊)**: `GAP_LOO = [v(N) − v(∅)] − Σ_i LOO_i`, `GAP_LOI = [v(N) − v(∅)] − Σ_i LOI_i`。**两个缺口都必须印在同一张表上。**
5. **Shapley(唯一一个恒好和的口径)**: `φ_i = Σ_{S⊆N∖i} |S|!(3−|S|−1)!/3! · [v(S∪{i}) − v(S)]`。3 个参与者 ⇒ **6 个排序全部枚举**, 每个信号在 6 个排序下的边际贡献**逐个列出**, 并给 min/max 跨度。`Σφ_i ≡ v(N) − v(∅)` 作为算术自检(残差必须 ≤ 1e-12 的量纲阈)。
6. **可分解性判据(先于数字)**: 若 `|GAP_LOO| > 0.5 · |v(N) − v(∅)|`, 则**声明该口径不可加性分解**, 只报 Shapley + 排序跨度, 并明确写「LOO 读数不能当作贡献」。

Shapley 只在**可加量**(per-anchor 平均 g)上作为主口径。对 CAGR / 夏普 / 回撤这些**非可加**量, Shapley 与 LOO 一律标注为**描述性**, 并在表头写明「这些量上不存在贡献分解」。

# 追加条 A1 · C-DEGEN-STATE(2026-09-20, 写在任何臂运行之前; 不改上文原字节)

**触发**: Gate S 已全绿(`CF_REBUILD VERDICT=PASS checks=22 failed=[]`, 收据 `CF_REBUILD.json` sha256 `e505040eeffe3396`), 在开始跑臂时发现 §5.1 的 C-DEGEN **没有说清一件事**: 某个组件退化(`chain` 的 `Σ|w| < 1e-9` 分支)时, **下一锚该组件的 EMA 状态 H 用什么**。这是一条定义, 不是一个结果, 必须在看到任何臂的数字之前钉死。

**裁定 C-DEGEN-STATE**: 退化组件在该锚的**书与被带到下一锚的 EMA 状态都取零向量**(该组件是平的)。另一个组件照常自持状态。

**为什么不是另外两种**:
- ❌「按状态文件缺席处理 ⇒ 下一锚暖启动」: 会把 **king 书的 H** 注入一个本应关闭的组件, 等于用另一条信号的持仓冒充这条信号的贡献。
- ❌「令 tgt = 0 让 EMA 衰减进去」: 更贴近算子, 但 `chain` 的死区(`|smv − H| < band = 2.5e-4`)会在 `|H| < 2.5e-3` 时**冻住残仓**, 于是一条**全窗关闭**的信号仍然永远留着一小块被冻结的书 —— 那是死区的产物, 不是经济含义。该变体**不运行**, 在结果件局限节点名。

**不影响 BASE 臂**: 档案里除首锚(2022-01-31T00Z, 在全部报告窗之外)外没有退化锚, 所以 Gate S 的逐位门不受本条影响。

**报告要求**: 每个臂逐时段点名报出 `DEGEN_BOTH` 与 `DEGEN_ONE` 的锚数(§7.3 的具名子集), 且这些锚**不得**被当作缺测从均值里删掉 —— 它们是有测量的(交易 king 文件 / 交易单组件书)。
