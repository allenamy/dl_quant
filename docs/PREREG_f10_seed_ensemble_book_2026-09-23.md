# 预注册:F10 双种子等权平均的整书检验(单轴)

动机与业界依据见 `docs/ANALYSIS_multi_seed_ensemble_2026-09-23.md`(f3897aeb6)。

**写本文时已看过的数字**:两个 F10 种子的截面秩相关(2023–26 为 0.731/0.840/0.825/0.860)与由此推出的理论 IC 倍数;研究员报告的 NEW_s42 / NEW_s2027 在"首次停机锁存"下的读数。**没有看过**任何认证引擎下 NEW_s42、NEW_s2027 或 NEW_ENS 的读数(Stage 1 仍在跑)。

## 1. 对象(只改一件事)

- **NEW_ENS**:与 NEW_s42 / NEW_s2027 **完全相同**的组合流程(King、资金费腿、动态席位、55/45、连续链状态、FTRIM、scaled_diagnostic 发布门、门失败 HOLD),**唯一不同**是 F10 分数:
  - 每锚 A,对两种子**都有限**的名字,各自取截面秩并归一到 [0,1];`F10_ENS = (rank_s42 + rank_s2027) / 2`;只有一个种子有限的名字记 NaN(当作未打分),并逐锚报告这类名字数(预期 0)。
  - 组合对 F10 本来就取截面秩(`combo_stage.py` 的 `rankdata(f10_pm[okf])`),所以这等价于"排名平均后再排名"。
- **等权、只用这两个种子、不看结果调整。** 种子集合与权重在本文冻结。

## 2. 引擎、设置、窗口、读数

与 Stage 1 **逐项相同**(`PREREG_old_vs_new_models_same_engine_2026-09-23.md` §1.2–§1.5):认证运行器主设置、32 条路径共用随机数、判据窗 2023-06-30T04Z → 2025-12-31T20Z、分段 2023H2/2024/2025(2026 只报告)、主读数 R-main。**NEW_s42、NEW_s2027 的 32 路径 NAV 直接复用 Stage 1 的产物**(须证明运行配置除目标路径/标签外逐字节相同);若 Stage 1 尚未产出,则等待,**不另跑一份**。

## 3. 判据 —— 它该交付的是"不变差 + 不再押在一个种子上",不是"收益更高"

| # | 判据(pre-2026) |
|---|---|
| E1 非劣 | 对**每个**单种子 k∈{42, 2027}:日收益差 `d̄(t) = r_ENS − r_k`(32 路径均值)的 30 日块 97.5% 双侧区间**下界 > −0.5 bps/日** |
| E2 不制造新的最差 | 2023H2 / 2024 / 2025 每一段:Sharpe(ENS) ≥ min(Sharpe(s42), Sharpe(s2027)) − 0.05 |
| E3 换手 | pre-2026 换手(ENS) ≤ 两单种子换手均值 × 1.05 |
| E4 回撤 | pre-2026 最大回撤(ENS) 不比两单种子中较差者更差超过 1 个百分点 |

- **PASS**(E1–E4 全过)⇒ 建议把"固定种子集合、等权排名平均"写进 F10 重训配方(下一次重训起用 **5 个事先写死编号的种子**;编号在那次重训的预注册里固定),**仍需用户裁定**。
- **FAIL** ⇒ 维持单种子,记录。
- 不存在"比单种子收益更高"的门 —— 那不是它的目的,也不得事后据此宣传。

## 4. 必须同报(不作判据)

1. ENS 与两个单种子的逐段 Sharpe / 收益 / 回撤 / 换手 / 现金分解。
2. **"组合层平均" vs "资金层平均"**:把 NEW_s42 与 NEW_s2027 两本书各 50% 资本的日收益序列,与 NEW_ENS 对比 —— 回答"分数层平均是否比简单分仓多带来东西"。
3. 目标距离:L1(ENS − s42)、L1(ENS − s2027)、L1(s42 − s2027),逐锚均值与逐年。
4. 发布资格:三者逐段可发布锚数;ENS 与各单种子发布资格不同的锚数。
5. 局限:只有 2 个种子,**无法直接估计集成对种子方差的削减量**;该削减由秩相关 ρ 与理论式推出,本检验只能检"不变差"。
