### 1.1 最终格局（覆盖率经真实 MEMBER110 直测，非代理宇宙）

| 场所 | 覆盖 | 尾部深度 | 新加坡准入 | 判 |

| **Hyperliquid** | **87/110 (79%)** | 薄 38× → **必须裁到 top-40** | ToS 未限制 SG；2026-06 入 MAS 警示名单（非禁令） | **可行退路** |

| dYdX v4 | 71/115 ⚠ | — | ToS 未点名 | 关闭（覆盖 + 数据不可达） |

**★ 方法论规则（Kraken 是反例）：覆盖率统计的是"挂牌"不是"流动性"。任何候选必须过尾部深度实测。**

**⚠ 覆盖数的证据等级不一致（2026-07-25 补注）**：Binance / Hyperliquid / Kraken 的数字是**用真实 MEMBER110 名册直测**的；**OKX 与 dYdX 的数字来自代理宇宙，未经直测 —— 服务器到二者的网络均不可达**（OKX 域名解析到 link-local 地址后 TCP 超时；dYdX 端点同样超时）。**先例警告：HL 用代理宇宙时读作 70/110，直测后是 87/110（低估 24%）。⇒ OKX 的 88/115 与 dYdX 的 71/115 大概率同样偏低，但我们无法验证，所以就明写无法验证。** 这不改变结论：OKX 出局的理由是**监管结构**（永续由未持牌实体提供）而非覆盖，dYdX 出局的理由是覆盖**加**不可达 —— 两者都不因覆盖数上修而翻案。

**备选池已空** —— 覆盖 ≥90% 的四家里 Gate/Bitget/Bybit 全部禁止新加坡。若 Binance 不通，只有 HL/OKX 的裁剪方案。

### 1.2 Hyperliquid 路线的完整画像

- **价格轴无脱节**：4h 收益与 Binance 相关中位 **0.99845**（93% 的币 >0.99），波动比 ≈1.00 ⇒ **DL king 腿（主力）可原样迁移**；

**★ 解法 —— 裁到 HL 自身成交额 top-40：**

**⚠ 裁剪的一个反向代价（2026-07-25 新增，待量化）**：funding carry 有 **34.8% 来自 small 档**（量纲修正后，此前估 29.4%）。裁到 top-40 在拿到滑点减半的同时会**丢掉一部分 carry** —— **执行增益与 carry 折损必须在同一口径下相减，不能只看前者。** 先验是执行增益（maker X=3 下 11.53 vs 8.90，+2.63 Sharpe）远大于 carry 折损，但**先验不是结论**：正在按**实际 HL top-40 名册**（而非市值代理）直测"carry 有多大比例落在名单外"。此前用外推替代直测已错过一次（宇宙缩窄），不重犯。

## 3. 收益预期 —— 闭式标定（pilot 从"试试看"变成"量参数"）

**对回测逐点验证，精度 ±0.15 Sharpe：**

```
现权重:      净收益%/gross = 182.3 − 14.66 × c     净Sharpe = ÷12.16    盈亏平衡 c = 12.43 bps
challenger:  净收益%/gross = 248.7 − 20.43 × c     净Sharpe = ÷13.66    盈亏平衡 c = 12.17 bps
```
（c = 实测有效成本 bps/side，已含 funding carry。**2026-07-25 修订：常数已更新为 funding 量纲修正后的版本**，方向有利 —— 部署预期 +5pp/年、盈亏平衡门从 12.15 放宽到 12.43bps。校验：c=1.9 → 154.4% / Sharpe 12.70；c=3.94 → 124.6% / 10.28。）

| 情形 | c | 年化/gross | Sharpe |
|---|---|---|---|
| 结构口径（机构费率，现表）| 1.9 | 154% | 12.7 |
| **Binance VIP0（1.8bps maker + 1.9 逆选择）** | **3.9** | **~125%** | **~10.3** |
| VIP1（$150k gross 即达）| 3.5 | ~126% | ~10.7 |

**费率×成交率曲面 240 格无一净负。** 每贵 1bps 有效成本 = −14.57pp/年。

**首年规划**：建模中枢 ~120%/gross，但**未建模的是操作性风险**（bug、场所事件、alt 腿逆选择比 BTC 差、模型无重训在衰减）—— 这些不表现为收益折价而是突发损失。**建议按 60-100%/gross 规划，并理解主要风险不是"赚少了"而是尾部事件。**

**两个免费优化**：① 再平衡排在 funding 结算后几分钟 → carry +5.17%→+6.49%（≈+1.3pp/年，只改 cron 分钟数）；② **残余 taker 补单是强制规格**（**≈+27pp/年，悲观下界 +12pp** —— 滞后持仓的代价远超多付的手续费；"省手续费不补单"= 违反协议）。

> **2026-07-25 更正**：原写 +32pp 是**高估**。回测把整个持仓（含补单那部分）按**锚点价**拿满 4h 收益，而真实补单在 +900s 成交 —— 且**延迟不是对称噪声**：我们买的是预测会涨的币，等 900 秒就是 alpha 漏进自己的执行。实测重算：中枢 **+27.1pp**、悲观上界（hour-1 的 alpha 全在前 900s）**+12.2pp**。**最坏情形仍为正 ⇒ 判词不变，只改幅度。** 这也是 `mid_at_anchor` 必须进日志 schema 的又一理由 —— pilot 能把这个数从假设变成观测。

**★ 顺带测出一个独立有用的事实 —— 本书的 alpha 随时间近似线性累积，不是前载的**：书 4h P&L +7.87bps vs 1h +2.34bps ⇒ **f1 = 0.297**（线性为 0.25）；新交易部分 f1_delta = 0.290。**⇒ 本策略对执行延迟的敏感度是温和的**，与单资产 y600 的强前载特性明显不同（见 `single_asset_record_caliber_correction`）。这为 §6 的"桌面部署可行（延迟不敏感）"提供了**实测支撑而非仅结构性论证**。

## 6. 部署架构（桌面机方案）

**这个策略恰好最容忍桌面部署**：延迟不敏感（4h 信号 + k=900s 被动挂单）；市场中性 ⇒ 断线不裸奔；4h 节奏 ⇒ 漏一轮代价小。

```
家里专机（模型权重 + 推理 + 执行）
   └─ WireGuard 出口 ─→ 微型 VPS（$5/月：固定 IP 可白名单 + 心跳看门狗）─→ 交易所
```

- **API key 三件套**：**禁提现 + IP 白名单 + 独立子账户** —— 安全性来自权限设计不是机器位置；
- **看门狗**：心跳断 N 分钟自动撤单/平仓（云上只放几十行保险丝，模型永不出门）；
- **专机**（旧笔记本/迷你主机）+ 关自动更新/休眠 + UPS + 手机热点故障转移。

## 7. 腿权重 —— 一个待验证的实质改善

**现权重（king 0.30）是被支配的选择，不是保守的选择：**

| | 现书 | **king 0.50** |
|---|---|---|
| Sharpe（VIP0）| 10.16 | **12.58** |
| 年化/gross | 120% | **172%** |
| 最差年 / 最大回撤 | 10.19 / −3.4% | **10.69 / −2.5%** |

**收益与风险指标同时改善。** 五重证伪全扛住（逐年 5/5 全胜、bootstrap CI[+2.21,+3.44] 排 0、walk-forward 选权重自 2023 起年年选中、成本 0-12bps 无交叉、**king IC 罚到只剩 30% 时最优仍是 0.50**；最大后悔 kw=0.30 → 3.12 Sharpe vs kw=0.50 → 0.35）。

**四条腿必须全留**：king=0.50 时任何单一伴腿只给 13.1-13.4，三腿均分给 15.50（三条弱腿互补 = +2 Sharpe 分散红利）。

**★ 2026-07-25 修订（funding 量纲 bug）**：`FUND_EMA` 存每结算周期费率而 55/140 币是 4h 结算 ⇒ rank-centring 洗不掉分组量纲差 ⇒ 制造了约 −0.006 的虚假负 IC（双人独立坐实，控制组 3.3e-12）。修正后 funding 腿：**价格漂移 −10.90%→−3.69%、carry +11.62%→+12.17%、净 +0.72%→+8.48%/年、solo Sharpe +0.07→+0.83**（虚假倾斜每年吃掉 ~7.2pp）。**口径必须说清：纯价格 rank-IC 口径下仍"接近零"，含 carry 的完整经济口径下是"弱正"。** 但 Sharpe 0.83 仍撑不起 0.30 的权重 —— **腿权重结论不变**（最大后悔不对称完整存活 2.98 vs 0.34；bootstrap +2.66 CI[2.07,3.30] 仍显著；FTX 日尾部逐位相同 −0.98%），建议区间重心微调至 **0.45-0.50**，challenger 定义不变。**第二个被污染通道 `xsr_fund`(ch28)：实测两通道以完全相同强度携带同一 artifact（−0.3837 vs −0.3837 —— rank 变换把组间位移原封不动传下去，不放大不稀释）；已由常驻断言守卫 `assert_funding_dim.py` 接进面板重建作硬门，「下游会跟着修好」从假设变成被检查的事实。** DL 不重训的裁定经独立检验通过（见下）。

**★ "artifact 有没有传进 DL" —— 可证伪检验（0C，替代了我原来不充分的理由）**：判"因子显不显著"是把它当信号；DL 当特征用，不显著的特征仍可携带结构性分组标记。正确问法是"artifact 有没有传进预测"，且**不重训就能测**。逐锚 rank-centred 组间落差：corr(gap(king), gap(artifact)) = **−0.010 ≈ 0**；**逐年形态反向且决定性**（artifact 2024 最强 −0.516、2026 塌到 −0.091；king 倾斜恰好 2024 最平、2026 最大 —— 若在给 artifact 定价必须同向）；gap(Y4) = −0.033 (t −9.9) 证明 **4h 组真实收益确实更差 ⇒ king 往这边倾斜是挣来的**；corr(gap(king), gap(Y4)) = **+0.356**。**⇒ 不重训裁定通过。** 残余边界：只证明未传进预测的组倾斜，未证明该通道毫无贡献（那需消融重训）。

**尾部辩护反转**：危机受益属性主要由 **king** 提供（最差 5% BTC 日 +70→+99→+112bps）；**全书最肥的左尾恰是 funding 腿自己造的**（FTX 日全书 −0.94%，solo-funding −0.98%）⇒ 降 funding 权重是**削尾**不是拆保险。

**落地：走 challenger 不直接改** —— shadow 双轨（champion=现权重 / challenger=king .50/s2 .17/funding .17/size .16），预注册判据"不显著更差"而非"显著更好"（60 天没有功效独立确认 +2.8 Sharpe）。**pilot 起步仍用现权重。唯一缺口：权重层面零真实样本外证据。**

## 8. 税务（新加坡）

- **8/8 badges of trade 全部指向"交易所得"**（持有 4-24h、年换手 1659 倍、全自动系统化、杠杆、纯投机标的、无长期意图）—— 无悬念；
- **★ 永续的资本利得辩护空间比现货更小**（无到期日、保证金持有、每 8h 结算 ⇒ 不具资本资产属性）；
- **★ 口径断层**：IRAS《Digital Tokens》指引（第三版 2026-01-30）**全文零命中 derivative/futures/perpetual/margin/leverage** —— 它管代币处置，不管代币合约。适用的是《所得税法》通用营业所得条款；
- **★ "离岸交易所 = 境外来源 = 免税"是错的** —— 按业务在哪里经营判定；人在新加坡即新加坡来源；
- **有效税率远低于头条 24%**：年利润 ~S$180k 时个人 ~10%、公司 ~8% ⇒ **起步规模个人主体够用，公司主体的价值要到年利润 S$300-500k 以上才显现**；
- **亏损可抵扣/结转**（交易定性的对称面）；
- 自有资金自营一般无需 CMS 牌照，**但涉及他人资金/业绩报酬/对外募集即变性质** —— 与合作方结构直接相关，须律师划界。

## 9. Pilot 协议要点（完整版见 server `pilot_protocol_prereg.md`，状态 DRAFT 待签署冻结）

**★ 核心设计：判据建在成本上，不建在 P&L 上。** Sharpe-12 的书，40 交易日估 Sharpe 的标准误 ±3.3 —— **区分不了 Sharpe 12 和 5**。而成本每天有几百个成交样本。**⇒ pilot 赚钱不构成验证，亏钱不构成证伪（除非触发止损）。**

**首要产出 = 四个数**：有效成本 c、**alt 腿 markout**、成交率 φ、实测换手。

| 项 | 绿 | 黄（不扩规模+定向处置） | 红 |
|---|---|---|---|
| **有效成本 c** | ≤4.5 | 4.5-7.0 | >7.0 持续 10 日 |
| **alt markout** | ≥−4.0 | −7.0~−4.0（砍尾部 N→40 + k 拉到 1800s）| <−7.0 |
| 成交率 φ | ≥0.60 | 诊断项，不单独否决 | — |
| 权重保真度 | corr ≥0.95 且 gross 利用率 ≥0.90 | — | — |

（两条阈值互相自洽：φ=0.7、markout=−7.0 ⇒ c≈6.8 ≈ 主门红线。）

**止损（触发即停，无裁量）**：c>9.0 连续 5 日 / 单日 <−6.7% gross（回测最差日 2×）/ 累计回撤 >6% / 崩盘日 markout 尾 <−25bps / 场所事件 / 权重 corr<0.85 持续 3 日 / 再平衡失败率 >5%。

**规模阶梯 $25k → $75k → $150k**，且 **c 随规模的斜率直接裁决一个未决分歧**（HL 参与度模型说 $19-65k 容量，深度模型说 $150k 仍 5.3bps，差 2-8×：$25k→$75k 若 c 升 <0.5bps 深度模型对，>1.5bps 则第二档取消）。币种 N=50，杠杆 ≤2x，全程用现权重。

**两个前置阻断项（未满足不得开仓）**：① 场所决定落地（Binance SG 可用性）；② 执行栈干跑通过（5 日纸面 ≥98% 完成率、单次再平衡 ≤90s、演练过断线恢复）。

**pilot 回答不了的 7 件事**：P&L 无统计意义 / 更大规模容量（不得外推 10× 以上）/ **模型衰减速率与重训周期（完全未知，需 6-12 个月，C4 重训未实装）** / 场所尾部风险（宕机·回滚·冻结）/ regime 覆盖（不含真崩盘）/ **腿权重仍无真实样本外证据** / 结构→部署的最后一跳。
