# 深调研: 2024–2026 谱域 / 图时序 / 稳定性 / LOB 前沿方法 → 对我们五个缺口的映射

> **创建:** 2026-08-23 | **Session:** 调研子代理 (team-lead 委派) | **状态:** 一次性调研交付 | **作废条件:** 内部任一 G1–G5 缺口被新实验关闭, 或 2027 后文献代际更替

**方法论声明**: 证据分级 A/B/C——**A** = 金融截面真实 OOS(实市、实成本、多年份); **B** = 金融数据回测/受控消融但单一市场或无成本; **C** = 仅通用基准(ETT/Weather/Traffic 类), 对我们只有机制参考价值。所有内部先验(编码器换壳≈0、TSFM 死、router 死、交互死、300 列饱和、多种子禁)作为**硬过滤器**使用, 不重新提案。录取门沿用内部: 特征 ΔP≥+0.005(LGBM/Ridge 前置)、腿 ΔP≥+0.003、S2 净额 G 族、Q4 最坏五分位不降。

## 轴 1: FourierGNN 谱系(hypervariate 图 + 频域图卷积)

**机制(白话)**: 把「每个变量在每个时刻的取值」都当成图上的一个节点(所谓 hypervariate 图 = 变量×时间全连接大图), 然后不在时域做图卷积, 而是先做傅里叶变换、在频域做一次矩阵乘(Fourier Graph Operator), 等价于对全图做 O(N log N) 的全局混合。卖点是"空间和时间依赖一次学完"。[FourierGNN, NeurIPS'23](https://arxiv.org/abs/2311.06190) ([OpenReview](https://openreview.net/forum?id=bGs1qWQ1Fx))

**2024–26 后继**: [SpikF-GO(2026, 脉冲神经元版 FGO, 可学习稀疏频率门)](https://arxiv.org/html/2606.13901)——主打省电而非精度; [ForecastGrapher(2024)](https://arxiv.org/pdf/2405.18036) 把预测重述为图节点回归。全部在通用基准上评测。

**证据等级**: C。全谱系无任何金融截面 OOS 证据; 我方查到的应用均为交通/电力/气象。

**映射到我们**: (name×anchor) 节点图在 D1 尺度 = 400×60 ≈ 24k 节点/样本, 计算可行, 但机制上 FGO = "同一批弹药上的另一种全局混合", 与 xattn+扫描卷积表达力重叠, 不针对 G1–G5 任何一个命名缺口。频域核是**全局静态**的, 对 G3(依赖随 regime 漂移)反而比 attention 更僵硬。

**判定: 免死(不做)**。理由一句话: 换一种编码器在同一批弹药上混合, 内部 5 次平行证据 + FinTSB 外部证据都说≈0, 且频域全局核对非平稳截面是倒退。

## 轴 2: 金融时空 GNN(names-as-nodes, 动态邻接)

**机制上真正的问题**: 400 名×短窗口下, 逐对相关估计是噪声主导的; "什么在机制上能赢过朴素跨名 attention"的答案在文献里收敛为三条路:

1. **稀疏化/过滤(收缩估计)**: 学一个邻接后砍掉弱边。[TimeFilter(ICML'25): patch 级时空图过滤, 对每个 patch 自适应保留关键依赖、滤掉无关相关](https://arxiv.org/abs/2501.13041); [STN-TGAT(2026): 先验引导 + 可学习软阈值稀疏化的 top-K 组合构建](https://arxiv.org/html/2607.19385); [CrossGNN(NeurIPS'23): 明确以抗噪声为设计目标的跨尺度/跨变量交互细化](https://arxiv.org/abs/2311.06190)。机制 = 对相关矩阵做可学习收缩, 这是 attention 裸 softmax 没有的。证据全 C/B-。
2. **中心化池化(星形替代逐对)**: [SOFTS(NeurIPS'24): STAR 模块, 所有序列聚合成一个全局 core 再分发回去, O(N) 复杂度, 论文明确主张对"个别通道很烂"更稳健](https://arxiv.org/abs/2404.14197); 同族 [StockMixer(AAAI'24): 简单 MLP 做 indicator→time→stock 三段 mixing, 用 stock↔market 双向影响替代逐对图, 打平/超过一票 GNN](https://ojs.aaai.org/index.php/AAAI/article/view/28681)。机制 = 把 N² 逐对依赖压成 name→市场因子→name, 天然是低秩收缩, 低 SNR 下方差更小。证据 B(股票基准)/C。
3. **显式 lead-lag(逐对学滞后)**: [DeltaLag(2025.11): 端到端稀疏跨名 attention + 每对股票学各自最优滞后, 用领先股的滞后对齐特征预测跟随股; 实测胜过固定滞后、自历史、以及一批时空 DL 基线](https://arxiv.org/pdf/2511.00390)。**这是唯一一个朴素 xattn 结构上表达不了的东西**: 我们的 xattn 在同一时刻截面上做混合, 无法给每对 name 配不同的时间错位。证据 B(单市场回测, 无成本细节)。
4. 其他 2026 截面工作: [ACT(2026): 指出多关系图"串扰"问题, 趋势/波动/冲击三分支解缠 + 结构净化](https://arxiv.org/pdf/2604.20204)——解决的是"多个关系图互相干扰", 我们没有多关系图, 不适用; [StockMamba(2026): MASTER 同协议下 CSI300/800 IC +12–13%, 跨股 attention + Mamba-2 线性扫描 + 秩位置损失](https://doi.org/10.3390/math14111859); [FinMamba(2025)](https://arxiv.org/pdf/2502.06707) / [SAMBA(ICASSP'25)](https://github.com/Ali-Meh619/SAMBA) 图+Mamba 谱系——本质仍是编码器换壳。
5. **最接近我们场景的外部证据**: [多关系 attention 做加密货币截面(ESWA 2026): Binance 150 币 2020–25, IC 0.071, L/S 年化 63%/Sharpe 2.25](https://www.sciencedirect.com/science/article/abs/pii/S0957417426023845)——数量级与我们 zoo 复合 0.067 相当, 说明**外部 SOTA 图方法在加密截面也就打到我们现有水平**, 没有超额天花板可抢。

**映射**: 全部指向 G3。但内部先验(编码器平行 5 连)意味着 1/2 类只值"观察名单"; 3 类(DeltaLag 的逐对滞后对齐)是结构性新机制, 值一个便宜探针——**注意内部 W4 瀑布代理 0/7 阴影在案**(4h 上跨名传导以"延续"而非"反转"形式存在), 探针判据必须预注册防挑点。

**臂 spec(低优先)**: D1 输入(400 名×4h 收益/成交列)→ DeltaLag 式稀疏逐对滞后 attention 产出"领先名对齐特征"一列→ 只作为 LGBM 新特征过 ΔP≥+0.005 特征门, 不进 DL; 失败即关, 引用 W4 受据。

## 轴 3: 频域/谱方法(FreTS/FITS/TimesNet/SAMformer/FilterNet/FreDF)

**逐个机制与判定**:

- [FITS(ICLR'24): 全模型只有约 10k 参数——一个复数线性层在频域做幅相插值, 外加低通滤波截断高频; 在通用基准打平 SOTA](https://arxiv.org/abs/2307.03756)。**白话: 它本质就是一个"可学习的 EMA/低通滤波器"**。对预测本身(D1/D2 编码器)是换壳, 免死; 但作为**分数链/特征链上的平滑器**是 G2 的直接工具(见轴 6)。
- [FilterNet(NeurIPS'24): 可学习频率滤波器(普适核 + 上下文核), 明确卖点是对高频噪声的鲁棒性](https://arxiv.org/abs/2411.01623)。同上: 机制=可学习带通, 证据 C。
- [FreDF(ICLR'25): 在频域算预测损失, 解决"多步预测标签自相关导致的偏置"](https://arxiv.org/abs/2402.02399)。我们的标签是单步 4h 截面秩, 不存在多步标签自相关问题——**免死, 问题不匹配**。
- [SAMformer(ICML'24 oral): 证明浅层 transformer 在时序上收敛进坏的尖锐极小值(attention 熵塌缩), 用 sharpness-aware minimization(SAM, 白话: 优化时故意找"平坦盆地"而非最深谷底, 平坦=对参数扰动不敏感=泛化好)解锁, 小模型打平大基础模型](https://arxiv.org/abs/2402.10198)。**这不是编码器, 是优化器改动**——与内部"镜像种子/regime 倾斜极小值"现象(G1)机制严格对上: 不同种子落进不同 regime-倾斜盆地 = 尖锐极小值家族。证据 C(通用基准), 但机制迁移面广(对任何现有冠军直接加 SAM, 弹药/架构零改动)。
- 「谱归纳偏置对弱信号有没有专门证据」——**诚实答案: 没有 A 级证据**。全部频域论文在高 SNR 通用基准上评测; 唯一沾边的是加密 LOB 研究里"Kalman/Savitzky-Golay 预滤波比加层更有用"(见轴 5, B 级), 支持"去噪在输入侧做"而非"谱编码器"。[OLinear(2025): 正交变换域线性模型](https://arxiv.org/pdf/2505.08550) 进一步佐证频域收益主要是"线性模型的变换域重参数化", 不是深度机制。

**判定**: 谱方法作为编码器免死; **保留两个非编码器用法**: (a) SAM/平坦极小值 → 并入轴 7 的 G1 臂; (b) FITS 式可学习低通 → 并入轴 6 的 G2 臂。

## 轴 4: 2025–26 多变量 SOTA(TimeXer/TimeMixer++/CARD/iTransformer 系/SOFTS/DUET)

- [TimeXer(NeurIPS'24): 内生变量 patch 级 + 外生变量 variate 级表征, 用全局 token 桥接](https://arxiv.org/abs/2402.19072); [TimeMixer++(ICLR'25): 多尺度分解混合的"模式机"](https://github.com/thuml/TimeXer)(同实验室谱系); [CARD(ICLR'24): 通道对齐双注意 + 信号衰减加权损失](https://arxiv.org/abs/2305.12095); [Pathformer(ICLR'24): 多尺度 patch 自适应路由](https://arxiv.org/abs/2402.05956); [DUET(KDD'25): 时间分布聚类 + 频域通道聚类双路由](https://arxiv.org/pdf/2412.10859)。
- 证据全部 C(通用基准)。[FinTSB(2025, ICAIF workshop 最佳论文): 系统金融基准结论——"没有任何单一方法在三维指标上全胜"、"现代深度方法并不普遍胜过传统量化/树模型"、LLM 系呈现悖论式缩放](https://arxiv.org/abs/2502.18834)——**外部确认了我们内部的编码器平价结论**。
- 对 G2/G3 的机制含量: TimeXer 的"外生/内生分离"与 DUET 的"通道聚类"是弱版依赖结构学习, 均不超出轴 2 已评估的机制; 无一个含分数持久性机制(G2)。

**判定: 整轴免死**。一句话: 这条赛道的进步全部发生在"同弹药上怎么混合"这个内部已判死的维度; FinTSB 亲自补刀。

## 轴 5(优先): LOB 原生深度模型 → 处女数据 D3(60 名×12 价带×30s×3.6 年)

**文献格局(先泼冷水再给路)**:

1. **基准幻灭线**: [LOBCAST 基准(2023→AIR 2024): 15 个 SOTA LOB 模型, FI-2010 上稳、换到 LOBSTER 真实市场全部大幅掉分, "对新数据的泛化性差"](https://link.springer.com/article/10.1007/s10462-024-10715-4) ([arXiv](https://arxiv.org/abs/2308.01915)); [TLOB(2025): 即便新 SOTA, 也实测"逐年可预测性下降(F1 −6.68)", 且把点差计入趋势定义后性能显著恶化; 同文证明**一个改装 MLP(MLPLOB)就能超过既有 SOTA**](https://arxiv.org/abs/2502.15757); [Briola 等《Deep LOB forecasting 微结构指南》(2024): 可预测性由股票微结构特征(tick 大小/流动性)决定, 统计预测力强≠可交易信号](https://arxiv.org/abs/2403.09267)。
2. **输入 > 架构(加密市场直接证据)**: [Bybit BTC LOB 研究(2025): 经 Kalman/Savitzky-Golay 预滤波与调参后, 逻辑回归/XGBoost 能打平甚至超过 DeepLOB 类深网——"更好的输入比再堆一层隐藏层重要"](https://arxiv.org/pdf/2506.05764)。B 级、同资产类。
3. **平稳化衍生量 > 原始书**: [Kolm–Turiel–Westray(Math. Finance 2023): 115 只 Nasdaq 股票、多视界, 用**订单流(OFI)等平稳输入**训练的普通网络显著胜过直接吃原始 LOB 状态的模型](https://onlinelibrary.wiley.com/doi/10.1111/mafi.12413)。A-。
4. **跨名共享一个模型(泛化性最强的正面证据)**: [Sirignano–Cont(2019): 全市场数据训练的"通用模型"OOS 胜过任何单资产模型, 且对训练集外股票成立——价格形成机制跨资产近似普适](https://arxiv.org/abs/1803.06917)。A-。**直接背书 D3 上 60 名共享参数、截面训练。**
5. **多价带怎么聚合(band=space 的正确打开方式)**: [Cont–Cucuringu–Zhang(QF 2023): 把多档 OFI 用 PCA 整合成"integrated OFI", 对价格冲击的解释力显著超过最优档 OFI; 跨资产 OFI 对**未来**收益有预测增量但**短视界、快速衰减**](https://arxiv.org/abs/2112.13213)。A-。含义: 12 带不是 12 个独立通道, 是一条深度曲线, 低维整合(PCA/斜率/不对称)是第一性表示。
6. **档间结构建模**: [HLOB(2024→ESWA 2025): 用 TMFG 信息过滤网络挖档位间依赖再做同调卷积; 系统刻画了"信息在 LOB 空间分布 + 随视界增大而衰减"](https://arxiv.org/abs/2405.18938); [LOBench(2025): LOB 表征学习系统基准(中国 A 股), 证实 LOB 表征对下游任务充分且必要、且优于通用时序模型直接搬运](https://arxiv.org/abs/2505.02139); [SimLOB(2024): transformer 自编码器学 LOB 潜向量, 保留档位先后序结构](https://arxiv.org/abs/2406.19396); [FastBiNLOB(2026): LOB 推断-算力前沿, 强调延迟-精度权衡](https://arxiv.org/pdf/2606.25986); [LiT(2025)](https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2025.1616485/full)。
7. **架构族结论**: 原始 band×time 网格上, 赢家形态收敛为"**band 维小卷积/空间注意 + time 维时序模块**"(DeepLOB 系 2D 卷积 → TLOB 双注意), 但 MLPLOB 的存在说明架构红利已薄; 30s 采样×±5% 价带比 tick 级 L2 粗得多, HFT 文献的 10–100 tick 视界结论**不能外推**到 4h。

**与内部先验对表**: ①「新增量只能来自新信息源」(弹药战役七判全负)——D3 正是新信息源, 这轴的期望值全在数据不在模型; ②「book 族退役 5 形态×3 目标全零」——那是**顶档/bar 级书特征**在 4h 的失败, 12 价带×30s 的空间结构(深度曲线形状、带间迁移、补单/撤单动力学)未被覆盖, 但该受据要求我们把"退役 5 形态"列入禁重复形态清单; ③维持"先过 LGBM 特征门再谈 DL"铁律——文献(2、3 条)恰好也是这个结论。

**臂 spec(最高优先)**:
- **第一阶段(特征轨)**: 输入 = 每名 12 带×30s 深度 → 每带平稳化变换(band-OFI/Δdepth、补撤单代理、跨带斜率与买卖不对称、integrated-OFI 第一主成分), 多半衰期(5m/1h/4h/24h)EMA 金字塔聚到 4h 锚 → 并入 D1 表格, LGBM 门 ΔP≥+0.005(特征)/+0.003(腿), 再过 S2 净额 G 族 + Q4。禁与退役 5 形态同构。
- **第二阶段(仅当一阶段过门)**: band×time 小 2D 卷积编码器(DeepLOB 式空间卷积, 60 名共享参数, film2 同尺寸预算), 目标 = 一阶段特征之上的正交残差; 双种子, σŷ/σy≥0.02, 逐折同号。
- **免死风险登记**: LOBCAST/TLOB 的泛化警告 + 30s→4h 的视界外推 + 退役受据, 三者共同压低先验成功率; 该臂的价值主张是"处女数据的期权", 不是文献胜率。

## 轴 6: 稳定性/换手感知架构(G2: 分数时间稳定性)

**这是文献直接给出可搬运机制最多的一轴。** MLP/LGBM 逐锚从零重排是结构缺陷: 它们看不见 t−1 的自己。四个互补机制:

1. **决策诱导的换手膨胀是已命名现象**: [SPO/决策聚焦学习的 KKT 分析(2026): 端到端"预测→优化"训练会把预测幅度打胖(prediction inflation)、诱发过度调仓; 修复 = 输出约束(裁剪/重标度)+ **部分调仓(partial adjustment)**并入训练](https://arxiv.org/pdf/2605.01176)。**对我们是双重身份: 既是 F-10 可微书损失的风险警告(损失里已含换手项可部分对冲), 也是机制来源。** 证据 B。
2. **换手正则直接进损失(金融证据)**: [期权端到端(ICAIF'24): 训练损失用换手调整后收益 = 优化 Sharpe 同时正则换手, 高成本环境显著胜出](https://arxiv.org/pdf/2407.21791); [Finance-Grounded Optimization(2025, 加密数据): 同族结论](https://arxiv.org/pdf/2509.04541); [DeePM(2026): 成本内化训练时用 γ=0.5 的**打折成本**反而比全成本训练 OOS 净 Sharpe 高约 50%(过强成本罚会杀死信号捕获)](https://arxiv.org/html/2601.05975v1)。B 级——**γ 折扣是可直接搬进 F-10 的免费旋钮**。
3. **churn 蒸馏(跨代分数一致性)**: [Churn Reduction via Distillation(ICLR'22): 新模型训练时向旧生产模型蒸馏 = 显式约束预测翻转率, 等价性有证明](https://arxiv.org/abs/2106.02654); [stability–plasticity 视角(2023)](https://arxiv.org/pdf/2305.04135)。对月度重训场景(RUNBOOK_monthly_retrain)机制严格对口: 换代日的整书重排是一次性巨额换手, 蒸馏正则直接压它。**注意**: 双模型互蒸(co-distillation)触多种子禁令, **只允许"旧生产模型单向做老师"**——旧模型是既成事实, 不是新增集成。证据 A-(ML 系统域)/C(金融域无直接)。
4. **头部约束(排序稳定的结构解)**: [RankGLU(2026): IC 导向下"过灵活的头会拟合不稳定的收益幅度"; 线性直通路 + 有界 sigmoid 门控旁路, CSI300 五种子 IC 0.0654→0.0727(p=0.013), 且主打多种子方差小](https://arxiv.org/html/2606.08930v1)——与我们「IC 是 alpha, β 是量纲」纪律同源; 检索式排序系统的分数稳定正则是更老的同族([WWW'20](https://dl.acm.org/doi/pdf/10.1145/3366423.3380030))。证据 B-。
5. **可学习平滑器(SSM/频域作为 smoother 而非 encoder)**: 文献没有现成"SSM-as-smoother"论文, 但 FITS 的复数线性低通(轴 3)恰好是这个东西的 10k 参数实现: 挂在每名分数链上、与 F-10 的 EMA 递推链联合训练, 让"平滑多少"由净额目标自己定——**是在役 EMA α=0.05/带宽 b=0.002 的可学习推广**。证据 C, 但成本极低且有在役基线可对照; 内部"自适应换手家族封卷"(66 格曲面 argmax 在噪声内)警告: 该臂唯一合法判据是**联合训练后的净额与换手帕累托**, 不是再调一次 α。

**臂 spec(高优先, 全部是损失/头部改动, 零弹药零架构变更)**: 冠军管线 + F-10 损失 → 加三件: (a) Δscore/Δrank 持久性罚(或旧模型蒸馏项, 换代月启用); (b) 成本项 γ∈{0.5,0.75,1.0} 剂量-反应; (c) RankGLU 式头替换(单变量原则下作为独立臂)。门: 同成本线净额 CI>0 且换手不升, Q4 不降, 双种子。

## 轴 7: regime 条件化(G1)——超越 FiLM, 区分「条件化」与「择时」

**内部红线先摆**: 择时/顺势轴五形态(FiLM/meta-score/IC 择时/router/趋势β)已全关; 允许的是**表征条件化**(film2 在役)与**训练目标层面的 regime 稳健化**。文献映射后, 真正的新东西在后者:

1. **最坏-regime 目标(把 Q4 门从"事后判据"变成"训练目标")**: [DeePM(2026): 对窗口化 Sharpe 取 SoftMin(数学上等价 EVaR——熵值风险度量, 白话: 自动给最差时段加权的软最小值), "强迫优化器优先保证最坏 regime 存活"; 50 期货 2010–25 实成本, 净风险调整收益约 2× 基线, 消融齐全](https://arxiv.org/html/2601.05975v1)——**这是本次调研中机制-证据积最高的单篇**。同族理论根 = group DRO([Sagawa 2020](https://arxiv.org/abs/1911.08731), 白话: 按最差组的损失做优化)。
2. **平坦极小值 × 最坏组的合流**: [ASGDRO(CVPR'25): 自适应 sharpness-aware + group DRO, 显式主张"在所有环境上找共同平坦极小值"才能学到充分不变特征](https://cvpr.thecvf.com/virtual/2025/poster/34665); SAMformer(轴 3)提供时序侧 SAM 证据。**与镜像种子问题的对应关系**: 种子间落入不同 regime-倾斜盆地 ⟺ 每个盆地都尖锐且只对部分环境低损; 共同平坦盆地假说预测: SAM/DRO 训练后**种子对之间的 regime 倾斜距离收缩**——这给了一个可证伪的中间观测量, 不用等净额。证据 B(视觉 OOD)/C(时序), 金融无直接。
3. **不变特征学习**: [InvariantStock(2024): 环境感知/环境无关双模块, 特征选择促独立, 中国 A 股涨跌两态均稳](https://arxiv.org/pdf/2409.00671)。B-。机制与 2 重叠但实现更重(特征选择器), 列为参考不立臂。
4. **MoE 软门控**: [MIGA(2024/ICLR'25 投稿): 63 风格专家 + 组内注意共享 + IC 损失 + 负载均衡路由, CSI300 超额 24%](https://arxiv.org/pdf/2410.02241); [MERA(WWW'25 companion): 检索增强 MoE](https://dl.acm.org/doi/10.1145/3701716.3715513); [regime 门控 transformer(2026)](https://arxiv.org/pdf/2606.29347)。**全部撞内部 router 关闭受据**: 专家切换 = 软路由 = 我们实测 +0.0019 OOS 不迁移那条轴。CSI 基准、无最坏-regime 压测、MIGA 录用状态不明。免死。
5. **测试时自适应(TTA)**: [TAFAS(AAAI'25): 用部分到达的真值在线校准预测器](https://arxiv.org/abs/2501.04970); [原理化 TTA(2026)](https://arxiv.org/pdf/2605.17250)。4h 锚一天 6 个, "在线自适应"退化为高频重训, 与月度重训 + 冻结纪律冲突, 且引入运维/泄漏面。免死。
6. 超网络(hypernetwork, 用市场状态生成另一网络的权重): 仅见 [reservoir 混搭(MDPI 2025)](https://www.mdpi.com/2075-1680/14/8/597) 级别证据, C-, 且机制上是 FiLM 的重参数化亲戚(FiLM 已在役/其择时用法已关)。免死。

**臂 spec(与轴 6 的 (b) 并列为损失层战役)**: 冠军管线不动 → 训练目标改为 regime 桶(按在役 regime 定义: 波动档/挤压日历/年份)上的 SoftMin-Sharpe 或 group-DRO 加权 F-10 净额, 可选 +SAM; 判据(预注册): ① Q4 净额 CI>0 改善且均值不降超 x%; ② 镜像种子 regime-倾斜距离收缩(中间机制观测); ③ 剂量-反应(SoftMin 温度 3 档)单调。**声明: 这是训练加权, 不产生任何 gross 择时输出, 不触 router 禁令。**

## 三句白话总结

1. **模型换壳这条街已经死透了, 外部基准(FinTSB/LOBCAST/TLOB 的 MLPLOB)现在也承认**; 2024–26 真正能搬的前沿不在编码器, 在**训练目标**(最坏-regime SoftMin、换手/churn 正则、打折成本)和**新数据**(D3 价带面板)两处。
2. D3 的文献配方很一致: **先做平稳化带级特征(OFI 族/深度曲线低维形状)喂 LGBM, 共享参数跨 60 名, 最后才考虑小卷积**——和我们自己的铁律一字不差, 所以这条臂没有方法论风险, 只有数据风险。
3. G1/G2 两个缺口第一次有了"结构上 LGBM/MLP 做不到、且不触任何内部禁令"的干净臂: 都只改损失和优化器, 冠军管线一行不动, 便宜到不做说不过去。
