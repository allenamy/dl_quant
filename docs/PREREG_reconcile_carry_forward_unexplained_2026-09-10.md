## 0. 问题(研究员第四轮实证, 我方接受)
现役 `reconcile` 逐窗比较: 窗 t 的残差 = (Q_t − Q_{t−1}) − K_t − clip(·, L_t, U_t)。**下一窗以场所观察 Q_t 为新基准**, 于是窗 t 未解释的余额(例: 已解释 50, 观察 80, 残差 30)在窗 t+1 消失: 若 t+1 无成交且观察仍 80, 残差 0, §4-5b/5e 两门 CLEAN, 历史残差 30 只留在 `residual_by_anchor` 里。研究员用真实 topup(两请求各 EXPIRED 成交 25)→ 回读 80 → 下锚零成交 → 回读 80 复现: 最新一格 CLEAN 不等于数量恒等式已闭合。**这是旧 latest-only 消费方式的盲点, 不是第四/五轮引入。** 同时, 第四/五轮的授权带只在含该行时间戳的窗口生效(不会重复花掉, 已由研究员穷举 20,301 对证实), 但晚到的成交在下一窗读成未解释(误报方向), 旧 UNKNOWN 行不自动关(第五轮后子成交可跨次抬 C, 但没有「下锚按 id 查终态」)。

## 1. 合同(冻结先于任何数字)
对每个 symbol s 维护两条跨窗状态, 直到被**可核对证据**解决:
1. **双时钟**: 每条证据带**事件时间**(场所执行/终态发生的时刻, 取场所 updateTime/成交 time)与**观察时间**(我们读到它的锚)。所有算术按事件时间排布; 观察时间只决定「哪一锚能算」。迟到的证据(观察时间晚于事件时间所在窗)**收窄同一请求**(C 升、余量降), 从不产生第二份执行, 也从不在观察时间处记增量。
2. **未解释余额 E_s 是累计恒等式, 不是逐窗递推**(修订 1): 对每个 symbol, 以启动/重启边界的回读 Q_s(t0) 为起点, 在任一锚 t 重算
   E_s(t) = [Q_s(t) − Q_s(t0)] − K_s(t) − clip([Q_s(t) − Q_s(t0)] − K_s(t), L_s(t), U_s(t)),
   其中 K_s(t) = Σ 事件时间 ≤ t 的已确认带号数量(含迟到证据), [L_s(t), U_s(t)] = 事件时间 ≤ t 且在 t 仍未终态的请求余量的 Minkowski 和(终态请求余量 0)。判门读 |E_s(t)|·mark。**为什么不能递推**: 研究员反例 —— 首窗未知 Q100 覆盖持仓 80(e_1 = 0), 次窗迟到终态 C50 且持仓仍 80: 字面递推 e_2 = (0 − 50) − clip(…) = −50 ⇒ E = −50; 同一 C50 若首窗已到 ⇒ E = +30。最终事实相同, 正确净未解释 = 80 − 50 − clip(30, 0, 0) = **+30**, 累计恒等式两种到达顺序都给 +30。
3. **未决请求集 P_s**: 第五轮账本里 `terminal=False` 或 `state=unknown` 的请求, 按事件时间跨窗保留其 [L, U] 直到终态(场所 status / C 达 Q / 显式授权更正); 同一请求的带在累计恒等式里只出现一次(不是逐窗重发额度); 一个请求的迟到成交进入 K 的同时其余量等量减少(supersedes 折叠), 不得既计 K 又留带。
4. **启动/重启边界**: Q_s(t0) 取复场/重启后的首次回读; 边界前的历史 E_s 归历史审计(报告, 不判门), 归零起点必须是记账行(用户字)。历史审计未决与当前风险报警分别建模: 带号 +30 与 −30 相抵只说明净暴露归零, 不证明两个事件已归属。
5. **解决 E_s 的证据**(仅三类): (a) 后到的可归属成交(userTrades 按 (symbol, orderId) 联接到 P_s 里的请求)抬 K; (b) 划转/结算等非交易类的显式记账; (c) 用户签字的授权更正行(orders 追加, 类型 `reconstructed`, 带来源 sha)。**没有第四类**: 尤其不允许「下一窗观察没变」自动清零。
6. 坏值规则同第四/五轮: 非有限 / side 缺失 / 矛盾 ⇒ 不可测(异常), 不入 E_s 的算术。

## 1b. 修订 2: 联合状态合同(研究员第六轮 D1–D4)

**对象**: 对 symbol s 的每张请求 i(身份, 方向 σᵢ, 请求量 Qᵢ, 出生锚 bᵢ, 终态锚 dᵢ 或 ∞), 维护**已执行量的可行区间** Xᵢ(t) = [xᵢ⁻(t), xᵢ⁺(t)], 表示「到时刻 t 为止该请求累计成交量」所有与证据相容的取值:
- 出生前 Xᵢ = [0, 0]; 出生后无证据 Xᵢ = [0, Qᵢ]; 有可信下界 C(子成交并集 / executedQty 读数)⇒ xᵢ⁻ = C; 终态且 C 可信 ⇒ [C, C]; **终态且 C 未知 ⇒ [xᵢ⁻, Qᵢ] 保持, 不因终态归零(D3)**。
- **单调**: xᵢ⁻(t) 随 t 不减(证据只增); 真实累计成交 xᵢ(t) 本身不减 ⇒ 对任意 t₁ < t₂, 可行解须满足 xᵢ(t₁) ≤ xᵢ(t₂)。
- **两种余量分开(D2)**: 未来容量 = Qᵢ − xᵢ⁻(t)(仅对 dᵢ = ∞ 的请求, 用于「还可能新增多少」); 历史未知 = xᵢ⁺ − xᵢ⁻(用于「过去已发生但未核实多少」)。两者不共用一个 U; K 只计 xᵢ⁻(独立证据), **隐含归属**(由持仓读数反推的 x)只进入可行集, 不进入 K。

**联合约束(D1)**: 给定读数序列 Q_s(t₀) = Q₀, Q_s(t₁), …, Q_s(tₙ) 与非交易流 F(tₖ), 要求存在单调可行向量 x(tₖ) ∈ ∏ᵢ Xᵢ(tₖ) 使每个 tₖ 满足 Q_s(tₖ) − Q₀ − F(tₖ) = Σᵢ σᵢ [xᵢ(tₖ) − xᵢ(t₀)]。
- **判定**: 逐锚区间传播(对 ≤ 3 张同名请求可精确): 把 tₖ 的和约束与 ∏ Xᵢ(tₖ) 相交, 再把每个 xᵢ 的下界向前传播到 tₖ₊₁(单调), 上界由 Xᵢ(tₖ₊₁) 给出; 任一步交集为空 ⇒ 「历史无法联合归属」(审计未决)。**只在每个时点各自投影得到 0 不算联合可行**: 单 BUY100 无其它流, 两读数水平 (first, second) 的联合可行集恰为 0 ≤ first ≤ second ≤ 100(5,151 对), 点时 clip 接受 10,201 对, 多出的 5,050 对全是下降轨迹(如 80→10)—— 下降在无卖出请求时不可归属。
- **两个指标分列(D1 后半)**: (a) 当前净暴露距离 e(tₙ) = Q_s(tₙ) − Q₀ − F − proj(可行集在 tₙ 的和区间)(可为 0); (b) 历史审计未决标记 = 联合约束不可满足的最早锚与涉及请求。触发哪个门由预注册另定, 本文不擅定停机政策; 至少 (b) 必须页。
- **迟到证据**: 更新同一请求的 Xᵢ(收窄), 整条轨迹重算; 当时在线的判定与收据保留, 不改写。

**同截面重启(D4)**: 重启/复场切点 t₀ 的 Q₀ 与「切点时各请求已执行量」必须是同一截面: 对跨切点的旧请求, 记录 xᵢ(t₀) 的区间(已知则 [C, C], 未知则 [xᵢ⁻, Qᵢ])并把 Xᵢ 的比较基准换成 xᵢ(t) − xᵢ(t₀); K 只计切点后的增量证据; 切点前的未解释历史归档到审计, 不进当前门。技术重启不产生新额度, 也不抹旧事件; 经用户签字的记账起点行才能建立新审计 epoch。**反控(研究员)**: 旧 BUY100 切点前已成交 80, Q₀ = 80, 剩余容量 20, 之后读 180: 误用全历史 K=80 + 余量 20 ⇒ e = 0(错); 同截面 ΔK = 0 + 余量 20 ⇒ e = 80(对)。

**验收判据追加**: (5b) 单 BUY100 双读数全域枚举: 联合判定接受的 (first, second) 集合 = {0 ≤ first ≤ second ≤ 100}, 与 first+second ≤ 100 的错合同交集 2,601、各自独有 2,550(核解集不核计数); (5c) 80→90 合法(同请求余量), 80→10 审计未决而非「当前必 −70」; (5d) 终态 C 未知 + 后读 80→90: 90 不可由同请求解释(终态后无容量)⇒ 未决; (5e) 切点反控 180 ⇒ e = 80。

## 1d. 修订 4: 恢复政策是合同的一部分(研究员第八轮 D8-1), 验收例更正(D8-2)

**D8-1 接受**: 「删除最早不可满足的约束后的最大可满足子集」不是唯一对象 —— 研究员两例: 单 BUY1 读数 1→0, 最大基数观测子集有两个({第 1 锚=1} ⇒ 下锚预测 {1}, 再读 0 距离 1; {第 2 锚=0} ⇒ 预测 {0,1}, 距离 0), 不同修复集给出不同风险读数; BUY2 读数 2→0→1, 按时间准入保留 1 条(第 1 锚), 全局最大基数保留 2 条(第 2/3 锚)。选择哪个是合同, 不是实现细节。

**政策(登记)**:
1. **可降级域**: 只有观测等式 (e)(持仓读数产生的每锚和约束)可以被降级; 硬约束 (a) 出生前 0、(b) 单调、(c) 终态后常量、(d) 证据下界 / 终态精确总量, 以及身份、方向、容量 **永不降级**。
2. **准入顺序 = 时间顺序(chronological admission)**: 观测等式按锚时间依次准入; 加入某条使 F 为空 ⇒ 该条降级为「被排除观测」(记锚、读数、当时的 F 摘要), **不再回头重排**; 已准入的等式不因后来的观测被撤销。理由: (i) 确定, 无并列; (ii) 审计一致 —— 一条读数在它到达时已被风控消费, 之后的读数必须与已接受的历史一致, 而不是反过来改写历史; (iii) 与「每锚一次判决」的运行方式同构。明写: 这**不是**全局最大基数子集; BUY2 2→0→1 保留第 1 锚(排除第 2/3 锚)。
3. **迟到硬证据**(终态 C、子成交并集)按其**事件时间**插入硬约束集; 硬约束变化 ⇒ **重建前缀**: 从该事件时间起重新按时间准入观测等式(硬约束在先), 之前已准入但现在不可满足的等式降级(记录「因迟到证据被排除」); 原始在线收据(当时的 e、当时的判决)一律保留, 不重写。例: 已准入观察 80, 迟到终态 C50 ⇒ 重建 ⇒ 观察 80 被排除, 当锚距离 = dist(80, {50}) = 30; 旧 0 收据保留。两种到达顺序终值皆 30(与研究员 D8-1 末段一致)。
4. **硬约束自身不可满足**(例: 同一请求两个不同的可信终态量; 精确总量 0 与 1)⇒ 该名**不可测**(坏值规则): 不伪造有限距离或 0, 不删成交事实 / 终态 / 身份 / 容量约束来换可算性。
5. **checkpoint 保存**: 硬约束集 + 已准入等式 + 被排除等式(含原因)+ 政策身份(名称 + 版本 = 本节 rev 4); 恢复时按同一政策重放, 结果必须逐位相同。
