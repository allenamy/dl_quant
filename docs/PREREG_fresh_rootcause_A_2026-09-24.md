## 0. 组合是怎么合成的(先于设计写明,决定什么能拆什么不能拆)

`combo_target.step` 实测(L30–L40):

```
w    = normalize([seat_king, 0, seat_fund])         # seats[1](rev24)被置零 = 掩码席位
zkc  = w0*king_rank + w2*fund_rank
zfc  = w0*f10_z     + w2*fund_rank
kc   = chain(zkc);  fc = chain(zfc)                 # chain = EMA/带/归一,非线性
raw  = 0.55*kc + 0.45*fc                            # 精确线性
weights = exec_reshape(raw)                         # 非线性
```

**可以精确拆的:** `raw = 0.55·kc + 0.45·fc`。**份额必然闭合**,这是恒等式。
**不能拆的(写明,不假装):**
1. **资金费不是一条可加的腿。** `fund_rank` 以 `w2` 同时进入 `zkc` 与 `zfc`,而且在**非线性 `chain` 之前**,
   所以在 `raw` 层**无法**把资金费分离成第三条腿。lead 任务书里的"kc / fc / 资金费"三分,
   **在这条管线里只有前两项是可加的**;资金费的份额**只能**通过 `w2` 报告其**权重**,不能报告其**收益贡献**。
2. `exec_reshape` 与引擎的执行/成本是非线性的,所以本阶段的拆解做在 **`raw` 层的代理 P&L** 上,不是引擎实现收益上。

## 2. A2 — 高席位锚的解剖(只读)

**(a) 代理 P&L 与它的标定(先做,后拆):**
`proxy[i] = Σ_n raw[i,n] · y4s[i,n]`(`y4s` = 两臂训练收据共同指名的标签)。

**(b) 精确可加的拆解(份额必须闭合,装置内断言):**

**(c) 只报权重不报收益的部分:** 逐锚 `w2`(资金费席位权重)与 `w0`(King 席位权重)的分布,高席位锚 vs 其余锚。

**(d) 分布对照(高席位锚 vs 其余锚),每项都报两组的中位数与四分位:**
