## 0. 为什么必须按族评估(rn8 这轮给的教训)

rn8 是**确定性的组合层改动**(删两行等价的输入替换),但书层效果**随 F10 抽样翻转**:
判据窗 `dbar` s42 **+1.18** / s2027 **−3.70**,2025 单年相差 **12 bps/日**。
而同一轮里 `Δfunding_paid` 两种子**几乎重合**(2026 差 0.001)。

⇒ **被测的两件事分辨率差一个量级。** 只用两个种子判组合层改动,功效只够看 ~2.6 bps/日以上的效应
(与 B1 同级)。**所以每个候选臂都必须在族内每个成员上跑一遍,得到 n 个配对差。**

**族(lead 指定)** = NC `s42` / `s2027` + dlarch 的 **T0 × 8 个 F10 种子(King 固定)** = **10 个成员**。
族产物在 dlarch 的书层产物之后才齐;**在齐之前只做 CPU 侧准备**(装置 + G0 类基线逐位控制),不跑引擎。

## 2. 候选臂(每个都写:机制 / 为什么预期改善 / **2026 regime 下是否还有作用**)

**2026 regime 的关键事实(dlarch b80a5fd31)**:掩码席位 `w0` 在 pre-2026 **43.0% 的锚是 bang-bang**(恰 0 或 1),
**2026 是 0%**(全在内点)。⇒ **凡机制依赖「席位取极值」的臂,在 2026 应当近乎失效**;这是每个臂的可证伪预测,不是修辞。

### A 席位估计

**A1 窗口匹配模型寿命 —— 不再提出:已由 B8 在组合层判 REFUTED**
(`RESULT_fresh_book_anomaly_2026-09-24.md` 附录 D)。它剩下的活口是**全管线确认**(F10 按短窗 `WL` 重训),
需要 GPU,由 lead 另排。**本轮不重复测。**

**A2 席位向等权收缩** `w3 ← (1−λ)·w3 + λ·(⅓,⅓,⅓)`,λ ∈ {0.25, 0.5}
- **机制**:`w3 = max(mean/std, 0)` 归一化,是**两个噪声量之比**,在 900 锚上抽样误差大;
  而 combo 只用 `s0 : s2` 的**比值**(`combo_target.py` L30 把 `rev24` 席位整列丢掉)。收缩降方差、增偏。
- **为什么预期改善**:B2 已证**全收缩(常数席位)对 NC/NEW_S 明确有害**(损失 6.9–8.7 bps/日,区间不含零)
  ⇒ 席位**确实携带信号**,所以 λ=1 坏、λ=0 是现状 ⇒ **若存在偏方差折中,最优在内点**。这是本臂唯一的立论。
- **2026 下是否还有作用**:**预期更弱**。2026 席位全在内点,收缩对内点值的移动量小于对 bang-bang 值的移动量。
  **可证伪预测:`|Δw0|` 的 2026 均值 < pre-2026 均值**,且书层效应同向变小。

**A3 稳健统计量替代 `mean/std`**:`median/MAD` 与 `10% 截尾均值 / 截尾 std` 两支
- **机制**:腿收益 `LR` 尾重;`mean/std` 被单个大锚拉动。`shp = max(mean/std, 0)` 一旦某腿的 `mean ≤ 0`
  就被**硬置零**,这正是 bang-bang 的来源(43.0%)。稳健统计量降低「某腿被整段置零」的频率。
- **为什么预期改善**:bang-bang 席位 ⇒ 单腿独占 ⇒ king/F10 分歧放大 ⇒ 抵消 ⇒ `raw gross` 塌破 0.4 ⇒ 预检失败
  (这条链在案:`seat_pushes_book_through_its_own_preflight_2026_09_20`)。降 bang-bang 频率应当直接减少该失败模式。
- **2026 下是否还有作用**:**预期近乎为零**(2026 bang-bang 已是 0%)。
  **可证伪预测:2026 的 `Δw0` 与书层差都应显著小于 pre-2026;若 2026 效应反而更大,本机制被否。**
- **必报**:两臂各自的 **bang-bang 锚占比**(原书 vs 变体),这是机制是否起作用的直接读数。

### B 混合方式(当前 `raw = .55·kc + .45·fc`,`combo_target.py` L38)

**B1 先各自归一再混合** `raw = .55·kc/‖kc‖₁ + .45·fc/‖fc‖₁`
- **机制**:`kc`/`fc` 各自过 `chain()`,而 dlarch 实测**保留率 King 34.8% / F10 58.1%** ⇒ 两者的 L1 范数**系统性不同**
  ⇒ **名义 0.55/0.45 不是有效混合比**。归一后声明的权重才是实际权重。
- **为什么预期改善**:如果 0.55/0.45 是有意选的,那么现在执行的其实是别的比例;归一把「配置说的」与「实际做的」对齐。
- **改变了什么 / 没改变什么**:**没改**每条腿内部的**符号结构与秩**;**改了**两腿的相对尺度,
  因此也改 `raw gross`(⇒ 可能改发布门命中)。**必报:归一前后的 ‖kc‖₁/‖fc‖₁ 比值分布。**
- **2026 下是否还有作用**:**有**,且可能更大 —— 保留率差异与席位无关,不随 bang-bang 消失。

**B2 按分歧度调节** `raw ← raw · f(agree(kc, fc))`,`f` 单调、有界
- **机制**:两腿分歧时逐名相消,`raw gross` 塌陷。
- **⚠ 为什么我预期它在 2026 近乎无效**:dlarch S1(标签 **VOID**,待零控制重跑)测到两链
  **权重相关 pre-2026 0.43 → 2026 0.91**,**抵消系数 0.83 → 0.98**,而**分数层 ρ 只有 0.07–0.11**;
  同期资金费份额 `w2` 由 0.354 升到 0.685。即**资金费占主导时两条链几乎是同一本书** ⇒ **2026 几乎没有分歧可调**。
  **可证伪预测:按 `w2` 分档,`f` 的作用应随 `w2` 上升而单调趋零。**
- **引用限定**:dlarch S1 现为 VOID,**本臂的立论依赖它**,所以**阶段 1 之前必须等 S1 的零控制重跑定论**;
  若 S1 被否,本臂的机制叙述需重写(臂本身仍可跑,但"为什么预期改善"没了依据)。

**B3 对抵消后的 gross 重新缩放以避开预检下限**
- **机制**:`raw gross` 塌破 0.4 就整锚不发布。缩放使其回到门内。
- **⚠ 一个必须先测而不能断言的等价**:执行器**先 L1 归一再乘 NAV × gross_mult**,所以 `raw gross` 的绝对值
  **在执行器处被整除掉**(在案:`three_signals_are_substitutes_not_a_decomposition_2026_09_20` 的「预检 0.4≤gross≤1.2
  不可能是风险控制」)。⇒ **B3 很可能与「放宽门限」(C2)在书层近乎等价。**
  **这是要测的命题,不是前提**:必报「B3 与 C2 的逐锚权重差异格数」,若为 0 则两臂合并为一。

### C 预检门

**C1 B4(门失败时照写)在 NC 自己的方案上重测**
- **机制/立论**:B4 对 FRESH(月折)**两种子同利** +1.91/+2.15;对 NEW_S(年折)**两种子反号** −2.59/+0.40。
  **NC 是年折**,与 NEW_S 同类 ⇒ **预期不明**,必须重测。**部署的就是 NC,所以这一格的优先级高于它的先验。**
- **2026 下**:2026 的预检失败率是关键前置事实 —— **必报 NC 原书逐年的 `gross < 0.4` 占比**,
  若 2026 近乎为 0,则 C1 在实盘 regime 无作用面。

**C2 门改为纯退化探测** `raw gross < 0.1` 才拦
- **机制**:见 B3 —— 门在执行器口径下不是风险控制,更像退化探测器。把门限下移到只拦真正退化。
- **预期**:发布率大幅上升。**但 B8 已给出警告:发布得更多并不等于书变好**(B8 里持有率 0.27→0.19 而 FRESH 无改善)。
  所以本臂的立论**不是**「发布更多更好」,而是「0.4 这个数没有受据来源,退化探测只需要远小于它的门限」。
- **必报**:被新门拦下的锚数与其 `raw gross` 分布(证明它真的只拦退化)。
