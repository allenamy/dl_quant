## 两条规则的具体差别(读码,`fund_block` L472–473 对 `nc_contract.snap_interval` / `ema_step`)

| 情形 | 旧(回放 = 09-24 前的生产者) | 新(NC 合同 = 在役口径) |
|---|---|---|
| 间距落在两档正中(如 3h、1.5h、5h、7h) | 取**小**的那一档(3h → 2,rn 翻 4 倍) | 取**大**的那一档(3h → 4,rn 翻 2 倍) |
| 该名的第一个事件 | 按 8h 计入 EMA | 间隔未知 ⇒ 重置,从下一个事件开始 |
| 间距 ≤ 0 或 > 24h | 按 8h 继续累积 | 间隔未知 ⇒ **重置** EMA |

本实验没有再把这三种情形分开计数;三者都在同一个开关 I 里。

## 含义

1. **EMA 通道的分歧不是数据缺陷,是口径差。** `fund_replay` 逐字编译了 09-24 之前在役生产者的资金费块,所以它的 EMA 就是**旧生产者的**间隔规则。真值(producer_snap)是现行 NC 合同的规则。
   **「研究 EMA 被污染」应改称「研究 EMA 用的是旧生产者口径」**:除跳过门那 117 格外,它忠实地复现了旧生产者。
2. **对普查(news2)的含义**:按类补查读 `ema_acc` / `fe_v` 的消费者时,判据应是「用的是哪一版间隔规则」,不是「有没有跳过门签名」。凡经由旧生产者块(`shadow_loop_v3.py` 6080073964 L451–484)或 `fund_replay.npz` 得到的 EMA,都属旧规则。
3. **对 G4 的含义**:H-EMA 这条竞争解释的内容应改写为「NEW_S/FRESH 与 NC 的 EMA 间隔规则不同」;它是口径差,判别实验仍是 NC 根上的 A1。
4. **对实盘的含义**(只陈述,不裁定):09-24 换装前,实盘生产者本身用的就是旧规则,所以当时实盘的 EMA 与研究回放一致(差跳过门那部分)。换装后的 NC 用新规则。
