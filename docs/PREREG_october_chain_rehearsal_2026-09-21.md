## §3 每步必须记什么(空转的绿防线)

对 §0★ 的**每一个**阶段(`preflight cache data gates king legs mwf refit arms judge export controls a0rerun member_rule per_year decision`), 逐条记:
- **ran**: 该阶段是否**真的被调度**(驱动的 `stage`/`FAIL_` 行), 还是被 `want <stage>` 过滤掉了;
- **produced**: 落盘了什么(收据 json / 标记 / 日志), 用 `ls` + sha 实测, 不凭脚本自述;
- **verdict**: **整行判词 + 退出码**。禁止裸 N/M 计数(本仓 N checks 同时印在 ALL PASS 与 FAILURES 两行上)。**生产者类装置不出判词** —— 对它们记 stdout 行 + 退出码 + 收据内门块, 并**明说该装置不出判词**(缺键就是缺键, 不是 null 判词)。

**空转防线(E-0920-G 第二层)**: 演练本身必须自证它做了事 ——
- 阶段人口是**闭合**的: 阶段清单从 `chain_v4_monthly.sh` 的 `want <stage>` 实测枚举, 不手写; `n_ran + n_blocked + n_not_reached = n_total` 必须平衡;
- **至少一个阶段真的被调度并产出收据**, 否则「演练全绿」= 「演练什么都没跑」, 本演练判 **VACUOUS**, 不判 PASS;
- 「没测到」的阶段进**具名子集** `NOT_REACHED`, **永不**进任何均值或「通过率」。
