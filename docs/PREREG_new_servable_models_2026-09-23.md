## 1. 对象 NEW_S(相对 NEW 只改"能不能在线上一模一样地算出来")

1. **成员规则**:锚 A 的成员 = 合法掩码(可交易 W24H ∧ 判活)∧ **加密币类**(按 `exchange_info` 的标的类型字段排除股票/ETF/大宗/指数/Pre-IPO 等非加密合约;字段与取值在构建前 dump 并冻结),按流动性取前 400。历史各锚按同一规则、用当时的合法掩码(含已下市币,不用今天的名单倒填)。
2. **一份实现**:训练特征**由生产者自己的特征代码**(在隔离副本上)逐锚计算产生;SWAPPKG 清单里"服务时必须改"的缺陷(D4–D9、D11、D13、D14,以及 D2 的按锚成员历史)**在这份代码里修一次**,训练与服务共用。D3 与 D10 **训练端向服务端对齐**:训练用生产者服务时的收益通道与资金费间隔口径。
3. **生产者供数**:生产者的拉取名单须覆盖上述加密币成员规则在服务时可能选中的全部名字;实际需要扩多少名(预计几十个,远少于 220),在构建前实测并报告。
4. **模型与训练配方**:与 NEW 相同(King 年折 78 特征 LGBM;F10 V2MAIN/FIX7 结构、85% 梯度窗、隔离 ≥60 锚),只换输入。F10 种子 **42 与 2027 都训**(可并行)。**部署种子预定 42**。
