## 1. T2 具体是什么改动(lead 第 1 项)

### 1.1 现状(T0)的损失在优化哪本书

`news2_train_f10.py` L35–L36 + L88–L90,在掩码 `WL` 之后(= T0):
```
r      = w0·soft_rank(score) + w2·zfd            # w1=0 ⇒ rev24 项恒等消失
u      = 去均值 → L1 归一 → cap·tanh             # 自制映射
target = scatter(u)
new    = (1−α)·held + α·target                   # F10 自己的 EMA
net    = 1e4·(new·y).sum() − 3.52·|new−held|.sum()
```
★ **`new` 是「F10 + 资金费」那本书,单独的。** 而生产交易的是 `raw = .55·kc + .45·fc`。
⇒ **F10 从来没有在损失里见过 King 那本书,却只占最终书的 45%。**
它被奖励的是「做一个更好的 King」(它的分数被放进 King 的槽位),而生产要的是「在 King 之外再加一点」。

### 1.2 T2 的改动(**一处**:损失说的是哪本书)

```
target = scatter(u)                              # ← 与 T0 逐字相同
fc_t   = (1−α)·fc_{t−1} + α·target               # F10 侧的 EMA,与 T0 相同
kc_t   = 档案里的 King 侧链后书(detach,无梯度)   # ← 新增的常数输入
raw_t  = .55·kc_t + .45·fc_t                     # ← 生产的混合(combo_target.py L38)
net    = 1e4·(raw_t·y).sum() − 3.52·|raw_t − raw_{t−1}|.sum()      # ← 损失换成混合书的净额
loss   = −mean(net) + 0.25·ES5%                  # 与 T0 逐字相同
```
**与 T0 的差异只有两行**:引入常数 `kc`,并把 `net` 的两项从 `new` 换成 `raw`。
**权重映射、EMA、成本系数 3.52、ES 权重 0.25、折、种子、步长、epoch 规则全部不动。**

### 1.3 三个设计决定,逐条给理由

| 决定 | 选择 | 理由 |
|---|---|---|
| **`kc` 从哪来** | **档案 `work/combo_s*/scaled_diagnostic.npz` 的 `kc` 列**,`detach` | 它就是生产那条 King 侧链后书(`chain(rn8(w0·king_rank + w2·fund))`),已由 S3 逐位平价认证。**实测 `kc` 在两个 F10 种子间逐位相同**(`np.array_equal` = True)⇒ 它**与 F10 的种子无关**,是真正的外生常数;而 `fc` 两种子不同(= False),两者对照证明我取的是该取的那一列 |
| **成本项算在谁头上** | **`\|raw_t − raw_{t−1}\|`(真实换手),不是 `\|fc_t − fc_{t−1}\|`** | `\|0.55Δkc + 0.45Δfc\|` **不可分离** ⇒ King 的换手会改变 F10 的成本**梯度**。这不是缺陷,**这正是互补性信号**:F10 被推着往「不在 King 的换手之上再加换手」的方向走。这是 train-what-you-serve 的诚实选择,**具名** |
| **要不要 `exec_reshape`** | **不要** | `exec_reshape`(`combo_stage.py` L199)是生产链的**又一步**。T2 测的是「损失说的是哪本书」,**不是「损失里塞进几步生产管线」——后者是 T3 的轴**。塞进来会让 T2 与 T3 纠缠。**具名排除,留作独立轴** |
| 发布门要不要进损失 | **不要** | 那是 T4,设计文档已**不推荐**(对着退化探测器优化,且会逼 F10 与 King 靠拢、毁掉正交性) |

### 1.4 为什么 T2 比 T6a 更对准机理(lead 第 1 项后半)

**T6a 已判 FAIL**(`RESULT_dlarch_pregates_2026-09-25.md` §3:ΔIC +0.00052,**输给 LGBM 的噪声地板 +0.00070**)。
**但 T6a 的失败不是 T2 的反证** —— 两者干预的是**不同的东西**:

| | T6a(已 FAIL) | T2(本文) |
|---|---|---|
| King 以什么形式进来 | **输入的一列**(King 的**分数**) | **损失里的一个常数**(King 的**书**) |
| 模型要做什么 | 从一列特征里**推断** King 会错在哪 | 不必推断 —— King 的书**已经给定**,模型只需让**合起来**更好 |
| 目标奖励什么 | 仍然奖励「做一个更好的 King」(分数放在 King 槽位) | **奖励混合书的净额** ⇒ 直接奖励互补 |
| 已测证据 | ΔIC +0.0005,**低于噪声地板** | **PG-T2:King 只解释锚内 R² 0.0165(中位 0.0062);剔掉它之后 171 列对残差仍有 IC +0.062** |

★ **PG-T2 证明「King 学不到的东西可学」**;T6a 证明「**把 King 当特征**学不到它」。
⇒ 剩下的可能是「**换目标**能学到」。**T2 就是那个未测的格。**
**旁证**:实测 ρ(F10 生产秩, King 秩) 只有 **+0.067 / +0.037**(pre-2026)⇒
**F10 事实上已经在做互补的事,但这是它自己撞出来的,不是损失要它做的。** T2 把副产品变成目标。

⚠ **诚实的反面**:`objective_ammunition_interaction` 实测**换目标单独 +0.037(≈0)**、换弹药单独 −0.184、合并 +0.305
⇒ **「换目标」这一轴单独动过一次,值 ≈0。** 本文的 T2 与那次的区别:那次换的是 V2MAIN 那个**书损失**(从秩目标换成书目标),
**本文换的是「这本书是谁的」**(自己的书 → 混合书)。**两者都在「目标」这个大轴上,所以先验不高。** 我把它写在这里,不藏。

### 3.1 ★ 但 T2 的 Δ 必须取**另一个**量,这一点必须事先说清

## 4. 与 T3 的关系,以及**事先写明**的合并路径(lead 第 2 项)

**T2 与 T3 是两个正交的改动**:
- **T3 改的是「权重映射」**(自制映射 → rn8 夹子 + 生产 `chain`);
- **T2 改的是「损失说的是哪本书」**(自己的书 → 混合书)。
- **T2 定义在 T0 之上,不是在 T3 之上** —— 这样两者可分,合并臂才是一个**真正的第三格**。

**事先声明的三步路径(不是事后拼凑)**
1. **T3 与 T2 各自单测,各过自己的腿层门**(T3 用 `L4fc`,T2 用 `L5raw`)。
2. **合并臂 `T2∧T3`**(生产 `chain` **且** 混合书损失)**单独跑**,**不用加法预测代替**
   (受据 `two_good_changes_dont_compose`:该案组合**高于**加法预测,与担心的方向相反 —— 所以**必须实测**)。
3. **只有合并臂才考虑进书层。** 理由是算术,不是偏好:单臂投影到 `dbar` 的效应
   (T3 预测 +0.21…+1.48 bps/日)**大概率低于书层门阶段 1 的分辨率 2.557 bps/日**;
   **合并臂是唯一有机会被书层门看见的形态。**
   ⚠ 这条**事先写在这里**,正是为了不让它变成「事后发现单臂不够,于是把两个臂拼起来再试一次」。
   **若合并臂也不过腿层门,路径到此结束,不再拼第三个。**

**2×2 的第四格(T2 无 T3、T3 无 T2 已有;两者皆无 = T0)**:四格齐全,交互可算。
**但交互的量化要等三个臂都有数**,而且**按 `objective_ammunition_interaction` 的教训,交互可能比单项大** ⇒
**不提前假设可加。**
