## 2. 可证伪的预测(从已裁定的机制推出,先于数字)

声明的机制是:float64/float32 与内核口径的改变,只在**判别边界附近**改变结果 —— 「v7 在 1e-4 门附近、qvm 排序在**第 400 名附近**」。

由此推出的预测:

- **P1**:差异符号在各自成员集中的 **qvm 排名应当集中在切口(第 400 名)附近**,而不是均匀散布在 1..400。
  - 判据:只在 NC 的符号,其在 NC 成员集内的 qvm 排名**中位数应落在最后 10%**(即 ≥ 0.9·n_members)。
- **P2**:**每锚的成员数两边应当几乎相同**(切口换人,不换人数)。判据:`|n_NC − n_RES|` 的中位数 ≤ 1。
- **P3**:差异应当**遍布大多数锚**而不是集中在少数锚(边界效应逐锚都会发生)。判据:有差异的锚占比 ≥ 50%。

**若 P1 为假**(排名散布在中间),则声明的机制**不足以解释**观察到的差异,必须另找原因并报 lead。这是本预注册的主要用途。

## 3. 判读规则(冻结)

1. **不设门**;产出是事实表 + 三条预测的成立与否。
2. 三条预测**分别**判,不合并成一个「通过/不通过」。
3. **机制验对了不等于机制解释得了量级**:即使 P1–P3 全成立,也只能说「差异的形状与 D5 成员筛一致」,**不能**说「D5 成员筛造成了全部 43,025 / 42,889 个差异」——那需要关掉 D5 重跑,不在本项。若要写份额,必须另设装置。
4. 只在一边的对**不可**用另一边的量去补(NC 没有非成员的 qvm),所以 P1 对「只在研究员」的那一半**无法用 NC 的 qvm 判**,这一半**具名不测**,只报计数与逐锚分布。

- **基线格**:随机抽取的「两边都在」的符号,其 qvm 排名分布应**不**集中在末 10%(否则末 10% 集中是所有符号的普遍性质,P1 就没有分辨力)。这一格必须先跑,且必须**不**集中,P1 才有意义。

- 两格任一不过 ⇒ 判 **UNAVAILABLE**,不报 P1。
