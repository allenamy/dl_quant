# DESIGN · F-10 可微书损失(Differentiable Book Loss)

## §1 为什么是这一步(受据链, 全部 2026-08-22 当日实测)
1. **F-4**: 89 新列在 king 原目标(4h)下书级 **−0.754**; 机理 = 增量寿命 4h < 持仓档案 26h(块2 IC **反号 −0.0053**)。
2. **F-6/D**: 目标换成"仓位实际赚到的那段"后, 同一批列 **+0.354**(β 中性化后更高, CI 下界 +0.005)⇒ **视界匹配是真机制**。
3. **F-7**: 增量**不可分离**为对在役分数的加法项(λ 0.5/1/2 全负且单调)⇒ 分数层拼装全族失败(与 F-8C 换腿/融合合并 DNR)。
4. **F-9**: 视界剂量-反应 ⇒ **弹药增益 ↑ 与 抗跌能力 ↓ 反向单调**, 三点无可采纳 ⇒ **单一标量目标下不可兼得**。
**⇒ 唯一未被证伪的方向: 不再用"某个视界的收益秩"当代理目标, 而是把书真正要最大化的量——净额路径——写成可微损失, 让模型在训练时自己权衡"排得准 / 别乱动 / 别在跌市翻车"。**

## §2 核心构造(把三件事变成损失里的三项)
输入 s_t = f_θ(x_t)(逐锚逐名分数)。**可微书管线**(逐字对应在役书的 rank→z→去均值→L1→cap→EMA→带):
1. **软秩** ρ_t = softrank(s_t; τ)(成对 sigmoid 或 Gaussian-CDF 近似; τ 退火)—— 可微版 rank-z, 保证与判据同构(判据是 rank-IC/净额, 不是 MSE)。
2. 去均值 + L1 归一 + **平滑 cap**(softclip 2.5/n)⇒ 目标权重 u_t。
3. **EMA 递推** w_t = (1−α) w_{t−1} + α u_t(α 可固定=在役, 亦可作**可学参数**, 这一步就是"半衰期进模型")。
4. **净额** net_t = Σ_i w_{t,i} r_{t,i} − c·Σ_i |w_{t,i} − w_{t−1,i}|(|·| 用 Huber 平滑)。
**损失** L = −mean_t(net_t) + λ_dd · CVaR_5%( net_t | 市场收益最低五分位 ) + λ_reg·‖θ‖
- 第一项 = 信号强度 × 可实现性(它天然内含"寿命": 权重靠 EMA 存活多锚, 只有对**整段持有期**有用的排序才拿得到正贡献);
- 第二项 = **抗跌**(直接把 F-9 的 P5 守卫写进目标, 而不是事后当门);
- 换手成本 c 直接用实测 3.52(并跑 6.64 敏感臂)。
**梯度沿 EMA 反传多锚 ⇒ 模型被迫学"这个排序未来 N 锚都值不值得持有"** —— 这正是 F-9 用标签近似、但标量目标做不到的那件事。

## §3 训练与切分
- 批 = **连续锚窗**(如 96 锚 ≈16 天), 递推深度 = 窗长; 窗间不重叠, walk-forward 逐年, embargo 60 锚(同 F-4/F-6)。
- 特征: 78 基座列 + 89 时间结构列(=F-9 的 167 列, 同一份 SHA), 便于与 F-9 曲线逐格对照。
- 模型体: 先 **MLP(167→256→256→1) + LayerNorm**(便宜、可多臂), 过门后再上 film2/序列体(避免"没证明目标有效就先堆架构")。
- 种子: 双种子起步; 单变量纪律。

## §4 判据(实现前冻结, 与 F-9 同场可比)
1. **平价**: 同一 f3 复制链 + C3full 1.668 ±0.002。
2. **主判据**: F-10 对 C3r 走 #71 G 族(Δ净@3.52 CI>0 / @6.64≥0 / 逐年≥3/4 / 夏普不降)**且** 最差市场五分位 Δ净 ≥ −1.0(F-9 的守卫原样)。
3. **机制消融(必须与主臂同跑)**: (a) 去掉成本项 ⇒ 换手必须显著上升(否则损失没起作用=装置假绿); (b) 去掉 CVaR 项 ⇒ 最差五分位必须显著恶化; (c) 冻结 α vs 可学 α ⇒ 学到的半衰期与在役 EMA 的距离作读数。

## §5 已知风险(先写)
- 弱信号下端到端优化极易过拟合路径; 对策 = 窗内不洗牌、逐年 walk-forward、双种子、消融三件套。
- 软秩温度 τ 与真 rank 的差可能在尾部失真 ⇒ 训练末期退火到接近硬秩, 并报"软/硬秩下净额差"。
- 成本项用常数 c 掩盖了逐名成本差异(快名更贵)⇒ 二期换成逐名 c_i(用实盘 markout 标定)。
- CVaR 项使用市场五分位 = 事后分档; 训练内改用"当锚市场收益的因果代理"(前一锚已实现波动/BTC 收益), 防止把未来分档信息喂进损失。**此条为实现时的硬约束。**

## §6 实现冻结(2026-08-23, 开工令已下; 本节先于任何 F-10 数字入库)

### §6.1 机制理论框架(有针对性, 非装饰)
F-10 在数学上 = **直接在策略空间上解一个带成本的动态组合控制问题**(模型即策略, 净额路径泛函即价值)。闭式理论参照 Gârleanu–Pedersen (2013) *Dynamic Trading with Predictable Returns and Transaction Costs*: 二次成本下最优交易 = 每期部分地向 **aim portfolio** 移动, aim = 各信号按**其衰减速率与成本**折价加权 —— 我们的链(u_t=当期排序书, EMA α=移动速率)正是该解的参数化; F-9 实测的"快信号在慢书里权重必须低"就是 GP 定理的表现形式。**可检验预测(事后对表)**: ① 可学 α 应收敛到成本-衰减最优带(先验 0.05–0.30); ② 89 快列的贡献非零但显著小于 4h 目标模型中的贡献。HRT RNN 参考件的可借鉴项: TBPTT 状态截断、学习型衰减门(其 interpolate/decay 即可学 EMA)、符号=批维、稳健 MAD 标定 —— v1 借 TBPTT+标定, 学习型衰减门留给 v2 分数体。
### §6.2 冻结的实现决策
1. **v1 = 单腿代理**(§2 原文): 训练时链只含模型自身分数; 终审在 f3 三腿链 king 槽(与 F-4/F-6 同装置同判据)。已知近似, 如实标注。
2. **尾部项 = 无条件 ES_5%**(修订 §5 第四条的实现形式): 逐窗取净额最差 5% 锚的均值。无任何分档变量 ⇒ "禁止事后分档"约束被平凡满足且更简; 因果代理条件版降级为诊断读数。λ_dd=0.25 冻结。
3. **防塌缩结构性成立**: u 经 L1 归一, gross 恒 ≈1, 模型无法用"空仓"逃避尾部项 —— 唯一自由度是排序与其时间稳定性, 这正是要学的两件事。
4. **TBPTT**: 窗 96 锚 + 燃烧段 24 锚(链态从 0 重建, α 下限 0.02 保证 24 锚覆盖 ≥ 半衰期); 训练窗打乱、步长 48; 验证/测试 = 严格时序整段推进(无燃烧近似)+ **硬秩**。
5. 软秩温度 τ: 分数先锚内 z 标准化, τ 0.5→0.1 线性退火。
6. α = 0.02+0.88·sigmoid(a), 初值 0.1, 可学(AFIX 消融臂冻结 0.1)。
7. 净额 bps = 1e4·Σw·r − 3.52·Σ|Δw|(平滑 |·|=√(x²+1e-12)); 6.64 只在终审敏感臂。
8. 臂: MAIN×双种子(42/2027) + 消融 C0(成本=0)/NOCVAR(λ=0)/AFIX 各 s42; 折/embargo/列(167)/LGBM 时代同一 SHA 弹药, 判据 = §4 原文(G 族 + P5≥−1.0 + 三件消融方向断言)。
9. 检查点 = 验证段(训练末 15% 锚, 时序尾)上 [mean−λ·ES] 最优 epoch。
