## DESIGN: D1-fixed-conditioning

MECHANISM
Every prior regime-conditioning FAIL used a mechanism that could not see regime level. Concretely: (1) `regime_extractor(x_feat)` runs at step 8a of `_encode_tail` on the RevIN-normalized tensor (`dual_lob_regarch.py` encode: `x_feat = self.revin.normalize(x_feat)` happens first), so vol_1200≈const and mean_feat0≈0 — absolute vol destroyed before the gate; (2) `regime_film.py:98-101` batch-z-scores the 6 descriptors, so a uniformly-shifted regime month is invisible at eval (and predictions are batch-size-dependent — a latent bug); (3) `regime_prior` is fed raw (FLAG 11), so vol_1h scale drift 2024→2026 silently shifts the FiLM operating point; (4) the conditioning inputs contain zero positioning data despite `data/funding/*` on disk. So "regime not causally learnable" was never tested with a seeing mechanism (appendix gaps #1, #2).

Why this can help where H5's +0.002-0.003 ceiling seems to forbid it: H5 bounded DAY-SCALE REWEIGHTING OF FINAL PREDICTIONS. FiLM conditions hidden features per-timestamp DURING TRAINING — it lets the 450d window's mixed regimes learn de-interfered mappings instead of one averaged map, and it can modulate output scale state-dependently. H1's verified failure mode is exactly a scale/calibration failure: β 30.8→5.1 while σp RISES (2026-04 σp=0.109 max) — overconfidence a level-aware affine gate can structurally fix (H1 design implication (b)). Funding-level input also enables the one surviving significant structure (short-decile×funding F3−F1=−3.59bps, t=−2.43) to be expressed inside the model. Honest framing: this is the enabling substrate + β/floor stabilizer, not by itself the 0.08 answer.

EXACT DESIGN
A. Bug-fix (new `multi_asset/model/regime_state.py`; `src/` untouched). `PreRevINRegimeExtractor`: same 6 descriptors, computed on x_feat BEFORE RevIN (stash `self._x_feat_pre_revin` in `encode` before `revin.normalize`; consume at 8a). Note pre-RevIN = post-static-450d-z, which is correct: cross-fold comparable but regime level preserved. Replace batch-z with TRAIN-WINDOW stats: at fold setup compute descriptor mean/std over ~50k sampled train windows, `register_buffer` in the model (persists in ckpt), normalize (f−μ)/σ clip±5. Same normalization applied to regime_prior (fixes FLAG 11).

B. New conditioning inputs (~18-d `state_prior`, multi-timescale 1h/6h/24h/5d, all ffill ≤t): funding last-print + z_30prints + std_5d; pidx mean/std at 1h and 24h (pidx_std = the only month-FE survivor in H2/H5); OI %chg 1h/24h + oi_z_5d; toptrader L/S level + Δ24h; taker L/S level + Δ24h; abs realized vol 24h/5d. Built offline by new `multi_asset/data/build_state_prior.py` (reuses verified `add_funding_channels.py` alignment math: metrics cut = t−300s, funding ≤t) into an OVERLAY dir `data/npz_v2arch_state/` (per-day npz keyed by timestamps; source cache read-only); `dual_lob_dataset.py` concatenates → d_prior=24. Conditioning vector, NOT X channels — sidesteps anti-pattern #29 entirely (~2-3K params).

C. Placement/expressiveness: keep existing zero-init affine sites — FiLMGate multistage (block1/block2/final-pool) + pooled-h FiLM (reuse `use_oi_regime` concat: fixed-extractor 6 ⊕ prior 24) + regime_bias. Stay AFFINE (H1 failure is scale, not functional form; H3 refuted momentum/reversion flipping; MoE σ-collapses on drift). ONE addition: conditioned scalar output gain g(prior)=1+0.5·tanh(zero-init linear) multiplying quantile outputs — the direct anti-overconfidence lever. Low-rank FiLM only as fallback if A/B shows conditioning signal saturating.

D. Isolation A/B: Run1 BUGFIX-ONLY (same 6 descriptors, fixed extractor + train-stat norms, no new inputs) vs Run2 BUGFIX+STATE (d_prior=24) vs frozen baseline. Identical configs/seed/patience/eval otherwise.

EXPECTED HONEST ΔP (cd-CLEAN)
- Strong 2025-10/11: 0.000±0.005 (adaptive already WIN here; zero-init protects; regression >−0.005 is a fail).
- Normal 2025-08/09/12: +0.002-0.005 (train-time de-interference of the mixed window).
- Drift 2026-01..03: +0.005-0.015 — H1 shows recoverable tail IC 0.03-0.06 exists; correct scale-conditioning converts some tail-only covariance into calibrated IC; unbounded by H5's day-reweighting ceiling but capped by descriptor quality (they explain ~1% of day-IC oracle 0.1246).
- Drift 2026-04/05: +0.000-0.005 IC; main claimed win = β from 0.19-0.32 toward ≥0.5 and σp overconfidence removed — mandate health gates need this regardless.

COST
Build 2-3 days (extractor 0.5, builder+overlay loader 1, train-stat plumbing 0.5, tests 0.5-1). Overlay cache: CPU hours (871 days, tiny files). GPU: gate = 3 folds × {Run1,Run2} ≈ 12-20 GPU-h; full 10-month confirm ≈ 40-80 GPU-h only after gate.

KILL GATE

KILL if mean(Run2−baseline) cd-CLEAN over the two drift folds < +0.003 AND drift β not moved ≥0.15 toward 1 — then file "regime-conditioning dead" as FINAL (now tested with a seeing mechanism) and pivot budget to orthogonal data (liquidations). Attribution kill: if Run2≈Run1, keep the bug-fix, stop positioning-input work. Pre-GPU sanity (CPU, hours): fixed descriptors must show inter-month separation (month-mean spread >1σ across 2025-10 vs 2026-04) — if even post-fix descriptors don't separate months, don't spend GPU.

(3) Init noise fake-win: bit-identity test at init (zero-init ⇒ output == baseline exactly; test pattern exists for MoE — replicate for gain head + widened prior). (4) Batch dependence: add eval invariance test preds(batch=512)==preds(batch=32) — currently false under old extractor; must be true post-fix. (5) Checkpoint peek: drift folds select at patience-exhaustion (best_epoch 15-18) — keep identical patience/σ-gate, log whether any win comes from a fallback σ<0.02 ckpt and flag it. (6) Caliber: per-day-CLEAN + DENSE both, mask applied, identical aggregator, same baseline months re-scored by the same script; no clip/EMA changes.
