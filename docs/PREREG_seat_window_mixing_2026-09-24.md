# 预注册: 检验"席位窗口跨模型"机制(只读,零引擎)

被检验的机制(`RESULT_fresh_book_anomaly_2026-09-24` §4,原文标"未检验"):
席位用过去 **900 锚**(`msharpe_look = 900`,实测)的腿收益估。年折下这 900 锚大多出自同一模型;月折下跨约 5 个月度模型。
⇒ 月折下席位衡量的是"过去那几个模型",不是"当下交易的这个模型"。
⇒ **预测:亏损强度随席位窗口内模型混杂度上升。**

## 1. 量的定义

- **混杂度 `mix(i)`** = 锚 `i` 之前 900 个锚(即 `[i-900, i-1]`,与 `fresh_legs.py` L66 的 `LR[leg][-look:]` 同窗)
  所落入的**不同 King 折模型**的个数。折归属按 `TRAIN_RECEIPT.folds` 的 `score_start`/`score_end` 判定。
  窗口不足 900 锚的锚**排除出人口**,并在收据里报排除数(不得按"不足即 1"混进来)。
- **亏损强度** = 该桶内 `(D − A)` 逐锚 price 通道差的**均值,bps/锚**。
- **份额** = 该桶 `(D − A)` 之和 ÷ 分母。

## 2. 主判据用强度,不用份额(先于看数写明理由)

**原始份额随桶内锚数机械放大** —— 锚多的桶天然份额大,这与机制无关。机制预测的是**每锚的亏损率**随混杂度上升。
所以:

- **主判据 = 每桶的 `bps/锚`(强度)。**
- **份额照报**(并要求闭合到 1),但**不作主判据**。

## 3. 判据(冻结)

设有效桶 = 该混杂度档内**锚数 ≥ 100** 的桶,按混杂度从低到高排列。

- **SUPPORTED(支持)**:同时满足
  1. 至少 **3 个连续**有效桶上,`bps/锚` **单调不增**(即越混杂越亏,允许相等);
  2. **最高**有效桶的 `bps/锚` **严格低于**(更负于)**最低**有效桶的 `bps/锚`。
- **REFUTED(证伪)**:有效桶 ≥ 3 但上述任一条不满足。
- **UNDECIDED**:有效桶 < 3(样本不足以判)。**只有这一种情况可以判 UNDECIDED**,不得因为"看起来不明显"而改判。

**判据不因看到数字而改动。** 若结果落在边缘,照原判据判,并在结果里点名边缘在哪。

## 4. 零对照(lead 要求)

**NEW_S(年折)臂的混杂度分布一并报。** 按本文 §1 的同一算法、同一窗口、同一装置,对 NEW_S 的 King 折计算 `mix`。
按本轮算术它应当**大多为 1 或 2**;这既是对照,也是对装置的检验:
**若 NEW_S 的混杂度也普遍 ≥ 3,说明 `mix` 算错了**,此时停下报 lead,不出判词。

## 5. 混杂度与席位的可分性(lead 要求)

同时报 `mix` 与**席位三分位**(切点沿用已冻结的 q33 = 0.5726 / q67 = 0.7810)之间的关联:
Spearman 相关与列联表。

- 若两者**高度相关**,则"高席位"与"高混杂"在这份数据里**分不开**,**照实写**,
  并且**不得**宣称本检验把亏损归给了混杂度而非席位。
- 无论相关多大,都**加报分层读数**:在**每个席位三分位内部**按 `mix` 分桶的 `bps/锚`(格内锚数 ≥ 50 才报)。
  分层后若混杂度效应消失,说明它是席位的影子;若在层内仍在,说明它有独立成分。**这一条写在看数之前。**

## 6. 分母与闭合

- 分母 = **与第二阶段完全相同**:pre-2026 判据窗内逐锚 `(D − A)` price 通道差之和 = **−3116.45 bps**(5,495 锚)。
- 因 §1 会排除窗口不足 900 锚的锚,**排除后的人口与分母人口不同** ⇒ 收据必须同时报:
  排除数、排除后人口的 `(D−A)` 之和、以及**两者的差**。份额按**排除后人口之和**闭合到 1,
  并**另报**排除后人口之和占原分母的比例。**不得**用原分母去除排除后的桶和而让份额不闭合。
