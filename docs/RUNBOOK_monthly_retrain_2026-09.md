## 0. 原则

- 月度重训 = **显式版本事件**: 影子/部署只认 SHA 钉死的 bundle, 换版必须整包换、留旧包、记录切换锚;
- 每步有**平价门**, 任一红即停(不带病换版); 判据沿用已冻结值, 不因"这个月数字更好看"调整。

## 1. 步骤(pod 一次会话 ~2-3 小时, 全 CPU)

1. **数据刷新**: pod_extend_vision.py(EXT_DAYS=上月全月 daily)+ 本机 jp_fund_aug.py(funding 尾巴)→ scp; 幂等。
2. **缓存/面板/特征重建**: pod_build_wide_ext.py(EXT_END=月末+1)→ pod_panel_ext.py → pod_fea_ext.py(env 参数化路径, _v3 命名, 不覆盖);
   平价门①: 面板重叠锚 13 因子+fund corr ≥0.999。
3. **慢引擎重训**: 按年扩张折不变(2026 折训练集自动加长一个月); 若 §28 判 ADOPT_FOR_V2 则起点 2020-01, 否则 2022-01;
   平价门②: 2024/2025 折 IC vs 上一代 |Δ|≤0.004(LGBM 非确定性口径)。
4. **bundle v3 导出**: pod_export_shadow_bundle.py(booster IC 门 |Δ|≤0.006 + v1iv 基线守卫 ±0.15 带)→ tar → 本机;
   平价门③: 基线守卫夏普带内(当前带心 2.42, 若 §28 采纳则按其新基线重标并入档)。
5. **影子换版**(本机): KILL 影子 → 备份旧 shadow_bundle → 解包 v3 → BOOTSTRAP 体检 → acceptance.py **全绿**(A2 平价窗自动用新 parity_signals)→ 重启影子;
   shadow_log 记录换版锚(booster_sha 变更即天然留痕)。
6. **入档**: P3 追加 §(重训世代记录: 折 IC 表/守卫数/bundle SHA), STATE.md 一行, memory 更新。

## 2. 判据红线(预写)

- 平价门任一红 ⇒ 不换版, 影子继续跑旧 bundle, 红因入档归因后另定;
- 新折 IC 若**好于**旧代 >0.008 ⇒ 同样暂停换版先查(单月数据不该有这么大改善——大概率是口径漂移不是进步, "好得反常=先怀疑仪器");
- 换版只在**锚间静默窗**执行(避免撞 :16 分运行)。

pod(CPU ≥32GB 内存)~2-3h; 本机 ~20min。可与 08-30 影子合并对账同会话执行(推荐: 一次 pod 会话做完 对账+§30+§28+重训四件)。
