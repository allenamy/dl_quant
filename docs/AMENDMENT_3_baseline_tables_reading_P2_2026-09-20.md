# AMENDMENT 3 · 读数 P2(日 −4% 停机 + 人工恢复语义 + §4-4 累计停机)

## 为什么(缺口的来源)

- 覆盖审计 E-20 与第六轮复审 **R6-03** 指出: 模拟器对 §4-2 日 −4% 止损的处理是**平仓后到下一个 UTC 日 00Z 自动恢复**(`exec_sim.py` L486–489), 而**实盘要求人工解锁**; 实测在每次整书平仓后, 书有 **8–20 小时**不再平衡(长期记忆: 19 个锚整锚被 `open_orders_halted` 拦下)。
- 已发布的读数 **P 只建模了 §4-4**(从起始权益累计 −25%, 不恢复), 没有建模 §4-2 的停机与恢复。R6-03 给的具体反例: 2024-01-01 起点在 A0 上 P 均值路径从未触 −25% 线, 但 **2024-04-12 全部 32 条路径都已触发日止损**; 按人工恢复政策, 那之后不应自动继续交易。
- 因此本修订新增 **P2**: 两条规则合用, 并把「人工」这件无法模拟的事**写成一条具名假设**, 同时给出它的敏感性与**严格下界**。

## P2 的定义

1. **§4-2 日止损 + 恢复假设**: 路径上每一次日止损平仓(时刻 t, 取自模拟器自己的 `flatten_log`), 从 t 起**不交易**, 直到**第一个 ≥ t + H 的锚**; 被扣住的锚其窗收益记为 **0**(空书: 无价格损益、无资金费、无手续费)。
   - **主读数 H = 12 小时**(实测 8–20 小时的中点);
   - **敏感性** H ∈ {8 小时, 20 小时}(实测区间两端), 以及 **H = 模拟器现行规则(下一个 00Z)** —— 后者等于已发布的 P, 作为扣得最少的一端;
   - **严格下界 H = ∞(永不恢复)**: 第一次日止损即结束该路径。这一档直接回答 R6-03 的字面读法(「没有人工恢复, 后面不应继续交易」), 是政策最严的一端。
2. **§4-4 累计 −25%**: 与读数 P 完全相同 —— 从基准起点的累计收益首次**严格低于** −25.00% 的锚末停机, 其后 NAV 不变, **不模拟恢复**。两条规则同时生效, 谁先触发谁先停。
3. **平仓成本**: 每一次停机(§4-2 或 §4-4)报出其所在窗的 `turnover_flatten`(相对 gross)与该窗的手续费, 明确 P/P2 的窗末收益**不是**扣除平仓成本后的下界(R6-03 的第三点)。
4. **报告口径**: 每次事件被扣住的锚数(逐路径最小 / 中位 / 最大)、逐路径被扣住的锚总数、P2 窗末收益(逐路径均值与 5/95)、与 P 及不停机口径并列; 均值路径与逐路径**分开报**(R6-12), 年化与期间收益**双列**(R6-13)。

## 这是后处理, 不是重跑 —— 它不能捕捉什么

P2 由已写好的逐路径窗账本计算, 不重跑模拟。**具名假设**: (a) 被扣住的锚收益为 0 —— 空书确实不产生价格损益与资金费, 但残余碎仓与其资金费被忽略; (b) 恢复后的书按**该锚的目标**重建 —— 这正是模拟器在任何一次平仓之后本来就做的事, 所以一阶上一致, 但恢复时点不同会让之后的成交价与成交随机性不同, 这部分**未建模**; (c) 平仓成本取自模拟器实际那次平仓, 不随 H 变化。
**P2 不是前瞻预期**, 也不是「实盘会拿到的收益」: 它是「按写死的两条政策线、加上一条具名的恢复假设, 这段历史会被停成什么样」。任何结论不得只引 P、P2、主读数三者之一。

## 不变的部分

主读数、逐年 / 21 格 / 成本敏感性 / 配对表 / 对账链的定义不变; 已发布的读数 P 不改动, P2 与其并列、单独标注。
