# 发现 · 席位规则把书推进它自己的预检失败模式(2023–2025 的亏损载体)

## §0 一句话

**生产者的 msharpe 席位规则在模型席位高时, 会机械地让 combo 书的 raw gross 塌到 0.4 门槛之下; 一旦塌破, 生产改写它原始的三腿 king 文件(仍带 rev24), 而那本书在全窗 g −1.244 bps/锚。2026 一次都没塌过。**

## §1 代数(不是拟合)

`combo_stage.py` L228–231:
```
w3m = [w3_king, 0, w3_fund] 归一化
z_kc = w3m[0]·z_king + w3m[2]·z_fund
z_fc = w3m[0]·z_f10  + w3m[2]·z_fund
书 = 0.55·chain(z_kc) + 0.45·chain(z_fc)
```
⇒ `z_kc − z_fc = w3m[0]·(z_king − z_f10)`。**资金费项在两个组件里逐位相同, 相减抵消。**
⇒ 模型席位 `w3m[0]` 越大, 两个组件差得越开; 0.55/0.45 混合时两本相异的书互相抵消, **合成 gross 下降**。资金费席位主导时两个组件几乎是同一本书, 混合不抵消。

## §2 实测(lead 自算; 8,029 个有预检记录的锚, 2023-01→2026-08, 排除 2022 热身)

|---|---|---|---|

`corr(king 席位, 不抵消率) = −0.839`; `corr(king 席位, 合成 gross) = −0.922`。
