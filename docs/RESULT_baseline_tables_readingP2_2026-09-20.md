## §1 规则与实现(照抄 AMENDMENT 3, 窗口切片照 AMENDMENT 4)

- **§4-2 日止损 + 恢复**: 每次日止损平仓(时刻 t, 取自模拟器自己的 `flatten_log`)之后不交易, 直到**第一个 ≥ t + H 的锚**; 被扣住的锚窗收益记 **0**(空书)。H = **12 小时**为主读数, **8 / 20 小时**为敏感性(实测 8–20 小时区间两端), **模拟器现行规则(下一个 00Z)** = 已发布的读数 P, **永不恢复**为严格下界。
- **§4-4**: 与读数 P 完全相同(从基准起点累计 < −25.00% 的锚末停机, 不恢复)。两条规则同时生效, 谁先触发谁先停。
- **窗口切片(AMENDMENT 4 §B, 两读法并列)**:
  - **W-ENTRY(主读数)**: 基准锚 = **入场时点**, 只有发生在基准锚当时或之后的日止损参与扣锚, **窗前的停机不继承**。选它的理由是结构性的: §4-4 的 −25% 计数器本来就在基准处归零(`cum = navm1/navm0_base − 1`), 两条规则必须用同一个时钟; 且配置里每个基准的标签本身就是「起点」。
  - **W-CARRY**: 报告窗是一条连续路径上的观察切片, 窗前开始且未恢复的停机带入窗内。**这是修复前的装置实际算的东西**(它从未声明过)。
  - **装置断言(违反即 REFUSE, 不落盘)**: 在 base = 路径起点的基准上、以及 H = `sim` 时, 两种读法必须**逐位相同**(B4-a / B4-b)。三条运行的收据里这两条全部通过。

### §2.2 扣锚口径: 按平仓**时刻**, 不按平仓所在**锚**

本装置扣住的是 `A >= t_flatten` 的锚, 即**平仓所在的那个窗口照常计入**。这是有意的, 不是疏忽: 模拟器把该次平仓的 `turnover_flatten` 与手续费**就记在那个窗口**里(`turn_flat[i] > 0` 的 `i` 正是含 t 的锚), 所以那个窗口**确实交易过**, 它的收益是实现了的。若改成连含 t 的锚一起扣住, 等于把一个**测量过**的窗口改记成 0 —— 那正是 E-0920-C 的同一个类。
**量化**(2024-01-01 起点, A0 `scaled`, 32/32 条路径都有窗内平仓): 按时刻(本装置)**−11.112%**, 按所在锚 **−10.818%**, 差 **+0.294 pp**, 方向是「按所在锚更乐观」。任何第二仪器若报出比本表高约 0.3 pp 的永不恢复读数, 先查这一条。

也就是说: **日止损几乎无处不在; 它是否改变结局, 取决于 §4-4 在该起点下咬不咬得住, 而这由入场时点决定。**

## §3 局限(具名)

1. **「人工恢复」不可模拟**: 本文给的是一条假设(H)及其敏感性与下界, 不是对真实恢复时点的估计; 实盘恢复是人的决定。
2. **后处理的一阶近似**: 被扣住的锚记 0 忽略残余碎仓与其资金费; 恢复时点不同会遇到不同的成交与成交随机性, 未建模(AMENDMENT 3 具名)。
3. **平仓成本未从窗末收益里再扣**: 见 §0 第 5 条, 因此 P/P2 的窗末**不是下界**。
4. **起点沿用既有仓位状态**: 各季度起点不是真实冷启动(复审 R6-03 同一条)。W-ENTRY 解决的是「窗前的**停机状态**不继承」, **不是**「仓位从零开始」—— 这两件事不同, 后者仍未建模, 仍是本文最大的一条局限。
5. **W-CARRY 在晚起点上几乎没有可读的数**: 2024-07-01 及以后的起点, 32 条路径**全部**无测量(V4 从 2025-07-01 起同样), 该列只能是「—」。这不是坏消息也不是好消息, 它只是说**那个问题在那些起点上问不出答案**; 主读数(W-ENTRY)在同样的起点上是可读的。
6. 与主读数、读数 P 的关系: 三者是同一批路径的三种读法, 必须一起引用。
