## §0 一页结论(白话)

1. **复审是对的: 日止损会打断这段历史, 而且不是偶发**。在完整配方窗里, 在役 A0 的**每条**成交路径都触发过日止损(每条路径中位 **8 次**), V4 中位 7 次。已发布的读数 P 完全没有反映这件事。
2. **但在完整配方窗上, 加不加恢复延迟几乎不改变结局 —— 因为 §4-4 的 −25% 线本来就会被触发**: H = 8 / 12 / 20 小时三档下, 仍然是 **32/32 路径**触到 −25%, 中位日期不变(A0 2024-03-18, V4 2024-03-11), P2 窗末收益 **−25.3%(A0)/ −25.2%(V4)**, 与读数 P 的 −25.27% / −25.17% 实际上一样。被扣住的锚中位只有 21–40 个(占窗口 0.3–0.6%)。
3. **真正改变结局的是「永不恢复」这一档**(复审的字面读法): 第一次日止损就结束该路径 ⇒ A0 中位扣住 **5,221 个锚**(完整配方窗的 **75%**), 只有 25/32 条路径在此之前触到 −25%, P2 窗末 **−22.0%**(路径均值, 5%/95% = −25.8% / 0.0%); V4 −22.0%(28/32)。**这不是「更好」**: 它只是把路径停在更早的位置, 收益分布从「几乎全部 −25%」变成「一部分停在小亏、一部分仍走到 −25%」。
4. **R6-03 的具体反例已量化**(2024-01-01 起点, 在役 A0): 读数 P 下 **0/32** 路径触 −25%, 窗末 **+178.8%**; 读数 P2(H = 12 小时)下 **32/32 路径都被日止损打断过**(复审说得对), 但扣住那些锚之后窗末仍是 **+168.8%**; 而在「永不恢复」下窗末是 **−9.7%**。**同一个起点, 结论从 +179% 到 −10%, 全部取决于那条无法模拟的人工恢复假设。** V4 在同一起点更糟: P2(H=12)下 32/32 触 −25%, 窗末 −25.3%。
5. **平仓成本**(复审的第三点): 每次日止损平掉的是**整本书** —— 平仓换手 / gross 中位 **1.000**(A0)/ 1.003(V4), 该窗手续费中位 **5.4 bps / 5.3 bps(相对 gross)**。P 与 P2 的窗末收益都是**盯市**的, 没有在停机点再扣一次退出成本; 因此 **P/P2 的窗末不是「下界」**, 真实停机会更差一点(每次约 5 bps × gross), 而恢复之后还可能继续亏。
6. **三条运行的结论同形**: 延长窗(到 09-18)与 V4 的表与 A0 一致(见各自的表); 差别只在 §4-4 的触发时点与不停机窗末。
7. **不主张**: P2 不是前瞻预期, 不是实盘会拿到的收益, 也不是「策略无效」的证明; 任何结论不得只引主读数、P、P2 其中之一(AMENDMENT 2 §3 / AMENDMENT 3)。

## §1 规则与实现(照抄 AMENDMENT 3)

- **§4-2 日止损 + 恢复**: 每次日止损平仓(时刻 t, 取自模拟器自己的 `flatten_log`)之后不交易, 直到**第一个 ≥ t + H 的锚**; 被扣住的锚窗收益记 **0**(空书)。H = **12 小时**为主读数, **8 / 20 小时**为敏感性(实测 8–20 小时区间两端), **模拟器现行规则(下一个 00Z)** = 已发布的读数 P, **永不恢复**为严格下界。
- **§4-4**: 与读数 P 完全相同(从基准起点累计 < −25.00% 的锚末停机, 不恢复)。两条规则同时生效, 谁先触发谁先停。
- **实现**: 后处理逐路径窗账本, **不重跑模拟**(装置 `bt_p2_reading.py`)。三条具名假设(空书收益为 0 / 恢复后按该锚目标重建 / 平仓成本取自实际那次平仓)写在 AMENDMENT 3 里, 本文不重复但同样适用。
- **装置验证**: 夹具测试 12/12 全绿(含 **H = sim 与已发布读数 P 的跨装置等值**、H = never 的下界、被扣住的锚必须恰好贡献 0、8h/20h 敏感性非空、npz 改动被 sha 拒收)。

## §3 局限(具名)

1. **「人工恢复」不可模拟**: 本文给的是一条假设(H)及其敏感性与下界, 不是对真实恢复时点的估计; 实盘恢复是人的决定。
2. **后处理的一阶近似**: 被扣住的锚记 0 忽略残余碎仓与其资金费; 恢复时点不同会遇到不同的成交与成交随机性, 未建模(AMENDMENT 3 具名)。
3. **平仓成本未从窗末收益里再扣**: 见 §0 第 5 条, 因此 P/P2 的窗末**不是下界**。
4. **起点沿用既有仓位状态**: 各季度起点不是真实冷启动(复审 R6-03 同一条), 本文只按窗内累计判定。
5. 与主读数、读数 P 的关系: 三者是同一批路径的三种读法, 必须一起引用。
