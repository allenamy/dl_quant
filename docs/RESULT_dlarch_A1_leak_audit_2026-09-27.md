### 4.1 L4c 的 +0.0028 从哪来、A0 有没有同样的底(lead 06:0xZ 两问; 描述)
**装置** `dlarch_a1leak_floor.py` + `run_floor.sh`,入库 `a738af249`,早于 A0 噪声模型训练与任何读数; 读法写在 docstring 里。**收据** `receipts/A1LEAK_FLOOR_2026-09-27.json`(19798f47,pod2 原件与副本一致),执行者日志 `A1LEAK_FLOOR_run_2026-09-27.log`(`FLOOR_DONE rc=0`)。pod2 配额告警时段内写出的 OOF 都做过完整解码(zip CRC)并与收据 sha 比对, 全部一致。

**(1) 打乱保留了什么**(从 `dlarch_a1leak_train.py` 235dc868 的 `permute()` 读出):
- 做法: 每个锚内, 只在「成员且标签有限」的格之间重排标签; 全程一个 rng(种子 20260927), 每个锚走一次。
- 保留: 锚本身、成员集、每个锚的标签取值多重集。
- 毁掉: 锚内哪个资产拿哪个标签(资产身份)。
- 不跨锚打乱。训练目标取锚内秩 ⇒ 目标是与特征无关的随机排序。

**(2) L4c 零分布的标尺问题**: L4c 把训练好的噪声模型**固定**, 只在测试端打乱配对, 所以它的散布只是「一个固定分数」的测试标签抽样噪声(sd 0.0007 / 0.0013)。噪声模型仍是 78 个特征的某个固定而任意的函数, 它对真标签的 IC 随「噪声抽样」而变, 而 L4c 的零分布不含这一部分。实测:
| | pre-2026 | 2026 |
|---|---|---|
| A1 噪声模型(种子 20260927) | +0.0028 | +0.0028 |
| **A0 噪声模型**, 种子 20260927(与 A1 同一份打乱标签) | **+0.0030**(自身零分布 [−0.0016, +0.0016] 之外) | **+0.0096**(零分布 [−0.0027, +0.0024] 之外) |
| A0 种子 20260928 / 20260929 / 20260930 | +0.0047 / −0.0005 / +0.0013 | −0.0029 / −0.0027 / +0.0066 |
| A0 4 次噪声抽样: 均值 / sd(n = 4, 只作标尺, 不是 σ) | +0.0021 / 0.0022 | +0.0027 / 0.0064 |
| L4c 置换零分布 sd(A1) | 0.0007 | 0.0013 |
| 合成例: 200 个随机方向 × 锚内秩化 X78 的 IC, sd [2.5%, 97.5%] | 0.030 [−0.054, +0.052] | 0.026 [−0.046, +0.046] |
- **问题 2, 按写定判据**: A0 同种子格在两段都落在自身零分布外, 且与 A1 同号 ⇒ **A0 有同样的底**。同一份打乱标签训出的 A0 与 A1 同号, 说明噪声模型的函数由这份特定的噪声决定。
- **+0.0028 的来源**: 它是「噪声抽样之间」的散布, 不是 A1 特有的偏移。
  - 同一配方换打乱种子, IC 在 −0.0029 到 +0.0096 之间, 两段都有正有负, sd 0.002–0.006, 是 L4c 置换零分布 sd 的 2–5 倍;
  - 合成例里任意线性特征组合的 IC 散布更大(sd 0.03), +0.0028 远在其 95% 之内(两段均为「平常值」);
  - 逐月扩展训练用的是同一份打乱标签, 后续模型彼此相近, 两段同为 +0.0028 与此相容。
  - pre-2026 4 次抽样有 3 次为正, 均值 +0.0021: n = 4 排除不了一个小的正均值, 照报。
- **对 D0 的含义**: D0 是两个**真实**模型之差, 噪声模型的底不叠加进 D0。D0 的标尺是成员配对的离散度: 2026 年 D0 为 +0.0021(y4s 谱), 8 对的 sd 为 0.00055, 8/8 为正; pre-2026 D0 为 +0.0076, sd 0.00068。噪声模型之间的大散布说明: 标签是噪声时, 函数几乎不受约束; 标签为真时, 不同随机种子的模型彼此很近。两者不是同一个量。⇒ 「L4c 的底与 D0 同量级, 所以要限定 A1 的 2026 优势」这一推论用错了标尺。

- **年龄效应**:
  - 每一年里, ΔIC 都随 A0 模型变老而上升;
  - A0 模型刚训完的头 90 天, 四年的 ΔIC 都约为 0(−1 到 +13, 区间全部跨 0);
  - 也就是说, 刚训好的年折模型和月度模型一样好, A1 的增益来自 A0 模型的老化。
- **年份效应也有**: 同一年龄桶内, 2025–2026 明显低于 2023–2024。[90, 180) 桶 2026 为 +8.7, 2023–2025 为 +49..+87;[180, 270) 桶 2025 为 +27, 2026 为 +47, 2023–2024 约 +95。
  - 描述性加法拟合(基准为 2023 年、[0, 90) 桶): 年龄桶系数 +46 / +60 / +117; 年份系数 2024 +22、2025 −21、2026 −31。
- **把 4 倍拆开(估计, 只能按一种顺序拆, 份额不可相加)**:
  - pre-2026 的 +73.3 与 2026 的 +16.9 相差 56.4;
  - 若 2026 各年龄桶的增益取 pre-2026 的桶均值(8.0 / 65.6 / 72.2), 按 2026 实际的天数构成(80 / 90 / 73 天)加权, 得 +48.6;
  - ⇒ 年龄构成约解释 24.7(2026 没有 [270, 400) 那一桶, 中间两桶天数也少), 其余约 31.7 是同龄桶内 2026 增益更低;
  - 反向拆法无定义, 因为 2026 缺最老的一桶。
- **具名混淆**: A1/A0 的训练样本量比同样随年龄上升(2023 最老一桶为 2.08, 2025 为 1.53)。「数据更新」与「数据更多」在本装置里分不开; 2023 年的 A0 只用 2022H2 训练, 是样本量效应最大的一年。
- y4s 口径的同表结论相同(各格与 T_net 相差 ≤ 14.3)。
