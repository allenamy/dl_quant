## 2. 装置与信号(全部因果; 4h 锚粒度)
- 挂钩 = 修正后的最终记账书挂钩(`w10_health_overlay.py` b063af79 之后版本: 每 run 新建叠加器、名义中性只缩不放、单侧清空归零); ctx 含上一锚记账书 HR(= 进入本锚时的持仓)、y4 行 < i、成员集。
- **空头篮子** = HR < 0 的名(上一锚记账书里做空的名); 多头篮子 = HR > 0。
- 信号(rows i−k..i−1 的 4h 收益, k ∈ {1, 2}):
  - `SB_up` 空头上涨广度 = 空头篮子里 k 锚累计收益 > 0 的名占比;
  - `SB_rel` 空头相对反弹 = mean(空头篮子 k 锚累计收益) − mean(多头篮子 k 锚累计收益);
  - `SB_loss` 短边损失 = Σ_{HR<0} HR·r(k 锚累计, 以毛额归一; 负 = 亏);
  - 触发量 = `SB_rel`(主)、`SB_loss`(副臂), 因果分位: 扩展历史 ≥ 200 观测后取 q 分位。
- 动作 = 限制**最终持仓预算**: 触发时整书乘 s(名义中性自动保持; 末端只缩不放 ⇒ 不会把减掉的风险补回同类名); 不改目标书, 不改腿 EMA。
- 网格: k ∈ {1, 2} × q ∈ {0.95, 0.98} × s ∈ {0.5, 0}(主触发 SB_rel, 8 条); 副臂 SB_loss k=1 q=0.95 s=0.5(1 条); **控制臂** r6c: 无条件整书乘常数 c̄ = 主臂 k=1,q=0.95,s=0.5 的平均预算系数(同平均杠杆), 1 条。共 10 臂 + 基线。
