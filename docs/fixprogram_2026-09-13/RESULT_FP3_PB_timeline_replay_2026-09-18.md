## 3. 读法(收紧)
1. **时间线钉准后, 席位与生产同值**: 播种起 72 锚 w3 差 ≤ 1e-4(生产记录只存 4 位小数, 62% 逐位相同, 其余差 1e-4 = 四舍五入位)。这证明腿收益历史、msharpe 席位、干预时刻三者与生产一致。
2. **书的残差是初始状态谱系, 且单调衰减不回弹**: 1.8% → 1.5% → 1.4% → 0.9% → 0.47%, 每次干预钉准后都下一台阶, 从不重置状态。当前代码版(不钉干预)在播种后跳到 12–14% 并停在那里——**干预时刻错一锚都会留下 10 pp 量级的永久足迹**, 所以 P-B 的两处驱动缺陷(§7)不是小事。
3. **与三锚精确结果的关系**: 从 09-17 12Z 生产快照精确初始化 ⇒ 后三锚 L1 = 0(`PREPLAY_SNAPSHOT_INIT_continuous_3anchors`); 从 08-30 引导态起 ⇒ 到同一段为 0.47%。两者之差(0.47%)就是「引导态 ≠ 真实 08-30 生产态」的全部代价, 上界清楚。**同码 + 同数据 + 同状态 ⇒ 同书** 在有快照的锚上精确成立, 在无快照的锚上残差有界且已知来源。
4. **仍是假设的部分**: 「0.47% 全部来自引导态」——按复审 §4 的要求, 归因阶梯(初始 H / EMA / 腿收益 extras / 名单 / 版本 / 播种)应逐项冻结对照才算分解; 本件只给了「干预钉准 ⇒ 台阶下降」的单调证据, 不写成分解。
5. **不证明的**: 收益(P-B 不记账); 执行器书层(P-C 未做, 设计已按复审改为决策前可见状态输入); 全历史折外(P-D 未做, 两条结果将分开标名)。
