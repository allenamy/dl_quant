## 3. 读法
1. **规则没有信息, 方向还是反的**: 九条条件臂 Δ 的 CI 全部整体 < 0(最好的一条 −0.057 [−0.107, −0.008]); 触发锚桶里的 Δ 三条显著为负、其余点估计 −1…−5 bps/锚/gross ⇒ **空头篮子反弹之后的那个锚, 书平均在赚**(触发锚的基线 g 见收据 `bucket.g_baseline`), 在那里缩预算是把均值回归的利润砍掉。这与 R1(市场事前广度)是同一个现象: 4h 粒度下, 反弹不预告下一步, 反而预告回摆。
2. **G4 全败**: 每一条条件臂在 maxDD 与止损线日两项上都不优于「永远只用 97.4% 预算」的无条件控制臂(maxDD −39.7%, 最差年夏普不变, Δ −0.016)。也就是说, 如果目标只是少一点尾部, 无条件少用 2.6% 杠杆就能做到, 条件规则只增加换手(×1.3–3.1)和损失。
3. **止损线日 1 → 0 的几条(k=1)**不是证据: 同时 maxDD 从 −40.6% 恶化到 −42…−46%、最差年夏普恶化——砍掉的是止损线附近那一天, 换来的是别的年份更深的回撤。
4. **因果性已单独证明**: 每 run 新建叠加器、未来扰动不改前缀(单元控 C 含 r6/r6l), 不是前视造成的负结果。
5. **限制**: 4h 锚粒度(「快」只能快到下一锚); 无锚内(15m/1h)收益; 无 OI/清算流; 只测 A0 s42; 触发量只有两种定义(相对反弹、短边损失)。独立研究员建议的锚内版本没有被本件否定——它需要生产路径(P-C/P-D)或独立装置, 是不同的题。
