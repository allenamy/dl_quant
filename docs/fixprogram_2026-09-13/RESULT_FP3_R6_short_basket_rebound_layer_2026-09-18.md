## 3. 读法(v2, 按独立研究员 8ba6d6a5 与第八轮复审更正; 分解收据 `FP3_receipts/R6_DECOMPOSITION_2026-09-18.json`, 装置 `FP3_devices/overlay/r6_decomposition.py`)

3. **少赚 ≠ 空头均值回归(首版机制读法撤回)**: 参照臂触发锚(n 479)上**基线**书的分解 = 净 +0.57 = 多头价格 **+2.57** + 空头价格 **−1.35** + carry +0.53 − 成本 0.12; 触发后的下一锚空头腿 **−4.60**(全样本空头腿均值 +0.31)。⇒ 空头篮子反弹之后**继续涨**(延续), 书在触发锚上赚钱是**多头腿盖过了空头亏损**; 整书减半砍掉的是多头利润。九臂里空头腿在触发锚上为负的占 47–57%, 下一锚空头腿全部为负(−1.9 … −7.5)。这是可用的信息, 只是「整书缩预算」是错的动作。
4. **恢复仓位的代价**: 参照臂总负差额 −871 里 41% 发生在触发桶之外, 每次恢复锚平均 −0.84(s=.5)/ −1.78(s=0)bps = 从缩减预算回到满仓的换手成本; s=0 的臂清空后下一锚没有持仓篮子、信号未定义、直接恢复满仓(合成验证出现满仓→空仓→满仓), 这是**规格缺陷**: 篮子应从目标书取, 恢复应带滞回——修正案 1(r6b: 篮子 = 上锚目标书 HB, 去掉 s=0, 滞回 q_off=0.80)已在跑。
5. **「三次独立测试」撤回**: R1/R4/R6 共享历史、组合与引擎, R4 测的是另一机制; 正确表述 = 暂停这些具体规格; 15 分钟/1 小时监测、共同风险约束、不同恢复机制未被否定。
