## 2. 根因: 三层, 各有数字
**层 A · 书的结构敞口是「簇」不是「市场」。** 回放里书对成员广度的日 β = 0.006(R² 0.0005); 广度顶十分位日均 **+0.22%**, 不是亏。亏的锚是**被做空的那一簇同时刻暴涨**: 最差 1% 锚里空头腿亏损份额 0.644(参照 0.558), 前三名只占 0.18(是一簇不是一名), 4 个最差日空头亏损份额 0.99 而当日广度只有 +2.9…+18%。做空的是极端费率 / 过度伸展名, 它们在普涨里的 β 远高于平时——这是**条件 β**, 线性 β 对冲(R4)和广度中性对它无效(R4 尾部零改善)。

**层 B · 触发量不预告。** 同时刻广度顶十分位锚 g = −2.20, 但**事前**(trailing-24h)顶十分位锚 g = **+1.547**(全样本最好的桶); 最差锚里事前触发只开着 14%(基率 8%)。4h 锚粒度下书只能在下一锚反应, 而下一锚平均已经在赚。所以「策略响应不了」不是模型慢, 是**这个量在事前没有信息**; 任何按事前普涨降杠杆的规则都在砍利润(R1: Δ CI 整体 < 0, 换手 +30–70%)。

**层 C · 尾部与 alpha 住在同一批名里。** 单名波动上限是唯一砍尾的杠杆(守帽分配修正后: maxDD −40.6 → −35.4, 告警线日 12 → 6, 止损线日 1 → 0), 报价是净额 **47%**, 且集中在 2026(g 2.834 → 1.02)。当前 regime 的 alpha 正是高波动名, 统一 2% 上限 + 恒定 2× 让它们同时是收益源与尾部源。

**层 D · 实盘比回放更尾**(未闭合的最大项)**。** 回放最差簇 2026-08-19…22 四天最差 −3.58%, 没有 ≤ −4%; 实盘 21 天 3 次。已量化的放大器: 执行器换手 1.5×(目标 3.5% → 成交 5.3% / 2·NAV, 平仓锚 p90 11.7×)、真实费率 2.6 bps(回放 2.1)、整形把止损名钉住(在案)、保护性平仓 5 bps taker + 再进场; 未量化: 九月路径本身(回放到 08-30 为止, 09-01 起的生产路径回放 P-B 修正版在跑, 执行器书层 P-C 未做)。**在 D 闭合前, 不能把九月尾部归给书层。**

## 3. 为什么现有防线不动作
- **−4% 日止损**: 回放史上 ≤−2.68% 日次日均 −0.18%(n 12, 58% 负)、后三日 +0.38% ⇒ 平仓既不保护也不显著花钱; 它是事后的, 不改变簇挤空发生的概率。
- **逐名止损 −30%/2 锚**: 对付单名, 而最差锚是一簇(前三名 0.18)。
- **FTRIM / 负费率硬出场(r3f)**: 尾部反增(≤−4% 日 1 → 2)。
- **席位(msharpe, 900 锚)**: 回看 150 天, 对锚级簇事件是常数。

## 5. 一句话
书亏在「被做空的那一簇在同一个 4h 锚里被挤爆」, 这个事件在事前的广度量里没有信息, 所以按普涨降杠杆只会砍利润; 能砍尾的只有按波动限仓, 报价接近净额一半; 实盘比回放更尾的部分还没分到层, 那是下一步该测的地方, 不是再加书层规则的地方。
