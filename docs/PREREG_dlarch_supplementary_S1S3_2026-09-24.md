## 3. S1 —— King 书与 F10 书的书层相关

**三个量(都在 `pre2026` 与三个分段上,两种子 × 两发布策略)**

1. **权重相关**:逐锚,`kc[i]` 与 `fc[i]` 在**并集非零名**上的 Pearson 与 Spearman;报均值、se、逐锚分布分位。
2. **收益相关**:两条时间序列 `u(kc)/|kc|₁·1e4` 与 `u(fc)/|fc|₁·1e4`(= 量尺件的 L4kc / L4fc)的
   **跨锚** Pearson 与 Spearman。**这一条才是分散化要的数。**
3. **抵消系数**:`|0.55·kc + 0.45·fc|₁ / (0.55·|kc|₁ + 0.45·|fc|₁)`,逐锚均值。

⚠ **明令禁止的一步**:**不得**从抵消系数反推权重相关(或反之)。
两者的关系依赖「逐元素同分布且独立」这类我没有验证过的假设;
把它算出来当机制就是「从一个数字断言机制」(受据 `full_gradient_window_buys_nothing_2026_09_07` 的撤回段:
「Spearman 秩相关**不**随权重份额线性稀释 —— 两个数接近是巧合,被我装成了定理」)。
本节**并列报三个量,不给任何一个推另一个**。

**零控制**:把 `fc[i]` 的**名字轴在锚内随机置换**(固定 RNG `default_rng([20260924, 1])`)后重算量 1 与量 3。
判据:置换后权重相关的均值 `|ρ_null| ≤ 3 · se_null`(**se 由 20 次置换的分布给出**,门形与
`AMENDMENT_1_dl_layer_ladder_null_gate_2026-09-24.md` 一致,由 lead 裁定过的形式)。

## 4. S2 —— D/E/J 三族在 F10 腿层收益里的份额(**恒等式,必须闭合**)

**为什么不是消融**:真正的消融要**去掉这 26–27 列重训 F10**,那要 GPU,现在不许动。
**本节测的是另一个量**:F10 **今天这个模型**的输出里,有多少落在 D/E/J 的张成里。
**两者不是同一个量**,这一句必须出现在结果的每一处引用旁。

**做法(逐锚,成员内)**
1. 取 F10 的原始分数 `p`(有限格),标准化为 `z = (p − mean)/sd`(与训练 `utility` L33 同式)。
2. 取 D/E/J 三族的列 `X_DEJ`(列由 §1 的重建流程决定),**逐锚**在成员内做 OLS:
   `z ≈ a + X_DEJ·b`(用 `lstsq`,列先在锚内标准化;秩亏时报 `rank_deficient` 计数并跳过该锚)。
   得 `z_fit`(张成内)与 `z_res = z − z_fit`(张成外)。
3. **线性腿功能**:`u(v) ≡ Σ_j v_j·y_j`(`y` 非有限 ⇒ 0)。因为 `u` 线性且 `z = z_fit + z_res`:
   ```
   u(z) == u(z_fit) + u(z_res)          （逐锚断言,容差 1e-9 · max|项|）
   ```
   三项**同除** `Σ|z|`(同一个分母)再 ×1e4 ⇒ 三个数单位一致且相加恰等。
4. 报 `R² = 1 − var(z_res)/var(z)` 的逐锚均值。

⚠ **注意与量尺件 L2 的区别**:量尺件的 F10 腿用的是**生产硬秩**;本节用的是**标准化原始分数**,
因为只有线性权重才能让分解闭合。两者的水平因此不同 —— 必须**并排报**「同一批锚上 `u(z)/Σ|z|` 与
量尺件的硬秩腿收益」,给出「换成线性权重后水平差多少」的桥。**不给这座桥就不许把两者放在一句话里。**

**列数配对安慰剂(F8 纪律,必须做)**:从 X89 的**其余 63 列**里随机抽与 D/E/J **同列数**的一组,
做同样的投影分解,5 个种子(`default_rng([20260924, 100+k])`)。
它给出「任意 26–27 列凭维数就能解释多少」的零点。
**判据:D/E/J 的 `u(z_fit)/Σ|z|` 必须超过安慰剂 5 个种子的最大值,否则本节结论 = 「D/E/J 的份额与同列数随机列不可区分」。**

**承重断言**
- 恒等式逐锚闭合(容差 1e-9),不放宽;人口计数单独报不作门。
- **红能力对**:把 `X_DEJ` 换成**全零矩阵**,断言 `u(z_fit) == 0` 且 `u(z_res) == u(z)`(逐位),证明分解真的在动。
- **非零格计数**(受据 `rank_transform_turns_all_nan_into_all_zero_2026_09_23`):报 D/E/J 各列在窗内的**非零格数**;
  若某族某列非零格为 0,标「该列无测量」而不是算成 0 贡献。

## 5. S3 —— 死区 `|trade| < 0.00025` 在 F10 侧切掉多少

**做法:单参数反事实重链。** 用 `continuous_combo.evolve` + `combo_target.step`(**原封不动 import,不重写**)
在同一批输入上跑两次,只改 `params['band']`:

| 臂 | `band` | 其余 |
|---|---|---|
| **P(平价臂)** | `0.00025`(生产) | 全部与 `news2_combo.py` L59–60 逐字相同 |
| **B0** | `0.0` | 同上 |

**承重断言(先红后绿,顺序固定)**
1. **平价门**:P 臂的 `kc / fc / raw / weights / trade_mask / reason` 必须与档案
   `work/combo_s{seed}/{policy}.npz` **逐位相同**(`np.array_equal` + sha)。
   **不逐位相同 ⇒ rc≠0,本节停止** —— 因为那说明我的 harness 不是生产路径,后面的差都不可解释。
2. **开关接上了**:B0 与 P 必须在 **> 0 个锚**上不同,并报
   「逐锚不同的权重格数」与「不同格的权重质量和」。
   **若差为 0 ⇒ 判 `SWITCH_NOT_WIRED`,不报任何「死区不值钱」的结论**
   (受据 `zero_delta_means_switch_not_wired`、`validator_can_pass_vacuously_family_2026_09_18`)。
3. **顺序**:平价门必须在 B0 之前跑完并打印判词。

**读数**
- 逐锚:死区导致「未被更新」的权重格数(= `|trade| < band` 且该格在 B0 下会变)与其质量占 `|fc|₁` 的比例;
  在 `fc` 与 `kc` 上分别报。
- 纸面收益:`u(fc)/|fc|₁` 与 `u(raw)/|raw|₁` 在 P 与 B0 下各自的窗口均值与差值;
  并报 **`trade_mask` 通过率**与 **`reason` 计数**的变化(死区影响 gross ⇒ 可能影响发布门)。
- 换手代理:`Σ|Δfc|` 的窗口均值在两臂下的差(死区就是为了省换手,必须把它省下的换手一起报)。

⚠ **三条限定,必须随每一处引用**
1. **`chain` 带状态**:B0 与 P 的状态轨迹从第一个差异锚起就分叉 ⇒ 这是**反事实重链**,
   不是「死区的边际贡献」的因果分解(受据 `counterfactual_rechain_beats_not_identifiable_2026_09_20`)。
2. **`y4s` 测不到死区省下的**真实**成本**(手续费在引擎层,`y4s` 是价格标签)⇒
   本节只能报「死区在价格通道上要价多少 + 它省下多少换手」,**不能**判它净值正负。
   净值要引擎 32 路径,那是书层实验,不在本节。
3. **绝对吸收态风险**:B0 可能让某些锚从 HOLD 变成发布(或反之),从而改变后续所有状态。
   必须报「两臂 `trade_mask` 首次分歧的锚」与「分歧之后的锚数占比」。
