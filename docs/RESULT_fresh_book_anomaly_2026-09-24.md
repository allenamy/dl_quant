## 3. 管线结构:King 与 F10 在训练层面就是耦合的

`fresh_train_f10.py` L83/L90:F10 的训练损失读 `legs.npz` 的 `WL`,而 `WL` 是由**含 king 列的腿收益历史**算出的 msharpe 席位
(`fresh_legs.py` L64–82:`r = stack(LR[leg][-look:])`,`WL[i] = w3`)。
所以 **King 的改动会经席位进入 F10 的训练目标**,两条腿在训练层面即耦合,
**"King 与 F10 可分离"的 2×2 在这条管线里不存在**。这是**管线结构**,不是 F10 的缺陷。

后果:原计划的交叉臂 B = {King NEW_S, F10 FRESH} 与 C = {King FRESH, F10 NEW_S} 是**这条管线永远产生不出来的配置**
(被交叉的 F10 是对着另一臂的席位优化出来的),其交互项会把这层耦合吸收进去,不能当作干净的 King×F10 交互来读。
**B、C 未跑**(lead 2026-09-24 裁定)。

## 4. 候选机制(**未检验**,写成可证伪的形式,不是结论)

**席位是用过去 900 锚的腿收益估的**(`bundle_config.json` 实测 `msharpe_look = 900`;900 锚 × 4h = 150 天 ≈ 4.9 个月)。

- **年折**下,这 900 锚**大多出自同一个模型**(一年约 2190 锚,900 锚约占 41%,至多跨一次折边界)。
- **月折**下,这 900 锚**跨了约 5 个不同的月度模型**。

⇒ **在月折下,席位衡量的是"过去那几个模型"的表现,而不是"当下正在交易的这个模型"。**

这**可以**解释第 2 节那个并列:席位高的时候,当下 King 的边际增益反而最小(3.1%),而亏损最大(68.6%)——
席位是被前几个模型的历史抬上去的,抬上去之后压的却是当下这个模型。

**怎么检验(还没做):** 按**席位窗口内模型的混杂度**分桶 —— 对每个锚,数它前 900 锚里出现过几个不同的 King 折模型,

两臂同装置、同分母,份额必须闭合。若亏损不随混杂度上升,本机制被否。

### B.3 前提成立,预测被否 —— 这两件事要分开说

- **机制的事实前提成立,而且比原先设想的更强:** FRESH 月折下,当下正在交易的那个模型在席位窗口里
  **从未超过 20.6%**,均值只有 **10.1%**。席位记忆**约九成来自别的模型**,这是按构造成立的。
- **但机制的可检验预测被否:** "当前模型占比越低越亏"这条**在数据上不成立**(U 形,区间跨零)。

⇒ 结论只能写成:**席位确实主要在衡量过去的模型(前提真),但书层亏损并不随这一比例单调变化(预测假)。**

### B.4 零对照的读数是退化的 —— 我自己的装置缺陷,照写

收据里 `zero_control.binned_by_NEWS_frac.spearman = 1.0000`,看起来像"年折臂上反而出现完美单调关系"。
**它不是发现,是退化统计量:** 因为 `frac_NEWS` 高度集中(中位数 **1.0000**,83.6% ≥ 0.5),
五个等频档里**只有两档有锚**(n = 1100 与 4395,其余三档为 0)。**两点之间的 Spearman 必然是 ±1**,不携带任何信息。
这与 `saturated_statistic_cannot_show_a_difference` 是同一族:**被界压住的统计量不能拿来比较**。
要让这条零对照有意义,应当按 `frac_NEWS` 自己的分布重新切档(或直接报分布本身),而不是套用同一套等频规则。
