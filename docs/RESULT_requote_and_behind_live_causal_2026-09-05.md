### 2.3 冻结判读
- 有帮助 ⇔ DiD < 0 且 CI 不含 0 且分支自洽: **CI 含 0 ⇒ 不成立**。有害 ⇔ 效应 > 0 且 CI 不含 0: **不成立**。⇒ **UNDECIDED**。
- 预注册对 UNDECIDED 的默认建议("撤回到 08-06 前路径")的前提是"实盘零期望"; 分支分解(同属预注册指标)与该前提相反(p ≫ p*, 三个窗点估计两负一正)。**本文不改冻结规则, 如实报两者; 处置归用户: 默认建议改为"不动, 补追认"**, 理由是撤回也是书行为改动, 而证据方向不支持撤回。
- 治理发现: 该机制 08-05 被自身装置否决、08-06 仍上线(提交说明未引否决 RESULT, 未见用户字)、08-09 文档仍称"未执行"、08-11 模拟再否决"关闭归档", 但实盘每锚运行 185 锚从未被真实账本判决 ⇒ 登记 E-0905-I。
