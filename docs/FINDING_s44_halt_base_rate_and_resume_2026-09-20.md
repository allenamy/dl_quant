# 发现 · §4-4(−25% 停机)的基率, 以及「触线之后怎么办」是一条没写下来的规则

## §0 一页白话

1. **§4-4 不是回撤规则, 是「保本」规则**: `watchdog.py` L131 `DRAWDOWN_LIMIT_PCT = -25.0` 算的是**从起始权益**的累计收益, 不是从峰值。⇒ **它依赖入场时点**: 同一本书, 两个账户起始日不同, 停机行为就不同。先涨 100% 再跌 30% 不触发; 开局就跌 25% 触发。
2. **基率(完整配方窗内 4,758 个起点 × 32 条成交路径)**: 新账户**一年内**触线的平均概率 **24.2%**; 至少一条路径触线的起点占 37.1%; 32 条全触线的起点占 17.4%。**180 天内**只有 **2.1%**。
3. **风险高度集中在两个事件, 不是均匀分布**: 一年内触线概率按起点月份 —— 2023-06…09 **100%**、2023-10 94%、2023-11 72%、2023-12 60%、2024-01 30%、2024-02 14%; 之后归零, 只在 2024-12(22%)/ 2025-01(9%)/ 2025-03(22%)有小簇; **2025-05 起全部为 0**。⇒ 有效样本 **≈2 个事件**, 不是 4,758 个。
4. **在唯一那次会真正触发的事件里, 那条线挡住了什么: 什么都没挡住。** 从完整配方窗基准算, 32/32 路径触线(中位 **2024-03-18**)。**若触线当刻不停机继续做**: 之后 7 天 **+6.4%**、30 天 +0.9%、90 天 −2.5%、365 天 **+37.4%**、到窗末 **+214.3%**(5% 分位 +190.4%)。**触线后 30 天内再跌 13% 以上的路径: 0 条。**
   ⚠ **这是 n=1**: 全部 32 条在同一时刻触线, 它们是同一历史事件的成交随机化复制, 不是 32 个独立观测。
5. **真正的缺口不是那条线, 是那条线之后**: §4-4 触发 ⇒ 取消 + 整书平仓 + 账户只减仓 + **只能人工恢复, 没有书面时限**。⇒ **默认情形就是最坏情形**(永不恢复), 而那正是值 −214pp⚠(**已撤回**, E-0921-D + R8-POL-02: 同一本金下逐路径均值差 **159.902772pp**)的那一支。

## §1 与今天另外两条发现的关系

- **不要与 §4-2 混淆**(lead 今日自犯, E-0920-D): §4-2 日止损的恢复延迟**被实盘界定**在 4–20 小时(19 个停机锚 / 9 段, 唯一确认的日止损停 16 h), 可达范围内结果只差 0.03 pp。**§4-4 从未在实盘触发过**, 所以它的恢复假设**没有任何证据约束** —— 这一条不因 E-0920-D 而作废。
- **它是今天唯一有报价的真实风险敞口**: 构造轴(书形态 / 席位 / 三信号配比)今天测下来天花板约 **+0.5 bps/锚**且多数不稳定([[FINDING_seat_drives_preflight_fallback]] / CF3); 而 §4-4 一次触发值 **−200pp 量级**。

## §2 实盘当前位置

账户 2026-08-26 起, 当前累计约 **−2%** ⇒ 距 −25% 线约 **23 个百分点**。按 §0-3, 起点落在 2025-05 之后的历史区段, 一年内触线基率为 **0%** —— 但**那正是与选型样本重合的区段**, 所以这个 0% 不可当作前瞻概率。诚实的读法是: **基率在 0% 与 24% 之间, 取决于 2023H2 那类环境是否重来**, 而那个问题今天无人能答(CF3: +2.8 的跨期差在所有世界里都出现, 无仪器解释)。

## §3 待裁定的建议(**不动风险偏好, 只补一条缺失的规则**)

**建议**: **保持 −25% 这条线一字不动**(它的取舍是用户的风险偏好, n≈2 不足以推翻它), 但**把「触发之后怎么办」写下来**。
理由: 现在没有书面恢复规则, 意味着**默认落到「永不恢复」这一支**, 而回放显示那一支在唯一观测到的事件里值 −214pp⚠(**已撤回**, 同本金下 **159.902772pp**; E-0921-D/R8-POL-02)。写下规则不改变承担多少风险, 只是把一个**无界假设**变成**有界假设**。

需要用户裁定的具体项(本文不预设答案):
1. 触发后是**定时恢复**(如 N 天)、**条件恢复**(如某状态量复位)、还是**始终人工**?
2. 恢复时是**满仓恢复**还是**分档爬坡**(与 2026-08-27 那次 1.5→1.75→2.0 的爬坡同形)?
3. 恢复后 −25% 的**计数器是否重置**(从新权益重新计, 还是继续从原始起始权益计)? —— 这一条不定义, 恢复后可能立刻再次触发。
4. 是否需要**逐日告警**在接近该线时(如 −15% / −20%)提前通知, 而不是等到触发。

## §4 未测 / 不得当已知

1. **n≈2 个事件**。基率 24.2% 的置信区间在事件层面极宽, 本文不给 CI, 因为按起点自举会把同一事件重复计入。
2. 「触线后继续做会赚 +214%」**条件在 2026 上**, 与选型样本重合。它说明的是「那条线在那次没有保护作用」, **不是**「那条线永远无用」。
3. 本文未测**恢复后的执行成本**(整书平仓 + 重建的换手与冲击), F 族测得日止损平仓单次窗口费约 5.4 bps of gross, 可作下界参考但不是同一事件。
4. 实盘 §4-4 从未触发 ⇒ **恢复流程从未演练过**。建议里第 1–4 项无论怎么裁, 都应先做一次**哑演练**(与 OPS 回滚动词演练同形)。
