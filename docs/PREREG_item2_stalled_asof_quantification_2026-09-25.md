## 2. 两个被比的量(各自绑到读它的那一行)

- **used(当锚实际用的)**:取 `snap/<A>/aux.json` 的 `ledger_tail[s]`,按 `nc_contract.funding_asof(state, last_row, A)` 的口径算 as-of —— 即该名在**该快照里**最后一笔 `ft <= A` 的结算。快照 = 生产者在该锚写完状态后的自留,所以它就是"它当时手上的账本"。
- **correct(正确的 as-of)**:同一函数、同一 `A`,但 `ledger_tail` 取**当前** `~/wide_shadow/state/aux.json`(事后已知的完整记录)限 `ft <= A`。
- **参照口径的自陈弱点**:correct 的来源是**同一个生产者**后来的账本,不是独立第三方。它能抓"当锚漏读了后来才知道的那笔",**抓不到**"这笔结算生产者从头到尾都没拿到"。后者只能等十月归档。⇒ 判词必须写「**相对事后已知账本**的 as-of 偏差」,**不得**写成「相对交易所真值」。
- `ledger_tail` 每名只留最后 400 行(`shadow_loop_v3.py:421`),所以某名若在 09-17..09-24 之后结算过 400 次(1h 尖峰约 17 天),其窗内早段可能已被截断 ⇒ 该 (锚, 名) 记 `OUT_OF_TAIL`,**不算成一致也不算成偏差**。

## 3. 人口与分母(冻结)

- **人口** = 该锚**书成员**格,成员集取 `snap/<A>/members_hist.npz`(生产者自己记的成员),**不是**全宇宙、**不是**"有分歧的格"。
- **分母** = `Σ_A |members(A)|`,即窗内逐锚成员格数之和。**所有比例一律以此为分母**,并逐锚同时报 `|members(A)|`。
- 排除并**具名计数**:`OUT_OF_TAIL`;`NO_ASOF`(两侧都没有 `ft <= A` 的结算);`NOT_FRESH_BOTH`(两侧都被 `FRESH_S=43200` 判 NaN 且一致)。
- **闭合断言**:`AGREE + STALE + OTHER_DIFF + OUT_OF_TAIL + NO_ASOF + NOT_FRESH_BOTH == 分母`。不闭合则不出数。

## 4. 分类(逐格,互斥)

| 类 | 定义 |
|---|---|
| `AGREE` | used 与 correct 逐位相同(含两侧同为 NaN) |
| `STALE` | 两者都有限且不同,且 used 的 as-of 时刻 **早于** correct 的 ⇒ 卡住 |
| `USED_NAN_CORRECT_FINITE` | used 为 NaN 而 correct 有限(冻结到超出新鲜窗) |
| `USED_FINITE_CORRECT_NAN` | 反向,须具名调查(不应发生) |
| `OTHER_DIFF` | 其余不同(同一 as-of 时刻但值不同 ⇒ 费率/间隔口径问题,不是卡住) |

**每个 `STALE` 格必报**:`used_ft`、`correct_ft`、落后秒数、used/correct 的 rate 与 iv、以及**该名在该锚的书内权重与方向(多/空)**(取 `snap/<A>/aux.json` 的目标权重),以及**随后 4h 收益**。

## 5. 基线绿(先于任何变异/结论)

1. **装置基线**:在 `2026-08` 上跑同一装置,`used` 与 `correct` 都取**当前** aux.json(即同一输入两次)⇒ 必须 **100% `AGREE`**,`STALE=0`。这测的是"比较器在输入相同时不会造出差异"。若不绿,先修装置,不出任何窗内数字。
2. **正控制**(必须能看见,否则"0 STALE"无意义):
   - 把某格的 used 替换成**上一笔结算**的值 ⇒ 必须归类为 `STALE`(这正是 `fund_replay` 缺陷的形状);
   - 1 个 **float32/float64 各自 dtype 的 ULP** 扰动 ⇒ 必须归类为 `OTHER_DIFF`(不是 `STALE`:同一 as-of 时刻);
   - 删掉某名 correct 侧的一笔 ⇒ 必须在**被搜索的那一侧**造出可见变化,而不是缩小分母。
   三条都必须**各自**红在**自己那一类**上,不接受"有东西红了"。
3. 控制跑的收据 `verdict` 一律写 `POSITIVE_CONTROL_RUN_NOT_AN_AUDIT`,并把"本跑本会报什么"留在具名字段;干净跑与控制跑必须**同一个 `self_sha256`**。
