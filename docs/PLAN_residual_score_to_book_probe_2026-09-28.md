# 残差分数到组合持仓的逐层诊断

目的：上轮已知RESID比RAW在2025排序更高但整书净额更低。核查哪一层转换改变其价格标签贡献与资金费暴露，而不是再训练一个规格。用户已授权持续独立归因与实验；本件沿用原实验的模型、输入、成员、组合和全部窗口，不新增策略候选、超参数或发布门。

方法：只读RAW、RESID、NC42、NC2027的封存预测和组合状态。将钉住生产chain的AST插入只读复制观察点，执行同一运算；从每锚封存的上锚kc/fc状态出发，复算该锚并要求kc/fc/raw/trade_mask逐位相等。观察分数排名、混入资金费、FTRIM、流动性去均值/封顶、EMA、免交易带、可持仓过滤及55/45混合。不跑成交模拟。

三个问题：
1. 模型分数与King/资金费分数的独立性是否在排名、混合和持仓层保留？
2. 更低发布gross来自子书自身gross下降，还是两子书互相抵消？逐锚要求 `0.55|kc|+0.45|fc|−cancellation=|raw|`。
3. 各层按共同原始4h价格标签、非零权重全可测条件求单位毛额贡献；任何非零名字缺标签则该锚该层不可测，不能隐含零。比较时单列各层人口和共同可测锚。此值是同步理想持仓的标签诊断，不是实际成交收益；HOLD目标零绝不当现金仓。

窗口固定2023H2、2024、2025、2026Jan–Aug、Sep1–18；未来标签只作事后结果，不参与状态或成员。即使某层好也不晋级。由于已看过经济结果，本件明确为探索性解释，不以其统计量声称新发现被确认。

预算：Pod CPU单线程、10分钟硬超时、6GiB预计RSS，资源余量不足8GiB不跑；无GPU、无场所调用、无本地重活。不重复原64路径；原归档只读。测试要求观察点不改变真实chain输出，改变已知输入能被输出平价抓住，缺标签与零gross不可测。
