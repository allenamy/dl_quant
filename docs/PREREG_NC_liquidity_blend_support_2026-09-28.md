# NC 资金费与流动性混合：先验完整目标及成本支持

承接 `RESULT_liquidity_cost_probe_2026-09-28.md`。既有 XIB 有历史选优、旧资金费输入和旧装置问题，本件不是复现旧夏普，而是在修正 NC 输入上的单个探索性移植。不开参数搜索，不重训 King/F10，不调交易所、不读实验分臂、不用 GPU。

机制：资金费排序提供方向；滞后流动性冲击指标改变该腿的截面配置，可能降低某些拥挤空头，也可能增加成本。不能先假定哪种发生。

固定唯一候选：当锚资金费基分布排名与上一锚 Amihud 排名等权相加，不再重排。Amihud 定义为上一锚结束的 288 根真实 5m 条的 `abs(sum(raw_simple_return))/sum(quote_volume)*1e6`；收益来自 NC `R_crypto`，量来自同源 `cache_crypto` 第3通道逐条 expm1(clip(logqv,0,30))，不采用“平均 log 量再取指数”。两者同格有效至少 ceil(.95×288)=274，成交量和须正。窗口右端 A−4h 包含，左端开。排名用平均秩 `rank/(n−1)−.5`，人口为该历史锚 NC 已合法、新鲜资金费基分布与可测 Amihud 的交集；少于10名则未知。与当锚资金费排名任一缺失，混合值未知，沿现有组合 nan_to_num 行为，不回填未来、不偷偷改为原信号。与旧面板的裁剪、端点、人口和再排名可能不同，必须称 NC 移植规格。

完整链：重建原始双精度资金费分数，先证明转float32与 NC ZFD 逐位同；按 NC 原公式、原 ready、前一连续 ready 锚及真实 raw 返回重算该腿 LR，原信号 LR 必须与归档逐位同，再重算900锚席位并与原 WL 逐位同。候选自己的 LR 决定自己的席位。保持 King、F10 两种子42/2027的已封存预测、FTRIM、55/45、连续EMA/带、宇宙、字面门及 scaled 历史门不变，失败发布保持数量语义不改。F10 未在新席位上重新训练，这是固定模型的组合配置实验，不是完整模型重训。

先跑“不改信号”完整组合，两种子两种发布政策的所有数组须与已归档 NC 逐位同。任一不符则停止候选。因果负控：改变 A−4h 之后的收益/量不改 A 信号，改变边界内有效量应可改变；候选 LR 的第i行不得影响席位第i行；基分布未来行改变不得回写历史分数。原码身份、输入sha及结果均封存。
