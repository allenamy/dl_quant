## 3. 类形状修法

1. **存储数组不外露**:`feature_cache_identity.capture_producer_inputs` 返回的 `data`,由 `rr_from_ch0` 在读取口里做一次整列替换,ch0 = rr(f32),与生产者 L661 同形。
   - 存储用的 f16 ch0 只以显式命名的字段(如 `ch0_storage_f16`)返回,调用者只有 `rr_from_ch0` 与状态写者。
   - 这样一来,`combo_stage` 以及以后任何新消费者写 `RD[:, :, 0]`,读到的都是 rr。
2. **去掉静默回退**:
   - `_btcv_series` 的 `RR=None` 回退、dlw / f8「缺 `ret_f32` 读 ch0」的回退,一律改为缺失即抛错(未知不是零)。
   - mini 缓存的 `data` 与 `ret_f32` 同源,都来自第 1 步替换后的数组。
3. **静态普查测试**(常设,进生产者发布测试集):
   - 用 AST 扫描 `shadow_loop_v3.py` 与 `fea171/*.py`,找出对滚动数据取通道 0 的下标,包括 `[..., 0]`、`[:, :, 0]`、`CHANNELS.index("ret5")` 和它的别名。
   - 白名单之外出现即红。
   - 验收问题是「明天新加一个消费者还会不会被抓住」,而不是「今天这几处改没改」。
4. **行为测试**(常设):
   - 夹具里放一个界值格:ch0 = f16(0.30),稀疏表 raw = 0.90。
   - 断言每个消费者的输出都随 raw 改变:X78 / X82 / X89、btcv、席位 y4v、beta 字段。
   - 把 raw 改成 0.30 的对照,输出必须回到裁剪值。这是用行为来测行为。
   - 先断言基线为绿,变异后必须为红。
5. **平价门覆盖**:`nc_parity_gate.py` 加第 12 个量 `beta_overlay.betas`。
   - 服务端取沙箱里 combo 写出的字段;研究侧用 `m2_lib.betas_at` 在研究 R 上重算。
   - 负控 NC-R 扩展为「beta 也必须变」。
   - 这是装置改动,按平价门改动的流程先审后用。
