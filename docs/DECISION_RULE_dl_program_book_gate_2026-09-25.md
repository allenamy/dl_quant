## 2. 被测量

## 3. 两阶段判据(种子预先钉死,不许事后挑)

**阶段 1:种子 42、2027、7。** 记 n=3 的 `mean(d)`、`sd(d)`。

- `SE = max( sd(d)/√n , σ_pre·√2/√n )` —— 取实测与尺度下限的较大者(配对在混沌训练下不保证降方差,所以用 √2·σ_pre 兜底)。n=3 时下限 = 0.852 ⇒ 3·SE ≥ 2.56。
- **RECOMMEND_TO_USER**(阶段 1 即成立)当且仅当全部满足:
  1. `mean(d) ≥ max(1.0, 3·SE)`;
  2. **3/3 种子 d > 0**;
  3. **2026 段** `mean(d_2026) ≥ 0`(点估计);
  4. 回撤护栏:pre-2026 最大回撤(固定 2× 逐锚复利 NAV)各种子平均**不比 T0 差 3 个百分点以上**。
- **EXTEND(进入阶段 2)**:`1.0 ≤ mean(d) < 3·SE` 且 3/3 同为正,且 3、4 两条满足。
- **REJECT**:`mean(d) ≤ 0`,或只有 ≤1 个种子 d > 0。
- **UNDECIDED**:其余情形。2026 段为负而判据窗为正时,判词写「判据窗与实盘窗方向相反」;种子反号时写「又一次按种子翻转」。

**阶段 2:追加种子 11、23、101(现在钉死)**,n=6 重算(下限 3·SE = 1.81)。
- RECOMMEND_TO_USER:1、3、4 同上,第 2 条改为 **≥5/6 种子 d > 0**;
- 否则 REJECT(mean ≤ 0)或 UNDECIDED。**不再追加第三阶段。**

**顺带测量**:每次运行都报 T0 各种子之间的 dbar 离散度,作为 F10 种子噪声 σ_F10 的第一批实测值。若 σ_F10 实测 > σ_pre,**下一次**运行起用 σ_F10 作下限(不追溯改本次判词)。

## 4. 不变的约束(用户永久规则)

- 多种子**只作测量**:部署时一律用**预先声明的种子 42**,不因哪个种子表现最好就换(不挑种子、不做集成、不做训后技巧)。
- RECOMMEND_TO_USER **不是部署授权**:任何通过的配方都是书行为改动,交用户裁定;判词行不得出现「采纳/上线/PASS」。

## 6. 修订 1(2026-09-25 02:2xZ,lead;写于任何 T0/T3 书层或腿层读数之前)

**起因**:dlarch 的投影(`5fa0deb02`,系数链全部取自已测量,其中「纸面→实现净额」一环跨口径,只作量级):按 §3 的下限 σ_pre,阶段 1 RECOMMEND 要求 T3 收回 F10 侧链损耗的 62%(把弱环设为 1 的上界读法)到 93%;而链损耗里还含净正的死区 ⇒ 对 T3 实际上不可达,书层几乎必然返回 UNDECIDED,无论 T3 真假。

**诊断**:σ_pre 来自 King `random_state` 扰动,扰动沿 King → 席位 → F10 重训 → 组合整条传播;**只改 F10 的臂 King 固定不动**,相关噪声是 F10 种子噪声 σ_F10,而它**从未被测过**(§1 已列为具名缺口)。用 σ_pre 当下限可能过度保守,也可能不够 —— 不测就不知道。

**改动(只此一处,其余条款不变)**:
1. **先测 σ_F10**:T0 用 **8 个种子**(42、2027、7、11、23、101、**3、5**;后两个现在钉死)各走到书层(引擎 base 格,32 路径),每个种子报 `dbar(T0_k) − dbar(在役 NC s42)` 的 pre-2026 与 2026 两段。σ̂_F10 = 这 8 个值的样本 SD(两段各一个)。
2. **新下限**:`σ_ref = 1.3533 · σ̂_F10`(σ 的 80% 单侧上界,χ² 自由度 7:√(7/3.822))。§3 的 `SE = max(sd(d)/√n, σ_ref·√2/√n)`,**σ_ref 取代 σ_pre**。无论 σ̂_F10 大于还是小于 σ_pre,都用它 —— 事先不知道方向,所以不偏向任一方向。
3. **在 σ_F10 测完之前,任何 F10 臂都不得按本文判书层**(腿层照跑不受影响)。
4. 1.0 bps/日的绝对下限、种子同号、2026 段、回撤护栏全部不变。
5. **分辨率换算**(供读者,不作门):σ̂_F10 = 0.5 ⇒ σ_ref = 0.68 ⇒ 阶段 1 3·SE ≈ 1.66、阶段 2 ≈ 1.17 bps/日;σ̂_F10 = 1.0 ⇒ 阶段 1 ≈ 3.3、阶段 2 ≈ 2.3。
