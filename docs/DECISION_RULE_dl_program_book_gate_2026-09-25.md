- **REJECT**:`mean(d) ≤ 0`,或只有 ≤1 个种子 d > 0。
- **UNDECIDED**:其余情形。2026 段为负而判据窗为正时,判词写「判据窗与实盘窗方向相反」;种子反号时写「又一次按种子翻转」。

**顺带测量**:每次运行都报 T0 各种子之间的 dbar 离散度,作为 F10 种子噪声 σ_F10 的第一批实测值。若 σ_F10 实测 > σ_pre,**下一次**运行起用 σ_F10 作下限(不追溯改本次判词)。
