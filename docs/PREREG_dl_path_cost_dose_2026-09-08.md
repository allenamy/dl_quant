**③ 模型已在优化扣换手成本后的净额, 旋钮就在损失函数里。** 读码(`pod_f10_train_monthly_earlystop.py`):
- 推理/训练同一 EMA: `wn = (1 − α)·w + α·u_new`, **α 越低越平滑**; `alpha(s) = 0.02 + 0.88·sigmoid(s.a)` ∈ [0.02, 0.90]。
- **训练损失**: `net = 1e4·(wn·Y).sum() − **COST·Σ|wn − w|**`, `COST = 3.52`(= `turnover_cost_reaudit_2026_08_21` 的实测换手成本), L281 有断言锁死。
- 学出的 **α ≈ 0.093 四臂几乎相同**(FIX7 0.0946 / X7FULL 0.0929 / X6FULL 0.0933 / CONST42 0.0955), **且方向与换手排序相反**(CONST42 α 最高却换手最高)⇒ **α 不是可用的自由变量**, 它已经贴在区间下沿。
- `LPP`(信号级持久罚 `|u_t − u_{t−1}|`)代码在, 但被 `* 0.0` 关掉。

⇒ **路径 2 的纯粹形态 = 在训练期把路径的价格调高(COST 剂量), 让模型在训练时就为换手多付, 从而产出更平滑的持仓路径。** 评估侧不受影响: 回放用的是独立的 `COSTB_JSON` 成本桶, 训练 COST 只是一个正则化器。

**先例与边界**: `turnover_shaping_ema_revalidated`(换手整形 EMA 14/14 臂改善净额, 最优 α=0.3, **当前被 T1 关掉, 恢复需用户重裁**)是**仓位层事后整形**, 与本臂的**训练期成本**不同轴; `adaptive_turnover_family_closed` 是 **DNR**, 但那是**状态自适应**换手, 本臂是**固定剂量**, 亦不同轴。**本文不重开这两条。**
