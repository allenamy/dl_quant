# 有针对性的宽宇宙 DL(400 名)—— 五件套设计 + 门

## 0. 已证的边界(不再碰)
- 同一输入上模型类等价(树/king/深表格 ±0.002; 三方等价定理); 5m 原始序列上 DL 天花板 0.0465(冻结 SSL = 监督, 110 名); 宽书 B 梯队 LGBM82 > film2, 堆叠 0.0703 最强但"弹药 > 模型类"; 多种子集成/训后技巧/FiLM 择时/router 全判负; 排序类结论对简单口径不翻(RC)。
- ⇒ 新 DL 只能靠 **新信息 / 新归纳偏置 / 新目标**, 且必须过**预门**: 同输入 Ridge/LGBM82 ΔIC ≥ +0.005 方可进入 DL 臂(CLAUDE.md 决策检查清单)。

## 1. 针对性(四个"新", 每个单独可关)
1. **横截面归纳偏置**: 400 名整体进模型(cross-sectional attention over names; 相对位置/簇/离散度/领先滞后), 树只能靠面板里的 xsec 秩列近似 —— 在役 king 有 xattn(110), 宽书 king 无(LGBM)。
2. **多视界多任务**: 共享编码器, 头 = y4 与 y12 残差简单收益(残差存活峰在 y12; 目标跨度单峰已关但多任务辅助未测), 只用 y4 头出分。
3. **简单收益残差目标**: 交易所记账口径(不含 carry), 残差基准不变(FF: 地基没歪); 损失 Huber(α→0 已证), 不训幅度(IC 是 alpha)。
4. **新输入**: 5m 7 通道 × 5 窗原料 + 横截面状态 token(离散度、BTC 主导率变化、funding regime 水平作**条件**而非择时; FiLM 形态判负, 这里只作输入列)+ basis(F-2 过门后)。

## 2. 数据 / 特征 / 模型 / 损失 / 验证
- 数据: 宽 5m 缓存 829 名(jpline 2022+; pod /workspace 2020+ 与 1.6GB 特征矩阵; F-1 正在 jpline 重建 2020-21); 因果面板; 实盘相位 [N, N+4h]; 成员 400(K400)。
- 特征: 与 LGBM82 同一 82 列(预门基准)+ 原始 5m 序列(DL 专有)+ xsec 状态 token。
- 模型: 编码器(ModernTCN/1D conv)逐名 → 横截面 attention 层(对 400 名)→ 双头(y4/y12); 参数预算对齐 film2 K400; 单种子(无集成); cuDNN 校验(memory `feedback_verify_cudnn_not_just_cuda`)。
- 损失: Huber on 残差简单收益(秩目标备选只作敏感); λ_orth=0(惩罚削平视界峰); 无多种子。
- 验证: 五折走前(与 king 协议同), 固定锚集, 双口径 IC(avg per-asset Pearson + xsec rank-IC, clean/dense), 逐折同号, σŷ/σy ≥ 0.02, Q4 最坏五分位, 泄漏: shuffle-future null + 锚→面板行偏移谱峰@0; 三种子只作噪声标定(不出结论)。

## 3. 门(冻结)
- G0 预门: 同 82 输入下 Ridge/LGBM82 在 400 名简单口径的 IC 作基准; DL 臂必须 ΔIC ≥ +0.005(秩 IC, 固定锚, 逐折 ≥ 4/5 同号)。
- G1 正交增量: 对宽书 slow king(LGBM82)残差 ΔIC ≥ +0.003 逐年 ≥0(腿录取 S1 同式)。
- G2 书级: 作为增量腿(或替换 king)进宽书同管线(d30, 简单口径, 3.52)的 G 族净额; **去 fund 腿情景**同报(用户目标: 摆脱 funding 主导)。
- 任一门不过 ⇒ 关臂, 不调参续命; 每臂一个变量。
