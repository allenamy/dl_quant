**读法**:
1. **资金费省的钱两段几乎一样**(FX1: −218.0 vs −219.6; FX3: −440.8 vs −432.1)⇒ 臂的"设计目的"在两段都达到了, 且**幅度相同**。
2. **价格代价在 2026 段暴涨**: FX1 −129.0 → **−686.5**(**5.3 倍**); FX3 −322.5 → **−882.4**(2.7 倍)。
3. ⇒ **pre-2026 资金费那一面赢**(`g` 为正 +76.5 / +72.4), **2026 价格那一面压倒性地赢**(`g` −477 / −488)。

**即: 空着"极端负资金费"的名字在 2026 段的价格收益比 pre-2026 大得多, 所以剪掉它们在 2026 代价也大得多, 而省下的资金费不变。**

## 4. 必报项 1:FX3 与在役 L33–34 夹子的格级重叠 —— FX3 **没有**碰任何新的格

| 量 | 格数 |
|---|---|
| FX3 命中 | **19,531** |
| 在役 L33–34 夹子**可命中**(上界) | **61,702** |
| 两者都 | **19,531** |
| **只 FX3** | **0** |
| 只基线可命中 | 42,171 |

**FX3 的命中集 100% 落在在役夹子的可命中集内。** ⚠ 但这**是算术强制的, 不是实证发现**:
FX3 用面板费率 `rate ≤ −0.001`, 基线用 `rn8 = rate·8/iv ≤ −0.001`, 而 `iv ≤ 8` 且费率为负 ⇒ `|rn8| ≥ |rate|`
⇒ `rate ≤ −0.001` **必然**推出 `rn8 ≤ −0.001`。所以这一行读作"包含关系由归一化保证", 不是"数据碰巧如此"。

⇒ **FX3 的作用不是"夹更多名", 而是"对同一批名换一种夹法"**: 层不同(权重层 vs z 层)、gross 处理不同(恢复 vs 不恢复)。
**基线侧是上界**: `z<0` 这个条件在 `step()` 内部, 不落盘, 所以基线的**真实**命中集是这 61,702 的一个子集, 我观察不到。
