# 预注册:特征面板逐列对比 —— NC 到底有没有复现研究员的 King 输入

**所以本项不是缺口归因,是部署正确性。** 即使它对缺口没有解释力,结论照样要报。

## 1. 一处与 lead 措辞的偏离,先说明

lead 写的是「`POD_FILES_SHA256.tsv` 里的 **X78** 那项」。**清单里没有 X78 面板。**清单里的特征面板是 `dlw_fea82.npz` 与 `f8_fea89.npz`。

- `data/dlw_targets.npz` `ca479fcc…`
- `data/dlw_fea82.npz` `3b7fa211…`

⇒ **King 吃的是 X82,不是 X78。**本预注册按 King 的训练收据对 **X82** 做主对比,并顺带对 **X89**(`f8_fea89.npz`,研究员也交了)。

**NC 的 `NC_FEATURES.npz` 里确实有 `X78` 这个键**,但研究员**没有交付 X78 面板**,所以 X78 **无法对比**,列为具名不测,不拿 X82 的结论替它背书。

- 人口 = 两边都存在的 (锚, 符号) 对;
- 只在一边的对**单独计数上报**,不并入一致率;
- 符号轴先断言逐位相同,不同则判 UNAVAILABLE(按下标比会比到不同的名字)。

## 3. 逐列要报的量(先于数字定死)

对人口内的每一列 j:
1. **逐位相同的比例** = `mean(a[:, j] == b[:, j])`,NaN 位置按「两边都是 NaN 也算相同」处理,并**单独报**两边 NaN 模式不一致的格数;
2. **最大绝对差** `max|a−b|`(只在两边都有限的格上);
3. **中位相对差** `median(|a−b| / (|b| + eps))`,eps 明写;
4. **列名**(取自研究员的 `names`),以及 NC 侧该列的列名来源(NC 面板若不带列名,则声明「NC 侧按位置对齐,列名取自研究员」——这是一个**假设**,写明);
5. 汇总:**完全逐位相同的列数 / 总列数**,以及**不同的列名清单**。

## 4. 判读规则(冻结)

1. **不设门**。本项是正确性检查,产出是事实表,不产生录取/否决。
2. 若 **82 列全部逐位相同** ⇒ 结论:「在共同 (锚,符号) 人口上,NC 复现了研究员的 X82」。**不得**由此推出「NC 复现了研究员的 King」——训练配方仍可能不同,那是 C 项。
3. 若**有列不同** ⇒ 逐列具名上报,**先报 lead 再做任何解释**;不得先猜机制。
4. **行数差 136 本身就是一个发现**,必须报:它意味着两边的成员集不完全一致,而这**独立于**数值是否相同。
5. **NaN 不当 0**。NaN 模式不同要单独成列报,不许用 `np.nan_to_num` 抹平后比。
6. 相对差的分母为零的格**不丢弃**,单列计数(「分母无定义就删行 = 缺测按不存在」)。

## 5. 红控制(非空转)

- **基线格**:NC 的列与它自己比,逐位相同比例必须恰好 1.0;
- **变异格**:把一格加上 1.0,同一表达式必须报出恰好 1 格不同;
- 两格任一不过 ⇒ 判 **UNAVAILABLE**,不报数字。
