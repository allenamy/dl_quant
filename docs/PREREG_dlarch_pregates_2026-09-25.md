### 3.1 A4b 的 10 列(「该名相对它自己的历史」,严格因果)

对 10 个量 `q ∈ {ret5_sum_48, ret5_sum_288, ret5_sum_864, ret5_sum_2016, ret5_sum_8640, vol_48, vol_288, vol_864, vol_2016, vol_8640}`
的**原值列**,把长格式铺成稠密 `(锚, 名)` 矩阵,对每个名计算
`z_self = (q[i] − mean(q[i−540 … i−1])) / (sd(q[i−540 … i−1]) + 1e-12)`(540 个锚 ≈ 90 天,**严格不含当锚**),
有效历史锚数 `< 120` 则该格 NaN(再 `nan_to_num` 为 0,并单独计数)。
**因果断言**:窗口上界是 `i−1`,**不含 `i`**;装置逐列断言所用行索引的最大值 `≤ i−1`。

### 3.2 A1 的 6 列(组内对比)

组 = 锚内十分位:`Lq` = `log_qv_8640` 的锚内秩十分位,`Lv` = `vol_2016` 的锚内秩十分位。
6 列 = {`ret5_sum_288`, `ret5_sum_2016`, `ret5_sum_48`} 在 `Lq` 组内的秩 ×3,
{`ret5_sum_288`, `ret5_sum_2016`} 在 `Lv` 组内的秩 ×2,`vol_288` 在 `Lq` 组内的秩 ×1。
组内不足 8 个名 ⇒ 该格取 0 并计数。**只用当锚信息,无跨锚,无泄漏面。**

### 3.3 A2 的 6 列(形状,只用 X82 的原值列,不读 5m 缓存)

令 `r48, r288, r864, r2016, r8640` = `ret5_sum_*` 的原值(嵌套累积和),`v288, v2016` = `vol_*` 原值。
```
a1 = r48
a2 = (r288 − r48)/5
a3 = (r2016 − r288)/6
shape1 = a1 − a2                      加速度
shape2 = a1 − 2·a2 + a3               曲率
shape3 = r48 / (v288 + 1e-9)          归一化的最近一根
shape4 = (r864 − r288)/2 − a2         中段加速度
shape5 = (r8640 − r2016)/(4·6) − a3   长段加速度
shape6 = Σ 1[r_w > 0], w ∈ 五个窗      嵌套窗同号计数(持续性/单调性)
```
每列再取**锚内秩**。**`shape6` 是关键一列**:A–J 十族里没有它,且窗均值原则上表达不了「五个嵌套窗是否同号」。
⚠ **为什么不用 X89 的 J 族做形状**:X89 的 A–G、J 列**已经是锚内秩**(`f8_higher_order_features.py` L341–L347),
**符号信息已被抹掉** ⇒ 用它们拼不出「连续几根为正」这类形状。这一条本身是一个发现,写进结果件。

## 5. 判据(冻结,先于数字)

**门形照 F8 的族门**:对模型 `M ∈ {Ridge, LGBM}`,
```
ΔIC(臂, M) = IC(臂, M) − IC(BASE, M)    在三年合并上
门:两个模型都满足  ΔIC ≥ +0.003  且  逐年 ΔIC > 0 的年数 ≥ 2/3（3/3 并报）
```
**外加两条(本门特有)**
- **安慰剂条件**:`ΔIC(臂) > max(ΔIC(PL 三个种子))`,否则该臂标「与列数白送分不可区分」。
- **A4a 的门是反向的**(它**去掉**列):`ΔIC(A4a) ≥ −0.001` 且逐年 ≥ 2/3 不劣 ⇒ 判「原值列可去」。
  ⚠ 这条**不是** +0.003 的门:去掉 40 列若**不变差**就已经是收益(反模式 #29 的负税 + 复杂度预算)。

**判词四选一(每臂)**:`PASS` / `PASS_CONDITIONAL`(逐年 2/3)/ `INDISTINGUISHABLE_FROM_PLACEBO` / `FAIL`。
**任何 PASS 都不是录取。**

## 6. 承重断言与零控制

1. **BASE 的合理性核对**:`IC(BASE, LGBM)` 必须落在 **0.03 – 0.09**;F8 的 `LGBM(82+89)` 是 0.0697、`Ridge` 0.0679
   (不同折、不同宇宙、不同标签谱系 ⇒ **只作量级核对,不作门**)。落在区间外 ⇒ 装置有误,先查再出数。
2. **红能力对(先绿后红)**:把 `A1` 的 6 列换成**全零列**,断言 `ΔIC == 0`(到 1e-12)⇒ 加零列不改结果;
   再把它换成**标签本身的锚内秩**,断言 `ΔIC` 巨大为正 ⇒ 门有能力变绿。两个实测值都打印。
3. **泄漏(按设计文档 C4,不照抄置换 null 与偏移谱)**
   - ① **结构断言**:A4b 的窗口上界 `≤ i−1`(逐列断言);A1 / A2 只用当锚列;
   - ② **陈化测试**:把每个臂的新列整体**推迟 1 个锚(4h)与 6 个锚(24h)**,`ΔIC` 必须下降;
     **不降 ⇒ 该臂的新列被判为「不是当锚信息」并标红**;
   - ③ **列数配对安慰剂**(§3 的 PL);
   - ④ **折外泄出 = 0**:断言训练行的 `max(锚) + 4h ≤ 测试首锚 − 60·4h`(由 `fold_rows` 保证,再显式断言一次)。
   - ⚠ **置换 null 与偏移谱照报、不作门** —— F8 已实测它们对 82 列基线同样红(`|null| = +0.0111` 比 `+ALL` 的 `+0.0096` 还高;
     偏移谱峰在 k=−6 而非 0),在「表格模型 + 锚内秩特征」这一类装置上不分辨。
4. **非零格计数**:每个新列报窗内非零格数;为 0 ⇒ 标「该列无测量」,不得算成 0 贡献
   (受据 `rank_transform_turns_all_nan_into_all_zero_2026_09_23`)。
5. **人口闭合**:报每折的训练行数 / 测试行数 / 打分对数 / 被 `MIN_NAMES` 跳过的锚数,**收支相抵**。
6. **计算量声明**:若为了时间对锚**下采样**,必须在收据里写下采样规则与实际锚数,并**对 BASE 与所有臂用同一个下采样**。
   **下采样不得改变判据。** 默认**不下采样**;只有实测单臂单折 LGBM > 12 分钟才启用 `每 2 个锚取 1`,并具名。
