# PREREG · 崩跌起始后的锚内延续: 多头极端名在第一根大跌 bar 之后还跌多少(A3 锚内退出的价值上界)

## 0. 问题(为什么这是最后一个定向角度)
- 事前(锚点时刻)分不出「会崩」与「会涨」(Phase 1 S-b FAIL)。剩下的定向问题是**事后但快于下一锚**: 一个队列多头名在锚内出现第一根大跌 bar(崩跌起始)之后, 接下来 1h / 3h / 到下一锚的收益是延续(负, 可提前退出)还是反转(正, 退出反而错)。W4 在 4h 粒度说延续; 本文在 5m 粒度、只对多头极端名队列、以事件研究回答, 并给出**锚内退出**的价值上界(不含执行成本以外的任何模型)。
- 反假设(必须可见): 起始 bar 之后均值回归 ⇒ 退出把已实现的亏损锁死并放弃反弹; 或延续为真但幅度 < 往返成本 7.84 bps + 滑点 ⇒ 无价值。

## 1. 事件与量(锁死; 5m 缓存 829 名 2022-01→2026-08; 队列 = Phase 1 的 C(t) 在锚 t 的多头名)
- **起始事件 O**: 队列名在锚 t 之后的锚内窗 (E, E+4h] 内, 5m 累计收益自锚起首次 ≤ −θ, θ ∈ {−5%, −8%, −12%}; 事件时刻 = 该 bar 收盘 τ; 每名每锚至多一次; 记 τ 距锚分钟数。
- **前向量**(从 τ 收盘起, 因果): r(τ→τ+1h), r(τ→τ+3h), r(τ→下一锚), r(τ→τ+12h); 含 τ 后第一根 bar 与不含的两口径(执行延迟 5 分钟)。
- **安慰剂**: 同名同锚内随机时刻(非事件锚)、同幅度**上涨**起始(镜像)、以及全宇宙非队列名的同幅度下跌起始。
- **分档**: 按 τ 距锚(前 1h / 1–3h / 后 1h)、按 rn8/cap 贴顶与否、按 3 日涨幅(≥ +20% vs 否)、按上市天数(≤90 / >90)、按年。
- **价值上界**: 对每个事件, 锚内退出(τ+5min 以 maker 出场, 成本 7.84 bps 往返计一半 3.92 + 逆向 markout 5 bps)vs 持有到下一锚的差 = −r(τ+5m→下一锚) − 8.9 bps; 按名义 = 该名在书里的权重 × gross 汇总为 bps/锚/gross(2024→26), 与 Phase 1 队列基率同装置。

## 2. 读数(冻结)
- **延续为真**: θ=−8% 事件的 r(τ+5m→下一锚) 均值 ≤ −40 bps 且 CI95 上界 < 0(UTC 日块 bootstrap 2000, 种子 20260905), 三年折(2024/2025/2026)中 ≥ 2 年成立且 2026 成立; 安慰剂(随机时刻、镜像上涨、非队列下跌)均值绝对值 < 15 bps 或符号相反。
- **有价值**: 延续为真 **且** 价值上界 ≥ +0.05 bps/锚/gross(2024→26, CI 下界 > 0)**且** 事件数 ≥ 1/锚(否则太稀不值得执行器改动)。
- **判负**: r(τ+5m→下一锚) CI95 下界 > −15 bps(无延续或幅度不够)或安慰剂同量级。其余 UNDECIDED。
- 部署含义(先写): 有价值 ⇒ A3 锚内延续退出进候选预注册(执行器锚内规则, 需 safe_commit + 电池 + 前向影子 + 用户字; 观察器把该出场视为授权行为); 判负 ⇒ 定向尾部族全部收口(事前 Phase 1 + 事后本文), 回吐控制 = 杠杆, 写入 DNR; UNDECIDED ⇒ 报用户。
