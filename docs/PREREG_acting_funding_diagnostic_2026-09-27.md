# 单一诊断：资金费当前状态相对三日 EMA 的恢复，是否预示空头进一步损失

本诊断继承已冻结研究仓 3b4a2815ad4b8d45ee09ed8b69222e04b5885301。只读 pod2 已有 L2N_data_s42/s2027.npz；不训练、不回测、不写服务器。人口严格继承 L2N：已发布 NC 持有目标为空头、资金费席位>0、ZFD<0、W24H 可交易。结果不用于部署或重开已 FAIL 的 S1。

冻结谓词：若“实时费率已恢复而三天 EMA 仍滞后”的横截面状态是稳定的额外风险标志，则同锚人口内 G=rank(RN8)-rank(FZ) 越大，下一不重叠 4h 的上涨越强；在控制 EMA 排名、King 排名与过去三日收益排名后，此关系仍为正。RN8/FZ 的排名均在该锚本人口内取平均秩，除以 n。G 是状态差代理，不是已证实的尖峰事件。

主统计：逐锚 n>=20，FWL 控制矩阵 [1,rank(FZ),rank(KZ),rank(R3D)]，同时残差化 G 与 rA；报告 partial Pearson。另把 rA 先转秩再残差化，报告 partial Spearman。每锚等权，先按 UTC 日平均，再按日等权；pre-2026=2023–2025、2026=01-01..08-30 两段独立报告，逐年附表。只有两人口、两段的两种相关均正且30日循环块 bootstrap 2000 次（seed 20260927）95%下界>0、每年同号，才称“稳定风险标志支持”；否则称“未建立”，若任一段上界<0则明确说方向被反驳。两个人口不当成两个独立市场样本。

控制：输入 SHA 对齐 build 收据；E/i/n 映射与标签 shifted SA 的 h=0逐元素一致；同锚至少20名；所有解释变量都是既有装置 <=t 的值。固定随机数的打乱残差并投影为正交噪声，构造 corr=0.015 正控与 corr=0 负控：各段主 Pearson 的正控下界必须>0、负控区间含0。这是装置分辨力而非真实信号功效保证，不能以构造恒等式证明现实因果。打印 MDE≈(1.96+0.84)*bootstrap_SE，让不能排除的效应量可见。
