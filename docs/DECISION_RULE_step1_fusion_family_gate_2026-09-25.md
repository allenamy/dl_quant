# 决策规则:第 1 步融合层(组合层)候选臂的「模型抽样族」判据

## 0. 为什么要按族判

rn8 夹子一题(fresh `543999b04` / `a4ad232ea`)实测:同一个确定性组合层改动,在两个 F10 种子上结论相反(判据窗 +1.18 / −3.70,2025 年两种子相差 12 bps/日),而同一轮的资金费节省两种子差 0.001。⇒ 组合层改动的书层效应**随模型抽样变化的幅度**远大于改动本身的机械效应的测量误差。只用两个种子判,等于用一台没有功效的仪器。

## 1. 族

- **成员(n = 10)**:在役 NC 的 F10 s42、s2027,加 dlarch T0 的 8 个 F10 种子(42/2027/7/11/23/101/3/5,23 折,`038e8e78f` 修订 1)。King 固定为在役 NC King。
- **具名限定**:族只覆盖 **F10 抽样**,不覆盖 King 抽样(King 扰动 σ_pre = 1.04 bps/日另有实测,`4b8723720`);T0 成员是掩码 `WL` 重训的 F10,与在役 F10 不完全相同,各成员对在役 F10 的逐年秩相关由 dlarch 读数装置必报。
- 成员按 sha 引用,不按目录名。缺任何成员 ⇒ 在该臂上 n 相应减少并具名;**n < 8 不出判词**(报 NO_VERDICT)。

## 2. 被测量

- `d_m = dbar(臂, 成员 m) − dbar(基准, 成员 m)`,基准 = 同一成员上的在役组合原书(G0 类逐位控制通过后);冻结 `news_stats.py` `dbar`,引擎 base 格,32 路径。
- 窗:**全窗合并**(2023H2 → 引擎末日)为主;pre-2026(2023H2–2025)与 2026 两段单报。

## 3. 判据(每臂独立;臂间不相加)

记 `n`、`mean(d)`、`sd(d)`、`SE = sd(d)/√n`。

- **RECOMMEND_TO_USER** 当且仅当全部满足:
  1. `mean(d) ≥ max(0.5, 3·SE)`(bps/日,全窗);
  2. **≥ 80% 的成员 d > 0**(n = 10 时 ≥ 8);
  3. pre-2026 与 2026 两段的族均值**都 ≥ 0**;
  4. 全窗最大回撤(固定 2× 逐锚复利 NAV)族均值**不比基准差 3 个百分点以上**;
  5. 在役成员 NC s42 上的 d **单列报告**(不作门,但若 < 0 须在判词旁写明「对在役模型本身为负」)。
- **REJECT**:`mean(d) ≤ 0`,或 ≤ 40% 的成员 d > 0。
- **UNDECIDED**:其余。两段反号写「判据窗与实盘窗方向相反」。
- 0.5 bps/日的绝对下限:任何组合层改动都有实现与验证成本,低于它不值得改在役书。
- 多重性:本轮 ≤ 6 个臂,每臂 3·SE 门(n=10 时约等于单侧 t 0.99 以上),不再另做校正;臂数若增加须先修订本文。
