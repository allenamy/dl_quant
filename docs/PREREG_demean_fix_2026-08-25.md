## §1 缺陷与改动(唯一变量)
`~/wide_shadow/shadow_loop_v3.py:442` 与 `fea171/sidecar_blend.py` chain() 中:
```python
w = np.where(sel, z, 0.0); w -= w[sel].mean()     # mu 减到全部 400 个成员上
```
非 sel(流动性不合格)名各得 `-mu`, 形成**等权多头篮**并承载书的**全部净额**。改为:
```python
w = np.where(sel, z, 0.0); w[sel] -= w[sel].mean()   # 只在 sel 内去均值; 非 sel 保持 0
```
后续 L1 归一在 sel 名上重新分配 ⇒ **毛额仍为 1.0**, 只是从 107 个不合格名转移到 293 个合格名。
