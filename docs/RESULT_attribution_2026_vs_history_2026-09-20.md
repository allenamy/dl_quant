## §3 块 A · 逐腿(A1 / A2 / A2b 三条路径与对账)

### 3.1 预注册的 A2 在数值上退化, 用不了 —— 这是本文的一条方法结论

预注册 §2-A 的 A2 写法是「每名的盈亏按 (1−φ)·king 权重 与 φ·F10 权重 的**份额**拆」, 即 s_i = a_i/(a_i+b_i)。实测:

- 持仓名-锚格里 \|s\| 的分位: 中位 0.933, p90 1.000, **p99 4.26, p99.9 41.9, 最大 1.66e6**; **12.4% 的格 s 落在 [0,1] 之外**。
- 后果: A2_king 在 2024 是 **+83.31**, 在 2025 是 **−78.37**(A1 分别是 +0.629 / +0.794)。逐段拆开看, **A2 与 A1 的全部差额都来自 \|s\| > 3 的名字**(2024: 差 +82.68, 其中 +82.34; 2025: 差 −79.17, 其中 −79.23)。

机理不是数值噪声而是概念问题: 当两条腿在一个名字上**方向相反、幅度相近**(a_i ≈ −b_i ⇒ m_i ≈ 0)时, 「这个名字的盈亏属于哪条腿」本身没有良定义; 份额写法把这种名字的权重放大成任意大的数, 再乘上整形(FTRIM / EMA / 带)带来的微小权重差, 就把整形噪声放大进了腿层读数。

**因此本文的腿层结论一律用 A1 / A2b**(同样在冻结配置里, 同样先于运行写定): A2b = A1 两项 + **具名的整形残差**, 三项逐锚精确相加等于纸面价格(残差 ≤ 2.8e-14)。A2 照报, 并按预注册的「差 > 5% 具名」规则标出: **除 2022H2(只有 king)与 2026JA 外, 每一个时段的 A1 与 A2 都差超过 5%** —— 这条规则在 A2 退化的前提下只是把退化重复陈述了一遍。
