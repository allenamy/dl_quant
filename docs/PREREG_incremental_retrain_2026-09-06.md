# PREREG · 增量重训: DL 热启动微调两臂 + king 增量两臂(LightGBM 叶值 refit / 续训); 预训练-微调路线分期

## 0. 机制(为什么值得测; VERIFIED 来源标注)
- §11 事实: 每月重训的 DL 模型之间一致性 0.54 ≈ 两个随机种子 0.53 ⇒ 每月换模型 = 换一次初始化; 固定种子把一致性抬到 0.80 但只收回缺口 1/3; 早停常选到近初始化模型。**热启动**(月 t 的模型从月 t−1 的最优权重出发)是"固定初始化"的更强形式: 不仅同种子, 还继承已训好的解, 与"新数据微调"同义; 它同时改变早停 regime(起点已是训好的模型, 验证曲线从高处出发)。
- king(LGBM): K1(月度全史重训, 禁运 60 锚 = 在役形态)与 K2/K3 全 UNDECIDED, 逐月模型本身也是重新生长的树。LightGBM 有两种"增量": **叶值 refit**(树结构不变, 用新窗口数据重估叶值, `Booster.refit(data, label, decay_rate=0.9)`)与 **续训**(`init_model` 上再长 n 棵树)。前者 = 结构稳定 + 数值更新, 后者 = 模型变大。
- 预训练-微调在本问题的含义: 标签不稀缺(每锚 × 每名都有标签), 信息在特征里(R² < 1%), 模型很小(MLP 256 隐层)⇒ 自监督预训练(掩码特征重建/对比)的先验低; 有先验的是两件事: **初始化稳定**(§11 已证明重要)与 **近期加权**(全史预训练 + 近期窗口微调)。因此分期: 先测 W(热启动)与 K(增量), 再决定 P1(近期微调), P2(自监督)只在 P1 有信号后立项。
- 席位上限提醒: 模型侧改动对书的杠杆 ≤ 席位(king ≈0.31, F10 ≈ φ 0.45 × 模型席位); 任何 W/K 臂的书层效应量级预期 ≤ 0.2 bps/锚/gross。
