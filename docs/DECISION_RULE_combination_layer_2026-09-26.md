# 判据:组合层 / 权重分配族(第一族:A1 cap050、A2 look1800、A3 orth;A4 描述、R 红控、O 上限控制)

作者 lead,对任何一臂的去留无利害。设计里 alloc 已披露自己对形状 R-A 有倾向;下面的选择按机理给出理由,不以该倾向为依据。

## 1. 被测量与 SE
- d_k,段 = dbar(臂, 种子 k) − dbar(同种子在役 NC 参照格),单位 bps/日,口径为冻结的 `news_stats.dbar`(v4 RAW 引擎 NAV,gm 2.0,32 路径均值,UTC 全日)。
- 段:pre-2026(915 天)、2026(截至 09-18T20Z,261 天);冻结的截断版并排报。
- **SE_段 = max( MBB30_SE(三种子平均后的逐日 d 序列), sd_k(d_k,段)/√3 )**,MBB 沿用冻结约定(B=10,000,rng (20260923,1),30 日块,`bt_tables.mbb_indices`)。**不使用** DL 门的 σ_ref 下限:组合层臂在固定 F10 下是确定性变换,不确定性主要来自时序(设计 §3.4-2)。
- 全窗 = 两段日序列拼接(1,176 天),SE 同式。

## 2. 顺序(每一步都是下一步的前置门;任何一步红即停,并报 lead)
0. **装置门**:设计 §5.4 的全部控制必须 PASS。
   - 恒等:combo 在 s42、s2027 两个种子上逐位相同;引擎 32/32 路径逐位相同。
   - 接线:非在役臂不得与在役逐位相同。
   - 因果探针:逐规则都要跑。
   - 红控 R(fundflip,s42):预期两段 D̄ < 0,且 MBB 95% 上界 < 0。**R 不满足 ⇒ 装置无分辨力,全族停止。**
1. **上限控制 O(先知席位,s42 单格)**:只用来决定席位臂跑不跑,**永不录取**。
   - 若 O 在 pre-2026 与 2026 两段都满足 `(O − NC) < MDE₈₀,段`(MDE₈₀ = 3.84·SE_段,SE 取 O 自己的配对序列),则席位臂 A1、A2 按构造分辨不了 ⇒ **不跑**,只跑 A3 与 A4。
   - 否则 A1、A2、A3、A4 都跑。
   - O 的数字一律并排报,作为用户问题「这条通道是否卡在局部最优」的上限答案。
2. **行为足迹**(零收益,只到 combo 层):照设计 §5.0-3 报。任何一臂若在 > 5% 的锚上触发 gross 门(0.4–1.2)而在役没有触发 ⇒ 该臂判「不可部署」,只作描述,不进门。
3. **引擎格**:每臂 × {42, 2027, 7},与同种子 NC 参照格配对。

## 3. 录取判据(候选 m = 3:A1、A2、A3;A4 预先声明不可录取)
**收益轨**(A1、A2、A3 均适用):
1. **主判**:全窗 D̄ ≥ 3·SE_全窗,且 3 个种子中至少 2 个的全窗 d_k > 0。
2. **两段都不得变差**:pre-2026 的 D̄ ≥ 0,且 2026 的 D̄ ≥ 0。第二个条件保留用户 09-25 对 DL 程序「当前行情为主」裁定的精神:一条改进若在 2026 为负,不推荐。
3. **回撤护栏**:两段各自的 maxDD 路径均值(按种子平均)都不得比 NC 差 3 个百分点以上。

**非劣轨**(只对 A3,因为它主张的是可诊断性而非收益):
- 两段都满足 `D̄_段 ≥ −max(0.5, 3.5·SE_段)`;
- 机制控制:2026 段 F10 书与 King 书的权重相关中位 **≤ 0.80**(在役为 0.944);
- 回撤护栏同上。
- 通过时判词只能写「可诊断性改进且不劣」,不能写「改进」。
- 它的用途是给 DL 程序恢复书层分辨力,不是作为独立的收益主张。

**判词**:PASS ⇒ `RECOMMEND_TO_USER`,附限定「F10 未按新席位或新结构重训」。部署前必须先做全管线确认(F10 按新席位 / 新效用重训,GPU)。确认必须在同一判据下通过,且方向相同;不同向 ⇒ 撤回推荐。

**其它结果**:
- 主判不过但点估计为正 ⇒ UNDECIDED。
- 任何一段 D̄ < 0,且其 MBB 95% 上界 < 0 ⇒ REJECT。
