## 1. ⚠ 开跑前必须写明的一处风险:F10 的逐位可复现性**未经测试**

红控制要求 `random_state=0` 这一次**逐位复现在案 `dbar`**。这要求整条链逐位可复现,而链里有一段是 **GPU 上的 torch 训练(F10 s42)**。

- **King 的种子与环境不变性已测过**(lead 确认;我的重拟合基线也实测 P 与在案 `KING_OOF.npz` 逐位相同 frac=1.0)。
- **F10 的逐位可复现性从未测过。** GPU 训练在未显式设定确定性标志时,常常不是逐位可复现的。

⇒ **`random_state=0` 这一次同时是「红控制」和「F10 确定性探针」。** 它失败有两种完全不同的原因:
1. 管线确实不确定(实验无法进行);
2. 仅 F10 的 GPU 训练不逐位可复现,而扰动实验本身仍可在「非逐位」口径下进行。

**本预注册的处置(先写死,不等看到数字)**:
- 若 `random_state=0` 的 `dbar` 与在案**逐位相同** ⇒ 继续跑其余 7 次。
- 若**不逐位相同** ⇒ **停下,报告,不自动重试,不放宽门**(lead 明令)。同时**报出不一致的幅度**(`dbar` 差值、F10 OOF 的逐位相同比例、King P 是否仍逐位相同),**供 lead 裁定是否修订门**。给出幅度**不是**放宽门——门仍然判失败;只是把裁定所需的事实一并交出。
- **不得**因为差值很小就自行继续。

## 3. ⚠ K=8 的统计限制(结论措辞必须随之保守)

SD 估计的相对标准误 ≈ 1/√(2(K−1)) = **1/√14 ≈ 26.7%**。

⇒ **8 个样本估出来的 SD,本身可能偏离真值约四分之一。**因此:
- 所有 z 值必须**同时报出 SD 的相对标准误 26.7%**,并写明 **z 的不确定度与之同阶**;
- **禁止**基于 z 报任何 p 值或「显著/不显著」;
- 判读只允许用下面 §4 的三档措辞,**不得细分**。

## 4. 判读规则(冻结)

1. **|z| < 1.5** ⇒ 「**该缺口与一次模型扰动不可区分**」。不得说研究员的方案更好。
2. **|z| > 3** ⇒ 「**扰动噪声解释不了该缺口**」,需另找机制。
3. **1.5 ≤ |z| ≤ 3** ⇒ 「**在这台仪器上分辨不出**」,不挑一边。
4. 三档的措辞都必须附 §3 的 26.7% 限定句。
5. **K=8 次是同一种扰动(`random_state`)的 8 个样本**,只刻画这一种扰动;行扰动/特征扰动的离散度**未测,不得外推**。
