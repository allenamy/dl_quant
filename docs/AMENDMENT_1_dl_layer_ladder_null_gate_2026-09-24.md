## 3. 新门的精确操作化(先于数字)

对每一个「(分段 × 受测量)」格,受测量 = 原 §3 的 L1 五条 IC(king / f10_s42 / f10_s2027 / fund_z / rev24_z)
与 L2 五条腿(king / rev24 / fund / f10_s42 / f10_s2027),分段 = `2023H2 / 2024 / 2025 / pre2026`:

1. 对 `b = 0 … 199`:用**独立的、可复现的** RNG 流,把每个锚的标签**在该锚成员内**打乱,重算该格的量,
   得到第 b 次置换的**窗口均值** `m_b`。
2. `mean_null = mean_b(m_b)`;`se_null = std_b(m_b, ddof=1) / sqrt(200)`。
3. **判词(lead 的门)**:该格通过 ⟺ `|mean_null| ≤ 3 · se_null`。
4. 全部格通过 ⟺ `NULL_GATE PASS`;否则 `NULL_GATE FAIL` 并逐格点名。

**RNG 契约(必须可复现)**:`np.random.default_rng([20260924, b])`,每个 `b` 一条独立流;
同一条流在整个窗口的所有锚上顺序消耗。RNG 规则写进收据。
**注意**:`b` 之间的 `m_b` 因此是独立同分布的,`se_null` 是对 `mean_null` 的**正确**标准误 —— 这是新门
与原门的关键差别:原门把**单次**置换的均值当成「零」去比一个与它自身噪声无关的常数。

## 4. 承重断言(先红后绿,不放宽)

- **N1′-a 分布非退化**:每格必须报 `std_b(m_b)`;若某格 `std_b = 0`,该格标 **NO_MEASUREMENT**(置换没接上),
  **不得**算成通过。(受据 `validator_can_pass_vacuously_family_2026_09_18` 第五变种:
  「模式旗标从未接上」⇒ 必须断言置换真的发生了。)
- **N1′-b 置换真的发生了**:每格额外报「200 次里,`m_b` 与**未置换**真值相等(到 1e-12)的次数」,
  必须为 **0**;若 > 0,说明打乱在该格是空操作。
- **N1′-c 红能力对**:对 **king / pre2026** 这一格做一次变异 —— 把置换改成**恒等置换**(不打乱),
  断言该格 `|mean_null|` 变成真值 `+1.6250` 并**远超** `3·se_null` ⇒ 门变红。
  基线格与变异格的**实测值都要打印**(受据 `red_capability_check_is_vacuous_when_baseline_is_red`)。
- **N1′-d 人口与恒等式分离**:锚数、非零格数**单独报,不作门**
  (受据 `brittle_check_welds_identity_to_population_expectation_2026_09_20`)。
