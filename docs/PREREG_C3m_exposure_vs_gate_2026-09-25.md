# 预注册 C3m:把「削敞口」与「松门」分开 —— C3 为什么让书变差

## 0. 为什么需要它

C3 实测(`d7e097b16`): **被移除的敞口本身在亏钱**(合计 −752.8 / −736.5 bps, q0 亏最多), **而书却变差**
(`Δg` −503.4 / −1272.7, pre-2026)。⇒ 损害**不来自**放弃利润。C3 同时做了三件事:
① 削掉负费率空头敞口; ② 少付资金费(实测 −344.4 / −270.3 bps); ③ **让预检门少咬**(`gross<0.4` 19.9%→12.9%, 发布 +575 锚)。
**`Δg` 一个数把三件事混在一起, 所以「C3 为什么让书变差」在 C3 自己的读数里无法回答。**

## 1. 臂的定义(可后处理表达, 与 B4/B5 同一论证)

**`C3m` = C3 的权重, 但发布决策冻结为基准的。**

```
trade_mask_C3m = trade_mask_base                      # 逐位取基准的
weights_C3m    = C3_weights  where trade_mask_base    # 基准发布的锚上用 C3 的权重
                 0           otherwise                # 基准没发布的锚一律不发布
```

可后处理表达的依据与 B4/B5 相同: `continuous_combo.evolve` L36–42 **无条件**写 `kc`/`fc`/`raw`, 只有
`trade_mask`/`weights` 取决于 `accepted`。所以「换一套发布决策」是对已产出字段的后处理, 与改 kernel 逐位等价。

⇒ **C3m 只做 ①②(削敞口 + 少付资金费), 不做 ③(门的咬合保持基准水平)。**

## 2. ⚠ 分解是**顺序的**, 不是加性的 —— 这一条必须先写

引擎是**路径依赖**的(仓位从上一锚带入), 所以

```
d(C3) ≠ d(C3m) + d(纯发布效应)
```

**不成立**。能定义的只有**给定顺序的**分解:

```
d(C3m)            = 削敞口的效应,            在基准发布决策下
d(C3) − d(C3m)    = 松门的效应, **给定敞口已被削**   ← 顺序依赖
```

**换成另一个顺序**(先松门、再削敞口)会得到**不同的拆分**, 因为两者有交互。所以:
- 结果件必须写明**用的是哪个顺序**, 并明写「另一顺序会给出不同数字, 本文没测」;
- **不得**把这两个数说成「C3 效应的两个组成部分」;
- 在案的同族反例: 三信号留一之和比总量大 68%–249%(`three_signals_are_substitutes…`)。

## 3. 控制(任一不过则停)

1. **发布决策逐位等于基准**: `trade_mask_C3m == trade_mask_base` **逐位**, 否则本臂定义没实现。
2. **已发布锚上的权重逐位等于 C3**: 在 `trade_mask_base` 为真的锚上, `weights_C3m == weights_C3` **逐位**。
3. **状态链不变**: `kc`/`fc`/`E_ts`/`symbols` 与 C3 逐位相同(本臂只改 `trade_mask`/`weights`)。
4. **非空**: C3m 必须**同时**与 C3 和基准都有逐锚差异 —— 与 C3 差在发布集(应恰为 C3 多发的那 575 锚),
   与基准差在权重。两个差都必须 > 0, 否则本臂退化成其中一方。
