# 可行性:代币解锁 / 归属释放作为事件源(零收益)

**利害披露**:这条线是我在 `SYNTHESIS_nonfunding_2026-09-27.md` §2 里唯一给「中偏低」先验的一族,我对它能否立项有利害。本文只报事实与算术。

## 0. 结论

- **数据可以免费拿到**:DefiLlama 的公开数据集 `emissionsIndex`(22 MB JSON,无需 key)含 370 个协议的完整解锁时间表,从 TGE 起。其中 359 个有事件,194 个能按代号映射到在役宇宙的币安永续。
- **在 NC LIVE 宇宙内、2023–2026 年的样本量**:内部人 / 私募 cliff 解锁,按「(永续, 时刻)」去重:
  - 全部:141 / 365 / 766 / 357 起;
  - 规模 ≥ 1% maxSupply 的:41 / 44 / 123 / 130 起,每年 12 / 15 / 27 / 35 个名。
- **三处硬限制**:
  - (a) **时点**是「今天的时间表」,不是当时公布的时间表:存在修订与补录,事前可知性无法逐事件核验;
  - (b) **幸存者**:只有 DefiLlama 仍在跟踪的协议;
  - (c) **时刻精度**混杂:17% 的事件落在 00:00Z,可能只有日精度。
- **先验不变,仍是「中偏低」**。行业研究(Keyrock,16,000 余起解锁)称「几乎总是负面」,但影响在解锁前约 30 天就开始。这对应的是一个**慢漂移状态量**,不是 4h 冲击;而慢漂移正是现有基线(动量、资金费秩)最可能已经吸收的信息(见综述 §1b)。
- **若要继续**:下一步仍是零收益,即时点核验、映射守卫、事件聚簇的有效样本;之后由 lead 写判据。本文不建议直接开读数。

## 3. 样本算术

若沿用 S2 的形状(事件间块自举;pre-2026 |t| ≥ 3;2026 同号):
- ≥ 1% 的事件在 pre-2026(2023–2025)有 208 起。24h 超额的 σ 取 6–10%,iid 时 SE ≈ 0.4–0.7%。
- 聚簇的设计效应粗估 1.5–2 倍(只有 12–27 个名,月度释放)⇒ SE ≈ 0.6–1.4% ⇒ **可分辨约 2–4% 的 24h 平均超额**。
- 行业研究说「影响在解锁前约 30 天开始」:
  - 如果多数效应在 t0 之前就已经释放,那么以解锁时刻为 t0 的事件研究,看到的可能只剩一小部分;
  - 如果改成「距解锁天数」这种截面状态量,就变成 S1 型门,需要低相关、全集 IC 约 0.02。可覆盖面只有每年 12–35 个名(≥ 1%),占 LIVE 名数的约 6–10%,O2 稀释很重 ⇒ **截面用法几乎不可能过门**。
- ⇒ 可行的用法只剩两种:
  - (i) 事件研究,作为「多头风险闸」:书若在解锁前持有该名的多头;
  - (ii) 足迹先行:先数出书在这些事件名上有多少仓位。这是零收益的,S2 设计 §0-3 的规则可以照搬。
