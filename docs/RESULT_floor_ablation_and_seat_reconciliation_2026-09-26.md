- **死区不是驱动**: D 只动 0.017。这一臂是冲着「死区每锚握 67% 活跃格 ⇒ 它必然造成相关」去的, 结论是**不成立**。

## 2. 三处自我更正(全部保留原句在各自文档里)

### 2.1 「chain 在 2026 吞掉独立性」—— 已撤回(01:5xZ)
原句在 `DECISION_RULE_dl_program_book_gate_2026-09-25.md` 修订 6 的结构性发现里: 「z 层共享项只能解释约 0.33, 其余来自 chain」。**错因**: 用**全轴**席位均值 [0.589, 0.411] 代替**段内**值。段内实测: pre-2026 [King 0.646, 资金费 0.354], 2026 **[King 0.315, 资金费 0.685]**; 结构下限 `w2²/(w0²+w2²)` 因此是 pre-2026 **0.231**、2026 **0.825**, 不是 0.33。

### 2.2 「chain 的额外贡献 +0.134 / +0.118」—— 本文撤回(新)
2.1 的更正里我写了「chain 的额外贡献在两段几乎相同(+0.134 / +0.118)」。那两个数是 `实测 − 公式` 算出来的, **前提是可相加**。臂 C 证伪了这个前提:
- 可相加的话, `w[2]=0` ⇒ 公式项 0 ⇒ 预测 0 + 0.118 = **+0.118**; 实测 **−0.043**, 差 **0.16**;
- 臂 B 同样落空: 公式 0.231 + 0.118 = **0.349**(这正是我**写在探针之前**的预测「约 0.35」), 实测 **0.489**, 差 **+0.14**。

**两臂朝相反方向落空** ⇒ chain 的贡献**依赖席位配比**, 不是一个可加的常数项。⇒ 「+0.134 / +0.118」作废; §1 只报**单条件替换的位移**, 不报份额。同族: [[three_signals_are_substitutes_not_a_decomposition]](留一不可相加)。

### 2.3 我写在探针之前的预测被证伪, 照报
「2026 席位换成 pre-2026 均值后, null 地板应降到约 0.35」⇒ 实测 **0.489**。**预测落空 +0.14**。这不是舍入: 它等于总跨度的 24%。**残差具名**: 席位换回去之后仍高出 pre-2026 实测 0.355 约 **0.134**, 这一截**不由席位解释**, 目前无归因。

## 4. ★ 研究席位 vs 实盘席位: 重叠窗内 101/101 锚**无一相同**

- 实盘真相源 = **追加式** `~/regime_dash/regime_dash.jsonl`(144 锚, 2026-09-02T08:00Z .. 09-26T04:00Z)。滚动的 `REGIME_DASH.md` 每锚整份重写, 不可作收据(DEV-14)。
- **字段语义先验证再使用**: `w3_masked_king` 我没按名字取。CLAUDE.md 记着 2026-09-13T12:00Z 为 king 0.3821 / fund 0.6179 ⇒ 55/45 拆分后 21% / 17%。该锚实测 `w3_masked_king = 0.3821`, ×0.55/×0.45 = **0.210 / 0.172** ⇒ 与记录的 21%/17% 对上 ⇒ 该字段是**合并后的模型席位**, 与研究侧 `w0` 同量。(先复现一个已知数, 再读新数。)
- **窗必须对齐**: 研究轴止于 09-19, 实盘记录始于 09-02 ⇒ **唯一可比窗 = 2026-09-02T08:00Z .. 09-19T00:00Z**。按原样(研究"2026 年"对实盘"9 月")比较的话, 两边窗**根本不重叠**, 那是两个人口戴一个标签。

**读法(严格限定)**:
1. **不是少数异常锚, 是普遍现象**: 0 个锚相同, 100/101 差超过 0.01;
2. **不是常数偏置**: 标准差 0.0385 > 均值 0.0160, 且**符号翻转**(09-02 实盘低 0.065, 09-06 实盘高 0.069);
3. **书层量级**: F10 的有效权重 = 0.45×w0 ⇒ 席位差 0.016 ≈ F10 权重差 **0.0072**, 相对 F10 自身权重(≈0.14)约 **5%**; 标准差折成 F10 权重是 0.017, **比均值差大一倍**;
4. **归因未定, 本装置判不了**: 研究侧读的是 news2 修正后输入建的 `legs.npz`, 实盘那几锚用的是当时的生产者 ⇒ **席位不同很可能正是「修数据」的预期效果, 而不是缺陷**。分开这两者需要**同输入**对照, 那正是 news2 手上的 King↔rev24 拆分定位。本文只给量, 不给因。

**射程(承重)**: 凡是依赖 2026 席位配比的研究读数——包括 §1 的地板、msharpe 席位构成、以及任何「≈62% funding + 21% king + 17% V2MAIN」式的构成引用——都是在一条**与实盘在每一个锚上都不相同**的席位序列上算的。这不推翻那些读数, 但它是引用它们时必须同时说出的限定。
