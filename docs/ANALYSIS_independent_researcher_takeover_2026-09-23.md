## §4 实盘亏损的机制诊断(我的新证据)

**直接原因:书的有效 beta 为负。**

| 量 | 值 | 来源 |
|---|---|---|
| 书日收益对 BTC 日收益 beta | **−0.354** | 实盘 daily_nav × 锚时刻 BTC 中间价,32 个相邻日对,08-03→09-23 |
| 相关系数 | **−0.469** | 同上 |
| BTC 单日 >+2% 的日子(n=4) | 书平均 **−1.39%/天** | 同上 |
| 其余日子(n=28) | 书平均 **+0.01%/天** | 同上 |
| 回撤窗 09-16→09-22 | BTC **+13.40%**,书 NAV **−5.95%** | 实盘锚中间价;研究员账本 |
| 同窗空头桶价格/成交 | **−26,156 USDT**,多头桶 +19,744 | 研究员 RESULT_recent_drawdown |
| 研究员连续诊断分环境 | 两种子只在 **UP_HIGHVOL** 亏(−13.7 / −13.1 bps/日);DOWN_HIGHVOL +56.6 / +56.8 | TABLES_complete_combo |

⚠ 限定:NAV 日点取 daily_nav 末行、BTC 取当日首锚,时点不完全对齐;32 个日对样本小。**方向与量级**与三个独立来源一致,可信;精确 beta 值不可引作常数。

**这不是 bug,是结构性暴露**:资金费动量腿做空的是资金费高、被追捧的山寨币,它们对 BTC 的 beta 高于多头腿。**在 BTC 强势上涨时,空头被挤。** 这也解释了在册的"回吐归因"与"九月同锚回放也亏、同一批空头名"。

**为什么不能直接"去掉 beta"**:研究员的 β 投影(改名字权重使 Σwβ=0)让四组长期 Sharpe 全降。可能原因:① 负 beta 有报酬(山寨币长期跑输 BTC 本身就是溢价的一部分);② 投影改变了名字权重,扭曲了 alpha。**这两个原因可以分开测**:不动 alpha 书,只加一条 BTC 永续对冲腿(预注册 Stage 2 的 M2)。
