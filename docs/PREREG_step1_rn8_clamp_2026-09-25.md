## 0. 被测对象(逐字)

`combo_target.py` L33–34,在 `step()` 内、算完 `zkc`/`zfc` 之后:

```python
zkc=np.where((zkc<0)&np.isfinite(rn8)&(rn8<=-.001),0.,zkc)
zfc=np.where((zfc<0)&np.isfinite(rn8)&(rn8<=-.001),0.,zfc)
```

**它做什么:** 对某个名字,若复合分数为**负**(要做空)**且** 8h 归一化资金费率 `rn8 ≤ −0.001`,就把分数**置零**——
即**拒绝去空那些「空头要付资金费」的名字**。

**机制(两面,方向相反):**
- **去掉夹子 ⇒ 价格通道拿回 alpha。** dlarch 实测夹子吃掉夹前 alpha 的 **19%–24%**(King / F10 两链)。
- **去掉夹子 ⇒ 资金费通道多付钱。** 这部分**在 y4s 口径里根本看不到**(收益标签不含资金费),
  所以**净值目前没有受据答案**——这正是本题存在的理由。

## 4. 主读数:引擎 `g`,拆通道 —— **四个通道,不是三个**

lead 指定拆 price / funding_paid / fee。**引擎实际暴露四个**(`bt_tables.py` L66–67):

| 键 | 含义 |
|---|---|
| `pnl` | `price_trade`,价格通道 |
| `car` | **`−funding`**(注意符号:`car` 为正 = 收到资金费) |
| `cst` | `fee` |
| **`unk`** | `unk_excluded × (unk_price + unk_funding)`,未知仓位通道 |

`g = 1e4 · r / gm`。**必报闭合恒等式:`g ≈ pnl + car + cst + unk`,逐锚断言,容差写进收据。**
**不得为了凑「三个通道」把 `unk` 丢掉** —— 那会让分解不闭合,且属于「把未测量当良性数值」那一族。
若 `unk` 在这两格恒为 0,**照报 0 并说明它是实测为 0,不是被省略**。
