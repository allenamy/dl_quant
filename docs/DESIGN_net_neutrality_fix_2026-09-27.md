# 设计:修复 chain 后段对 Σw = 0 的破坏(在役书结构性偏空)

**利害披露**:这个题目是我在 `SYNTHESIS_nonfunding_2026-09-27.md` §3c(ii) 里提议的,我对它能否立项、采用哪种修法都有利害。**本文只列机制、候选修法、终点与样本算术;所有阈值与判据由 lead 在任何读数之前写定。**

## 0. 事实(已在册,零收益)

- 在役 NC 书落盘的 `weights`,**在 100% 的已发布锚上多空毛额都不相等**,空头侧系统性偏高。
- 偏斜 (short − long) / gross,依次为 2023 / 2024 / 2025 / 2026:
  - s42:+0.0075 / +0.0072 / +0.0073 / **+0.0445**;
  - s2027:+0.0038 / +0.0174 / +0.0091 / **+0.0440**。
  - 2026 年约 90% 的锚偏空(记忆 `book_short_gross_tilt_is_structural_2026_09_25`)。
- **量级**:gross = 2.0 × NAV 时,偏斜 4.4% 相当于净空约 **0.088 × NAV**。书的空头多为高 beta 山寨,所以这等于一个对山寨指数的净空敞口。
- 这不是有意设计的「方向赌注」:chain 第一步明确做了集合内去均值,见 §1。

## 1. 机制:chain 里哪几步打破了 Σw = 0

依据生产 `combo_stage.py::chain`(sha fb5a9407,pod2 副本)的逐行阅读:

| 步 | 代码 | 对 Σw 的影响 |
|---|---|---|
| ① 去均值 | `w = w − mean(w[sel])`(sel 集合内) | **建立** Σw = 0 |
| ② 按毛额归一 | `w /= Σ\|w\|` | 保持 |
| ③ **单名上限** | `w = clip(w, ±cap_mult / n_sel)`,再按毛额归一 | **可能打破**:截面分布不对称时,两侧被截掉的量不同;归一只调尺度,不调中心 |
| ④ **EMA** | `smv = H + 0.1·(tgt − H)` | 不产生新偏斜,但**把过去的偏斜带进来**:Σsmv = 0.9·ΣH + 0.1·Σtgt,半衰约 6.6 锚 |
| ⑤ **交易带** | `\|smv − H\| < 2.5e-4` 的名保持 H | **可能打破**:被带住的名不参与本锚的再平衡 |
| ⑥ **强制出场** | 不在 keep 集合(LIVE ∧ 成员 ∧ 流动性)的名置 0 | **可能打破**:出场名原来的符号就是净额的变化量 |

- 在册记忆只点了 ④⑤⑥;逐行阅读后,③ 的上限截断也是候选源头。
- **2026 年突然放大 6 倍**的机理尚未拆分。可能的原因:
  - 2026 年资金费席位更高(w_f 中位 0.68;`T7NC_ZERO_A.json`),资金费秩分布的尾部不对称,使 ③ 的截断不对称;
  - 2026 年 LIVE 宇宙扩到每锚约 361 名,出入更频繁,⑥ 的贡献更大。
- 这两条都是**待验证的假说**,见 §3 步 0。

## 2. 候选修法与各自的书行为影响

每个候选都在 chain 末尾(⑥ 之后)或局部改动。改动对象都是生产 chain,属于**书行为改动**:须预注册、用户字、部署协议。

| 代号 | 修法 | 修的是哪一步 | 书行为影响(预期,待零收益测量) |
|---|---|---|---|
| F0 | 不改(对照) | — | — |
| F1a | ⑥ 之后**加法去均值**:在持仓非零的名上减去 mean(smv) | ③–⑥ 全部 | 每个持仓名都有一个小平移;可能让很小的持仓变号;换手略增 |
| F1b | ⑥ 之后**按侧缩放,偏重的一侧缩到与轻侧相等** | ③–⑥ 全部 | 侧内秩不变;毛额下降约 \|skew\|(2026 年约 4%);杠杆略降 |
| F1c | ⑥ 之后**按侧缩放,轻侧放大到与重侧相等** | ③–⑥ 全部 | 侧内秩不变;毛额上升约 \|skew\|;须与 gross 上限及交易所保证金核对 |
| F2 | ③ 之后**重新去均值**,迭代「截断 ↔ 去均值」直到收敛 | 只修 ③ | 只修源头之一;④⑤⑥ 的偏斜仍在;改动最小 |
| F3 | 在 M3 BTC-beta 覆盖层上**加一个等权山寨腿**(beta 中性,而不是美元中性) | 不改 chain,改覆盖层 | 这是另一种解法:承认 alpha 书不中性,在覆盖层上对冲;与 M3 的交互须单独设计 |

**要预先写明的交互**:
- **M3**:M3 BTC-beta 覆盖层已由用户采纳,生效状态以 STATE 为准。F1 系列改变的是 alpha 书的美元净额,会改变 M3 测到的 beta。所以每个候选都要在 **M3 开 / 关两种状态**下各评一次。
- **漂移依赖**(记忆 `live_book_is_short_btc_beta_2026_09_23` 的 How to apply):去掉净空山寨敞口,在山寨上涨段会改善,下跌段会变差。**均值上的差异本质上是在赌山寨漂移**。判据必须把「对冲腿的漂移收益」与「方差下降」分开;只靠漂移得来的收益判 DRIFT-DEPENDENT,不作为采纳理由。

## 4. 样本算术(近似,标明假设)

- **E1、E2** 是确定性的,每个已发布锚都可算,没有抽样误差。
- **E3**:日 beta 的 SE ≈ σ_resid / (σ_mkt · √n)。
  - 假设 σ_book 约 1.5% / 日,等权山寨 σ_mkt 约 4% / 日;2025–2026 约 600 天 ⇒ SE(β) ≈ 1.5 / (4 · √600) ≈ **0.015**。
  - 修法的预期效应:净空约 0.088 NAV × 山寨 beta 约 1.2 ⇒ Δβ ≈ **+0.1**,约为 SE 的 7 倍,**可分辨**。
  - 若只看 2026 年,约 250 天,SE ≈ 0.024,仍可分辨。
  - σ 的取值是假设,须在步 1 里用实测替换。
- **E4**:配对的方差比。F0 与候选的日收益相关系数预计 > 0.99,差序列的 σ 约为 0.088 × 4% ≈ **0.35% / 日**,远小于书的 σ。比值的 CI 很窄,几周到几个月的数据就能分辨方差的变化。
- **E6**:差序列 σ 约 0.35% / 日时,600 天的 SE(Δmean) ≈ **1.4 bps / 日**。这足以判「不劣」,但均值差异本身主要反映山寨在样本期的漂移(§2),不宜作为主判。
- **对比**:以书层均值为主判时,pre-2026 的功效不足(在役书自身的 t 只有 1.6–1.9);这里的 E1–E5 都不依赖这一点。
