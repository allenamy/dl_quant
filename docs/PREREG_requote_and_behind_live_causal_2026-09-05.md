## 2. 口径(冻结)
- **参考价** = `mid_at_anchor`(书的纸面价, 与全部执行成本文档同一参考)。单笔成交成本 c = side × (fill_px − mid_anchor)/mid_anchor × 1e4 (bps, 正 = 比纸面付得多); 费 = fee_paid/|notional| × 1e4。
- **计划级全包成本(意向处理, ITT)**: 一个计划 = (锚, 名) 的 maker 意向; 其全部成交(maker 首挂 + 重挂 + 全部补单)的 Σ|notional|×(c + 费) ÷ |intended_notional|, 单位 bps/单位意向名义。补单按政策补满残差, 故意向名义≈实现名义(尘量除外); 未实现部分按 0 计并单列其占比。
- **markout60** = side × (mid_at_fill_plus_60s − fill_px)/fill_px × 1e4 (正 = 成交后价格朝有利方向; 负 = 逆向选择), 成交额加权, 只对有标记的成交计, 覆盖率单列。
- **重挂问题的总体**: attempt-1 被 −5022 拒的计划。前期(无重挂)08-02..08-05, 后期(有重挂)08-06..09-05。效应 = 后期被拒计划 ITT 成本 − 前期被拒计划 ITT 成本, **双重差分**减去同锚未被拒计划的成本变化(去 regime)。分支分解(后期): 重挂落单且成交 / 重挂落单未成交→from_partial / 二次拒→from_reject, 各报 ITT 成本与占比; 用真实分支成本重算 08-05 的盈亏平衡 p* 与实测 p。
- **behind 问题的总体**: 08-12..09-05 bandit 期内 attempt-1 maker 计划, placement_arm ∈ {join, behind}(逐单确定性随机, 锚内可比)。指标: (a) 计划级 ITT 成本差(behind − join), 锚内配对(逐锚按名义加权的臂均值之差, 再按锚名义加权汇总); (b) maker 腿成交比例(含重挂); (c) 首次 −5022 率; (d) 成交价 vs 参考(条件于成交); (e) markout60(全覆盖)差; (f) 补单占比。
- **区间**: UTC 日块 bootstrap 2000 次, 种子 20260905; 报 CI95。单位换算(bps→USDT/日)由脚本打印: 被拒计划日均意向名义 × 效应。
- 子窗: 重挂另报 08-06..08-21 与 08-26..09-05; behind 另报 08-26..09-05。

## 3. 判读(冻结, 先于数字)
- **重挂有帮助** ⇔ 双重差分效应 < 0 且 CI95 不含 0, 且分支分解自洽(落单成交占比 ≥ 用真实分支成本重算的 p*)。**有害** ⇔ 效应 > 0 且 CI95 不含 0。其余 **UNDECIDED**: 一个从未被判决、两次被纸面否决的机制在实盘上零期望 ⇒ 建议撤回到 08-06 前路径(属书行为改动, 需预注册 + 用户字), 本文只给读数。
