# 判据:D10 阶段 2(资金费真值规则、平价门、T+1 对账、十月重建)

作者 lead,对任何实现的去留无利害。设计 §6 列出的五项裁定逐条答复如下。

## 1. 线 A:真值规则
- **事件与费率**:以 P2 `ledger_full.npz` 为真值源,9 月用月度归档发布后补(十月 runbook §8b)。依据:全账本 263 万行里 src=4(API 与 zip 冲突)为 0;2026-08 独立双源逐位相同(news2 `67b43fbe3`)。
- **间隔(设计 §6 第 5 项:3h 等非标准间距怎么记)**:**按实际结算间距记,用小时的精确值,不吸附到网格**。理由:资金费按实际经过的时间累计,而过渡行上归档的列是前瞻的(写的是新制度)。四个实测例都在尖峰退出处,用列会把 RN8 低估 2–4 倍。边界处理:
  - 一个名的第一笔事件,或与上一笔相隔超过 24h:用交易所声明的间隔;
  - 实际间距超出 [1, 8] 小时:截到边界,并逐事件具名计数。
  - 这是**建模约定**,在役 NC 的 `snap_interval`(吸附、平局取大)与它不同。按用户裁定,训练与实盘必须同一规则,所以十月重建时生产者一并改用本规则,走部署协议。
- **常量只写一处**:允许的间隔集合只在 `common/funding_interval.py` 里定义,其它地方一律 import;找不到就抛错,不许回落到本地副本。
