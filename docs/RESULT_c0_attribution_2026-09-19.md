### 1.2 复现门(已跑, PASS; 这是全书合计, 不是分组数字)

`c0_repro.py`(d48053c1)在**两种子的每一个记录锚**(不是抽样; ts ≤ UB 共 10,038 锚)上用 W × y4 / W × 资金费重算 pnl_ex、carry_ex、cost_ex, 并重算 fund 腿两个序列。门在装置 docstring 里先于首跑写定:

| 门 | 定义 | A0 s42 | A0 s2027 |
|---|---|---|---|
| R1 pnl_ex | \|Δ\| ≤ 1e-6 · max(\|ref\|, Σ\|smr·y\|·1e4) | 0 / 10,038 失败; \|Δ\| 最大 7.4e-6 bps; 尺度相对最大 1.7e-8 | 0 失败; 2.1e-8 |
| (报告, 非门)普通相对误差 \|Δ\|/\|ref\| | ≤ 1e-6 的锚占比; \|ref\| ≥ 0.1 bps 上的 p99 / 最大 | 98.9%; 7.0e-7 / 3.5e-6 | 98.9%; 7.2e-7 / 9.9e-6 |
| R2 carry_ex | 同上(尺度 = Σ\|smr·f·4/iv\|) | 0 失败; 尺度相对 3.5e-8; 普通相对 ≤ 1e-6 占 99.6% | 0 失败; 3.6e-8; 99.7% |
| R3 cost_ex | 同上(尺度 = Σ(\|smr\|+\|smr_prev\|)·费率) | 0 失败; 6.1e-9 | 0 失败; 6.1e-9 |

| R6 `legs_fund`(席位输入, 已存) | 同上 | **0.0** | **0.0** |

**为什么门用 max(|ref|, 尺度) 而不是只用 |ref|**: W 以 float32 存储(每个权重相对精度 2⁻²⁴ ≈ 6e-8), Σ w·y 可达的绝对精度约 6e-8 × Σ|w·y|; 当全书合计相互抵消到接近 0 时, 普通相对误差没有意义。普通相对误差照报: 98.9% 的锚 ≤ 1e-6, 其余是抵消锚, 最大 9.9e-6。**任务书要求的「1e-6 相对」在尺度相对意义下全部满足, 在普通相对意义下 98.9% 满足**, 差的部分由 float32 存储决定, 不是公式差异(fund 腿两序列在 float64 输入上逐位为 0.0 即是公式同一的证明)。

同一次运行测得: **书在成员集外的 gross 占比** 2025–26 平均 A0 s42 10.5% / s2027 10.2%(2025 上半年 12–13%, 2026 年 8.4–9.8%; 2026-08: 9.6% / 9.5%)—— 这部分在装置里不产生盈亏(1.1 的 OUT)。

### 1.6 读法约束(先于数字)

- 分组数字是**描述**: 一个名字同时属于七个特征的某一格, 格与格之间不独立, 不作检验、不给 CI、不作「该格应被剔除 / 加权」的结论。
- 「H1 的超额由哪些格承载」按净贡献(可加)读; 「8 月哪些格失败」按 8 月 − H1 的**价格 / gross**(该格资金的收益变化)与净贡献变化**同时**读, 以区分「仓位变了」与「收益率变了」。
- 集中度只回答「少数名字 vs 普遍」, 不回答「这些名字是否可事前识别」。
- 本文所有数字来自研究书(见 1.1), 与实盘现金没有对账关系。
