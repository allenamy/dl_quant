# BTC 对冲的价值拆分:押方向,还是结构性择时?

## 0. 问题(用户 09-23 13:3xZ)

用户的条件:若未来 regime 会让对冲获益(像 2023–25)就考虑采纳,否则不考虑。

"未来像哪一段"在这里几乎等于"BTC 未来涨还是跌"。我们没有可信的方向预测能力(书层按事前信号缩仓三次独立测试全负,见 `rebound_conditional_deleveraging_loses_at_4h`)。

所以先回答一个**不需要预测方向**的问题:对冲的历史收益里,有多少来自"平均 β × BTC 平均涨跌"(押方向),有多少来自"β 与随后 BTC 涨跌的协同"(择时)。择时部分若稳定为正,说明书的负 β 恰在 BTC 要涨之前加深,对冲在任何方向的行情里都有结构性价值。

## 1. 定义(零自由参数)

- **对冲仓位** `h_t`:
  - 取 M3b 执行路径收据的逐锚 `-beta_exec_c`,即执行书事前 β 的相反数,单位 = sizing gross;两底座 OLD / NEW_s42。
  - 在 4h 网格上把已发布锚的 `h` 向后填充到下一个已发布锚:HOLD 锚持仓不动,对冲腿也不动。
  - 窗口外不填。
- **BTC 收益** `r_t`:认证原始价格表(`price_full_raw_x0918r`,sha 23af32bd)上 BTCUSDT 在 (t, t+4h] 的简单收益 `expm1(对数收益)`。
  - 用 `m2_lib.bars_4h` 同一构造。
  - 无效 bar 剔除并计数,不填 0。
- **对冲毛收益** `g_t = h_t · r_t`(gross 单位;×2 = NAV 单位,在役 2× 杠杆)。**不含**资金费与手续费(M3b 实测约 0.2 bps/日)、不复利、不含执行与止损交互 —— 这是目标层的近似,只用于拆分。
- **拆分**(按段,N 为段内有效锚数):
  - `Σg = N·mean(h)·mean(r)`(**方向项**)+ `Σ(h−h̄)(r−r̄)`(**择时项**),恒等式,残差须 < 1e-12。
- **段**:2023H2、2024、2025、2026-01-01 → 2026-08-31、延伸 2026-08-31 → 09-18(只描述)。
- **报告**:
  - 各段 Σg(NAV %)、方向项、择时项、mean(h)、BTC 段收益。
  - 全窗择时项的 30 日块自举 95% 区间(B = 10,000,rng 20260923)。
  - `corr(h_t, BTC 前 7 日 / 前 30 日收益)`,判断负 β 是否在上涨后加深。
  - 序列最后一锚的 h。

## 2. 读法(冻结)

- **(S) 结构性**:两个底座都满足"全窗择时项 > 0,且四段中至少 3 段择时项 ≥ 0"。
  ⇒ 对冲价值有不依赖方向判断的成分;采纳不需要押未来 regime。
- **(D) 押方向**:两个底座在四段中至少 3 段满足 |方向项| > |择时项|,且方向项与 Σg 同号。
  ⇒ 对冲收益基本是 BTC 方向的函数;采纳与否等于"要不要保留一个做空 BTC beta 的方向押注",应按书的授权(市场中性)决定,而不是按 regime 预测决定。
- 两者都不满足 ⇒ **(M) 混合**,如实报告。
- 本分析不改 M3b 判词,不构成新的上线判据;它回答"对冲的价值依不依赖预测未来"。
