## 追记 · 第五轮复审后的更正(2026-09-19, lead; 上文原字节保留, 冲突处以本节为准)

复审 `REVIEW_round5_stage1_codex_2026-09-19.md` §6 对十项裁定逐项给了意见。接受以下更正:

- **#2 重建锚全部追单 —— 理由更正, 实施时点后移。** 原理由「这些锚本就不进分析, 主估计量不受影响」**不成立**: 重建锚上的成交会改变下一锚的持仓、冷却、换手和之后进入分析人口的名字, 存在跨锚影响路径(复审 §6-2)。更正后的最佳建议: 策略本身(重建锚全部追单)仍采纳, 但**在 CFG-04(10-01 16Z 或 100 个可配对锚)与 CFG-06(≈10-14)两个实验都到停止点之前不部署**, 这样两个实验的整个运行期都在同一政策下。执行器克隆里的实现与测试照常完成(不部署); 部署时记录政策生效时点与执行器版本。代价: 实验期内重建锚仍有约一半名字不追单, 重建慢一锚(09-13 12Z 一例未成交毛额 6,979 USDT) —— 这是机会成本, 不是已实现亏损; 且两次缺陷触发的整书平仓的根因已修, 重建锚本来就少。
- **#3 十月链现形态不建 —— 补上替代路线。** 复审接受暂停, 但要求给出能按月执行、能产出部署候选的替代闭环, 不能长期悬空。路线见 `docs/RESPONSE_review_round5_2026-09-19.md` §4(数据延长 → 合法成员 → 两腿折外 / 重拟合 → 在役参照前向打分 → 认证判官配对 → 导出与发布排练 → 用户字)。它依赖本轮的三项修复(模拟器 v3、原始价格、认证生产路径), 在它们通过前不启动正式月度链。
- **#4 FP2-8 不换装** 维持; 删去「流 R 同量级点估计」作为关闭理由 —— 原来的 G1′ UNDECIDED 本身就是不换装的理由, 流 R 的数字不增加证据(复审 §6-4)。
- **#6 融合后逐名帽** 维持排入生产者维护批; 验收时**同时**核最终目标与执行后持仓两层都不越帽(复审 §6-6), 不以越帽量级小为长期忽略理由。
- **#8 cron 只读补查** 维持; 新读者一律用统一的成交去重与完整人口(复审 §6-8)。
- **#10 不改 −4% 日止损** 维持; 删去「流 R: 历史上小幅负贡献且不降最大回撤」作为依据 —— 该数字建立在有因果缺陷的 v2 模拟器上(R5-01 / R5-02)。「保持不动」不等于当前阈值已经最优。

实施顺序更正: 需改实盘代码的三项里, **#5(看门狗划转盲区)先做**; #2 等两个实验停止点之后; #8 为只读 cron, 不触碰执行器, 可随时。
