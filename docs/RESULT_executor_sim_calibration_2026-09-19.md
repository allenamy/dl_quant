## 6. V1 之后发现的结构缺陷与 v2 修正(不是调参)

- **怎么发现的**: 分析 (b)−(a) 时 (b) 的 book gross / 定规模 gross 从 0.985 滑到 0.948(实盘 0.99–1.00, (a) 0.985–1.00)。逐名拆: 09-15 00Z (b) 的缺口 16.3k 里 **11.3k 来自冷却名**(ESPORTS、STAR、TAC、LAB、BEAT、XAN、VELVET 各持 1–3 USDT 尘仓)。
- **机理**: 期望值成交让每次退出剩 12% 左右, 几次之后落到地板以下, `plan` 按最小名义跳过, 尘仓永远留着; 冷却 / 撤名的名因持有非零仓位**不被 POP**, 进入 reshape 分到正常权重, 再被 CLAMP 的 add_blocked 钉回尘仓 —— 该名的目标 gross 就此从书里消失。v1 (b) 最多 148 个尘仓、被钉掉的目标 gross 达定规模 gross 的 ~5%; (a) 也有(09-05 16Z 9.0k / 171k), 只是被 4 次整书平仓周期性清掉。实盘里退出的真实分布是「整笔成交或原封不动」, 剩尾巴的情形很少(实盘 add_blocked 后期 0–1 名)。
- **v2 修正**: 执行器目标恰为 0 的名, 若本锚执行后**期望剩余**低于其地板, 按 maker 首腿价格与费率一并平掉(期望值表示里那部分概率质量代表「整笔尚未退出、下一锚会整笔再退」, 不代表一条永远平不掉的细丝)。标定参数一个未动; v1 装置原样存档。
- **v2 效果**: (b) book / 定规模 gross 回到 0.98–1.00; (a) 0.997–1.000(实盘 0.991–0.999)。**V1 回归(v2)**: 手续费 0.9754、换手 0.9648、资金费 1.0264、价格差 +105.53(CI95 [−107.34, +108.87])—— 4/4 PASS, 相关 0.988, Σgross 比 1.007。
- **读法**: 记录判词不变(v1 PASS); v2 回归通过只说明修正没有破坏重叠段的对账, **不能**当作对 v2 的独立验收(看过 V1 之后改的装置)。流 R 做长期回放必须用 v2: 没有整书平仓的月份里 v1 的尘仓会一直累积。
