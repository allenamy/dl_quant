```
key                                   (symbol, trade_id)
n_trade_ids_used_by_multiple_symbols        0     ← 实测, 不是假设
notional_total                    2,501,946.29
```

> **⇒ 本次的数字不受该缺陷影响(0 次碰撞), 但契约现在是对的。**
