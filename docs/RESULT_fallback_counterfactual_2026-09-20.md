## §0 白话结论(先读这一节)

**1. 回退形态确实是亏损的载体, 这一条站住了。** 在 1,323 个「预检失败 ⇒ 生产改写三腿 king 文件」的锚上(2023-06-30 → 2025-12-31), 在役行为 F0 的 g 是 **−1.2438 bps/锚**, 日夏普 **−2.038**。四个反事实臂在这批锚上**全部**优于 F0, 而且 32/32 条成交路径方向一致。

**2. 但「照写 combo 就能把 +0.418 bps/锚 拿回来」是错的 —— 朴素反事实被否决。** FINDING §4 的朴素填充假设那些锚的 combo 书能挣到全窗 combo 桶的 **+0.490**。实测: **F1 在这批锚上的 g 是 −0.0750**, 不是 +0.490。真实的全窗提升是 F1−F0 = **+0.2795 bps/锚**(HIST), 比朴素数字 +0.418 小三分之一。**lead 在 §5 写下的预期「F1 会低于 +0.490」在点估计上成立**; 但它的 CI95 是 [−1.513, +1.231], **不排除** +0.490 —— 所以只能说「点估计远低于」, **不能说「显著低于」**, 我按这个措辞报。

**3. 去掉 rev24 只解释了一半, 「F4 ≈ F1 ⇒ 问题是 rev24」这个单因解释被否决。** 在回退锚上, 相对 F0 的配对提升是 F1 **+1.1688**、F4a **+0.5445**。也就是说, 把 rev24 从回退书里拿掉, 只回收了 F0→F1 缺口的 **约 47%**; 剩下一半来自**形态本身**(单成分 king 书 vs 55/45 的 combo 复合)。预注册 §2 说「若 F4 ≈ F1 则问题是 rev24; 若 F4 ≈ F0 则问题是回退形态」—— 实测两头都不是, 它落在中间, 所以**两个变量都真, 谁也不能被单独归因**。
> 这 47% 大概率还是**上界**: F4a 用的 kc 分量额外带着 FTRIM(受据方向有利), 见 §1 的具名混淆。干净的单变量消融 F4b 跑完后**自废了**(§8.1), 它的副产物是一条独立的、关于 rev24 的强陈述: **席位把 100% 权重给 rev24 的锚有 172/10,039(1.7%)**(2023 有 83 个, 2024 有 21 个), 在那些锚上「去掉 rev24 的 king 书」根本不是一本书 —— **rev24 不是搭便车的腿, 按席位自己的规则它有时就是整本书。**

**4. 更刺眼的一条: 在那些锚上「什么都不做」比「去掉 rev24 重新交易」还好。** F2(预检失败就不下新目标、沿用上一锚)在回退锚上相对 F0 是 **+0.7631**, 高于 F4a 的 +0.5445。也就是说, 在书自己都判定「这本书不该交易」的那些时刻, **持有不动的收益高于重新构造一本去了 rev24 的 king 书**。

**5. 上面这套排序在实盘风控读数下不成立, 这是本次最重要的一条 —— 而且它还随「从哪个起点算累计」整体翻转。** 预注册 §3 要求同时报三种读数。**读数 P / P2** = 实盘看门狗 §4-4: 从**基准锚**起累计收益 −25% ⇒ 取消挂单 + 整书平仓 + 账户转只减仓, **只能人工恢复**(不模拟恢复)。两个基准必须一起看:

| 臂 | 基准 = FULL_RECIPE 起点 2023-06-30 | | 基准 = run 窗起点 2022-06-30 | |
|---|---|---|---|---|
| | 触发路径 | P 窗末(均值) | 触发路径 | P 窗末(均值) |
| F0 | **32 / 32** | −0.2527 | **32 / 32** | −0.2527 |
| F1 | **32 / 32** | −0.2519 | **0 / 32** | **+3.0995** |
| F4a | **32 / 32** | −0.2514 | **0 / 32** | **+2.5397** |
| F2 | **10 / 32** | +1.2889(中位 +1.8832) | **0 / 32** | **+2.6908** |

**以 FULL_RECIPE 起点算**: 主读数上最好的 F1 与在役的 F0 **没有任何区别** —— 都 32/32 打穿并永久停机, 只是日期不同(F0 2024-03 → F4a 2024-06 → F1 2024-07)。唯一有路径存活的是 F2, 而 F2 恰恰是配对表里唯一被判 (C) 不可判的那一臂。
**以 run 窗起点算**: 只有 F0 被打穿(2023-01, 2022H2 热身段的亏损把它送过门), 另外三臂**一条路径都没触发**。

**两个基准给出相反的排序, 所以只报一个都不诚实。** 能同时成立的只有一句: **只看主读数说「F1 更好」是不完整的**, 因为在其中一个基准下 F1 与 F0 的终局完全一样。读数 P2(日止损扣住 + H 后恢复)同向, 并且 **H 越短 F2 越差**(H=12h 时它的中位数也被打穿到 −0.2501)⇒ F2 的优势**依赖恢复规则**。详见 §6。

**6. 预注册 §4 的风险列: lead 的 5.3× 放大是对的, 但它没有变成单名集中度。** F1 在回退锚上的放大倍数 `gross_mult / gross_in` 中位 **5.303**(gross_in 中位 0.3772, 与 FINDING 的 0.377 一致), F0 是 3.348。但两本书都在放大之前做 L1 归一化, 所以**放大倍数不等于仓位集中**: F1 的单名最大权重 p95 只有 F0 的 **1.10 倍**(阈值 1.5), 有效名数 211 vs 224。**预注册 §4 的集中度门在任何一格都没有越界。** F2 的代价在另一处: 它最长 **130 个锚 = 21.7 天**不再平衡(全窗最长 1,110 锚 = 185 天, 但那一段整段落在 PARTIAL_RECIPE 窗内)。

**7. 裁定层面本文做了什么、没做什么。** 窗口是**回顾级 R**, 预注册写死「**只能否决, 不能晋级**」。因此本文**不含任何「有效」判词, 不提出换装, 也不建议改预检**。它做到的是四件事: 否决了朴素反事实 +0.418; 否决了「问题只是 rev24」的单因解释; 否决了字面的 F4b 这条臂本身(它自废, §8.1); 并给后续任何改回退行为的候选加了一条硬门 —— **必须同时报 §4-4 读数的两个基准**, 因为主读数上的排序在其中一个基准下整个消失。

### F3 不可实现(不是「没来得及」, 是这条通道做不到)

预注册 §2 把所有臂限制在**目标文件通道**里。一份零目标走不了这条通道:

* 生产执行器 `exec_tree_409ea16/live/external_book.py` L317 `weights must be a non-empty object {symbol: weight}`、L342 `gross_norm={gn} must be > 0 and finite` ⇒ 零目标被**拒收**, 执行器随即走它自己的 `on_unavailable = hold`。
* 认证判官同形: `bt_hist_sim31.target_doc` L198 `if not weights: return None` ⇒ `write_target` L317 记 `empty_target`, 不写文件 ⇒ HOLD。

**所以「写一份全零目标」在生产语义下逐位等于 F2, 不是「平掉」。** 要让 F3 真的是「平掉」, 需要一个 flatten **事件**; 而规则模式下 `exec_sim` 里唯一的 flatten 来源是 `on_eval` L487 的 §4-2 日亏 −4% 规则(它还会 HALT 到次日 00Z)。加第二个 flatten 来源 = 改认证模拟器, 预注册 §3 明文禁止(「不另建判官」)。**这一条在出任何数字之前就上报给了 lead, 处置待裁定**: (a) 撤掉 F3 并记录原因; (b) 承认 F3 ≡ F2 并用一臂两标签; (c) 授权一次具名的判官扩展(需要它自己的电池)。**我没有替裁定做选择, 也没有偷偷把 F3 改成别的东西。**

### F4a 的具名混淆(必须先读, 否则会把它读成干净的 rev24 消融)

F4a 用的是存档里的 **kc 分量**(`P3.vec.npz` 的 `kc_idx/kc_val`)。它确实是一本「去了 rev24、自己走完整链条、自己有 EMA 态」的 king 书 —— `combo_stage_replay_3520d363.py` L232-234 `w3m = [w3[0], 0.0, w3[2]]` 归一化后 `z_kc = w3m[0]·king + w3m[2]·fund`, 而 `chain` 对输入的正数缩放不变(去均值 → 除 Σ|w| → 在归一化之后才 cap → 再归一化), 所以 w3m 的重归一化是空操作。**但 kc 还带着 FTRIM**(L241-249: 8h 归一化费率 ≤ −0.0010 的负 z 名在去均值前置零), 而 king 文件没有。所以 **F0 vs F4a 同时改了两件事: 去掉 rev24, 加上 FTRIM**。FTRIM 已受据的方向是**有利的**(+0.21~+0.23 bps/锚), 所以 F4a 很可能**高估**了「单去 rev24」的好处 —— 也就是说 §0 第 3 条里「rev24 只解释 47%」大概率还是**上界**。干净的单变量消融是 F4b(§8)。

### 8.1 F4b 跑完了, 而且它**自己把自己废掉了** —— 两个装置分别判 REFUSED
