# 设计 · 多头极端名的崩跌风险: 定向条件尾部模型(特征构造 + 尾部目标)与非常规调整层

## 0. 承认与盘点(为什么此前的尾部工作是浅的)
- 此前六种砍尾形态(书级波动目标 / 去集中 / 多头费率门槛 / 对冲 / 止损梯 / 逐名波动上限)全部判负, 它们共有一个缺陷: **对称、无条件、非定向** —— 用"波动大"或"费率高"当代理, 一刀切地缩掉同一批既赚钱又崩的名; 唯一定向的是逐名停机条款(深度 −30% × 连续两个终锚), 那是**事后两锚**的反应。
- 从未提出过的问题: **在这个多头极端名的队列里, 哪些名在接下来 4–12 小时崩的概率显著高于同队列其它名, 且其条件期望收益 ≤ 0**。这是一个尾部目标(崩跌指示 / 下分位数)上的定向模型, 不是均值排序(xregime 只测了均值排序), 也不是波动预测(LOB 风险层 / vol-predictable 测的是方差, 方差可预测但按方差行动亏)。
- 机制(为什么可能有信号): 队列 = fund 腿多头端 = 费率最高的名 = 正在抛物线上涨、多头付费的新名; 抛物线的终结有已知前兆: 费率贴顶(交易所逐名 cap)、涨幅加速后成交量与主动买占比衰竭、区间内收盘位置下移、上市天数短、OI 快速堆积后见顶; 而 W4 受据说**瀑布在 4h 延续不反转** ⇒ 第一根大跌 bar 之后还有得跌, 提前一锚或锚内更早退出有价值。反假设(必须可见): 前兆同样出现在继续上涨的名里(09-05 00Z 那锚 +139 bps 的名与 09-06 00Z 崩的名是同一批), 模型只是在预测波动 ⇒ 定向门失败, 判负。

## 3. 分数层门(冻结; 先于任何动作)
- **S-a 判别力**: T1 每折 AUC ≥ 0.60 且前 10% 风险分位的事件率 ≥ 2.0 × 队列基率(双种子)。
- **S-b 定向门(与波动族分界的关键)**: 前 10% 风险名的**条件平均 4h 收益** ≤ 队列均值 − 30 bps, CI95 上界 < 0(UTC 日块 bootstrap), 三折中 ≥ 2 折且 2026 折成立; 否则模型预测的是方差, 按既有受据(vol 可测但行动亏)判负, 不进 Phase 2。
- **S-c 稳定性(只报)**: 逐折前 5 特征重要度; 定向门在正费率名 vs 非正费率名的分解; 逐年事件数。
- 读法: **PASS** = S-a ∧ S-b(双种子); **FAIL** = 任一不成立; 家族 = T1/T2/T3 三目标(以 T1 为主判, T2/T3 只报)。
