# 第 0 部分：一句话 + 一个类比

**一句话：** 我们在训练一个模型，每小时给 110 个加密货币（币）排个序 —— 预测未来几小时哪些币会相对涨、哪些会相对跌 —— 然后买预测最强的、卖空预测最弱的，靠这个"相对排序"赚钱。

**ML 类比：** 这本质是一个**极低信噪比的截面 learning-to-rank 问题**。
- 每个"样本"= 某个时间戳 t 上的一个币，特征是它的盘口/成交/价格历史，标签是它未来的收益。
- 但和普通 ML 不同：**信号极弱**（R² < 1%，即特征只能解释收益方差的不到 1%），**分布持续漂移**（非平稳），而且**评价的是横截面排序**（同一时刻 110 个币谁排前谁排后），不是绝对值。
- 你可以把它想成：在一个 99% 是噪声的数据集上做 ranking，且训练集和测试集的分布每个月都在变。难点从来不是"拟合"，而是"从噪声里抠出那 1% 真实且能持续的结构，并证明它不是过拟合"。

# 第 1 部分：金融基础概念（从零讲起）

## 1.1 我们交易的东西：USDT 永续合约 (USDT-perp)

- **现货 (spot)**：直接买币，你拥有那个币。
- **永续合约 (perpetual futures, "perp")**：一种衍生品，你不持有币，只是和交易所对赌"币价涨还是跌"。可以做多（赌涨）也可以做空（赌跌），且可以加杠杆。
- **USDT-perp**：用 USDT（一种锚定美元的稳定币，1 USDT ≈ $1）计价和结算的永续合约。我们全程交易这个，因为它流动性最好、能做空、能加杠杆。
- **为什么用 perp 不用现货**：我们的策略要**同时做多一批币、做空另一批币**（见 1.5），做空只能用衍生品；而且 perp 能加杠杆放大小信号。

## 1.2 订单簿 (Order Book / LOB) —— 价格是怎么形成的

想象一个实时更新的双边挂单表：
- **bid（买单）**：一堆人挂着"我愿意用 X 价格买"，按价格从高到低排。
- **ask（卖单）**：一堆人挂着"我愿意用 Y 价格卖"，按价格从低到高排。
- **best bid / best ask**：最高的买价 / 最低的卖价。
- **spread（价差）**：best ask − best bid，是买卖之间的缝隙。流动性好的币 spread 很窄（BTC ~0.02bps），小币 spread 宽（~2bps）。
- **mid price（中间价）**：(best bid + best ask) / 2，我们通常用它当"当前公允价格"。
- **LOB (Limit Order Book)**：整个挂单表。我们的数据有 5 档（bid/ask 各前 5 个价位）到 25 档（BTC 高精度数据）的深度。
- **bps (basis point, 基点)**：1bps = 0.01% = 万分之一。金融里衡量小幅度价格/成本的单位。"成本 2bps" = 每笔交易损耗万分之二。

## 1.3 Maker vs Taker —— 你是"挂单方"还是"吃单方"（决定成本，极重要）

这是理解整个项目经济学的核心概念：

- **Taker（吃单者）**：你想马上成交 → 直接吃掉对方挂着的单 → **立刻成交但付更高费率**（Binance perp 零售约 5bps/单边）。像"市价单"。
- **Maker（挂单者）**：你挂一个单在盘口等别人来吃 → **可能不成交，但费率极低甚至为负（返佣）**（高等级账户 maker 费 ≈ 0）。像"限价单"。

**★ 为什么这决定生死：** 我们的策略每天要交易几百次，每笔的 edge（利润）只有几个 bps。
- 如果全用 taker（5bps 成本）→ 成本吃掉全部利润，策略必亏 → 这就是本项目早期一堆"信号无效"判决的真相：**不是信号死，是 taker 成本死。**
- 如果用 maker（~0 费率）→ 成本压到 ~2bps（主要是"逆选择"，见第 7 部分）→ 策略可行。

所以本项目所有可部署结论都建立在 **maker 执行** 上。这不是脚注，是设计前提。

## 1.4 Funding Rate（资金费率）—— perp 独有的关键信号源

永续合约没有到期日，靠一个机制把 perp 价格拴在现货价格附近：**funding rate（资金费率）**，每 8 小时结算一次。

- 如果 perp 价格 > 现货（多头太多、太贪婪）→ funding 为正 → **多头付钱给空头**。
- 如果 perp 价格 < 现货（空头太多）→ funding 为负 → **空头付钱给多头**。

**关键洞察：funding rate 直接读出"市场当前有多拥挤、往哪边拥挤"。** 高正 funding = 一堆人加杠杆做多、每 8 小时还在付费维持仓位 = 过度拥挤 = 容易反转（这就是我们的 funding 因子，见 5.1）。

## 1.5 横截面 vs 时序 —— 我们赚的是"相对"不是"绝对"

- **时序预测 (time-series)**：预测"BTC 明天涨还是跌"（绝对方向）。
- **横截面预测 (cross-sectional)**：在同一时刻，预测"这 110 个币里，谁会相对跑赢、谁会相对跑输"（相对排序）。

我们做的是**横截面**。具体地：
- 每个时间戳，模型给 110 个币各打一个分。
- **做多**得分最高的一批（如 top decile，前 10%），**做空**得分最低的一批（bottom decile）。
- 多空金额相等 → 这叫 **dollar-neutral（美元中性）/ market-neutral（市场中性）**。

**★ 为什么要中性：** 如果整个加密市场一起暴跌，我们多的和空的一起跌，多空盈亏抵消 → **我们不赌市场方向，只赌"相对排序对不对"**。这让策略在牛市熊市都能赚，且回撤小。代价是：单靠这个赚的是"结构性小钱"，需要高频次 + 高杠杆放大。

## 1.6 Alpha vs Beta —— 什么是"真本事"

- **Beta（贝塔）**：你的收益里"跟着大盘走"的部分。比如 ETH 天然跟 BTC 高度同涨同跌（相关性 0.84），这部分不是本事，是"搭便车"。
- **Alpha（阿尔法）**：扣掉 beta 之后，你**真正预测对的相对超额部分**。这才是本事。

**★ 本项目最核心的 reframing（方法论支点）：**
- 同期 BTC → alt（山寨币）的 beta 巨大（平均 ~0.70）—— 也就是说，"用 BTC 的走势去解释 alt"能白送约 0.045 的相关性。
- 但这是**同期**的，不可交易（你要预测未来，不能用未来的 BTC）。滞后的 BTC → alt 影响很弱（~0.02）。
- ⇒ 模型的真正任务不是学 beta（那个白送），而是学 **residual alpha（残差 alpha）** —— 扣掉所有已知的、便宜的、可解释的部分之后，剩下的真本事。这条贯穿整个项目：**我们所有 DL 因子的功劳，都只按"对残差目标的增量"计**（见 4.2）。

## 1.7 中频 (mid-frequency) —— 我们在哪个时间尺度

- **高频 (HFT)**：毫秒-秒级，抢盘口微观结构，拼速度和基础设施。
- **中频 (mid-frequency)**：分钟-小时级。我们在这里（预测未来 4h-24h）。
- **低频**：天-月级，传统因子投资。

**★ 为什么选中频：** 秒级信号（盘口瞬时不平衡）在几秒后就衰减殆尽，且拼不过 HFT 巨头。天级信号在加密里样本太少、噪声太大。小时级是"信号还活着 + 我们能用 bar 数据 + maker 挂单来得及成交"的甜点区。**"信号活多久"这件事后面会反复出现（fill-window 法则，第 7 部分）。**

# 第 2 部分：预测目标与评价指标

## 2.1 预测目标：y_600 / target horizon

- **y_600**：未来 600 秒（10 分钟）的收益率。早期单资产用这个。
- 多资产阶段主要用 **4h（H4）** 和 **24h（H24）** 的前向对数收益。
- **对数收益 (log return)**：log(price[t+H] / price[t])。用 log 而非百分比，因为它可加、对称、数值稳定。

## 2.2 IC —— 衡量预测好不好的核心指标

**IC (Information Coefficient)** = 预测值和真实收益的相关系数。两种口径：

- **Pearson IC**：普通线性相关。对异常值敏感。
- **Rank-IC (Spearman)**：先把预测和真实值各自转成排名，再算相关。**只看排序对不对，不看具体数值** —— 对重尾（加密收益经常暴涨暴跌）稳健。

**★ 我们以 rank-IC 为准（部署指标）。** 因为交易时我们只关心"谁排前谁排后"（做多前 10%、做空后 10%），不关心预测的绝对数值。rank-IC = 0.06-0.08 在中频加密里是很健康的水平。

- **IR (Information Ratio)**：IC 的均值 / IC 的标准差。衡量 IC 有多稳定。IR 高 = 每个横截面都稳定地对，不是靠某几次撞大运。
- **注意**：本项目里逐横截面的 IC t-stat（IC-IR）经常是 16-29，这**不是 Sharpe**（有人会误读成 Sharpe 29）—— 它是"每个时间截面的统计显著性"，因为每年有 ~2000 个横截面，样本量大所以 t 值天然高。

## 2.3 Sharpe Ratio —— 衡量策略赚钱质量

**Sharpe = 年化收益率 / 年化波动率。** 直觉：每承担一单位风险（波动），你赚多少。

- Sharpe 1 = 一般；2-3 = 很好；> 4 = 优秀（传统资管里）。
- **★ 但高 Sharpe 可以来自"低波动"而非"高收益"。** 我们的书 Sharpe 12（结构口径）主要是因为**波动极低**（横截面中性 + 110 币分散 + 高频次），不是因为收益率高得离谱。这点在第 9 部分详述 —— 别被 Sharpe 12 吓到，它有明确的算术来源。

## 2.4 ★ 三层口径 —— 同一个策略，三个诚实程度不同的数字

这是全项目最重要的"防自欺"纪律。同一个策略可以报出天差地别的 Sharpe，取决于口径：

1. **信号级 / 结构口径 (structural / frictionless)**：只扣极少显性成本（1.9bps），假设完美成交。= **信号质量的上界**，用来和学界/业界的信号级研究对标。我们的 canonical = 这个口径，Sharpe 12.2。
2. **可部署-已校准口径**：加上 magnitude 校准（isotonic）后的变体，Sharpe 10.84。
3. **诚实可部署口径 (deployment)**：叠上真实执行摩擦（成交率 < 1、逆选择、冲击、容量），Sharpe 掉到中个位数。**这才是真钱能拿到的。**

**★ 铁律：任何 Sharpe 数字必须标口径。** 报 12.2 而不说"这是结构上界"就是误导。项目里每张表都带这个标注。

## 2.5 塌缩守卫 (collapse guard)：σŷ/σy

低信噪比训练里，模型可能"偷懒"输出几乎恒定的预测（方差趋近 0）—— 这时 IC 可能虚高但完全不可交易。**σŷ/σy ≥ 0.02**（预测的标准差 / 真实值的标准差）是硬守卫，低于直接 reject。rank-IC 本身也天然抗这个（排序对任意缩放不变）。

## 2.6 ★ IC 是 alpha，β 是量纲（一条辩证铁律）

代数支点：**β = r · (σy/σŷ)**，其中 r 是 IC。把预测 ŷ 乘一个常数 c：**IC 完全不变，但 β 变成 β/c**。

含义：
- **alpha 判定只看 IC / rank-IC**（尺度不变的信息量）。
- **β 的绝对水平几乎不由模型质量决定** —— β=3 和 β=1 常是同一个模型差一个标量。禁止把"β 改善"当 alpha 奖励（曾经踩过：为了 β=1 去训练，反而伤了 IC）。
- β 的合法角色只有两个：塌缩监视（但真守卫是 σŷ/σy）、跨 regime 稳定性。
- **部署需要真实 bps 幅度时**：事后接一个校准层（把排序信号映射到真实 bps），不把 β 训进模型。这就是 isotonic 校准的角色（第 8 部分）。

# 第 3 部分：为什么这个问题难（三个不可违反的约束）

## 3.1 信号极弱 (R² < 1%)

特征只能解释收益方差的不到 1%。**容量必须匹配信号** —— 不能用大模型强行拟合，那只会拟合噪声。这是为什么我们的模型只有 ~25 万参数（很小），而不是几亿。

## 3.2 非平稳性 (non-stationarity)

分布、币之间的领先滞后关系、相关性，都在持续漂移（concept drift）。**任何结论必须多日、跨 regime 的时序 walk-forward 验证**（见 4.3）。单日、单折、单 seed 的结果一律不可信。

## 3.3 预处理 > 架构；机制 > 堆叠

- **特征工程的优先级永远高于模型创新。**
- **每个 feature / 模块必须有清晰的作用机理**（为什么它应该带来信号）+ 通过定量门。禁止"试试看"式的堆叠。这是用户的硬约束，也是为什么本项目每个因子都有一段"机制解释"。

## 3.4 参数池化 (parameter pooling) —— 多资产的核心杠杆

单资产时，模型参数 : 样本 ≈ 18:1（很容易过拟合）。多资产时，14-110 个币**共享同一个模型**（参数池化）→ 参数 : 样本翻到 ~1:1000。这是多资产相对单资产的根本优势，也是"信号那么弱还能学出东西"的原因。

# 第 4 部分：因子挖掘的漏斗与纪律（怎么防自欺）

低信噪比 + 非平稳 = **极易过拟合、极易自欺**。整个项目一半的工作量在"证明一个因子是真的"，而不是"找到它"。核心纪律：

## 4.1 五门工厂 (5-gate factory)

每个候选因子必须依次通过五道门才能进书：
- **(a) 标准独立 IC + 经验零假设 z**：因子本身有没有预测力，且显著性用**经验 null**（打乱数据重跑几十次，看真实 IC 比随机高多少个标准差）而非"IC > 0"来判。
- **(b) 增量正交 IC**：扣掉已有因子后，还有没有**增量**（见 4.2）。这是最容易死的门。
- **(c) 正交性**：和已有因子的相关性 < 0.7（不能是换皮）。
- **(d) walk-forward Ridge/GBDT ΔIC 符号一致**：跨时间稳定，不是某段时间的幻觉。
- **(e) 净成本贡献**：扣掉真实交易成本后还赚不赚。

## 4.2 ★ 残差目标 (residual target) —— "只按增量给功劳"

这是本项目最精妙的设计之一。我们不让模型去预测原始收益，而是预测 **YR（残差目标）**：
- YR = 原始收益 − [已知便宜因子（funding + 因子动物园）能解释的部分]，再做横截面 demean（去掉市场整体）。
- 具体：对每个时间戳，把原始收益对 8 列基线因子做 OLS 回归，取**残差**作为新目标。

**为什么这样做：** 如果模型能预测 YR，那它学到的一定是**已知因子之外的新东西**（构造上正交）。这就把"增量"焊进了训练目标里 —— 模型不可能靠重复已知因子来刷分。

后来更进一步：挖补充因子时，把**已进书的 DL 因子（king、S2）的预测也加进基线**里残差化（YR4B / YR12B / YR24B），这样新因子只能挣"整本书之外"的钱。

## 4.3 Walk-forward + embargo —— 严格的时序隔离

- **Walk-forward（滚动前向验证）**：用过去训练、未来测试，逐年往前滚（train 2021 → test 2022，train 2021-22 → test 2023，…）。绝不用未来数据训练。
- **Embargo（隔离带）**：训练集结束和测试集开始之间留一个空档（如 8-16 天），防止标签重叠造成的泄漏。标签是"未来 H 小时收益"，如果训练最后一天的标签窗口伸进了测试期，就泄漏了。
- **#2 反模式**：`stride < horizon`（步长小于预测周期）会导致标签重叠 → 评估虚高。训练可以用重叠标签（dense），但**评估必须用非重叠的 clean 锚点**。

## 4.4 泄漏检测（leakage）—— 三种武器

泄漏 = 模型偷看了未来，是低信噪比研究里最常见的致命错误。三种检测：

- **shuffle-future null**：把未来标签打乱重训，如果 IC 还高 → 有泄漏。
- **★ forward-window-decay 因果测（最强）**：看预测和收益在不同时间滞后上的相关性。真信号的签名是：**滞后 0 处峰值，向未来平滑衰减，向过去（负滞后）反号**。如果在负滞后处还高 → 偷看了未来。这是 shuffle-future 抓不住的泄漏（尤其 in-context 类模型）都能抓住的决定性判别器。
  - 我们的 king 因子实测：lag 0 = +0.070，+1h = +0.063，+4h = +0.045（平滑前向衰减 ✓），−4h = **−0.153**（负滞后反号 = 反泄漏铁证 ✓，且揭示了机制是"短期反转"）。
- **byte-level panel 校验**：不同臂用的数据面板 md5 逐字节一致，排除数据口径差异。

## 4.5 ★ 动态 IC vs 静态 IC —— 防"持久 tilt 灌水"

一个因子的 IC 可以分解成：
- **静态部分 (static tilt)**：一个持久的、不变的横截面倾斜（比如"永远偏好小币"）。这个可能是靠过拟合某种结构刷出来的。
- **动态部分 (dynamic)**：真正的择时技能 —— 每个时刻都在做不同的、正确的相对判断。

用 shuffle-future 把时间打乱后，静态部分还在，动态部分消失。**排行榜只认动态 IC。** 我们的 king 动态占比 0.92-0.96，说明是真择时不是灌水。

## 4.6 诚实 ensemble（防选择偏差）

模型有多个头（预测头），报告时必须用**所有头的等权平均（ensemble）**，而不是"每折挑最好的那个头"（per-fold best-head）—— 后者有选择偏差，会系统性虚高。这个坑本项目踩过两次，都被抓住。

## 4.7 双人验证（two-person rule）

关键数字必须由两个独立的 agent（0B 建/跑，0C 独立评分/审计）交叉验证。本项目双人验证实际拦下了至少 6 个错误：归因错误、协议错标、stale 文件撞名、blend 稀释、isotonic 误归因、我自己的收益率单位误读。**"好得惊人的数字必审计"** 是硬纪律。

# 第 5 部分：每一个因子的详解（含义 + 理论基础 + 结局）

当前部署的书有 **4 条腿（因子）**，每条机制完全不同、互相正交。另有一批"真实但没进书"的存档因子 —— 它们的死因本身就是重要结论。

## 5.1 ★ funding_ema —— 拥挤反转（压舱石）

**机制（为什么应该有信号）：** funding rate 直读市场拥挤度（见 1.4）。
- 高正 funding = 一堆人加杠杆做多、还在付费维持 = 多头过度拥挤 = 一有风吹草动就爆仓踩踏、容易反转 → **做空高 funding 的币**。
- 负 funding = 空头拥挤 = **做多低/负 funding 的币**。
- 这叫 **crowding reversion（拥挤反转）** 或 positioning reversion。

**为什么它是好因子：**
- 8 小时结算一次 = 天然慢、高自相关 = **换手率低 = 成本友好**（这是所有因子里成本余量最大的，break-even 18.8bps/side）。
- 机制清晰，不拥挤（市场上大家用 funding 做 delta-neutral 套利，那个赛道 2025 已经不赚了；但用它做**方向性 alpha** 的横截面排序不拥挤，2026 仍显著）。

**结局：** 七年回放 5/7 年正，均值 +0.97 Sharpe，最差 −0.44。**压舱石**。
**技术细节（引擎阶段发现）：** 用 z-score + L1 加权时会过度集中到极端单币（单名权重到 0.49，FTX 崩盘日 −18σ）；改成 **rank 加权** 后天然有界（单名 0.049），风险自动可控（见第 8 部分）。

## 5.2 ★★ DL king —— 残差空间的短期横截面反转（alpha 引擎，本项目的皇冠）

这是整个项目的核心成果，也是最复杂的一条腿。

**它预测什么：** 110 币的残差目标 YR4（4h 前向、扣掉 funding+zoo 基线后的残差）。
**机制（信号是什么）：** 通过 forward-decay 因果测揭示 —— 这是 **110 币残差空间里的短期横截面反转**：买"最近相对跌多了的残差输家"，卖"最近相对涨多了的残差赢家"。负滞后处的 −0.15 相关就是"反转"的签名（近期输家倾向回弹）。这是均值回归的一种，不需要趋势 regime 就成立，所以跨 regime 稳健。

**架构（两个可解释的 lever，本项目的科学产出）：**

模型 = Conformer 时序编码器（每个币独立处理时间维）+ 1 层跨资产注意力（让 110 个币互相"看"）+ 6 个预测头，输出诚实 ensemble。

机制被一张 2×2 表钉死：

|  | 有正交惩罚 (lam_orth=1) | 无正交惩罚 (lam_orth=0) |
|---|---|---|
| 无跨资产注意力 | 0.033 | 0.067 |
| 有跨资产注意力 (1层) | 0.041 | **0.084** |

- **Lever #1 — 去掉正交惩罚（+0.035，最大杠杆）：** 原来的损失函数里有一项 `lam_orth=1.0`，强迫 6 个预测头彼此正交（不同）。这把模型一半的容量花在"让头彼此不同"而不是"预测得准"上 —— **这是一个 loss 设计 bug，自项目启动以来把每个模型的 IC 砍半了。** 去掉它，IC 翻倍。★ 教训：正交性应该事后去重，不该写进训练损失。
- **Lever #2 — 跨资产注意力（clean 基线上 +0.028）：** 让 110 个币互相看（cross-asset attention），学习币之间的相对结构。被正交惩罚压制了 3.4 倍（所以早期一直"温和领先但不惊艳"，真实贡献被埋没）。
- **饱和边界**：加第 2 层注意力无增量（一次消息传递已提尽）；辅助监督（aux-MTL）反而有害。

**结局（四关加冕）：**
- 5 年扩张 walk-forward：2022 +0.048 / 2023 +0.080 / 2024 +0.086 / 2025 +0.104 / 2026H1 +0.099，**五年全正，均值 +0.0835**（2025/26 触到 0.10 —— 项目最初的目标线）。
- 动态占比 0.96（真择时）、seeds CoV 2.7%（换随机种子稳定）、六项泄漏审计全清。
- **CROWN SEALED（皇冠加冕）。** 部署实现 = 单个 `lam_orth=0 + xattn` 模型。

**损失函数的一个验证性发现：** 我们的主损失 `LambdaRankIC`（位移加权的 listwise 排序损失，直接优化 rank-IC）—— 后来调研发现它**逐字就是 2026 年最前沿论文（arXiv 2605.00501）的公式**。我们独立收敛到了前沿。

## 5.3 SIZE —— 规模溢价（分散腿）

**机制：** 小市值币系统性地和大市值币有不同的收益特征（规模溢价，size premium，传统股票市场的经典因子）。在 110 币宽宇宙里，这个因子活（在 14 个大币的窄宇宙里它消失 —— 见 5.7 的宇宙宽度洞察）。
**结局：** 宽宇宙因子册里唯一同时过五门的商品化 sleeve，与其余腿相关性近零。作为分散腿进书。

## 5.4 ★ S2 —— 24h 慢因子（补充因子阶段唯一 ACCEPT）

**机制：** 和 king 同一个 DL 架构，但预测 **24 小时** horizon 的全书残差（YR24B = 扣掉 king 和 S2 自己之外的残差）。24h 是"慢价格结构"，换手只有 king 的 1/6。
**为什么它能进书而 S1（4h 再挖）不能：** 见 5.6 的核心教训。关键是 **horizon 多样性** —— 它和 king 的预测相关只有 0.22（做的是实质不同的下注），且换手节奏完全不同。
**它的诚实定位（重要）：** S2 **不是 Sharpe 提升器，是分散/最差年保护 sleeve**。
- 逐年 king-正交增量全正（pooled +0.029），2026H1（king 的弱年）增量最大 +0.042。
- 四腿装配：S2↔SIZE 相关 0.002，S2↔king 0.224 = 真第四分散腿。加进去后组合 Sharpe 6.60→7.10，**最差月 −2.84→−2.42，2026H1 弱年 5.91→6.61（最差年保护兑现）**。
- ★ 它单独看很弱（独立 Sharpe 4），成对和 king blend 不显著 —— **价值只在多腿组合的语境里兑现**。这是"sleeve 判据（按组合分散价值判）而非 blend 判据（按单独叠加判）"的教科书案例。
**权重：** ~0.10 风险预算。

## 5.5 存档因子之一：S1（4h 王座残差再挖）—— CLOSE

**做了什么：** 用同一个 king 架构，在 4h（和 king 同 horizon）上再挖 king 的残差（YR4K = 扣掉 king 的残差）。
**结局：** 增量 +0.0181 统计真实，但 **pred-corr vs king = 0.36、book-corr = 0.48 = 大部分冗余**（模型绕道又学回了 king）；作第五腿伤书（Sharpe 8.06→7.63）。**存档。**
**★ 教训（第一次证明）：** 在 king 已饱和的 4h horizon 上，同架构再挖 = 递减回报，即便统计增量真实也不加书值。

## 5.6 ★★ 核心教条：横向多样性才是进书门槛，架构新颖度不是

对比 S2（进书）和 S1（存档）：
- 两者的"统计增量"都真实（+0.029 vs +0.018）。
- 差别在 **horizon 多样性**：S2（24h，corr 0.22，换手 1/6）ACCEPT；S1（4h，corr 0.48，同执行画像）ARCHIVE。
- **⇒ 让补充因子进书的是 horizon + 执行画像的多样性，不是架构或统计增量。** 对饱和 king 的同 horizon 再挖不加值。

## 5.7 ★ 宇宙宽度是一个因子：N=110 的解锁

- 在 14 个大币（mega-cap）上，价量因子（Alpha101、国泰君安那类经典因子）几乎全 NULL（规模/流动性/反转在大币上消失）。
- 扩到 110 币宽宇宙后，14/20 个价量因子复活（z > 15）。
- 反过来，**funding 只在大币上活**，宽宇宙上作为线性因子反而不显著（z 1.7）—— 但它的宽宇宙价值以"DL 输入做非线性交互"的形式存在。
- **⇒ 宇宙宽度本身就是一个信息源。** 这解锁了整个 v3 factor-mining（Engine A）。

## 5.8 存档的其它探索（每个都是一条被封死的轴）

这些是"真实但没进书 / 或干净负结论"，记录它们防止重复劳动：

- **S3（168h 周级）：** 信号真（king 和 S2 双正交，CI 排 0），但 **breadth 饥饿** —— 每年只有 ~52 个非重叠锚点，52 注 × IC 0.025 → Sharpe 天花板只有 ~1，比书低 7 倍。**便宜执行 ≠ book 价值；是 breadth（频率 × 截面宽度）把 IC 转成 Sharpe。** 存档。
- **OI / 持仓数据轴（3 连 NULL）：** 花了大力气拉了 188K 个日档、140 币的持仓量（Open Interest）和多空比数据 → 双门 FAIL：1h 线性（+0.0007）、1h 非线性 GBDT（−0.0004）、24h DL 输入（−0.010 净拖累）。泄漏审计全清（"干净但无预测价值"）。**OI/持仓在小时尺度对残差目标无增量。** 数据资产保留备用（换 8h/日频 horizon 未测）。
- **前沿双臂（N2/N1b/N1a，2026-07-15 收官）：** 用 2025-26 最前沿范式再挖两个因子，**0 进书**：
  - **N2（LambdaRankIC 损失）**：前置核查发现它就是 king 现在的主损失（已在前沿），无处可加 → 塌缩存档。
  - **N1b（多关系跨资产注意力）**：增量真实（结构确实被用，alpha 训到 −0.099），但 pred-corr vs king 0.378 越资格线 = **换皮**（换了架构没换 basin）。
  - **N1a（未来共动对比预训练）**：预训练成功、12h horizon 成功逃出 king basin（corr vs king 0.294 通过！），但死在**和 S2 的邻接冗余**（corr 0.363，仅超线 0.003）。
  - **★ 三死法同指一个结论：四腿书在现数据轴上 alpha-complete（alpha 完备）** —— 残差空间的可预测部分已被现有腿覆盖满（快端 king 占 4h、慢端 S2 占 24h、中间被邻接吃掉、更慢 breadth 饥饿）。**剩余增量 EV 只在新数据轴（现有价量/funding 面板之外的正交信息源），不在架构/损失/horizon。**

**★★ 这是一个非常有价值的负结论：** 它意味着"再调模型/再换架构"已经到头了，下一个突破必须来自新数据（如代币解锁日历、链上资金流、期货期限结构），而不是更聪明的网络。

# 第 6 部分：深度学习技术栈

## 6.1 数据

- **原始数据**：14 币 1 秒 bar（`/mnt/storage/share/bar_data`，2022-2025，5 档 LOB + 成交流 + 挂撤单）；BTC 高精度 Tardis µs 级 25 档数据（用于执行验证）。
- **宽宇宙面板**：110 币小时级面板 `wide_dl_full.npz`，形状 (T=48168 小时, N=140 币, C=32 通道)，跨 2021-2026。通道 = 因子动物园 + 原始收益 + funding。
- **point-in-time 成员掩码 (MEMBER110)**：每个时间戳只用当时真实存在、可交易的币（新币按上市日、退市币按退市日掩码）—— 防**幸存者偏差**（survivorship bias，用今天的币池回测过去 = 作弊）。

## 6.2 模型架构（可插拔骨干）

`PanelEncoder` 契约：`forward(x (B,N,W,C), mask (B,N)) → h (B,N,d)`
- B = batch，N = 币数，W = 时间窗，C = 通道，d = 隐藏维。
- **Conformer stem**：每个币独立的时序编码器（卷积 + 注意力混合，源自语音识别的 Conformer）。捕捉单币的时间结构。
- **Cross-asset attention（跨资产注意力）**：让 N 个币在**同一时刻**互相注意（member-mask 保证只在同期跨币混合，不跨时间 → 无泄漏）。这是学"币之间相对结构"的模块。
- **K 个预测头 + 诚实 ensemble**：多个头，等权平均输出。

## 6.3 损失函数

- **LambdaRankIC（主损失）**：位移加权的 listwise 排序损失，闭式梯度直接优化横截面 Spearman rank-IC。权重公式 w_ij = 12·|预测秩差|·|真实秩差|/(n(n²−1))。**直接优化部署指标（rank-IC），这是它比逐点损失（MSE/Huber）好的原因。**
- **pinball / 分位数头**：预测多个分位数（如 25 个），implied-mean 作点预测。曾经以为它是 king 的核心，后来发现真核心是"去掉正交惩罚"，pinball 头本身中性。
- **去掉的**：`lam_orth` 正交惩罚（那个 bug）、tail-focal、dir_huber（会导致 σ 塌缩）。

## 6.4 训练技巧

- **dense_train（opt-in）**：训练用所有重叠标签（dense，样本多），评估用非重叠 clean 锚点。对慢 horizon（24h/168h）必需，否则 clean 锚点太稀疏导致过拟合（24h 的 params:sample 从 1:0.4 恢复到 1:9.6）。
- **checkpoint on rank-IC**：以验证集 rank-IC 选最佳检查点（不是 loss，不是 Pearson）。
- **σ-gate + EMA**：塌缩守卫 + 参数指数移动平均（稳定）。

## 6.5 基础设施

- 本地开发（Mac），rsync 推到服务器 `jpline`（单张 RTX 3090）串行训练。conda 环境 `hsy_v5push`。
- 双 agent 团队：**0B（stage0B-d1-substrate）** 建代码/跑训练；**0C（stage0C-d3-factors）** 独立评分/审计。主 agent 协调 + 落档 + 汇报。
- 所有判决产物落 `exports/eda/*.json`，文档落 `docs/`，关键结论落 memory。

# 第 7 部分：执行与经济学（信号 → 真钱之间的那道墙）

**这是本项目下半程的重头戏。一个信号 rank-IC 再高，赚不赚钱取决于执行经济学。**

## 7.1 ★ fill-window 法则（信号活多久决定能不能 maker）

Maker 挂单不是马上成交，要等（挂单窗 k，如 60-900 秒）。**只有 alpha 半衰期 ≫ 挂单成交窗的信号，才有资格用 maker 执行。**
- 秒级微观信号（如瞬时 OFI）：alpha 30 秒就衰减 90% → 等不到成交 alpha 就没了 → maker 救不活。
- 4h/24h 慢信号：alpha 半衰期远超几分钟的挂单窗 → maker 有充分时间成交 → 可行。
- **这条法则解释了为什么中频（4h）是甜点，也解释了为什么很多"快信号"其实不可交易。**

## 7.2 Maker/Taker 成本的真相（tick 级验证）

用 BTC 的 µs 级真实逐笔数据（Tardis 25 档）重演挂单成交，得出：
- **1s bar 近似是乐观的，不是保守的**（一个反直觉发现）：它高估成交率 1.5 倍，且几乎完全漏掉逆选择。
- **逆选择 (adverse selection)** = maker 的经典陷阱：你的被动单**恰好在你错的时候更容易成交**（价格冲过来打你 = 对手方可能知道些什么），在你对的时候反而不成交。成交样本天然偏向坏交易。
  - 实测 markout（成交后价格逆你走多少）：平静日 −1bps / 正常 −1.7 / 压力 −3.2 / **崩盘日 −5.3（尾部 −20）**。强 regime 依赖，压力日恶化 3-5 倍。
- **有效成本**：maker 口径 normal ~1.9bps / stress ~2.7-2.9bps（vs taker 零售 5bps，砍到 1/3-1/2）。**费率本身 ≈ 0（高 VIP 档），成本主体是逆选择。**

## 7.3 容量 (capacity)

- 我们挂单占某币小时成交额的比例越高，成交率越低、冲击越大。
- **容量表**：$5-10M gross 起步（保留 85-90% 无摩擦边际），软天花板 $40-80M。25% 权重在小币是容量杀手（底档币只有 $0.63M/小时成交额）。
- **★ 容量只稀释不翻负**：装太多钱时小币腿被 cap 压掉（丢它们的 alpha），但大中盘腿继续撑正。

## 7.4 结论：为什么早期一堆"信号死"其实是"taker 死"

用户曾质疑"顶级 prop 都用 DL 做 multi-asset rank 预测，难道都 beat 不了费率？" —— 这个质疑是对的。重新审视后：**很多"信号无效"的判决是 taker 成本条件下的，maker 口径下信号是活的。** 这个 reframing 反转了多个结论。

# 第 8 部分：交易引擎（6 个组件，从信号到目标持仓）

信号只是原料，一个能跑的引擎还需要一套组件。全部在 `multi_asset/engine/`，回放测试过：

- **C1 信号生产链**：面板@t → 四腿预测（king/S2 用模型推理，funding/SIZE 用因子公式）→ 加权组合 → 校准 → gate → 市场中性目标持仓（dollar-neutral 精确到 1e-14）。
- **C2 vol-gate（执行战术门）**：★ 一个概念修正 —— 实测**书是危机受益者**（危机日各腿相关反而变负 −0.05，最差 BTC 日组合均值 +0.47，高波动 regime Sharpe 反而 +4.14）→ **书级降杠杆是错工具**（会白丢正收益 + 放弃尾部对冲属性）。所以 vol-gate 只调**执行战术**（崩盘日挂单更宽/更耐心，因为那时逆选择 −5.3），**不缩目标持仓**。
- **C3 isotonic 校准（部署工具，不是 alpha）**：把排序信号单调映射到真实 bps 幅度（Kelly/净成本门需要真实 E[bps]）。★ 关键发现：它本身是 **−1.3 Sharpe 的代价**（稀疏尾饱和会压平高信念仓位，砍均值不砍波动），不是收益来源。合法角色是部署校准，代价明示。所以 canonical 结构表**不含** isotonic。
- **C4 IC 监控 + 冠军/挑战者切换骨架**：滚动实盘 rank-IC 监控 + 衰减告警 + 在线重训触发桩（OneNet-lite 形态）。这是应对非平稳的生产端方案。
- **C5 funding 腿专项风控**：per-name winsorize + 集中度上限 + dispersion 门。★ 但改用 rank 加权后（见 5.1）**完全 inert**（on/off 逐字节一致）—— 天然有界的构造从根上消灭了单名集中，风控组件变成保险。构造优于修补。
- **C6 跨腿净额执行**：四腿在同一 110 币宇宙交易，先内部撮合（一条腿要买的和另一条腿要卖的抵消）再对外下单 → 省 ~200bps/年。★ 陷阱：日频批量看似省 75%，但那 90% 是"king 不交易自己的 alpha"= 信号损失伪装成执行节省，别引用；真净额节省是逐时/4h-sync 的 ~12%/200bps。

# 第 9 部分：当前结论、数字、目标

## 9.1 部署书 = 四腿（机制互不相同）

| 腿 | 机制 | horizon/换手 | 风险权重 |
|---|---|---|---|
| **funding** | 拥挤反转（rank 加权）| 8h，极慢 | ~0.28 |
| **DL king** | 110 币残差反转 + 跨资产注意力 | 4h，快（需 maker）| 0.35-0.40 |
| **SIZE** | 规模溢价 | 慢 | ~0.28 |
| **S2** | 24h 慢因子（护弱年）| 24h，king 的 1/6 | ~0.10 |

组合性质：两两日收益相关近零到负、领导权逐年轮动（每年不同的腿在扛）、危机日相关反而下降（危机受益者）。

## 9.2 数字（三层口径，务必分清）

| 口径 | Sharpe | 年化收益/gross | 含义 |
|---|---|---|---|
| **结构 (canonical, rank+cap)** | **12.2** | **144%** | 信号质量上界，对标学界信号级研究 |
| 可部署-已校准 (含 isotonic) | 10.8 | ~ | 加了部署校准的变体 |
| **诚实可部署 (待 pilot)** | **中个位数** | **~结构的 1/3-1/2** | 真钱能拿到的，叠 fill<1 + 逆选择 |

逐年结构 net Sharpe：2022 9.6 / 2023 11.8 / 2024 12.6 / **2025 16.0** / **2026H1 11.1**（波动仅 ~11.8%/年）。

**★ 为什么 Sharpe 这么高、收益率这么高：**
- 高 Sharpe = **低波动**给的（横截面中性 + 110 币分散 + 高频次把日波动压到 ~0.6%）。IR ≈ IC × √breadth，breadth（110 币 × 每天 6 次）很大。
- 高收益率（144%/gross）= **高换手**（857 倍 gross/年）× 每单位小 edge。
- **两者是同一枚硬币**：正因为高换手，执行折损（fill 0.51、逆选择）直接乘在收益上 → 可部署打到结构的 1/3-1/2。想赚更多美元，路径是**容量工程**（更多 venue/更好执行）而非再抬 IC。

## 9.3 业界对标

- 已发表加密横截面 L/S 信号级研究：Sharpe 1-2.5。我们结构 12 是其 5-8 倍，可部署估计（中个位数）在最上沿。
- 加密市场中性基金真实净值：头部 2-4。我们可部署估计与其头部持平，**但容量小 1-2 个量级**（$5-10M vs 数亿）—— 小容量本身是 Sharpe 的来源，对比要带这个脚注。
- **定性：这是"小容量高 Sharpe"象限里的健康画像，护城河是执行不是公式。** 这类书在 prop shop 内部跑，不以基金形态存在（装不下外部资本）。

## 9.4 目标达成度

- 最初目标：avg per-asset Pearson 0.10 @ 10-30min。
- king 五年表 2025/2026 触到 0.10（横截面残差口径）—— **目标线在最强年份触及。**
- 更重要的产出是**方法论**：三层口径纪律、残差目标、双人验证、fill-window 法则、"横向多样性才进书"教条、"现数据轴 alpha-complete"这个干净的负结论边界。

## 9.5 剩下什么（下一步的三个方向）

1. **新数据轴调研**（唯一能再挖 alpha 的方向）：代币解锁日历（供给冲击，最便宜最干净）、链上资金流、季度期货期限结构。因为架构/horizon 轴已证明挖满。
2. **实时数据接口**（shadow 管道从回放转实时，为 pilot 做准备）。
3. **$2-5M live maker-fill pilot**（等交易账户）：唯一离线不可测的残余是 alt 腿的逆选择，只能真钱实测。证据链已到离线极限。
