## §5 判据(**数字之前冻结**; 因子与理由先写)

**为什么是 /3 和 /10(先于看数):**
1. 偏差若 ≤ 效应的 1/3, 它**不可能单独把效应的符号翻过来**, 且移动点估计的幅度小于该尺度效应的典型 CI95 半宽 ⇒ 它会削弱判决而不会反转判决。
2. `r18_judge.py:31` 与 `PREREG_r18_foundation:59` 已冻结判官的**工作分辨率 0.23 bps/锚**(「smaller moves are not results」)。任何自称可用的装置, 其偏差必须**远在 0.23 以下**才在判官的工作分辨率下不可见。
3. /10 是常规「可忽略」档: 偏差低于判官报数的一个量级。

**裁定阶梯(取 U_mean 为主判, U_max 为并列硬约束):**

| 判 | 条件 |
|---|---|
| **FIT-STRICT(全 0.02–0.6 区间)** | `U_mean ≤ 0.02/10 = 0.002` bps **且** `U_max ≤ 0.02/3 = 0.006667` bps |
| **FIT(全 0.02–0.6 区间)** | `U_mean ≤ 0.02/3 = 0.006667` bps |
| **PARTIALLY FIT** | `0.006667 < U_mean ≤ 0.6/3 = 0.2` bps ⇒ 报可用下限 `X_fit = 3 × U_mean`, 装置只对 ≥ X_fit 的效应可用 |
| **UNFIT(全区间)** | `U_mean > 0.2` bps |

**并列噪声条款(只降级不升级):** 即使 U_mean 过关, 若 `S_rms > 0.1 × σ_g_ref`(≈ 2.30 bps), 判**「偏差合格但噪声超标」**, 装置只可用于配对设计, 不可用于非配对替身。

**证伪(任一条成立即判装置不适用 / 本次测量作废):**
- F1: `U_mean > 0.2` bps ⇒ 装置对题面整个 0.02–0.6 区间 **UNFIT**。
- F2: **阳性对照不为 0** —— 12Z / 16Z 两锚上任一名字的 Δw ≠ 0.0(严格浮点相等), 或 Δg ≠ 0.0 ⇒ **本管线有错, 立即停下上报, 不报任何主窗数字**。
- F3: **完整性门 G-M1 红**(见 §6) ⇒ 盘上的回放产物不是受据所描述的那批, 停下。
- F4: `G-M0` 红且触到裁剪的名字在某锚有 |Δw| > 0 ⇒ 收益口径在该锚被 E-0908-B 污染, 该锚的 Δg 标为不可用并单列。

## §7 分解(§C, 定义冻结)

1. **受影响名集合** `S14` := { i : max_A |Δw_i(A)| > 1e-6 }。报 |S14|(预期 14, 与 RESULT 对账), 以及逐锚 `Σ_{i∈S14} Δw_i r_i / Σ_i Δw_i r_i` 的份额, 与 `Σ_{i∈S14}|Δw_i| / Σ_i |Δw_i|`。
2. **尺度 vs 截面**。令 `β(A) = Σ_i w_r,i w_l,i / Σ_i w_l,i²`(过原点回归), `Δw = (β−1)·w_live + e`(构造上 `e ⊥ w_live`)。则
   ```
   Δg = (β−1) · g_live + 1e4 × Σ_i e_i r_i / G_live,      g_live := 1e4 × Σ_i w_l,i r_i / G_live
   ```
   逐锚报 `β−1`、尺度项、截面项、以及截面项占 |Δg| 的份额。
3. **秩与 L1**: 逐锚 Spearman ρ 与 Pearson r(两书在名字并集上, 缺失填 0), `L1_frac = Σ|Δw| / G_live`, `gross_frac = (G_replay − G_live)/G_live`。

### A1.1【更正·度量】归一化必须逐书用自己的 gross

**错在哪**: 原 §1.3 写 `Δg = 1e4 × Σ(w_r,i − w_l,i)·r_i / G_live`。执行器不是这样用书的。运行树 `918559f` 我已逐行打开核对:

- `live/external_book.py:489` `target_vector()`: `gn = float(ext.get("gross_in") or ext["gross_norm"])`; 返回 `w_i / gn`。
- `live/external_book.py:363/390`: `gross_in = sum(abs(v) for v in w_in.values())`, `w_in` = **在宇宙内**的子书。
- `scheduler/anchor_loop.py:1636` `book = {"target_w": EXT.target_vector(external, symbols)}`; `:1763` `target = LG.to_notional(book["target_w"], symbols, self.gross)`; `signal/legs.py:340-342` `to_notional` 只乘 gross, 不再归一化。

⇒ **每本书按自己的 gross 归一**, 所以差应是

```
Δg(A) = 1e4 × Σ_i ( w_r,i / G_r(A) − w_l,i / G_l(A) ) · r_i        【新, 主】
```

原式与新式之差 = `−(G_r − G_l)/G_l × g_replay`。**最干净的反例(研究员给的)**: 把整本书乘 1.0001, 执行器看到的目标向量变化 ≤1.74e-18(即**无操作**), 而原式的红能力控却要求读到非零 −0.000212 bps —— 原式在度量一个执行器不会产生的差。

**分母的已知缺口(明写)**: 执行器真正的分母是 `gross_in`(**在宇宙内**求和), 需要当锚的场所可交易名单, 离线复现不了。本装置用**文件自身全支持**的 `Σ|w|`(= 文件 `gross_norm` 字段, 已断言逐位相等)。研究员的补充诊断同此选择。⇒ **宇宙过滤、持仓、cap、withheld、sizing、停机一概不在内。**

### A1.2【更正·撤回】原 §1.3 的「NAV 层影响 ≈ 2 × Δg_raw」作废

不成立。若实际 gross = 2×NAV 且支持集相同, NAV 层是 `2×Δg`(新式); 只有 `G_r = G_l` 时才化简到 `2×Δg_raw/G_l`, 仍不是 `2×Δg_raw`。动态 sizing 与宇宙过滤不能略掉后再声称精确现金影响。**本预注册不再给任何 NAV 层换算。**

### A1.3【更正·统计】`|m| + CI 半宽` 不是百分位区间的上界

百分位自举区间**不以样本均值为中心**, 所以 `|m| + (hi−lo)/2` 不是「该区间允许的最大绝对偏差」。正确的量是**区间端点自身**:

```
U = max( |ci95_lo| , |ci95_hi| )        【新, 替换原 §4 的 U_mean】
```

原读数按新定义复述: 旧式 `|m|+H = 0.001994`, 但 `max(|lo|,|hi|) = 0.002122592` ⇒ **原 RESULT「均值已达严格线 0.002」的说法不成立, 撤回。** 普通线 0.006667 不因这一项翻转, 但见 A1.6: 整个「资格」框架本身降级。

**新公式也不把 8 个日块的自举变成分布无关保证。** `U_max = max_A |Δg(A)|` 是**样本**最大值, 不是未来硬上界。

### A1.4【更正·门】完整性必须绑逐文件 SHA256, L∞ 只是平价统计量

**反例(研究员给的, 我已复现)**: 在最差锚 `1788782400` 的**内存副本**上, 把一个**非最大**残差名 `DOODUSDT` 的 Δw 改成 0.9×L∞ —— L∞ 保持 `0.00011254748699554042` **精确不变**, 而该锚旧式 Δg 从 **−0.03169888 变成 +0.12333468 bps**。**原 G-M1 仍然过门, 输入和经济量却已经变了。**

**新 G-M1′**: 逐文件 SHA256 绑定, 三层:
1. 读到的每一个 book 文件(44 replay + 44 live, 两个书对共 176 个)的 SHA256 全部写进收据;
2. 每个文件与**生产者自己写的 `.json.sha256` 边车**比对(两棵树都有边车), 不符即红;
3. 符号轴 `config.json` 的 SHA + **每锚 r 向量 float64 字节的 SHA** 一并入收据(把收益切片也绑住)。

L∞ 与冻结链收据的比对**保留**, 但**降级为平价统计量**, 不再充当完整性证明。

### A1.5【更正·红能力】尺度档改为不变性测试, 另立真红控

新归一化下**整本书缩放是恒等操作**, 所以原 G-M5 的尺度档方向反了。改为:
- **G-M5a 不变性**: `w_r ← c·w_r`(c = 1.0001)后 Δg 必须**不变**(到浮点舍入)。这是性质测试。
- **G-M5b 红控**: 单名加 δ, 闭式 `Δg′ = 1e4·[ (Σw_r·r + δ·r_j)/G_r′ − (Σw_l·r)/G_l ]`, 其中 `G_r′ = G_r + (|w_r,j+δ| − |w_r,j|)`; 实测必须等于闭式且非零。
- **G-M6 L∞ 盲区**: 把 A1.4 的反例做成常设门 —— 必须复现「L∞ 不变而 Δg 变」, 以此证明 G-M1′ 抓的是 L∞ 抓不到的东西。

### A1.6【降级】交付物是**本窗基线残差测量**, 不是装置资格证

**撤回原 §9.6 的「未配对读数是配对设计的保守上界」。** 这是错的: 设装置误差为 `e(θ)`, 配对实验的误差是 `e(θ1) − e(θ0)`。测得 `e(θ0)` 小, **既不**证明 `|e(θ1)|` 小, **也不**证明两者同号 —— `e(θ0)=0, e(θ1)=0.03` 就能给真实为零的提升造出 +0.03 bps。候选若改动席位/平滑, 正是最可能改变误差传播的那类改动。

**同理撤回「共模抵消」的一般化**: 收益代理误差 ε 的贡献是 `ΣΔw·ε`, 一般不为零。G-M0(裁剪命中名 Δw=0)与 Σ/Π 敏感性是**本窗局部证据**, 不覆盖缓存误填、FP16、执行钟、真实 funding/cost。

**§5 的阶梯(FIT-STRICT / FIT / PARTIALLY-FIT / UNFIT)不再作为「装置对候选是否可用」的资格判决。** 阈值数值保留, 但只用作**本窗基线残差大小的刻度**, 判词改写为:

| 新判词 | 条件(阈值不变) |
|---|---|
| 「本窗基线残差 **远小于** 0.02–0.6 bps 尺度」 | `U ≤ 0.006667` |
| 「本窗基线残差 **可比于** 该尺度」 | `0.006667 < U ≤ 0.2` |
| 「本窗基线残差 **大于** 该尺度」 | `U > 0.2` |

### A1.7【更正·范围】成本补项只能叫补充敏感性

原 §5.3 的换手×固定成本率读数**不是**执行成本误差上界: 缺真实宇宙、成交钟、冲击非线性、资金费、链首锚前驱, 且只有两个系数、40 个样本。改称**补充敏感性**, 不得用来补上本预注册 §9.8 明确排除的执行合同。

### A1.8【新增】本测量**不授权**什么(点名)

1. **不授权任何候选晋级。** 基线误差不上界候选误差(A1.6)。要据本装置裁定候选, 必须先核对候选改动的状态是否被装置同码复现, 并测**候选自身**或**候选−基线**的误差。
2. **不授权任何净额(net-P&L)结论。** 度量的是缓存**价格**收益, 不含 funding/carry、不含成本、不含执行钟、不含真实成交。
3. **不授权任何风险实验或风险读数。** 一个小的窗均值不认证停机频率、尾损、最大回撤, 也不认证任何单锚操作。
4. **不外推到其它窗口或其它 regime。** 41 锚 / 8 个 UTC 日块 / 单一 regime。
5. 历史 G-P2 FAIL(0/41 ≤1e-6)、前向 3/3 精确、G2-A「当前 live450 子门过 / 829×40日 原门未过」**继续分别陈述**, 互不注销。
