## 三个研究发现

### 1. Differentiable Spearman 直接优化 rank IC 有效

soft_rank (sigmoid pairwise diff) + Pearson on soft ranks → 1 - spearman_loss. 在 y_1800 上 EMA test S 从 baseline 的 0.039 涨到 0.045 (+15%),且 β 从 0.80 升到 0.94 接近 calibration target。

**机制:** rank loss 直接 push 模型让 σ_ŷ 与 σ_y 量级匹配 (因为 rank 距离要稳定 ranking),自然让 β 收敛到 1。这是个意外的 calibration 副效应。

### 2. σ-anchor learnable α 是 anti-pattern (#13 已加入 CLAUDE.md)

learnable scalar α 是单一 free parameter,**val 调它到一个让 val ranks 对齐的特定值,但 α 不 transfer 到 test**。EMA 平均权重但 α 是同一标量,**没有平滑效果在 α 自己**上。

**普适教训:** 低 SNR + 单一 free scalar = overfitting magnifier。任何 in-graph β scaling 必须用 batch-statistics anchor (e.g. `α = σ_y_running / σ_ŷ_running`),不能 free Parameter。

### 3. "Less is more" — 单一 rank loss > 组合 rank losses

Phase 1.1b 同时用 utility_rank + diff_spearman 双 rank-aware loss → val 0.043 → test 0.026 (drift -0.017)。
Phase 1.1 单用 diff_spearman → val 0.034 → test 0.041 (transparent transfer,test 反高于 val)。

**机制 hypothesis:** 两个 rank loss 提供冗余但相关性≠1 的梯度,模型可以同时 fit 两个的 val noise 但不 transfer。单一 loss 强制模型学到的是单一 rank 信号,泛化更稳。

**普适教训:** 在 noisy regression 上,精心选择 ONE auxiliary loss 比堆叠多个相似 loss 好。

## Pearson 提升路径 (user's key concern)

Phase 1.1 EMA test P=0.036 (+38% vs ema_pool 0.026, +6% vs baseline conv_lasts 0.034)。

**距离 user 目标 P≥0.05 还差 +0.014。** 几个未被 explored 的方向:

1. **更长的 input window** (1200s → 1800s+): 让 backbone 看到 30-min horizon 需要的更长 context
2. **长程 features** (multi-scale vol, OBI persistence): 加 1h/4h scale 的衍生特征 (CPU Ridge gate first per anti-pattern #9)
3. **多 seed ensemble** (Phase 1.1 with seed=7,17): 验证 single-seed lucky?

6. **不同 backbone**: Phase 1.1 test 只在 ema_pool 跑过,可在 conv_lasts/Mamba 上重做 (但 ema_pool 在 Phase 0 已是 winner)

**最优先级 (per Phase 0 finding "DL has real representational value"):** 全 3-fold Phase 1.1 + 长程 features Phase 4。
