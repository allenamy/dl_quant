# RESULT · 多头极端名崩跌风险: 定向条件尾部模型(Phase 0 基率 + Phase 1 分数层门)

## §0 白话结论
1. **崩跌是可以被识别的, 但被识别出来的名并不是"该减的名"。** 在多头极端名队列(fund 腿多头端 ∪ 上锚书的重仓多头, 625,614 行, 2024→26 崩跌事件 657 / 1,613 / 1,301)上, 七族因果特征 + LightGBM 的 4h 崩跌(≤ −10%)模型每折 AUC 0.79 / 0.84 / 0.86, 锚内前 10% 风险名的崩跌率是队列的 2.3× / 4.8× / 5.4×(置换空值 ≈ 1.0)⇒ **S-a 判别门通过(双种子)**。
2. **定向门 S-b 全部不成立(0/3 折, 双种子)。** 前 10% 风险名的条件平均 4h 收益 − 队列均值: 2024 −4.2 [−9.1, +0.5] / −3.2 [−8.2, +1.5] bps, 2025 −0.7 [−10.9, +9.7] / −2.1 [−12.3, +8.2], **2026 +8.4 [−7.8, +25.5] / +15.0 [−0.3, +31.7]**(门要求 ≤ −30 且 CI 上界 < 0)。被标记的名崩得更多, 也涨得更多: 模型学到的是**方差**, 不是方向。这正是预注册写在前面的反假设, 也是既有受据"波动可测但按波动行动亏"的又一次出现。
3. **读法 FAIL ⇒ Phase 2 动作层(预先减仓 / 不新开 / 锚内延续退出)不启动, 实盘不动**; 定向尾部模型与逐名波动上限、对称砍尾族同归 DNR: 在这本书里, 尾部与 alpha 同源, 回吐控制量是杠杆。
4. **有用的副读数**: 队列崩跌基率是宇宙的 1.7×(2026 年 2.5×)而队列均值收益更高(2026 +7.1 vs −0.2 bps); 判别特征以锚内路径(n_big_4h、min_ret5_4h)、队列级泡沫广度(coh_mean_du7、coh_mean_rate_over_cap、n_rn8_ge15)与上市年龄为主; T3(12h ≤ −15%)与 T2(5% 分位回归, 分位损失优于常数 5–21%)给出同样的"判别强、方向无"形态。
5. 装置收据: 命中率 ≥ 0.987; 平移谱前向单调衰减(字面峰位在 −2, 因 F4 族含行 E, 见 §4); shuffle-future 锚内倍数归 1; 折/禁运 = 目标窗长; 单位链脚本打印; fundingInfo 一次拉取标 INFERRED。

## §6 局限
- **F7 持仓量未建**(预注册 1b 只在定向门过后拉取); F2 的 cap 是 09-06 现值(INFERRED 历史代理, 669/829 名), 历史 cap 变动未建模; 1h 结算名(19.7k 格)按其自身间隔的 rn8 处理。
- **S-b 的形式**: 用锚内前 10%(因果横截面切)的条件均值差, UTC 日块 bootstrap; 门阈 −30 bps 相对 2024→26 队列均值(+2.9 / −1.1 / +7.8 bps)是很强的要求, 但任何弱一点的阈也不会翻转 2026 折(点估计 +8 / +15 为正)。
- **AUC 的锚间成分**: pooled AUC 含锚间判别(F6 广度列), 置换空值 0.48–0.68 说明 2024 折的 AUC 有一半来自"哪些锚崩得多"; 锚内倍数(2.3–5.5×, 空值 ≈ 1)是更干净的判别读数, S-a 两项都过, 结论不受影响。
- **平移谱字面峰位在 −2**(见 §4): 因为特征含行 E 与 E−1(锚内路径族), 与 RESULT_trackA 的"+1 bar 时移"约定不同(本预注册允许行 ≤ E); 若要求字面峰在 0, 需把 F4 族右端退一根 bar 重建 — 不影响 S-b 的判决(方向性与对齐无关)。
- **队列定义**依赖回放书 W(M1_UPIT_prod_s42)与 L1 归一(41 名/锚 vs raw 17 名/锚); 用 raw-W 队列会更小但 fund-top15 部分(60% 以上)不变。
- **未做**: 多种子(仅 42/2027); 更长目标窗(24h)与更深阈值(−20%); 队列外(全宇宙)的定向门; 这些都不改变"被标记名条件均值 ≥ 队列"的核心读数, 除非换目标定义。
