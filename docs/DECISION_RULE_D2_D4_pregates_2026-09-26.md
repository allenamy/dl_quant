# 判据:D4(资金费腿失效闸)与 D2(双正交残差)的前置门

作者 lead,对两族去留无利害。两份草案都已把「很可能分辨力不足」写在最前面,所以判据的首要作用是**先证明装置能看见**,再决定要不要看。

## D4(优先;直接对着 G5 的核心事实:资金费腿的价值随时间变号)
- **特征表照 §3 冻结,6 项不删不增。** F3(BTC 7 天收益)与 M3 针对的是同一种方向风险,按草案规定不与 M3 叠加判,一次只改一处。
- **PG-D4-3 分辨力(最先做)**:在 T-b 上种入已知分量,使 fail 标签与 F1 的真实 AUC 为 0.75(H=7)。装置必须在 **pre-2026 段**检出:AUC 对置换 null 的 z ≥ 3。检不出 ⇒ 全族停止。2026 段的检出情况只报告,不作门(按样本算术它本来就看不见)。
- **PG-D4-0 目标有效性**:T-a 与 T-b 的逐年均值在 4 格(2023H2 / 2024 / 2025 / 2026)中至少 3 格同号。不满足 ⇒ 停止(T-b 不代表书层)。
- **PG-D4-1 可预测性**(主地平线 H = 7;H = 30 只作描述):pre-2026 的 OOS AUC(M) ≥ 0.60,且高于置换 null 的 p97.5;2026 的 AUC(M) 点估计 ≥ 0.50,只要求「不反向」。
- **PG-D4-2 增量**:pre-2026 的 AUC(M) − AUC(B0) 周块 bootstrap 95% 下界 > 0;2026 的点估计 > 0。
- **泄漏**:照草案逐元素断言;任何一格不满足 ⇒ VOID。
- **四项都过** ⇒ 放行书层预注册。g、c、λ 由 lead 在任何书层读数之前写定,用 alloc 的席位规则装置,判据沿用组合层族的形状:全窗主判,两段都不得变差。

## D2(次优先;前置门零 GPU,可与 D4 并行)
- **PG-D2-3 分辨力(最先做)**:种入分量的真实 IC 为 0.010。装置须在 pre-2026 与 2026 **两段**都以 95% 下界 > 0 检出,否则停止。
- **PG-D2-0 正交性**:逐锚残差对 KZ、ZFD 的截面相关的最大绝对值 ≤ 1e-10;红控必须非零。
- **PG-D2-1 可学性**:ridge 与 LGBM 至少一种在**两段**都满足截面 IC 的 95% 下界 > 0,且 σŷ/σy ≥ 0.02。
- **PG-D2-2 独立性**:只作描述,照报。
- **GPU 训练臂的放行另加一条**:alloc 的 A3(orth)须先在组合层族里得到非劣轨的 PASS,或者 lead 另行裁定。理由:草案 §0 已测出,在役混合下书层对 D2 无分辨力;只有资金费项拆开之后,D2 的价值才可能显形。在此之前只跑前置门,不开 GPU。
