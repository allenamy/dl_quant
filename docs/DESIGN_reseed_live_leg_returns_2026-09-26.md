**⇒ 实盘正在用一个"已被覆盖、无法溯源"的模型的腿收益,给在役模型配席位。** 而**研究回测的席位用的就是重放 LR**,所以修好之后**实盘会与被验证的回测一致** —— 这是修复的论据,也是它的验收方向。

## 2. 改什么

把 `~/wide_shadow/state/leg_returns_live.json` 里**属于播种的那一段**,替换为 `legs.npz`(`9ee5886f`)的 `LR`,**按时间戳对齐**。三腿同时换(king / rev24 / fund),不单换一腿 —— 单换会造出第四种混合口径。

## 3. ★ 对齐:实盘文件没有时间戳,怎么拼

**这是本设计最容易错的一处,所以写在最前面。**

实盘文件是 `{"king":[950 floats], "rev24":[...], "fund":[...]}` —— **只有位置,没有时间戳**(`shadow_loop_v3.py:427-429`,`n_keep = 900 + 50`)。所以**不能**按时间戳直接写入;必须先把位置**推回**时间戳:

1. **锚定末端**:列表的**最后一个**元素对应**最近一次成功追加**的那个 LR 条目。追加发生在 `shadow_loop_v3.py:752-766`,条件是 `prev["anchor_ts"] == last_anchor and anchor - last_anchor == 14400` ⇒ 它对应的锚是**该次运行的前一个锚**。
2. **可核对的锚点**:`state/snap/<anchor>/leg_returns_live.json` 逐锚快照存在(49 个,09-17T12:00Z 起)。**用相邻两个快照的差**确定每个锚追加了几条(正常 1 条,跳锚则 0 条),从而把位置→时间戳的映射**测出来而不是假设**。
3. **必须断言而非假定**:重建出的映射,其**末端时间戳**必须等于当前 `state/generation.json` / `prev_rec.anchor_ts` 指示的那个锚的前一锚;不等则**停止,不写**。
4. **若映射无法唯一确定**(例如窗口内有跳锚且快照不足以定位),则**不拼接**,改用 §4 的整体重建路径。

**为什么不能只靠"倒数第 k 个 = 当前锚往前 k 个"**:那假设**每个锚都追加了恰好一条**。实测研究侧有 1,086 个锚没有条目;实盘也有跳锚(`open_orders_halted`、整书平仓后的 8–20 小时不再平衡在案)。**把位置当时间戳用,正是这次缺口的同族错误**(实盘文件丢掉时间戳才让播种与重放的混用无人发现)。

## 4. 两条实施路径(交 lead 选)

- **(A) 整体重建(推荐)**:直接用 `legs.npz` 的 `LR`,取**当前锚往前 950 个有条目的锚**,整份覆盖 `leg_returns_live.json`。**不需要**位置→时间戳映射,因为整份都来自带时间戳的源。代价:丢掉实盘自 09-01 起自己累积的 82 条(它们与重放不同口径);但那正是我们要去掉的东西。
- **(B) 只换播种段**:保留实盘 09-01 之后自己累积的部分,只替换更早的 818 条。需要 §3 的映射,风险更高,且会留下**两种口径的拼缝**。

**我推荐 (A)**:口径单一、不需要位置推断、且与"研究回测的席位就是这么算的"完全一致。

## 5. 预期影响(必须在实施前测出来,方案里只给做法)

1. **席位对比**:对 **09-24 起**的每个锚,用新播种按 `shadow_loop_v3.py:784-790` 的公式算出 `w3`,与 `regime_dash.jsonl` 记录的 `w3_raw` 并列;报三腿各自的 Δ 与分布。
2. **组合层影响**:把新席位代入 `combo`(**不跑引擎**),报目标权重的变化 —— `sum|Δw|`、逐名 top-20、gross 变化、以及**有多少名的方向翻转**。
3. **必报的限定**:这只是**席位**的改动;King/F10/资金费特征都不动。

## 6. 回滚

1. 实施前 `cp leg_returns_live.json leg_returns_live.json.pre_reseed_<UTC>` —— 与在案的 `.pre_seatseed_v3_20260905`、`.pre_seatfix_20260904` 同样式;
2. 回滚 = 把备份拷回,**下一锚生效**,无需重启(状态每锚从磁盘读);
3. 回滚后**必须**再跑一次 §5.1 的席位对比,确认 `w3` 回到实盘历史值 —— **"拷回去了"不等于"回到原状态"**;
4. 备份文件**不得**放在 `state/` 之外(那会让快照链丢掉它)。
