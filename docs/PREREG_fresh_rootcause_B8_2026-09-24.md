## 1. 可行性:席位可以重算,**不需要重建 legs**

`fresh_legs.py` L63–69:`w3` 只依赖 **`LR` 的历史**与 `look`:
```
r = stack([LR[leg][-look:] for leg in (king, rev24, fund)])
shp = r.mean(1)/(r.std(1)+1e-9); shp = maximum(shp, 0)
w3 = shp/shp.sum() if shp.sum() > 0 else [1/3,1/3,1/3]
```
