Research Brief · 2026-09-02

Wide-Book Crypto Strategy：下一阶段潜在 Edge

给研究团队的简版建议：按“对 NAV 的真实杠杆”排序，而不是按技术新颖度排序。

核心判断：当前最值得研究的，不是再换一个更强的 4h return predictor。现有证据显示模型腿席位有限、模型结构/训练目标多轮改造未转化为书层净额。下一阶段应重点研究：funding→price 映射的跨 regime 自适应、执行智能、市场状态建模、动态有效广度。

1. 优先级最高的四条研究线

P0

Fund Mapping Meta-Learning

问题：Funding 是独立的杠杆资金状态量，但历史上会从 reversal 翻成 continuation。

建议：借鉴 FinPFN / in-context adaptation，让模型根据最近一段 funding state → realized return 映射判断当前 regime，而不是学习永久固定规则。

  • 输入先保持经济可解释：fund EMA、shock、OI、basis、σfund、rank persistence、tail share。
  • 第一阶段只做 shadow/dashboard，不直接改 production。
  • 成功标准：能跨 2021→2026 捕捉符号变化，且书层扣成本后优于固定 mapping。
P0

Execution Intelligence

问题：未来资金扩大后，容量瓶颈更可能来自 maker fill、逆向选择、机会成本和大单 markout。

路线：监督学习 → contextual bandit → world-model + RL。

  • Fill survival：预测 1/5/20min 成交概率。
  • 联合预测 implementation shortfall / missed alpha。
  • 根据状态选择 shallow/deep、timeout、chase/no-chase。
  • 现有随机化 placement/chase 数据非常适合因果化学习。
P1

Market-State / World Model

问题：2027 最大未知量是市场状态如何演化，而不是单币 4h 收益。

建议：预测 p(S[t+1:t+H] | S≤t)，状态包括 σfund、eligible N、短周期 funding 占比、rank persistence、carry concentration、OI/basis/liquidation、sleeve PnL。

TimesFM-3 / Chronos / 小型 SSM-Mamba 可作为 benchmark，优先做概率/分位数输出。

P1

Dynamic Effective Breadth / Graph

问题：250 个持仓不等于 250 个独立 bet，有效 breadth 可能在 nominal breadth 不变时骤降。

建议：构建动态 cross-asset graph / cluster，重点输出 N_effective、cluster concentration、crowding exposure，而不是优先用 GNN 预测 return。

2. TimesFM-3 / 时序大模型怎么用

不建议：直接 zero-shot 预测 450 个币未来 4h return，再替换 King/V2。时序 forecasting objective 与横截面排序目标并不一致，金融 return 本身也低信噪比。

更合理：把 TS foundation model 当成多变量状态表征器 / probabilistic regime forecaster：funding、OI、basis、vol、liquidity、breadth 历史 → state embedding / future state quantiles → FundMap context 或 dashboard。

3. RL / 世界模型的正确落点

场景判断原因
Regime 自动切 Fund/King 权重暂不推荐真正独立的 regime transition 样本太少，容易过拟合。
Execution contextual bandit推荐订单样本多、reward 快、已有随机实验。
World-model + RL execution中长期推荐当需要连续挂单→撤单→重挂→追单时，MDP 才真正成立。
LOB generative simulator有潜力用于 counterfactual execution：回答“如果当时换一个动作会怎样”。

4. 建议研究顺序

  1. P0 FundMap in-context / meta-learning shadow。
  2. P0 Execution：Fill Survival → Conditional Shortfall → Contextual Bandit。
  3. P1 Regime Dashboard 升级为 probabilistic state forecast；TimesFM-3 仅作为 benchmark 之一。
  4. P1 Dynamic effective breadth / graph risk。
  5. P2 只有前述方向出现稳定证据后，再考虑小型 crypto-domain pretraining / execution world model。

5. 研究纪律

  • 问题优先于模型：每个实验先说明解决哪个已验证瓶颈。
  • Prediction ≠ Action：IC/regime 诊断有效，不等于改仓有效；先 shadow，再书层，再 forward。
  • 统一按净额判：alpha、carry、换手、执行成本、尾部风险一起算。
  • 复杂模型必须击败简单 baseline：EMA / VAR / LightGBM / small SSM 没输之前，不需要 foundation model。
  • 暂不做 architecture zoo：当前模型腿结构/目标轴已多轮 DNR；除非出现新的经济假设或模型腿席位明显上升。

一句话：下一阶段不是寻找“更强预测模型”，而是让系统更早知道 funding 的含义是否正在改变、更聪明地把 alpha 执行出来，并实时知道 250 个仓位究竟还剩多少真正独立的 bets。
